# 02 内容资产与题材市场

商业化的本质是**把内容资产拆分、定价、复用**。做不出资产台账，后续所有授权、周边、联名都会落空。

## 1. 可商业化资产台账

逐项登记，不要只写"这个 IP 很好"。

| 资产类型 | 具体内容 | 识别度 | 可复用性 | 权利状态 | 开发难度 | 优先级 |
|---|---|---|---|---|---|---|
| 核心角色 | 主角、反派、人气配角 | 高/中/低 | 高/中/低 | 自有/共有/待确认 | 低/中/高 | A/B/C |
| 角色群像 | 组合关系、阵营 | | | | | |
| 视觉符号 | 标识、纹样、道具、配色、口头禅 | | | | | |
| 世界观 | 地理、规则、组织、术语体系 | | | | | |
| 名场面 | 可截图、可复述、可二创的名镜头 | | | | | |
| 情绪母题 | 一句话能说清的情感内核 | | | | | |
| 作者人格 | 创作者人设、创作方法、幕后故事 | | | | | |
| 声音资产 | 配音、主题曲、音效记忆点 | | | | | |

**识别度判断标准**：给一个没看过的人看 3 秒图 / 听一句话，能否复述出特征。不能，则不算资产。

## 2. 角色商业化五问

一个角色能否被单独拿去做商品、联名、代言，先过这五问：

1. **一句话能不能说清他是谁？**（说清 = 性格 + 欲望 + 特征）
2. **有没有视觉记忆点？**（一个可被画成贴纸的符号）
3. **有没有情绪投射？**（用户把自己或理想自我放在他身上）
4. **能不能脱离主线独立存在？**（单独出周边、番外仍有意义）
5. **有没有可延展的场景？**（日常、节日、职业、联名场景）

五问中 ≥4 个"是" → A 级角色（可做核心授权资产）；2–3 个 → B 级（可做配套商品）；≤1 个 → C 级（仅内容使用）。

## 3. 资产分级

| 级别 | 定义 | 允许的开发方式 |
|---|---|---|
| A 核心资产 | 高识别 + 高复用 + 权利清晰 | 主授权标的、联名主形象、系列商品、跨媒介主角 |
| B 次级资产 | 单项强、另一项弱 | 配角周边、场景类商品、活动物料、限定联名 |
| C 储备资产 | 无独立识别度 | 仅内容内使用，不单独对外授权 |

分级必须给理由。把所有角色都定为 A 级，等于没有分级。

## 4. 题材市场判断

不预测"会不会爆"，只判断四件事：

| 维度 | 判断问题 | 判断依据 |
|---|---|---|
| 容量 | 这个题材有稳定受众盘吗 | 平台同题材在榜数量与更新量（E2，需标时间） |
| 竞争密度 | 头部是否被少数作品锁死 | 榜单集中度、新作进榜难度 |
| 付费习惯 | 该题材用户是否已养成付费 | 平台该题材付费/会员/单点情况 |
| 渠道偏好 | 该题材在哪类渠道更容易起量 | 各平台同类作品的表现结构 |
| 尺度风险 | 题材是否存在审核与下架风险 | 平台规则、近期同类下架案例 |

结论必须写成：`该题材在【渠道】具备【容量判断】，竞品集中度【高/中/低】，本项目差异化依赖【变量】，主要风险【x】`。

## 5. 内容形态适配矩阵

同一 IP 换形态，有的变强，有的变弱。逐格判断：**强 / 平 / 弱 / 不可行**。

| 形态 | 需要的前提 | 常见减分项 |
|---|---|---|
| 小说 / 网文 | 文字张力、叙事密度、更新产能 | 依赖视觉的设定难以传达 |
| 短剧 | 强冲突、快节奏、可拍摄场景、低成本演员需求 | 世界观过大、特效依赖高 |
| 动态漫 | 分镜感、角色颜值、单元结构 | 动作复杂、场景切换频繁 |
| 漫画 | 画力稳定、分镜与产能 | 长线更新成本高 |
| 动画 | 世界观可视化、动作戏、制作预算 | 单集成本高、回本周期长 |
| 影视 | 可改编的强情节、可控制作规模 | 审查、投资体量 |
| 游戏 | 规则化世界、可玩法化的能力体系 | 开发成本、玩法与叙事耦合难 |
| 音频剧 | 声音辨识、对话驱动 | 高视觉依赖 |
| 实体商品 | 视觉符号、角色偏好、供应链 | 无形象则不可行 |

矩阵结论只用于**排序**，不用于"全都要"。

## 6. 输出格式

```
1. 资产台账（表）
2. A/B/C 分级结论 + 理由
3. 可开发资产 Top3（附开发方式与前置条件）
4. 题材市场判断（容量/竞争/付费/渠道/尺度，各注证据等级）
5. 形态适配矩阵 + 优先级排序（首选 / 次选 / 暂不做）
6. 资产缺口清单（缺什么才能支撑下一步变现）
```

## 7. 禁止项

- 不得在无视觉资产时规划周边与形象授权。
- 不得在权利未厘清时把角色列为 A 级授权标的。
- 不得把"设定很多"等同于"资产很多"。
- 不得用未标注来源的榜单排名当作市场结论。
