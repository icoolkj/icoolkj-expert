# 05 场景与正文技法

## 1. 场景的定义

场景 = 某个时间、某个地点、某些人，为某件事争夺，得到一个结果。

四要素缺一不可：

| 要素 | 检验问句 |
|---|---|
| 时间 | 此刻是一天中的什么时候？距上一场多久？ |
| 地点 | 具体到可看见的东西（不是"城里"，是"桥洞下的第三个墩"） |
| 争夺 | 这场里谁想从谁那里拿到什么？ |
| 结果 | 结束时谁拿到了？代价是什么？ |

## 2. 进场与退场

**进场直接**：跳过抵达。第一句就落在有动作的地方。

| 拖沓 | 干脆 |
|---|---|
| 苏瑾从客栈出来，沿着长街往南走，街上人不多…… | 桥头有人等她。 |
| 他推开门，走进房间，房间里很暗，他摸到灯…… | 灯亮的时候，他已经站在她身后了。 |

**退场干脆**：结果一出现就走，不要额外总结。删除"他知道，从今往后……"这类句子。

**场景转换**：用空行或分隔符直接切，不写"与此同时""另一边"。读者能自己接上。

## 3. 五种描写的配比

| 类型 | 作用 | 别超过 |
|---|---|---|
| 动作 | 推进、显示性格 | 无上限，越多越好 |
| 对话 | 冲突、信息、关系 | 单段对话不超过 8 句不加动作 |
| 心理 | 只写主角（限知） | 每次不超过 2–3 句 |
| 环境 | 定调、压迫、暗示 | 一次不超过 3 句，且必须有用 |
| 细节 | 记忆点、暗示 | 每场 1–2 个精准的，不是一堆 |

**环境必须干活**。写雨不是因为有氛围，而是因为雨让脚印消失／让火把灭了／让伤口疼。

## 4. 对话写作

### 4.1 三条铁律

1. **人不直说**。想求人的人先骂两句；想告白的人先问天气。
2. **人有口头习惯**。句长、用词层级、是否用敬语、是否打断别人、回避什么话题。
3. **对话要有信息差**。A 知道 B 不知道的，或双方都以为对方不知道。

### 4.2 潜台词

| 直给 | 有潜台词 |
|---|---|
| "我很担心你。" | "你鞋上哪来的泥。" |
| "我恨你。" | "你坐吧。我给你倒杯水。" |
| "别走。" | "外面下雨了。" |

### 4.3 对话的功能检查

一段对话删掉后：
- 剧情受影响？→ 必要。
- 人物关系受影响？→ 必要。
- 都不受影响 → 是废话，删。

### 4.4 常见病

| 病 | 症状 | 修法 |
|---|---|---|
| 信息倾倒 | "你知道的，我们家族三百年前……" | 拆成三次，各说一半，且都带情绪 |
| 千人一腔 | 遮住名字分不出谁 | 给每人一个语言标记（见 `06`） |
| 复读机 | A 说一句，B 重复一遍再回答 | 让 B 直接回答后半句 |
| 播音腔 | 吵架时说话完整有逻辑 | 打碎句子，加打断、加答非所问 |
| 旁白混入 | 角色说出自己不该知道的设定 | 只给角色能知道的信息 |

## 5. 心理描写

限知视角下，心理是主角的特权。写法按距离分三档：

| 距离 | 写法 | 例 |
|---|---|---|
| 远 | 只写行为 | 他把杯子放回原位，摆正。 |
| 中 | 行为 + 一句推断 | 他把杯子摆正。她走的时候没摆正过。 |
| 近 | 直接写念头（简短） | 摆正了。像她还在。他忽然想砸了它。 |

**规矩**：一章内不要长时间停在"近"。停在近处太久，节奏会粘。写完一段内心立刻给一个外部动作打断它。

## 6. 打斗与追逐

### 6.1 打斗三条

1. **写意图，不写招式名**。读者关心"他想干什么、为什么没干成"。
2. **一次只写一个决定性动作**。混战写结果与感受，不写逐招。
3. **必须有人性代价**：喘、疼、怕、犹豫、误判。

不合格：

> 他一记"天山折梅手"击出，对方以"金刚不坏体"硬接，双方各退三步。

合格：

> 他先动手，因为再等一秒手就会抖。拳头落在对方肩上，像打在石头上。对方没退，他自己退了一步。

### 6.2 大场面（战争、群战）

用**一个具体的人的眼睛**看。不写"两军交战死伤惨重"，写某个士兵找他的鞋。

## 7. 情绪场景

情绪不能靠形容词，要靠**具体的错位**：

| 情绪 | 可写的具体物 |
|---|---|
| 悲 | 多摆了一副碗筷；忘了买一个人的份 |
| 恐惧 | 反复确认门锁；听见自己的呼吸太响 |
| 愤怒 | 手在抖，于是去擦一个已经很干净的杯子 |
| 羞愧 | 说话时看着对方的鞋 |
| 释然 | 把那件一直带着的东西放下了 |

**哭的写法**：写他忍的过程，比写他哭更有力。真要哭，写一个不体面的细节（鼻涕、打嗝、妆花了）。

## 8. 段落与句子节奏

- 紧张处：短句、短段、多句号、少形容词。
- 舒缓处：长句、复合句、可有一处环境。
- 动作连续时：把三个动作压进一句，用逗号连接。
- 转折处：单独成段，一句话。

示例（紧张）：

> 门开了。
>
> 他没动。

示例（舒缓）：

> 雨停了有一阵，屋檐上还挂着水，偶尔落一滴在石阶上，声音很轻，像有人在很远的地方数着。

## 9. 烂句清单与改法

| 烂句 | 问题 | 改法 |
|---|---|---|
| 他心中五味杂陈 | 抽象 | 写一个具体动作 |
| 一股强大的气息扑面而来 | 空洞 | 写旁人反应或物件变化 |
| 时间仿佛静止了 | 陈词 | 删，或写一个具体的慢动作 |
| 他知道，一切都结束了 | 总结 | 删，让场景自己结束 |
| 她的眼中闪过一丝复杂的神色 | 套话 | 写她做了什么 |
| 不得不说，这确实很厉害 | 旁白 | 让对手用行动承认 |
| 不知过了多久 | 偷懒 | 给一个时间锚（灯烧了一半） |
| 空气仿佛凝固了 | 陈词 | 写声音消失（谁都不说话，只有筷子碰到碗） |

## 10. 正文交付前的最后一遍

只做四件事，不改内容：

1. 删掉第一个自然段（80% 的情况下开场太慢）。
2. 删掉所有"他知道／她明白／这意味着"开头的句子。
3. 找出重复出现的词，换掉一半。
4. 朗读一遍：读着别扭的地方，句子一定有问题。
