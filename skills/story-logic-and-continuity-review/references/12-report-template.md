# 12 审校报告模板（M12）

## 1. 报告结构

```
一、项目与版本信息
二、审校范围与资料清单
三、已确认事实基准
四、审校维度与方法
五、问题总览（统计表）
六、严重问题详情（P0 / P1）
七、一般问题详情（P2 / P3 / P4）
八、潜在风险（证据不足项）
九、待作者确认事项
十、修复建议汇总与优先级
十一、影响范围总表
十二、复审要求与结论
附录：事实基准表 / 时间线表 / 认知台账 / 伏笔台账（按需）
```

---

## 2. 各章节写法规范

### 一、项目与版本信息

| 项 | 内容 |
|---|---|
| 项目名称 | |
| 内容类型 | 长篇小说 / 短剧剧本 / 分镜 / 多媒介 |
| 审校版本 | 文件名 + 版本号 + 日期 |
| 审校日期 | |
| 审校模式 | A 快速 / B 全面 / C 专项 / D 跨媒介 / E 复审 |
| 审校人 | |

### 二、审校范围与资料清单

必须写清**审了什么**和**没审什么**：

- 已覆盖：章节/集数/页码范围（精确）
- 未覆盖：明确列出，并说明原因（未提供 / 超时 / 不在本次范围）
- 资料清单：逐份列出文件名、版本、用途（作为基准 / 作为被审对象）

> 强制要求：不得声称检查过未提供的文件。范围外内容如需引用，标注"据作者口述"或"未核验"。

### 三、已确认事实基准

只列本次审校实际用到的事实，按主体分组。格式：

| 事实 ID | 主体 | 属性 | 取值 | 位置 | 证据等级 |
|---|---|---|---|---|---|

并在末尾说明：本次基准共 N 条，其中 CONFIRMED x 条、TEXTUAL y 条、INFERRED z 条。INFERRED 项不作为判定 P1 的唯一依据。

### 四、审校维度与方法

列出执行的模块（M01–M10），未执行的模块说明原因。简述方法（如"采用状态快照法逐场比对"）。

### 五、问题总览

**统计表：**

| 等级 | 数量 | 占比 |
|---|---|---|
| P0 | | |
| P1 | | |
| P2 | | |
| P3 | | |
| P4 | | |
| 合计 | | |

**分布表（按模块）：**

| 模块 | P0 | P1 | P2 | P3 | P4 |
|---|---|---|---|---|---|

**问题索引表：**

| 编号 | 标题 | 等级 | 模块 | 位置 | 状态 |
|---|---|---|---|---|---|

### 六、严重问题详情（P0/P1）
逐条使用第 8 节的标准问题结构。**必须完整**，不得省略任何字段。

### 七、一般问题详情（P2/P3/P4）
P2 用完整结构；P3/P4 可用精简结构：

```
- 编号 / 标题 / 等级 / 位置
- 问题（1–2 句）
- 建议（1 句）
```

### 八、潜在风险
证据不足但值得提醒的项。每条必须写：
- 疑点内容
- 为何证据不足
- 若成立会影响什么
- 建议作者确认的问题（一句话，可直接回答）

### 九、待作者确认事项
以**问句**列出，每条可独立回答，不与问题编号混淆：

```
Q1. 第 9 章主角"不知道仓库位置"是否为有意设定？（影响 LOGIC-003 的定级）
Q2. 沈砚的年龄以小说（27）还是剧本（25）为准？（影响 MEDIA-004）
```

### 十、修复建议汇总
按优先级排序，给出批次建议：

- **第一批（必须）**：全部 P0 + P1，附方案 A/B。
- **第二批（建议）**：P2 中影响主线者。
- **第三批（可选）**：P3/P4。

每条只写"编号 + 推荐方案 + 改动量"，详情见正文。

### 十一、影响范围总表

| 问题 ID | 源头位置 | 派生位置数 | 受影响章节 | 需同步文件 |
|---|---|---|---|---|

### 十二、复审要求与结论

- 复审需检查的具体项（逐条）
- 复审结论（本次为初次审校则写"待复审"）
- 可信度声明

## 3. 可信度声明模板

报告末尾必须附，按实际情况选择：

**资料完整时：**
> 本次审校覆盖 [范围]，基于 [N] 份资料（版本见第二节）。结论适用于该范围，范围外内容未核验。

**资料不完整时：**
> 本次审校仅基于 [已提供资料]，缺少 [世界观设定/人物档案/前序章节] 等资料，
> 因此 [M03 世界观规则 / M09 跨媒介] 维度的结论可信度有限，
> 相关问题已标注为"待确认"而非确定错误。建议补齐资料后复审。

**仅抽样时：**
> 本次为抽样审校，覆盖 [列举]，未覆盖部分不代表无问题。
> 抽样方法：[说明]。

---

## 4. 报告写作要求

1. **每条问题独立可读**：不依赖上下文也能看懂。
2. **引用原文**：不改写、不概括关键限定词。
3. **不夹带评价**：写"与第5章冲突"，不写"作者显然疏忽了"。
4. **方案不越界**：给方案不给成品段落。
5. **等级不通胀**：严格遵守 `10-severity-and-false-positive.md`。
6. **不虚构**：未读的不写，未核的不判。
7. **长度可控**：P3/P4 精简，P0/P1 详尽。

## 5. 精简版报告（模式 A 快速审校用）

```

## 覆盖范围
已审：<章节>  未审：<章节>

## 问题清单
| 编号 | 等级 | 位置 | 问题 | 建议 |
|---|---|---|---|---|

## 需要你确认
1. ...

## 说明
本次仅检查明显逻辑错误与前后衔接，未做全面审校；人物动机、伏笔、跨媒介
等维度未展开。
```

## 6. 复审报告模板（模式 E）

```
# 复审报告：<作品> <版本>

## 一、复审依据
原报告：<文件名/日期>  修改稿：<版本>  修改说明：有/无

## 二、逐条核对结果
| 编号 | 原等级 | 结果 | 说明 |
|---|---|---|---|
| TIME-001 | P1 | 已解决 | 第13章已改为第五日，第14、16章同步调整 |
| KNOW-003 | P1 | 部分解决 | 第18章已加推理依据，但第22章仍有"你早知道"式表述 |

统计：已解决 x / 部分解决 y / 未解决 z / 转化为新问题 w

## 三、新增问题
（用标准结构，编号沿用原台账继续递增）

## 四、回归检查
- 事实连锁：无 / 有（列出）
- 动机连锁：无 / 有
- 情感连锁：无 / 有
- 需同步更新文件：<列出>

## 五、复审结论
通过 / 有条件通过 / 需再修 / 不通过
理由：...

## 六、遗留事项
...
```
