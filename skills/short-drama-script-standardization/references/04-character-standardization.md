# 04 人物标准化与称谓映射

人物混乱是短剧剧本最常见、最影响制作的问题，也是本 Skill 最能体现价值的环节。

## 4.1 人物标准名

一个角色在标准剧本中只能有一个"标准名"，用于人物行与对白署名。

规则：

- 优先取原稿中**首次出场的完整姓名**作为标准名。
- 全名不明时取原稿最常用称呼，并在人物表标注"身份待确认"。
- 未具名角色保留描述性称呼：`黑衣人`、`护士甲`、`司机`。
- 群体角色用 `群演1`、`群演2` 或 `宾客若干`，不与主要角色混编。
- 标准名不得含标点、括号、职务（`苏总` 不是标准名，`苏瑾` 才是）。

## 4.2 别名与称谓映射表

必备字段：

| 标准名 | 别名/称谓 | 使用者关系 | 使用场次 | 备注 |
| --- | --- | --- | --- | --- |
| 苏瑾 | 苏总、瑾姐、小瑾 | 下属、弟弟、母亲 | 1-1、2-3、5-7 | "苏总"仅职场场合 |
| 陈默 | 阿默、陈师傅 | 苏瑾、客户 | 1-1、3-2 | |

使用要点：

1. 对白**署名**用标准名；对白**内容**里的称呼保持原样（人物怎么叫是人物关系的一部分）。
2. 同一人物在不同人称谓不同，属于正常，不视为不统一；只有**署名**混乱才需要修。
3. 同一称谓被两个人物使用（两个"苏总"）时，必须在人物行区分：`苏瑾、苏明远`，禁止都写 `苏总`。

## 4.3 署名错误的识别

以下情形判定为署名不统一（P1）：

- 同一场中 `苏瑾：` 与 `苏总：` 交替出现，且指向同一人。
- 人物行写 `苏瑾`，对白署名写 `小瑾`。
- 全名与昵称混用于署名：`陈默：` / `阿默：` / `默哥：`。
- 拼音缩写或代号署名：`SJ：`、`男1：`（原稿若为编号人物，如 `男1/女2`，保留但需在人物表映射到身份）。

## 4.4 人物首次出场

首次出场必须让读者知道：**这个人是谁、和谁有关系、为什么在这里**。

检查项：

- 首次出现的角色是否有可识别的姓名或稳定称呼。
- 是否在本场或前场有身份提示（动作、他人称呼、标注）。
- 是否在人物行中列出。

不符合时：不补写介绍，在首次出场处标 `【待确认：身份】`，并列入待确认清单。

## 4.5 人物关系与身份的边界

可以做的：统一名称、补全映射表、标注缺失信息、指出矛盾。

不可以做的：

- 推断"两个人是同一个人"并合并。
- 给角色补姓氏、补职务、补年龄。
- 调整人物关系（如把"前男友"改成"哥哥"）。
- 删除"多余"角色。

关系矛盾（A 场称母亲、B 场称继母）属 C 类内容问题，只报告。

## 4.6 人物表字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 标准名 | 是 | 用于署名 |
| 别名/称谓 | 否 | 全部列出 |
| 身份 | 是 | 原稿可确定的部分，不确定写"待确认" |
| 性别/年龄段 | 否 | 仅原稿明确时填写 |
| 首次出场 | 是 | 场号 |
| 出场场次 | 是 | 全量列举 |
| 对白条数 | 否 | 用于判断角色权重 |
| 关系 | 否 | 只写原稿明确的关系 |
| 备注 | 否 | 待确认项、疑似重复角色 |

## 4.7 待确认清单写法

格式：`编号 | 位置 | 事项 | 可选解释 | 建议`

示例：

```
Q01 | 2-4 人物行 | "小瑾"与"苏瑾"是否同一人 | A 同一人（昵称） / B 苏瑾的妹妹 | 建议按 A 统一署名，请确认
Q02 | 5-1 | "老周"身份未交代 | A 苏家司机 / B 陈默的合伙人 | 需作者确认
```

禁止写"暂无待确认事项"来回避真实缺口。

## 4.8 人物一致性抽检方法

1. 全稿提取所有对白署名，去重成集合。
2. 与人物表标准名对表，差集即"未登记署名"。
3. 对差集逐一判断：别名（补映射）／署名错误（修正）／新角色（补登记）。
4. 对标准名做相似度比对（如"苏瑾/苏谨/苏锦"），相似度高的列入疑似同一人，人工确认。
5. 统计每个人物出场场次，检查"出场一次即消失"的角色是否原稿如此。

`scripts/script_lint.py` 会自动完成 1、2、4 步的初筛。

## 4.9 群体与非人物声音

| 类型 | 署名写法 | 说明 |
| --- | --- | --- |
| 群体 | `众人：`、`宾客（议论）：` | 不拆分到个人 |
| 电话另一端 | `陈默（电话）：` 或 `电话里的陈默：` | 项目内统一一种 |
| 广播/电视 | `【广播：…】` 或 `播音员（画外）：` | 优先用标注 |
| 系统/AI 语音 | `导航（机械音）：` | 保留原稿风格 |
| 动物/非人 | `【音效：狗吠】` | 不作对白 |

## 4.10 人物标准化施工顺序

1. 抽全量署名 → 建原始署名清单。
2. 建别名映射 → 定标准名。
3. 回填人物行（按 `03-scene-structure.md`）。
4. 统一署名（只改署名，不改台词内容）。
5. 建人物表、出场表。
6. 输出待确认清单。
7. 每步记入修改记录（批量替换可合并为一条，注明影响场次数）。
