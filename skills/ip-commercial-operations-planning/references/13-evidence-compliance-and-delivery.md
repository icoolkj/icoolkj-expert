# 13 证据体系、合规与交付规范

最终输出前必读。本文件决定"这份方案能不能交给别人看"。

## 1. 证据分级

| 级别 | 定义 | 例子 | 允许的表达 |
|---|---|---|---|
| E1 | 真实项目数据 | 后台截图、销售流水、合同、财报、真实问卷 | "实测……" |
| E2 | 可靠外部证据 | 行业报告、平台公开规则、上市公司公告、竞品公开数据 | "据【来源】（【时间】）……" |
| E3 | 项目内部观察 | 创作者经验、用户访谈、试运营反馈 | "观察到……（样本 n，非随机）" |
| E4 | 策略假设 | 模型推演、类比、预测 | "假设……；若成立，则……" |

标注写法：

```
用户规模：约 2.4 万关注（E1，平台后台，2026-10-31）
短剧付费转化：行业常见区间 3%–8%（E4，类比推算，待核实）
平台分账单价：待核实（E2 待补，规则可能已调整）
```

**禁止**：把 E4 写成陈述句；用"行业普遍认为"代替来源；用精确小数包装猜测。

## 2. 状态标记

| 标记 | 含义 |
|---|---|
| `[已确认]` | 用户明确确认 |
| `[用户设想]` | 用户提出，未最终确认 |
| `[专家建议]` | 本 Skill 的观点 |
| `[待确认]` | 需用户决策 |
| `[待验证]` | 需市场/数据/测试支持 |
| `[权利待确认]` | 版权与授权相关 |

## 3. 完整商业策划书结构（20 章）

| # | 章节 | 必备内容 | 可裁剪条件 |
|---|---|---|---|
| 1 | 项目摘要 | 一页说清：是什么、给谁、怎么赚、要什么 | 不可省 |
| 2 | IP 项目介绍 | 类型、题材、内容量、阶段 | 不可省 |
| 3 | 核心内容与资产 | 资产台账、A/B/C 分级 | 不可省 |
| 4 | 市场环境分析 | 三层市场判断（内容/注意力/消费） | 内部决策可简 |
| 5 | 竞品分析 | 3–5 个拆解 + 差异化陈述 | 不可省 |
| 6 | 目标用户定位 | 三层用户 + 画像 + 付费动机 | 不可省 |
| 7 | 品牌定位与差异化 | 一句话定位、主张、关键词、介绍文案 | 不可省 |
| 8 | 商业模式设计 | 三档排序 + 准入条件 | 不可省 |
| 9 | 内容发行策略 | 主辅渠道 + 节奏 + 改造方案 | 单渠道项目可简 |
| 10 | 营销推广计划 | 矩阵 + 日历 + 预算 | 可简为要点 |
| 11 | 用户运营体系 | 分层 + 社群机制 + 权益 | 可简 |
| 12 | 授权与衍生开发 | 权利盘点 + 授权九要素 + 优先级 | P0–P2 可标"暂缓" |
| 13 | 商务合作计划 | 对象画像 + 模式 + 提案要点 | 可简 |
| 14 | 团队与资源需求 | 岗位、外包、缺口 | 不可省（常被忽略） |
| 15 | 投资预算 | 成本表 + 口径 | 不可省 |
| 16 | 收益预测 | 三情景 + 单位经济 + 敏感性 | 不可省 |
| 17 | 风险评估 | 内容/市场/权利/运营/财务 | 不可省 |
| 18 | 实施路线图 | 30 天 / 90 天 / 12 个月 | 不可省 |
| 19 | 阶段性目标 | 每阶段 1–3 个可验证目标 + 止损线 | 不可省 |
| 20 | 项目总结 | 三句话：优势、最大风险、需要的决策 | 不可省 |

裁剪原则：可以合并章节，不可以"有标题没内容"，也不可以为凑结构编内容。

## 4. 各模式交付清单

| 模式 | 必交内容 | 篇幅参考 |
|---|---|---|
| A 诊断 | 诊断简报（九段式） | 1000–2000 字 |
| B 完整方案 | 20 章裁剪版 + 路线图 | 5000–12000 字 |
| C 市场竞品 | 拆解表 + 差异化 + 壁垒判断 | 1500–3000 字 |
| D 品牌定位 | 定位/主张/关键词/三版介绍/口号 | 1200–2500 字 |
| E 商业化设计 | 模式三档 + 授权方案 + 单位经济 | 2500–5000 字 |
| F 营销运营 | 矩阵 + 日历 + 社群机制 + 指标 | 2000–4000 字 |
| G 商业计划书 | 20 章 + 财务附件 | 6000–15000 字 |
| H 数据复盘 | 复盘报告八段式 | 1500–3000 字 |

## 5. 表达规范

| 项 | 要求 |
|---|---|
| 结论位置 | 每节开头先给结论，再给依据 |
| 数字 | 统一单位，标明口径；预测不给小数 |
| 术语 | 首次出现给一句解释（面向非专业合作方） |
| 表格 | 能表格化的不写长段 |
| 引用 | 外部数据标来源与时间 |
| 长度 | 一页一个核心判断，不堆砌 |

## 6. 合规红线

| 领域 | 禁止 |
|---|---|
| 广告宣传 | 绝对化用语（第一、最、唯一、顶级）；虚假或无法验证的效果承诺 |
| 收益承诺 | 保证收益、保本、稳赚、必爆、必上推荐位 |
| 数据 | 编造数据、伪造截图、刷量买粉、虚构案例 |
| 合作 | 虚构合作方、虚构意向、虚构已签约 |
| 版权 | 未经授权使用他人作品、形象、音乐、字体；默认用户拥有全部权利 |
| 商标 | 建议使用可能侵权的名称而不提示 |
| 未成年人 | 涉及未成年人的商业设计与内容不做擦边、不做诱导消费 |
| 隐私 | 收集用户信息不说明用途；公开他人个人信息 |
| 金融 | 不设计未经许可的类金融、众筹、预付卡方案而不提示合规风险 |
| 特殊品类 | 食品、化妆品、医疗器械、出版物等需资质，不绕过 |

## 7. 发布前质量检查

逐项打勾，任一项不过则修正后再交付：

- [ ] 阶段判定有依据，方案与阶段匹配。
- [ ] 每个关键判断有证据等级标注。
- [ ] 无未标注的 E4 数字；无精确到小数点的猜测。
- [ ] 无收益承诺、无绝对化用语、无虚构合作。
- [ ] 差异化陈述能写成一句话，且含"代价"。
- [ ] 商业模式有三档排序，"暂不做"有理由。
- [ ] 每条商业机会有验证卡（方式、成本、周期、成功标准、止损）。
- [ ] 财务有三情景区间、口径说明、敏感性分析。
- [ ] 权利问题被单独列出，未越权给授权报价。
- [ ] 路线图有 30/90/365 天节点与责任方。
- [ ] 有明确的待确认事项清单（决策点，不是开放问题）。
- [ ] 交付物能被非专业读者读懂第一页。

## 8. 交付时的固定结尾

每次正式方案结尾附：

```
本方案的判断依据与不确定性：
- 已实测（E1）：__
- 外部证据（E2）：__
- 内部观察（E3）：__
- 关键假设（E4）：__
需您确认的决策点：
1. __
2. __
3. __
建议的下一步（7 天内可完成）：__
```

这一段是方案可信度的来源，不得省略。
