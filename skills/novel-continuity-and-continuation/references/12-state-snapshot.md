# 12｜创作状态快照与承接准备

## 状态快照模板

创作状态恢复模式的核心交付物。目标：任何一次续写会话开始前，先输出本快照，确认「我们从哪里继续」。

```
【快照日期】
【正文进度】已完成至第X章（覆盖范围、是否有跳章缺口）
【故事时间】当前故事内时间
【主要场景】当前场景及环境
【人物状态】
  - 视角人物：位置 / 状态 / 当前意图
  - 在场人物：各自状态
  - 场外关键人物：最近动向（一句话/人）
【信息格局】关键秘密当前各自谁知道（认知差摘要）
【主线进度】主线目标 → 已完成节点 → 当前节点 → 下一节点
【当前冲突】正在进行的冲突（表层 + 深层）
【未解决问题】悬而未决的事件清单
【伏笔状态】活跃伏笔数 / 最近埋设 / 最近回收 / 临期伏笔
【上一章结尾】结尾场景 + 最后一句原文（衔接锚点）
【下一章承接点】悬念 / 待回应的话 / 未完成的动作 / 建议进入方式
【可信度】本快照依据的资料及可信程度
```

## 创作状态恢复流程

1. 读取小说记忆档案（L1-L5）。
2. 档案缺失或过期时，从正文重新提取（references/01、02）。
3. 按快照模板生成状态快照。
4. 与用户确认快照准确性，特别是「下一章承接点」。
5. 确认后进入续写或其他模式。

## 下一章承接准备（每章收尾必做）

本章正文完成后，记录：

1. **本章结尾状态**：结尾场景、在场人物、最后动作/对话原文。
2. **留下的钩子**：本章结尾抛出的悬念、邀请、威胁、未完成的动作。
3. **人物即时意图**：主要人物此刻想做什么。
4. **承接建议**：下一章的自然进入方式（无缝推进 / 时间推进 / 视角切换），及可选的剧情方向（仅建议，待用户确认）。

用户没有要求时，不自动生成下一章正文。

## 交接纪律

- 快照中的「下一章承接点」是建议而非决定，正文走向以用户后续确认为准。
- 快照信息必须来自已发生正文或已确认计划，标注状态分类（SKILL.md 第 6 节）。
- 记忆恢复模式交付时按快照模板输出，并附「资料依据与可信度」说明。
