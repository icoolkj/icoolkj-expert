# 03 短剧改编价值评估

## 目标

在投入创作前，判断这个原著"值不值得改、怎么改、代价是什么"。评估必须给依据，不允许只给分数。

## 一、十维评估表

每维 1-5 分，并强制填写"依据"列。无依据的分数一律作废。

| 维度 | 判断问题 | 5 分特征 | 1-2 分特征 |
|---|---|---|---|
| 1 题材吸引力 | 题材本身有没有观众基础 | 强情绪、强关系、有明确受众 | 题材过时、无情绪抓手 |
| 2 核心创意辨识度 | 一句话能不能让人记住 | 设定有反差、有钩子 | 与市面作品高度同质 |
| 3 受众适配 | 目标观众是否清晰 | 受众年龄/性别/情绪需求明确 | 谁都可能看，等于谁都不看 |
| 4 人物辨识度 | 主角是否可被一句话描述 | 身份+性格+目标有记忆点 | 主角是通用模板 |
| 5 戏剧冲突强度 | 是否有人与人正面对抗 | 每集都有具体对手和具体损失 | 冲突靠内心、靠环境 |
| 6 情节推进力 | 多少字能被压缩成一集 | 事件密度高，一场一变化 | 大量铺垫、日常、心理 |
| 7 视觉表现力 | 关键场面能否拍出来 | 有可拍的动作与场面 | 关键转折在心里发生 |
| 8 短剧化难度 | 改编工作量（反向计分） | 结构已接近短剧节奏 | 需要推翻重写 |
| 9 制作可行性 | 场景/人数/特效成本 | 3-5 个主场景可承载 | 需要大场面、群演、特效 |
| 10 改编风险 | 审查/版权/逻辑风险 | 无明显风险 | 敏感内容、设定漏洞多 |

> 第 8 维为反向计分：5 分 = 容易改编，1 分 = 极难改编。评估表底部注明计分方向，避免误读。

## 二、权重与结论

按项目类型调整权重（示例，需按用户目标调整并说明）：

| 项目类型 | 权重重点 |
|---|---|
| 平台投稿/分账 | 题材吸引力、受众适配、情节推进力 |
| 自制低成本 | 制作可行性、视觉表现力、短剧化难度 |
| 品牌/宣传短剧 | 主题契合、视觉表现力 |

结论三档，必须配一句可执行建议：

- **强（推荐改编）**：内核清晰、冲突强、可拍。→ 建议等级 + 首选结构策略。
- **中（有条件改编）**：某几维弱，但可通过重构解决。→ 列出必须解决的具体问题，说明解决后的预期效果。
- **弱（不建议直接改编）**：内核依赖文字、冲突缺失或制作不可行。→ 给出替代方案（只取设定做 C 级改编 / 建议先做小说修订 / 建议放弃）。

评估结论必须区分"艺术判断"与"商业判断"。**没有可靠数据时，不得断言商业表现。**

## 三、必答的六个问题

无论评分如何，以下六问必须有答案：

1. 这个故事最不能被替换的是什么？（内核测试）
2. 观众看第一集前 90 秒，能看到什么冲突？
3. 主角每 3 集是否有一个明确的、可赢可输的目标？
4. 反派是否有独立动机，还是纯工具？
5. 有没有至少 3 个"必须拍出来"的名场面？
6. 用最少场景能拍完吗？需要几个主场景、几个主要演员？

## 四、短剧化难度分级

| 等级 | 特征 | 处理方式 |
|---|---|---|
| L1 轻改 | 章节本身接近场景，冲突密集 | 压缩 + 分集，保留 80% 事件 |
| L2 中改 | 有主线但节奏慢、心理多 | 重构节奏，重排事件顺序，合并角色 |
| L3 重改 | 结构松散、靠氛围、主角被动 | 重设主角目标与对手，重写中段 |
| L4 只取设定 | 内核不适合短剧，但设定有卖点 | C 级改编，重写故事 |

难度分级直接影响报价与交付周期说明。L3 以上必须提前告知用户"这不是缩编，是重写"。

## 五、风险清单

逐项确认，命中即写入评估报告：

- **审查风险**：涉政、涉黑、涉黄、涉未成年、过度暴力、迷信。
- **版权风险**：原著是否有明确授权；是否含他人作品片段、真实人物影射。
- **逻辑风险**：核心反转依赖巧合、依赖读者不知道的信息。
- **设定风险**：世界观规则前后不一，改编时会被放大。
- **同质风险**：与近期热门作品高度相似，需做差异化处理。
- **制作风险**：关键场面超出预算（车祸、爆破、古装大场面、动物、儿童）。
- **受众风险**：主情绪与目标平台受众错位。

每条风险给出"规避方式"，而不是只列风险。

## 六、评估报告结构

```markdown
# 《书名》短剧改编价值评估

## 1. 评估范围与依据
## 2. 十维评估表（含依据）
## 3. 综合结论（强/中/弱 + 一句话建议）
## 4. 六个必答问题
## 5. 短剧化难度等级与工作量说明
## 6. 推荐改编策略
   - 忠实度等级建议（A/B/C）
   - 结构策略（保留主线重排 / 换主角视角 / 提前真相 / 合并支线）
   - 规格建议（集数 × 时长）
## 7. 风险清单与规避方式
## 8. 待用户确认事项
```

## 七、常用判定句式

- "该故事的强项在人物关系而非事件密度，适合 L2 中改：保留关系网，重写事件链。"
- "原著前 8 章为铺垫，短剧必须把第 12 章的冲突提到第 1 集开场，代价是提前消耗一个反转。"
- "核心反转依赖读者不知道主角是双胞胎，属于信息不对称型反转，影视化后观众会立刻看穿，建议改为观众知情、人物不知情的悬念结构。"

## 八、禁止事项

- 不得用"这个题材最近很火"作为评估依据，除非能给出可核实的来源与时间。
- 不得给出"预计播放量 X 亿""预计收益 X 万"这类无依据的量化预测。
- 不得因为个人偏好把 L4 项目评为"强"。
- 不得省略"制作可行性"，短剧的第一约束是能不能拍。
