# 01 IP 商业价值诊断

## 0. 纪律先行

诊断是**判断**，不是夸奖。输出的每一句结论都要能指向具体依据。

- 有数据用数据（E1/E2），没数据用观察（E3），都没有就写假设（E4）并说明如何验证。
- 不得用"潜力巨大""市场广阔""极具商业价值"等无指向的形容词替代判断。
- 诊断阶段不写执行方案，只回答：现在在哪、值多少、缺什么、先做什么。

## 1. 诊断输入清单

| 类别 | 必查项 | 缺失时的处理 |
|---|---|---|
| 内容 | 类型、题材、篇幅/集数、完成度、更新稳定性 | 标 `[待确认]`，按最小假设推进 |
| 故事 | 一句话故事、核心冲突、差异化设定 | 无法判断差异化时，明确"差异化未成立" |
| 人物 | 主角、核心配角、反派、人物关系 | 无人物辨识度则商业开发优先级下调 |
| 世界观 | 规则是否自洽、是否可延展、是否有可视化元素 | 延展性弱则不做长线 IP 规划 |
| 视觉 | 是否已有形象、风格是否统一、是否有记忆点 | 无视觉资产则商品/授权线全部押后 |
| 数据 | 曝光、阅读/播放、完读/完播、关注、互动、付费 | 无数据只做定性诊断 |
| 渠道 | 已发平台、账号矩阵、私域规模 | 无渠道则先做渠道可行性判断 |
| 资源 | 人力、产能、外包、资金、时间 | 资源不足则方案必须"减法" |
| 权利 | 著作权归属、改编权、商标、是否共有 | 不明则一切授权类建议挂起 |

## 2. 十维诊断表

每个维度给 **0–5 分 + 一句依据 + 一条证据等级**。分数只用于横向比较，不作为结论。

| # | 维度 | 核心自检问题 | 高分特征 | 低分信号 |
|---|---|---|---|---|
| 1 | 内容价值 | 抛开商业，这个故事值得被看完吗 | 有明确主题、情绪落点、可复述的记忆点 | 靠设定堆砌、无情绪出口 |
| 2 | 故事差异化 | 与同类相比，观众为什么选它 | 变量替换清晰、公式独特 | 差异只在"设定更新" |
| 3 | 题材市场适配 | 这个题材现在有买单的人吗 | 有稳定受众盘、渠道明确 | 题材已过热或极冷且无差异化 |
| 4 | 人物吸引力 | 角色能否被一句话说清并让人想跟随 | 有欲望、有缺陷、有辨识行为 | 功能型角色、可被任意替换 |
| 5 | 世界观延展力 | 能否支撑续作、番外、外传、衍生 | 规则可推演、有未开发区域 | 只为单部服务，一次性消耗 |
| 6 | 视觉识别度 | 能否被记住并画出来 | 有符号化元素、色彩/造型统一 | 只有文字描述，形象依赖画师临时发挥 |
| 7 | 多媒介开发潜力 | 换形态后是否更强而非更弱 | 强情节/强视觉/强情绪至少占一 | 高度依赖文字语言美感 |
| 8 | 用户消费潜力 | 用户会为什么付钱、付多少 | 有明确付费场景与心理账户 | 只有"喜欢"，无付费动机 |
| 9 | 商业合作可能 | 品牌方为什么愿意挂上它 | 调性可嫁接到具体品类 | 调性敏感、受众过窄 |
| 10 | 版权与运营风险 | 有什么可能让商业化归零 | 权利清晰、无敏感内容 | 权利共有、题材敏感、易侵权 |

## 3. 评分的使用规则

1. 先写依据，再打分；不允许先打分再编理由。
2. 单一维度低分不必然否决项目，但**维度 10（权利风险）低分必须前置解决**。
3. 加权建议（可按项目调整，须说明）：
   - 内容/人物/差异化 合计 50%
   - 题材适配/用户消费 合计 30%
   - 延展/视觉/多媒介 合计 20%
4. 总分对照仅作参考：
   - ≥4.0：具备商业化基础，可进入模式设计。
   - 3.0–3.9：需先补短板（明确补哪一项），再谈变现。
   - <3.0：建议先解决内容与定位问题，暂缓商业化投入。

## 4. 阶段判定证据表

| 判断项 | P0 | P1 | P2 | P3 | P4 |
|---|---|---|---|---|---|
| 内容量 | 构想/片段 | 样稿、设定集 | 稳定连载/上线 | 完结或多季 | 多形态并行 |
| 用户 | 无 | 内测/小范围反馈 | 有自然增长数据 | 有核心粉与付费 | 有品牌认知与跨圈层受众 |
| 付费 | 无 | 无 | 零星（打赏/首充） | 有稳定付费记录 | 多收入线并行 |
| 合作 | 无 | 无 | 偶发咨询 | 有成交案例 | 长期框架合作 |
| 授权 | 无 | 无 | 无 | 有明确授权意向 | 有已履约授权 |

阶段结论写法：`当前阶段：P2（依据：稳定更新 8 个月、单平台关注 2.4 万、完读率 E1、尚无付费记录）`。

## 5. 诊断简报模板

```
一、结论（3–5 条，可直接决策）
二、项目现状（类型 / 题材 / 体量 / 渠道 / 数据）
三、核心竞争力（≤3 条，每条给证据）
四、主要商业机会（≤3 条，按可行性排序，含验证方式）
五、当前短板（≤4 条，说明影响哪条收入线）
六、主要风险（内容 / 市场 / 权利 / 运营 / 团队）
七、阶段判定（P?，依据）
八、优先动作（≤5 条，每条含责任方、成本量级、完成判据）
九、待确认事项（决策点，不要问开放式问题）
```

## 6. 常见诊断错误

| 错误 | 后果 | 纠正 |
|---|---|---|
| 用粉丝数代替商业价值 | 高估变现能力 | 看付费率、复购、互动质量 |
| 用"我喜欢"代替市场判断 | 方案自嗨 | 引入竞品与替代品视角 |
| 把设定复杂当世界观强 | 延展性误判 | 看规则是否可推演、可复用 |
| 把一次爆款当能力 | 资源错配 | 看持续性与可复制性 |
| 回避权利问题 | 后续全部白做 | 权利前置，写入风险第一行 |
| 阶段拔高 | 投入浪费 | 以证据表为准，不按愿望判定 |
