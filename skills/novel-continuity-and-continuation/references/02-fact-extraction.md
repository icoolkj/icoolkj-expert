# 02｜章节解析与事实提取

## 提取目标

从小说正文中提取结构化事实，建立可追溯的故事事实库。所有事实必须尽量附带章节来源，重要事实附带原文依据。

## 八类提取对象

### 1. 重要事件

- 事件内容、发生章节、发生顺序。
- 事件的起因、经过、结果。
- 事件的直接后果和连锁影响。

### 2. 人物行动

- 每个主要人物在事件中做了什么。
- 行动体现的性格特征和能力表现。
- 关键抉择及其理由。

### 3. 人物关系变化

- 关系建立、加深、破裂、转变的节点。
- 关系当前性质（盟友、敌对、师徒、恋人等）。
- 关系变化的原因章节。

### 4. 重要信息揭露

- 什么秘密在什么章节被向谁揭露。
- 揭露方式（对话、发现、旁观、转述）。
- 揭露后各方的反应。

### 5. 时间和地点

- 每个事件的相对时间位置和持续时长。
- 场景切换的轨迹（人物移动路线）。
- 故事内时间流速（用于时间线管理，见 05）。

### 6. 物品状态变化

- 重要物品的获得、失去、转手、损毁、使用。
- 物品当前持有者。
- 物品附带的能力、诅咒、秘密等设定。

### 7. 势力变化

- 势力的建立、壮大、衰落、覆灭。
- 势力之间的结盟与敌对变化。
- 势力关键人物的变动。

### 8. 伏笔及悬念

- 语句中暗示但未明说的信息。
- 未解释的现象、未回答的问题、未完成的承诺。
- 提取后转入伏笔档案管理（见 08）。

## 提取规范

1. **逐章提取**：按章节顺序处理，每章产出一组事实条目。
2. **原文锚定**：每条重要事实记录「章节 + 原文短句」，禁止只写脱离原文的概括结论。
3. **区分明确与暗示**：正文明确写的标为已发生；正文暗示未明说的标为待核实或伏笔。
4. **不做推测**：提取阶段不做剧情推测，推测留到续写规划阶段并明确标注。
5. **量化优先**：能用数字记录的（时间跨度、距离、人数、金额）记录数字，避免模糊表述。

## 事实条目格式

```
【编号】F-章节号-序号
【状态】已发生 / 待核实
【事件】一句话概括
【时间】故事内时间
【地点】发生地点
【人物】参与者及各自行动
【结果】直接后果
【来源】第X章，原文依据："……"
【关联】相关伏笔编号 / 人物编号 / 事件编号
```

## 输出要求

前文解析模式交付时包含：章节覆盖范围、重要事件清单、人物状态、时间线、伏笔清单、未解决问题、信息缺口。
