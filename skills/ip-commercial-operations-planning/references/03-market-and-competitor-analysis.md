# 03 市场环境与竞品分析

## 0. 纪律先行

本文件提供**分析框架**，不提供实时数据。

- 平台规则、榜单、分账政策、用户规模、竞品动态：必须联网检索并标注来源与时间，否则写 `[待验证]`。
- 禁止编造播放量、收入、用户数、转化率、融资额。
- 无法获取竞品内部数据时，用可观察代理指标（评论结构、更新节奏、衍生品上架情况、商务合作密度）替代，并说明这是代理指标。

## 1. 先划清三层市场

同一个 IP 同时面对三个不同市场，混在一起会导致定位混乱：

| 层 | 定义 | 竞争对象 | 判断指标 |
|---|---|---|---|
| 内容市场 | 用户在选择看什么 | 同类作品 | 完读/完播、追更率、口碑结构 |
| 注意力市场 | 用户在刷什么 | 短视频、直播、游戏 | 曝光、点击率、停留 |
| 消费市场 | 用户在买什么 | 同类商品/联名/门票 | 转化率、客单价、复购 |

方案中每条结论要注明属于哪一层。用注意力市场的表现推断消费市场，是最常见的错判。

## 2. 市场规模的处理方式

优先级从高到低：

1. **E2 直接引用**：权威报告/平台官方数据。必须写：来源、发布时间、统计口径、统计范围。
2. **自下而上估算**：目标用户数 × 渗透率 × 付费率 × 客单价。每一步参数单独标 E4 与来源。
3. **自上而下估算**：所属细分市场总额 × 可争取份额。
4. **不做数字**：只做定性拥挤度判断 + 验证方式。

估算必须写清："这是量级估算，用于排序而非对外承诺。"

## 3. 竞品选择规则

- 数量：3–5 个。太少看不清结构，太多失焦。
- 结构：2–3 个头部（看标准）+ 1–2 个同量级（看可行）+ 1 个失败案例（看红线）。
- 相关性：同题材、同渠道、同受众至少占两项。

## 4. 竞品拆解表

| 项目 | 形态/体量 | 核心公式 | 主角设定 | 主要卖点 | 节奏特征 | 获客方式 | 变现方式 | 明显短板 | 与本项目关系 |
|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | 参照/规避/超越 |

### 核心公式的写法

用一句句式概括，不抄情节：

> 【什么身份的人】在【什么困境】里，用【什么方式】解决【什么矛盾】，代价是【什么】。

### 必须回答的五个问题

1. 竞品**为什么被选择**（用户的第一动机，不是作品优点列表）。
2. 竞品的**差异化到底是什么**（能否一句话说清）。
3. 竞品**如何获客**（平台推荐 / 达人分发 / 二创 / 投流 / 私域）。
4. 竞品**是否形成品牌认知**（是否有独立于作品的讨论、梗、形象流通）。
5. 竞品**有哪些商业化方式**（哪些成功、哪些试过就停）。

### 短板分析的价值

差评集中在哪（拖沓、降智、烂尾、人设崩、付费点恶心）——这些就是本项目的**红线清单**。竞品的失败比成功更有信息量。

## 5. 差异化陈述

必须能写成这一句，写不出说明差异化未成立：

> 相比【竞品 A】的【做法】，本项目把【变量】换成【新做法】，因此用户能获得【不同体验】，代价是【放弃了什么】。

"代价"不可省略——没有代价的差异化通常是伪差异化。

## 6. 壁垒判断

IP 商业化的壁垒只有四类，逐项判断本项目有没有：

| 壁垒 | 表现 | 是否可被快速复制 |
|---|---|---|
| 内容壁垒 | 叙事能力、情绪密度、更新产能 | 难复制，但难量化 |
| 角色壁垒 | 角色成为独立符号，能脱离作品流通 | 形成后极难复制 |
| 渠道壁垒 | 私域、达人网络、平台关系 | 可用钱买，但有时间成本 |
| 供应壁垒 | 独家供应链、成本优势、产能 | 可复制，靠规模 |

壁垒为 0 的项目，方案必须写明"靠执行速度与低成本试错取胜"，不能假装有护城河。

## 7. 输出格式

```
1. 市场三层判断（内容/注意力/消费）各一句结论
2. 竞品拆解表（3–5 个）
3. 五个必答问题的答案
4. 竞品红线清单（差评集中点 → 本项目规避措施）
5. 差异化陈述（一句话 + 代价）
6. 壁垒判断（四类，含"无壁垒"的诚实结论）
7. 机会窗口与风险（含时效判断）
8. 待验证事项与验证方式
```

## 8. 禁止项

- 不得只列作品名单不做拆解。
- 不得用"制作精良""剧情紧凑"这类无法验证的评语作为竞品优势。
- 不得把竞品的公开热度直接当收入。
- 不得忽略失败案例。
