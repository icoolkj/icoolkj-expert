# 09 剧本写作规范

## 目标

产出导演、演员、制片三方能直接使用的剧本：场景清楚、动作可拍、对白可演、成本可控。

## 一、页面结构

```
第 X 集：集名

【本集提要】（可选，一句话，仅供内部使用，不进入成片）

场次 X-1
场景：内景 · 老宅书房 · 夜
人物：林晚、舅舅

△ 林晚推门进来。舅舅正把一份文件塞进抽屉，动作没停。

舅舅：这么晚不睡？

林晚：（走到桌前，没坐）三月十七，你签的字。

△ 舅舅的手停在抽屉把手上。

舅舅：（笑）你妈知道你在查这个吗？

△ 林晚没有回答。她把一张复印页放在桌上，指尖按着签名处。

林晚：这张，我复印了七份。

△ 舅舅脸上的笑消失。他慢慢关上抽屉。

舅舅：你想要什么？

（切至）
```

## 二、格式细则

| 元素 | 写法 | 说明 |
|---|---|---|
| 集标题 | `第 X 集：集名` | 集名 2-5 字，可留悬念 |
| 场次号 | `场次 X-Y` | X=集数，Y=场序 |
| 场景行 | `场景：内景/外景 · 地点 · 时间` | 三者齐全，时间写日/夜/晨/黄昏 |
| 人物行 | `人物：A、B` | 按出场顺序 |
| 动作行 | 以 `△` 开头 | 现在时，可拍摄 |
| 对白 | `人物：对白` | 不加引号 |
| 表演提示 | `（低声）（停顿）（转向窗外）` | 放在对白前，短，少用 |
| 转场 | `（切至）` `（叠化）` `（硬切）` | 仅在有意义时写 |
| 字幕 | `【字幕：三个月后】` | 用于时间跳跃 |

## 三、动作行写法

### 三条规则

1. **写摄影机能拍到的**：不写"她很委屈"，写"她低头看着自己的鞋"。
2. **写现在进行时**：不写"她曾经想过离开"，写"她把行李箱推到床下"。
3. **一段不超过三行**：导演不会读长段描述。

### 对照改稿

| 原著/初稿 | 剧本写法 |
|---|---|
| 林晚内心充满了愤怒和不甘，她想起这三年来受的所有委屈。 | △ 林晚把碗放进水池。手一松，碗碎了。她没去看。 |
| 舅舅是个阴险狡诈的人，多年来一直在暗中侵吞家产。 | △ 舅舅把账本锁进抽屉，钥匙串上挂着老宅所有房间的钥匙。 |
| 空气凝固了，所有人都屏住了呼吸。 | △ 没人动。茶杯里的水还在晃。 |

## 四、对白规则

- **一句话一个信息**，不叠加。
- **不用对白交代背景**。背景用画面、道具、他人反应交代。
- **人物说话方式要区分**：舅舅用反问，母亲用沉默和短句，表妹用撒娇转移话题。
- **关键台词前置**：把最有力的一句放在场景开头或结尾，不埋在中间。
- **删掉所有"你知道的……""正如我先前所说……"**。

对白长度：竖屏单句不超过 20 字；横屏单段不超过 60 字。

## 五、场景转场

| 转场 | 用途 |
|---|---|
| 硬切（直接换场） | 默认，最经济 |
| 动作接动作 | 上一场结尾的动作接下一场开头的同类动作（开门→开门） |
| 声音桥 | 上一场的声音延续到下一场画面 |
| 对比切 | 上一场的富贵接下一场的窘迫 |

避免：黑场、长时间空镜、无意义的淡入淡出（在竖屏短剧中会掉留存）。

## 六、蒙太奇与闪回

- **蒙太奇**：用于压缩时间（练功、查资料、连败）。写清"三段画面 + 一句旁白/字幕"，总长不超过 15 秒。
- **闪回**：只在提供关键新信息时使用。同一段闪回不得重复出现超过两次；重复时必须增加新细节。
- 禁止用闪回补人物关系（那是编剧没写清）。

## 七、旁白

默认不用。允许的三种情形：

1. 开场 10 秒内建立世界观（不超过两句）。
2. 结尾余味（不超过一句）。
3. 主角第一人称的"日记式"结构（需全剧统一，不能中途出现）。

旁白不得解释剧情、不得替观众理解人物情绪。

## 八、集末钩子的写法

钩子必须写在最后一场的最后两行：

```
△ 林晚打开抽屉。里面是空的。

林晚：（很轻）他知道我拿过。

（切至黑）
```

写法要点：

- 用一个具体动作/物件制造信息冲击。
- 最后一句台词尽量短（5-12 字）。
- 不要在钩子后加任何解释或下一集预告。

## 九、导演版与 AI 制作版（附加）

仅当用户明确要求时另出文件，不混入标准剧本：

- **导演版**：加镜头号、景别、运镜、光线、表演重点。
- **AI 制作版**：加画面 Prompt、参考图说明、首尾帧描述、时长。

文件名区分：`第07集_剧本.md` / `第07集_导演版.md` / `第07集_AI制作版.md`。

## 十、常见错误

| 错误 | 表现 | 修正 |
|---|---|---|
| 小说体 | 大段心理和环境描写 | 全改为动作行 |
| 说明书对白 | "当年你父亲把公司交给了你叔叔……" | 改为画面或冲突中的信息碎片 |
| 场景过多 | 一集 12 个地点 | 合并到 3-5 个 |
| 无场景结果 | 每场都以"两人对视"结束 | 每场必须有处境变化 |
| 人物声音相同 | 所有人说话一个腔调 | 给每人一个语言习惯 |
| 术语混入 | 剧本里写"推镜至特写" | 移入导演版 |

## 十一、交付前格式检查

- 场景行三要素齐全。
- 每场都有动作行，不只是对白。
- 无"他想""她感到"等内心描写。
- 集末有钩子，且不含解释。
- 场次编号连续无跳号。
- 单集地点数、演员数已统计。
