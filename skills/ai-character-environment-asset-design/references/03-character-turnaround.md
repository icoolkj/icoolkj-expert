# 03｜角色三视图与多视角设定

## 1. 为什么三视图是资产核心

三视图是把「一张好看的图」变成「可复用的资产」的关键：它把角色的三维信息压缩成可核对的平面信息，让后续任何角度的生成都有参照。

## 2. 标准视图清单

| 视图 | 用途 | 必须呈现 |
|------|------|----------|
| 正面全身 | 主基准 | 完整剪影、比例、服装结构 |
| 45° 前侧全身 | 立体感基准 | 面部转折、肩颈关系、服装体积 |
| 90° 正侧全身 | 侧脸身份 | 鼻额角、下颌线、后脑形、脊背弧度 |
| 背面全身 | 背面一致性 | 发型背面、背部服装、后腰结构 |
| 面部正面特写 | 表情基准 | 五官比例、皮肤质感 |
| 面部 45° 特写 | 识别特征 | 疤痕/痣的位置关系 |

P1 角色可裁到「正面 + 45° + 背面 + 面部正面」。P2 只做「正面半身 + 面部」。

## 3. 三视图制图规范

1. **同一画布、同一标尺**：所有视图角色高度一致，画一条水平基准线对齐脚底、一条对齐头顶。
2. **同一光位**：统一正面偏上的柔光，不加戏剧光，避免光影干扰结构判断。
3. **同一表情**：中性表情，嘴闭合，视线平视。
4. **同一姿势**：标准站姿，双臂自然下垂微离身体（露出服装侧面）。
5. **无透视**：正交视角，避免近大远小。
6. **纯色背景**：中性灰或中低饱和底色，不抢主体。
7. **标注**：身高线、头部高度、关键结构线（肩线、腰线、膝线）。

## 4. 生成策略

### 4.1 单图多视图（Turnaround Sheet）
优势：一次生成即内部自洽。劣势：分辨率分散、单视角细节不足。

写 Prompt 时明确：
- 视图数量与顺序（正面 / 45° / 侧面 / 背面，从左到右）。
- "orthographic turnaround sheet, front view, three-quarter view, side view, back view, full body, consistent scale, neutral gray background, T-pose / A-pose"
- 禁止项："no perspective distortion, no dramatic lighting, no cropping"

### 4.2 分图生成 + 参考图锁定
优势：单视角质量高。劣势：跨图一致性需额外控制。

流程：先出正面 → 用正面作参考图生成 45° → 用 45° 补侧面 → 侧面推背面。逐级传递，链条越长漂移越大，**侧面与背面尽量用正面 + 侧脸描述双参考**。

### 4.3 3D 辅助
条件允许时，先做低模或使用 3D 姿态工具确定比例和角度，再以渲染图作参考。这是最稳的多视角一致性方案。

## 5. 常见问题与处理

| 问题 | 原因 | 处理 |
|------|------|------|
| 各视图形变、比例不一 | 单图塞太多视图 | 减少到 2–3 视图，或改分图生成 |
| 背面出现新设计 | 背面信息缺失 | 先写背面设定文字（发尾、背部服装结构）再生成 |
| 侧面鼻子突变 | 侧脸特征未描述 | 增加鼻额角、鼻尖方向、下巴前突度的明确描述 |
| 服装在侧面塌陷 | 只描述了正面 | 补充侧缝、袖窿、下摆厚度 |
| 身高在各图中不一致 | 无基准线 | Prompt 加 "consistent height, standing on same baseline" |

## 6. 交付格式

输出物包含：
1. 三视图成图（或生成 Prompt + 参数）。
2. 视图说明表：每个视图的角度、分辨率、用途。
3. 结构标注说明：身高、头身比、关键比例。
4. 与基础档案的一致性核对结论。
