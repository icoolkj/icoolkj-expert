# 05｜故事时间线管理

## 时间记录体系

为小说建立双轨时间记录：

### 故事内时间（作品世界的时间）

- 采用「故事历」记录：如「第三年 春 / 主角离乡后第 47 天」。
- 每个重要事件标注其故事内时间点。
- 记录时间流速特殊设定（如：修炼闭关十年、时间流速不同的秘境）。

### 叙事时间（阅读顺序的时间）

- 章节顺序即叙事顺序。
- 记录每章覆盖的故事内时间跨度（如：第 12 章覆盖一天；第 13 章跳过三个月）。

## 时间线条目模板

```
【事件】
【故事内时间】
【章节】第X章
【持续时长】
【参与人物】
【前后事件】上一事件 → 本事件 → 下一事件
【时间跳跃】与上一事件之间跳跃了多久、如何交代
```

## 时间连续性检查规则

1. **单向流动**：同一视角下，事件时间必须单调递增。发现时间倒流即严重冲突。
2. **跳跃有交代**：任何超过日常跨度的时间推进，正文中必须有过渡交代（如「三日后」「开春时」）。无交代的长跳跃记为连续性风险。
3. **行程时间合理**：核对人物移动耗时——上一章傍晚在甲城，下一章清晨出现在千里之外的乙城且无传送设定，即时间/空间冲突。
4. **恢复周期合理**：重伤、中毒、修炼等需要时间的进程，检查后续章节的时间是否给足了恢复周期。
5. **年龄一致**：核对人物年龄随时间推进的变化；闪回/回忆中的年龄也要一致。
6. **并行线对齐**：多视角/平行叙事时，各条线的故事时间必须能对齐，会合场景的时间必须吻合。

## 常见时间线错误类型

| 错误 | 表现 | 等级 |
|---|---|---|
| 时间倒流 | 后章事件早于前章同类事件 | 严重冲突 |
| 无依据跳跃 | 大段时间无过渡直接跳过 | 连续性风险 |
| 行程矛盾 | 移动耗时与距离/能力不符 | 潜在冲突 |
| 恢复缺失 | 重伤次日满状态 | 潜在冲突 |
| 季节错乱 | 前章深冬后章盛夏且无交代 | 潜在冲突 |
| 年龄穿帮 | 同一时期年龄对不上 | 严重冲突 |

## 输出要求

时间线检查模式交付时包含：检查范围、时间轴摘要（关键节点列表）、发现的问题及等级、原文依据、修改建议。
