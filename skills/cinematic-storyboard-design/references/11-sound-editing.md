# 11 声音与剪辑：让镜头连成一场戏

画面告诉观众"发生了什么"，声音告诉观众"这意味着什么"，剪辑决定"什么时候知道"。

## 11.1 声音的六个层次

必须分列，不得混为"音效"。

| 层次 | 定义 | 记法 | 作用 |
| --- | --- | --- | --- |
| 对白 | 角色说出的台词 | `对白` | 信息与冲突 |
| OS | 在场者的内心/低声自语 | `OS` | 主观、隐瞒、反讽 |
| VO | 不在场叙述者的旁白 | `VO` | 叙述框架、回忆 |
| 环境声 | 空间的底噪 | `环境` | 建立真实与空间 |
| 音效 | 具体动作/物件声 | `音效` | 强调、节奏、悬念 |
| 音乐 | 配乐 | `音乐` | 情绪引导 |

OS 与 VO 的区别常被写错：**OS 是画面内人物的内部声音，VO 是画面外叙述者的声音。**

## 11.2 声音的三重功能

| 功能 | 做法 | 例 |
| --- | --- | --- |
| 补充画面外空间 | 用画外声暗示画面之外 | 门外脚步声 |
| 制造悬念 | 先声后画 | 咳嗽声先于推门 |
| 替代画面 | 用声音叙述省略事件 | 打斗声 + 静止的听者面部 |

**画外空间是省钱的高级手段。** 一场需要大场面的戏，用声音 + 听者反应就能成立。

## 11.3 静默的使用

静默是最强的声音设计，但有条件：

| 用法 | 效果 | 条件 |
| --- | --- | --- |
| 突然静音 | 冲击、耳鸣感 | 前面必须有足够噪音 |
| 全场静默 | 压迫、尴尬 | 需要有微小声音支撑（呼吸、钟表） |
| 声音渐远 | 抽离、失神 | 配合主观镜 |
| 只听心跳/呼吸 | 极端主观 | 不宜过长 |

**完全无声在成片里几乎不存在**，写"静默"时要说明保留了什么底噪。

## 11.4 声音的进出场

| 手法 | 说明 |
| --- | --- |
| J-cut | 下一场的声音先进，画面后到（提前进入） |
| L-cut | 上一场的声音延续到下一场画面（延后退出） |
| 声音桥 | 用同一声音连接两个空间 |
| 声音对撞 | 从极静切到极吵 |

在 `dialogue_audio` 与 `transition` 字段都标注，避免剪辑时遗漏。

## 11.5 剪辑的基本连接

| 类型 | 逻辑 | 适用 |
| --- | --- | --- |
| 动作接 | 动作跨镜延续 | 流畅、隐形 |
| 视线接 | 看→所看 | 引导注意力 |
| 图形接 | 形状/构图相似 | 隐喻、时间跳跃 |
| 声音接 | 声音跨镜延续 | 压缩时间 |
| 节奏接 | 按固定节拍切 | 音乐段、蒙太奇 |
| 跳切 | 同机位同景别直接跳 | 焦躁、时间流逝 |
| 匹配剪辑 | 前后镜构图高度相似 | 强表达、转场 |

## 11.6 节奏控制

| 手段 | 加快 | 放慢 |
| --- | --- | --- |
| 镜头时长 | 缩短 | 延长 |
| 景别变化 | 频繁跳变 | 稳定 |
| 机位变化 | 多角度 | 单一 |
| 对白密度 | 抢话、重叠 | 留白、停顿 |
| 声音 | 密集音效、音乐推进 | 环境声、静默 |
| 运动 | 运动镜头多 | 固定 |

**节奏不是越快越好。** 一场戏的节奏曲线应该是"起—压—放"，全程高亢等于没有高潮。

## 11.7 顿点的设计

顿点＝刻意制造的停顿瞬间，观众在此消化信息。

| 顿点类型 | 做法 | 放在哪 |
| --- | --- | --- |
| 表演顿 | 台词后给 1–2 秒无台词反应 | 关键信息揭晓后 |
| 空镜顿 | 插入一个环境镜 | 场景转换前 |
| 声音顿 | 所有声音抽掉一拍 | 冲击前 |
| 视线顿 | 人物看向画外，镜头停留 | 悬念设置 |
| 走位顿 | 人物停步 | 决定前后 |

没有顿点的分镜，剪出来会"一路滑过去"，观众记不住任何东西。

## 11.8 转场方式

| 转场 | 效果 | 适用 | 慎用 |
| --- | --- | --- | --- |
| 硬切 | 直接、有力 | 90% 的情况 | — |
| 叠化 | 时间流逝、柔和 | 时间跳跃、情绪过渡 | 用多了显得软 |
| 淡入淡出 | 段落分隔 | 集首集尾 | 集内滥用拖节奏 |
| 划像 | 风格化 | 特殊类型 | 现代剧慎用 |
| 白场/黑场 | 断裂 | 强转折 | — |
| 匹配剪辑 | 巧思 | 主题对照 | 刻意感强 |
| 声音转场 | 无缝 | 时间压缩 | 需要声音设计配合 |

**默认用硬切。** 每个非硬切都要能说出为什么。

## 11.9 音乐的使用

| 原则 | 说明 |
| --- | --- |
| 不解释情绪 | 画面已经演了，音乐不要再重复"这里很悲伤" |
| 进出要早于/晚于情绪点 | 提前进=预告；延后出=余味 |
| 留白 | 一场戏可以完全无音乐，反而更有力 |
| 主题复用 | 同一动机在不同场景变奏，形成记忆 |
| 不做墙纸 | 全程铺底音乐会让观众麻木 |

在镜头表里用 `音乐进/音乐出` 标出位置，不必写曲名。

## 11.10 声音与信息的配合

| 需要观众注意 | 做法 |
| --- | --- |
| 台词 | 压低环境声与音乐 |
| 画外事件 | 提高该音效，画面不变 |
| 情绪 | 环境声渐弱，只留呼吸 |
| 悬念 | 加入不协和音或低频 |
| 时间流逝 | 钟表、雨声、风扇等持续声 |

**同一时刻只让一个声音主导。** 三个声音抢注意力＝观众什么都没听清。

## 11.11 交付时的声音说明格式

每场一段，不必逐镜写：

```
SC03（夜·走廊）
环境：雨声（窗外，中等）、老宅木地板吱呀（偶发）
音效：钥匙串碰撞、锁芯转动（重点，配合特写）、门内咳嗽（画外，关键信息）
音乐：无。至 SH14 咳嗽后进入低频持续音，延续到下一场（L-cut）
对白：全部现场同期感，陈默台词压低
静默：SH11 苏瑾转身瞬间，环境声降 60%，只留雨声
```

## 11.12 自检

- [ ] 六层声音已分列，OS/VO 未混用
- [ ] 每场有画外空间设计（至少一处）
- [ ] 关键信息有声音强调
- [ ] 有顿点设计，不是一路平推
- [ ] 转场以硬切为主，非硬切有理由
- [ ] 音乐有进出点，非全程铺底
- [ ] 同一时刻只有一个声音主导
- [ ] J-cut / L-cut 已标注
