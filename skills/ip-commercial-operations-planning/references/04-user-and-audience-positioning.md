# 04 用户与受众定位

## 0. 纪律先行

无真实调研时，用户画像是**假设**，必须标 `[待验证]`。不得写成"数据显示用户以一二线城市 25–35 岁女性为主"。

判断用户画像是否合格：把名字遮掉，能不能与另外三个同类 IP 的用户画像区分开。不能，说明是模板。

## 1. 三层用户结构

| 层级 | 定义 | 作用 | 对应动作 |
|---|---|---|---|
| 核心用户 | 会追更、会互动、会付费、会自发传播 | 决定内容节奏与口碑 | 深度运营、共创、优先反馈 |
| 次级用户 | 会看但不付费、不互动 | 决定传播规模 | 降低门槛、做分享钩子 |
| 商业用户 | 品牌方、合作方、渠道方、授权买家 | 决定变现天花板 | 商业提案、案例包装 |

三层缺一层，方案就有缺口：只有核心用户 → 长不大；只有次级用户 → 不变现；没有商业用户 → 授权与联名无从谈起。

## 2. 用户画像表

每类用户填一张，最多 3 类，多了等于没定位。

| 维度 | 要写的内容 | 反例 |
|---|---|---|
| 身份 | 具体职业/生活状态 | "年轻女性" |
| 场景 | 什么时间、什么设备、什么状态下消费 | "有空的时候" |
| 需求 | 想获得什么情绪或心理补偿 | "喜欢好故事" |
| 替代品 | 不看我的会去看什么 | "没什么替代" |
| 决策触发 | 什么让他点开第一章/第一集 | "看到推荐" |
| 付费动机 | 为什么愿意掏钱、掏多少 | "愿意支持" |
| 分享动机 | 分享时想表达自己什么 | "觉得好看" |
| 流失原因 | 什么情况下会弃 | "不好看就走" |

## 3. 需求地图

| 需求类型 | 用户真正要的 | 内容供给特征 | 商业化含义 |
|---|---|---|---|
| 情绪补偿 | 被压抑的部分被释放 | 快速兑现、压制—反转 | 付费点前置，单点爽感可卖 |
| 悬念紧张 | 信息差被逐步揭开 | 钩子密度高、章末断点 | 追更驱动，适合订阅 |
| 情感沉浸 | 关系细腻、情绪有落点 | 慢热、留白、CP 关系 | 角色周边、二次创作活跃 |
| 世界观探索 | 规则可推演、可讨论 | 设定严密、有考据空间 | 设定集、周边、社群讨论 |
| 陪伴轻松 | 低门槛、可随时进入 | 单元结构、日常感 | 会员、周边、联名 |
| 身份认同 | 找到同类、表达价值观 | 群体共鸣、态度鲜明 | 社群、联名、线下活动 |

一个项目主打 **1 个主需求 + 1 个辅需求**。主需求决定节奏，辅需求决定气质与商业化方向。

## 4. 付费动机与阻力

| 付费动机 | 表现 | 适配变现 |
|---|---|---|
| 追更焦虑 | 想知道后续 | 付费章节、提前看、会员 |
| 收藏占有 | 想要实体/限定 | 周边、限定商品、设定集 |
| 身份表达 | 想展示我属于这个群体 | 服饰、徽章、联名 |
| 支持创作者 | 情感连接 | 打赏、众筹、会员 |
| 社交货币 | 想拿去分享/送人 | 礼盒、联名、票务 |
| 便捷省时 | 想一次看完 | 打包购买、会员 |

| 付费阻力 | 表现 | 应对 |
|---|---|---|
| 价格锚点不清 | 不知道值不值 | 提供对比锚（同类商品/单集价） |
| 信任不足 | 怕是劣质品 | 展示打样、评价、退换承诺 |
| 决策成本高 | 选择太多 | 减少 SKU，做组合 |
| 支付摩擦 | 流程太长 | 缩短路径、常用支付方式 |
| 时机不对 | 热度已过 | 与内容节点绑定 |

## 5. 用户旅程

| 阶段 | 关键问题 | 指标 | 常见断点 |
|---|---|---|---|
| 触达 | 他怎么第一次看到 | 曝光、点击率 | 封面/标题无信息 |
| 首体验 | 前 30 秒/前 3 章能不能留住 | 首屏跳出、首章完读 | 开场慢、信息密度低 |
| 追更 | 为什么会回来 | 追更率、回访频次 | 断点无钩子、更新不稳 |
| 互动 | 为什么愿意说话 | 评论率、二创数 | 无话题设计 |
| 付费 | 为什么此刻掏钱 | 付费转化、客单价 | 付费点与情绪错位 |
| 自传播 | 为什么愿意推荐 | 分享率、UGC 量 | 无分享素材、无身份标签 |
| 召回 | 流失后怎么回来 | 召回率 | 无触达渠道、无新钩子 |

旅程中每一环写一条具体动作，不要写"提升用户体验"。

## 6. 分层运营策略

| 层级 | 目标 | 手段 | 判断标准 |
|---|---|---|---|
| 潜在用户 | 降低首次接触门槛 | 免费试读/试看、切片、达人分发 | 首章完读率 |
| 初次用户 | 建立继续消费的理由 | 钩子前置、更新承诺 | 7 日回访率 |
| 普通关注 | 转化为互动者 | 话题、投票、答疑 | 互动率 |
| 核心粉丝 | 转为共创与传播者 | 内测、命名权、二创激励 | UGC 产出数 |
| 高活跃 | 转为付费与线下参与 | 会员、限定、活动 | 付费率、到场率 |
| 付费用户 | 提升频次与客单 | 组合包、复购权益 | 复购率、ARPU |
| 商业合作用户 | 转为长期合作 | 案例、数据包、履约记录 | 复购合作数 |

## 7. 无调研时的写法

```
用户假设（E4，待验证）：
- 核心用户：__（身份）在__（场景）为__（需求）消费，替代品是__。
- 首要验证方式：__（问卷/访谈/小规模投放），样本__，周期__，成功判据__。
```

## 8. 禁止项

- 不用年龄性别标签代替场景与动机。
- 不把"年轻人""Z 世代"当受众定义。
- 不把点赞、评论数当付费意愿。
- 不假设用户会为了"支持原创"而付费。
