# 07 分集规划与结尾钩子

## 目标

把全剧结构落成逐集条目，使每一集都有明确的功能、变化与出口。分集大纲是剧本之前的最后一道设计关卡，也是与用户、制片对齐的主要文件。

## 一、单集内部结构

### 竖屏（1-2 分钟）

```
0-10 秒   承接上集钩子，直接给反应或后果
10-40 秒  本集目标出现（主角要做什么）
40-70 秒  阻碍出现（对手/误会/意外）
70-100 秒 冲突升级，主角做出选择
100-120 秒 结果 + 新信息 + 钩子
```

不允许：本集内解决完所有问题且不留下任何新问题。

### 横屏（8-15 分钟）

```
第一场  承接 + 本集目标建立（1-2 分钟）
第二场  阻碍与试探（2-3 分钟）
第三场  冲突爆发 / 关系变化（3-5 分钟）
第四场  结果 + 反转（2-3 分钟）
第五场  短场，钩子（30-60 秒）
```

## 二、分集条目模板

```markdown
### 第 7 集：以退为进

- **核心目标**：主角要让舅舅在家族会上承认账目有问题
- **开场吸引点**：主角把一叠账本放在桌上，说"先从三月开始"
- **主要人物**：主角、舅舅、母亲、表妹
- **核心事件**：账本被调包，主角反被指控偷钱
- **戏剧冲突**：主角掌握证据 vs 舅舅掌握家族话语权
- **情绪走向**：自信（4）→ 被围攻（7）→ 反制（8）
- **关键信息**：账本第三页有舅舅的签名
- **反转/高潮**：主角早拍下原件，当场投影
- **结尾钩子**：投影上出现第二份签名——母亲的
- **与下集承接**：第 8 集开场即母亲的反应，主角第一次怀疑母亲
- **原著对应**：第 14 章（压缩，合并了第 15 章的部分内容）
- **改编记录**：DIFF-006
```

字段缺一不可。缺"原著对应"会导致一致性失控；缺"情绪走向"会导致节奏平板。

## 三、章节到集数的映射

不是一章节一集，也不是平均切分。

### 映射算法

1. 把事件卡按"是否改变处境"分组，每组 = 1 集（竖屏）或 1-2 集（横屏）。
2. 检查每组是否有钩子；没有钩子的组，与相邻组合并。
3. 检查连续三集是否同一冲突类型；是则插入一次"变奏"（换地点/换对手/换目标）。
4. 若总集数不足，用"代价"和"误解"扩写，不用"重复打脸"注水。
5. 若总集数超出，优先合并"同对手的连续冲突"，把三次打脸压成一次更强的。

### 密度对照

| 原著内容 | 竖屏集数 | 横屏集数 |
|---|---|---|
| 1 个完整冲突回合（挑事—反制—结果） | 1 集 | 1 集 |
| 1 个关系变化 | 0.5-1 集 | 1 集 |
| 1 段日常/铺垫 | 0-0.3 集 | 0.5 集 |
| 1 个真相揭露 | 1 集 + 1 集余波 | 1-2 集 |

## 四、结尾钩子

### 五种有效钩子

| 类型 | 机制 | 例子 |
|---|---|---|
| 信息差钩子 | 观众知道、主角不知道，或反之 | 主角进门，观众先看到对手在翻他的抽屉 |
| 选择钩子 | 把主角逼到必须二选一 | "救你妈，还是救你女儿？" |
| 危机钩子 | 直接的生命/身份/关系威胁 | 车灯直冲过来，画面黑 |
| 关系反转钩子 | 一段关系的性质被改变 | "我不是你妹妹。" |
| 代价钩子 | 赢了，但付出了不该付的东西 | 主角赢了官司，抬头看见母亲被带走 |

### 钩子写作四规则

1. **必须是本集已建立的信息的延伸**，不能凭空出现新人物、新组织、新设定。
2. **落在最后一个动作或最后一句台词**，不解释、不总结、不预告。
3. **一句话能说清发生了什么**，否则信息过载。
4. **下一集必须立即回应**，不能跳开去讲另一条线。

### 钩子轮换表

连续使用同一类型会疲劳。建议轮换：

```
第1集 危机 → 第2集 信息差 → 第3集 选择 → 第4集 关系反转 → 第5集 代价 → 循环
```

同一类型最多连用两集。

### 无效钩子（禁用）

- 主角突然晕倒（无信息量）。
- 手机响了，屏幕看不清是谁。
- "三个月后……"时间跳跃（逃避冲突）。
- 旁白："他不知道，更大的危机正在靠近。"
- 新角色推门而入，此前从未提及。

## 五、水集检测

一集如果满足以下任一条，即为水集：

- 删掉后后续剧情无需任何修改。
- 本集没有产生新信息、新冲突、关系变化或目标变化。
- 本集冲突与上集同类型且强度未升。
- 全集靠对话解释前情。
- 主角在本集没有做出任何选择。

处理：合并进邻集，或改造为"变奏集"（换场景、换对手视角、加一次代价）。

## 六、分集表输出

先给全剧总表，再给逐集条目：

```markdown
## 全剧分集总表

| 集 | 集名 | 核心事件 | 冲突 | 钩子类型 | 原著对应 |
|---|---|---|---|---|---|
| 1 | | | | | |
```

逐集条目按第二节模板展开。全剧超过 30 集时，先交付第一阶段的逐集条目（10-15 集），其余只给总表，等用户确认后再展开。

## 七、常见问题与修正

| 问题 | 表现 | 修正 |
|---|---|---|
| 集与集之间是并列关系 | 每集都在打脸不同的人 | 改成递进：同一对手，每次加码 |
| 主角每集都赢 | 无风险感 | 插入"赢但付出代价"或"输了但拿到信息" |
| 反派每集都输 | 反派贬值 | 让反派在中段赢一次大的 |
| 钩子靠误会堆叠 | 观众厌烦 | 每三次误会给一次真实揭露 |
| 集数不够 | 拖节奏 | 增加"代价"与"关系深化"，不加新角色 |
| 集数过多 | 挤压 | 合并同类型冲突，删支线 |

## 八、自检清单

- 每集是否至少有一个有效变化？
- 每集钩子是否可在不解释的情况下被理解？
- 钩子类型是否轮换？
- 是否存在连续三集同冲突类型？
- 每 3-5 集是否有一次爽点兑现？
- 每 10 集是否释放一个中秘密？
- 每集条目是否标注了原著对应与改编记录？
