# 15 AI 制作交接：让分镜能被生成

交接的目标：**执行方拿到文件后不需要再问导演问题，就能开始生成。**

## 15.1 交接包的五件套

| 文件 | 作用 | 缺了会怎样 |
| --- | --- | --- |
| 镜头表 | 全量参数，机器可读 | 无法批量生成 |
| 逐镜提示词 | 每条可直接投喂 | 生成方自行发挥，风格漂移 |
| 角色锚点卡 | 人脸/服装一致性 | 每镜换脸 |
| 场景锚点卡 | 空间一致性 | 每镜换房间 |
| 连续性状态表 | 跨镜状态传递 | 道具/伤势漂移 |

## 15.2 资产拆分

分镜里的元素分为四类资产，**必须分开生成再合成或分别管理**：

| 资产类型 | 内容 | 生成方式 |
| --- | --- | --- |
| 角色资产 | 正面/侧面/全身/表情组/服装 | 单独生成，确立锚点 |
| 场景资产 | 空间全景/各机位视角/关键角落 | 单独生成，确立锚点 |
| 道具资产 | 关键道具多角度特写 | 单独生成 |
| 镜头资产 | 最终画面（图或视频） | 结合以上三者生成 |

**不要试图用一个提示词同时生成角色+场景+复杂动作。** 一致性会崩。

## 15.3 角色锚点卡格式

```yaml
character_id: SUJIN
name: 苏瑾
age_range: 24-27
ethnicity: 东亚
face: 鹅蛋脸，眉形平直，右眉尾一颗小痣，鼻梁窄挺
hair: 黑色齐肩直发，中分，无刘海
body: 身高约 165cm，偏瘦
costume_A: 米色羊毛大衣（及膝，左肩雨渍），黑色高领内搭，无饰品
costume_B: 深灰家居服，光脚
anchor_string: "25岁东亚女性，鹅蛋脸，黑色齐肩直发中分，右眉尾一颗小痣，米色羊毛大衣及膝左肩雨渍，黑色高领内搭"
```

`anchor_string` 是逐字复用的字符串，**不允许改写**。

## 15.4 场景锚点卡格式

```yaml
scene_id: SC03
name: 老宅二楼走廊
time: 夜，雨
layout: 深色木地板；右侧三扇关闭的门；尽头一扇窗；左侧墙挂山水画；天花板吊灯未开
key_objects: 黄铜门锁（主卧门，崭新）、门牌、走廊矮柜
light_sources: 窗外街灯（冷青）、走廊尽头小夜灯（暖琥珀）
anchor_string: "老宅二楼走廊，深色木地板，右侧三扇深色木门，尽头带窗，窗外雨夜街灯，墙面米黄剥落，天花板吊灯未开启"
```

## 15.5 连续性状态传递表

按镜头顺序记录"进入本镜时的状态"，生成方按此填提示词：

| 镜号 | 人物状态 | 手持 | 服装/伤势 | 光线 | 时间 |
| --- | --- | --- | --- | --- | --- |
| SH01 | 苏瑾：站立，面向门 | 伞（收拢） | 大衣左肩湿 | 冷青侧光 | 夜 |
| SH07 | 同上 | 伞靠墙（已放下） | 同上 | 同上 | 夜 |
| SH12 | 苏瑾：转身，面向楼梯 | 无 | 同上 | 暖光渐入 | 夜 |

## 15.6 提示词交付格式

每条一行，前置镜号，便于批量处理：

```
EP01-SC03-SH07 | 2.39:1 cinematic realism, film grain, muted palette | medium close-up, over-the-shoulder, slight low angle | 25岁东亚女性苏瑾（锚点串） | 右手抬起指尖触碰黄铜门锁，拇指摩挲，视线下移 | 老宅二楼走廊（锚点串），前景虚焦男性肩部占左1/4 | 走廊暖光右后侧入射，面部左侧入暗，1:6，暖3000K | 三分构图主体偏右，浅景深 | 静态图
```

视频镜头追加运动与时长：

```
EP01-SC03-SH08 | ... | 运动：极缓推近，约画面高5%，3.5s | 首帧同 SH07 末帧
```

## 15.7 首尾帧衔接

AI 视频最难的是镜头之间的衔接。处理方式：

| 方式 | 做法 | 适用 |
| --- | --- | --- |
| 末帧续接 | 取上一镜最后一帧作为下一镜首帧 | 同机位连续动作 |
| 关键帧插值 | 分别生成首帧与尾帧，模型补中间 | 有明确起止的运镜 |
| 独立生成 | 各镜独立，靠剪辑接 | 切镜、换机位 |

在交接单中注明每个镜头采用哪种方式。

## 15.8 不可生成内容的处理

| 内容 | 问题 | 处理 |
| --- | --- | --- |
| 精确文字（门牌、信件） | 模型写不对字 | 后期加字；或在提示词中避免文字入画 |
| 复杂手部动作 | 手指崩坏 | 改景别规避，或手部单独生成合成 |
| 多人快速交互 | 穿模/换脸 | 拆为单人镜 + 反应镜 |
| 精细道具操作 | 变形 | 用特写 + 剪辑暗示 |
| 长镜头复杂运动 | 漂移 | 拆成 2–3 个短镜 |
| 镜子/倒影 | 逻辑错乱 | 避免正对镜面，或后期合成 |

这些不是"做不出来"，是"做出来成本高"。交接时要标明哪些镜头是高风险镜，供制作方评估。

## 15.9 交接单模板

```markdown
# AI 制作交接单

## 项目
- 项目名 / 集数范围 / 画幅 / 总镜头数 / 总时长

## 资产清单
- 角色：3（苏瑾、陈默、父亲）→ 锚点卡见附件 A
- 场景：4（走廊、主卧、楼梯、街道）→ 锚点卡见附件 B
- 道具：5（门锁、伞、药瓶、信、钥匙）

## 镜头清单
- 文件：03_镜头表_EP01.csv
- 提示词：04_提示词_EP01.txt（逐行，含镜号）

## 一致性约束
- 角色锚点串逐字复用，禁改写
- 场景锚点串逐字复用
- 同一场光线方向不变
- 禁色：饱和红（除 SC11 暴力时刻）

## 高风险镜
| 镜号 | 风险 | 建议 |
| --- | --- | --- |
| SH07 | 手部特写 | 单独生成手部素材后期合成 |
| SH12 | 门内咳嗽+转身（复合动作） | 拆为 SH12A 咳嗽反应、SH12B 转身 |

## 验收标准
- 角色一致性：与锚点卡对比，面部特征、发型、服装一致
- 空间一致性：门/窗/家具位置与场景卡一致
- 光线一致性：主光方向与镜头表一致
- 无穿模、无多指、无文字错乱
```

## 15.10 交接后的责任边界

| 事项 | 归属 |
| --- | --- |
| 镜头设计是否合理 | 分镜（本 Skill） |
| 生成结果是否符合镜头设计 | 制作方按验收标准判定 |
| 一致性冲突 | 分镜提供锚点，制作方执行 |
| 需要改设计 | 回到分镜，不在生成阶段私自改 |

## 15.11 自检

- [ ] 五件套齐全
- [ ] 角色/场景锚点串已固定，逐字复用
- [ ] 提示词逐镜编号，可直接投喂
- [ ] 连续性状态表按镜序排列
- [ ] 首尾帧衔接方式已注明
- [ ] 高风险镜已标出并给替代方案
- [ ] 验收标准可判定（不是"看起来像"）
