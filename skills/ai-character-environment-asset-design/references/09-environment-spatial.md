# 09｜场景空间设计

## 1. 先有平面，才有画面

场景资产的第一步不是画好看的图，而是确定**平面布局**。平面决定了：人物怎么走、镜头放哪、门在哪、光从哪进。没有平面的场景，多视角必然崩塌。

## 2. 平面设计要素

| 要素 | 必须明确 | 影响 |
|------|----------|------|
| 空间尺寸 | 长宽高（米）或相对比例 | 镜头焦段、景深、走位时间 |
| 形状 | 矩形 / L 形 / 回字 / 不规则 | 遮挡关系、纵深 |
| 结构 | 承重墙、柱、梁、楼梯、夹层 | 构图分割、视线阻断 |
| 开口 | 门（数量/位置/开启方向）、窗（朝向/尺寸/高度） | 光线动机、进出动线 |
| 分区 | 功能区域划分（如办公区/操作区/储物区） | 场面调度 |
| 家具 | 位置、朝向、体量 | 演员可用空间、前景层次 |
| 动线 | 主要移动路径、视觉引导线 | 镜头调度 |
| 机位空间 | 可放机位的位置与高度 | 分镜可行性 |

## 3. 平面描述法（无绘图工具时）

用「网格 + 方位」文字描述，足以支撑多视角生成：

```
ENV-003 解剖室 平面：矩形 8m(东西) × 6m(南北)，层高 3.6m
北墙：整面瓷砖，中央不锈钢双开门（宽 1.6m，向外开），门西侧 1.2m 处为器械柜
东墙：两扇高窗（离地 1.5m，宽 1.2m），窗外为天井
南墙：无开口，挂白板与值班表
西墙：冷藏柜四组，靠墙排列，占墙长 4m
中央：不锈钢解剖台（2.2m × 0.8m），长边东西向
西北角：洗手台 + 更衣柜
主光：东窗侧光，上午强、下午弱；顶灯为 4 组条形 LED，冷白 5000K
机位：可从西南角获得过肩全景；特写机位在台头位置
```

## 4. 空间叙事

- **空间即人物**：整洁到冷酷 vs 杂乱到窒息，用空间表达角色心理。
- **门的政治**：谁能进入、门开向谁、门是否可以锁，是权力关系。
- **视觉焦点**：每个场景应有一个"第一眼"落点，且该落点在多个视角中位置合理。
- **出口压力**：封闭空间的紧张感来自出口可见但不可达。

## 5. 与分镜的耦合

在平面确定后，用一张「机位图」标注：
- 每个镜头的机位点（编号 SHOT-XXX-XXX）。
- 镜头朝向与焦段。
- 演员进出的路径。

这能提前暴露"这个镜头拍不到"的问题，避免资产做完才发现分镜不成立。

## 6. 常见错误

| 错误 | 后果 |
|------|------|
| 无平面直接出图 | 反打视角门窗位置对不上 |
| 窗户朝向随意 | 光影方向在不同镜头相反 |
| 家具只放不定位 | 演员走位穿透家具 |
| 空间过大 | 对话场景需要长焦，氛围变远 |
| 忽略层高 | 仰拍时天花板缺失 |

## 7. 交付

1. 平面文字描述（或示意图）。
2. 尺寸与材质表。
3. 机位图说明。
4. 动线说明。
5. 与关联角色的空间关系说明。
