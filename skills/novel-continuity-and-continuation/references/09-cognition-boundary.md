# 09｜人物认知边界管理

## 三层认知模型

| 层面 | 掌握的信息 | 约束对象 |
|---|---|---|
| 作者层 | 完整故事信息（含所有秘密、伏笔答案、未来计划） | 创作系统/作者 |
| 人物层 | 每个角色根据其经历、身份和已接触的信息掌握的内容 | 正文中的角色行为 |
| 读者层 | 正文已经向读者揭示的信息 | 悬念管理 |

## 核心铁律

1. **人物不是作者**：人物不能自动知道作者知道的全部信息。角色的每个判断、行动只能基于其认知范围内的信息。
2. **读者不是人物**：读者也不知道尚未通过正文揭示的秘密。叙述中不得泄露视角人物不知道的信息（有限视角时）。
3. **信息获取有路径**：人物获得新信息必须有合理途径——亲历、被告知、偷听、推理、文书证据。无路径的「恰巧知道」是认知越界。
4. **认知不明确时保守处理**：当无法确认某人物是否知道某信息时，不得为了方便续写而随意赋予人物新信息；先回溯检索其经历，仍无法确认则与用户核实。

## 认知边界档案

在人物档案（references/04）的「掌握的信息 / 不知道的信息」字段中维护：

```
【C-003 掌握的信息】
- 知道密室机关的位置（第X章亲自发现）
- 知道 A 是内奸（第Y章 B 告知）
【C-003 不知道的信息】
- 不知道 B 已倒戈（信息在其倒戈后未接触）
- 不知道自己的身世（伏笔 FB-007，计划第Z章揭示）
```

## 信息传播追踪

多条信息在人物间传播时，追踪「谁在哪一章通过什么途径知道了什么」：

```
【信息编号】I-001：真凶是 X
【产生】第5章（事件发生）
【传播链】
  - 第8章：Y 目击线索，产生怀疑（未确证）
  - 第15章：Y 告知 A（A 已知）
  - 尚未告知：B、C
```

## 续写中的应用检查

写对话和决策前逐人核对：

1. 该角色在此场景中说这句话，是否基于其已知信息？
2. 该角色的反应（惊讶/平静/恐惧）是否与其信息量匹配？——知道内情的人不该对相关消息表现震惊。
3. 该角色的推理是否跳步？其结论必须能从其已知信息合理推出。
4. 保密动机是否成立？知道秘密的角色为何不说，需要有性格、立场或情境上的理由。
5. 视角纪律：有限视角章节中，叙述信息量不超过视角人物的感知范围。

## 常见认知越界类型

| 类型 | 表现 | 等级 |
|---|---|---|
| 无径知晓 | 角色说出不可能接触到的信息 | 严重冲突 |
| 反应失当 | 对自己不应知情的消息作出知情反应 | 潜在冲突 |
| 推理跳步 | 结论超出已知信息的支撑范围 | 潜在冲突 |
| 视角泄底 | 叙述泄露视角人物不知道的信息 | 连续性风险 |

注意：全知视角作品中「视角泄底」由作者控制，属叙事策略而非错误，检查前先确认 L1 记忆中的叙事视角设定。
