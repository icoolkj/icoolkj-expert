# 16 综合质量验收：交付前的最后一道门

验收不是"再看一遍"，是按清单逐项打勾。任一项未过，不得报完成。

## 16.1 五道门

| 门 | 检查对象 | 通过条件 |
| --- | --- | --- |
| 一 事实门 | 与剧本的一致性 | 无篡改、无未标注新增 |
| 二 叙事门 | 镜头是否服务剧情 | 每镜有功能，无冗余 |
| 三 技术门 | 字段与连续性 | 18 字段齐、P0 冲突清零 |
| 四 美学门 | 风格统一 | 与视觉方案一致 |
| 五 交付门 | 可用性 | 下游可直接开工 |

## 16.2 事实门

- [ ] 人物身份、关系与剧本一致
- [ ] 事件顺序未改（若调整揭示顺序，已标 `[建议]`）
- [ ] 核心对白未改写
- [ ] 伏笔已视觉化，无遗漏
- [ ] 角色认知边界未被突破（无人说出他不该知道的事）
- [ ] 所有新增视觉设计已标 `[建议]` 或 `[转译]`
- [ ] `visual_prompt` 中不含未确认的 `[建议]` 内容

## 16.3 叙事门

- [ ] 每场能用一句话说出功能
- [ ] 每个镜头有 `shot_function`，且同场内无三个以上重复功能
- [ ] 无"删掉也不影响"的镜头
- [ ] 每场有建立、转折、落点
- [ ] 关键信息有专门镜头承载（不靠台词带过）
- [ ] 每场有顿点，不是一路平推
- [ ] 场末落点有设计
- [ ] 场间衔接方式已写明

## 16.4 技术门

- [ ] `shot_id` 无重复，格式统一
- [ ] 18 字段无空缺（未知填"待确认/待估"）
- [ ] 枚举字段使用规范值（景别/机位/运镜/转场）
- [ ] 时长格式可统计（`3.5s` 或"待估"）
- [ ] 已运行 `shotlist_lint.py`，报错已处理
- [ ] 连续性十项逐项核过
- [ ] P0 冲突清零
- [ ] 动作接的衔接点在两个镜头都写明
- [ ] 银幕方向一致
- [ ] 视线高度/方向/距离匹配

## 16.5 美学门

- [ ] 与视觉方案的画幅一致
- [ ] 景别策略与方案一致（无突然的极远/极近滥用）
- [ ] 机位基准高度统一，越界有理由
- [ ] 动镜比例在方案规定范围内
- [ ] 同一场光位与色温一致
- [ ] 色彩策略执行（有禁色则未违规）
- [ ] 母题按计划出现，未过度重复
- [ ] 无"炫技型"设计残留

## 16.6 交付门

- [ ] 九段式交付件齐全（或按约定档位）
- [ ] 每场有统计块（镜头数/时长/景别分布/动镜比例）
- [ ] 待确认事项已分三档：影响拍摄 / 影响生成 / 仅影响美观
- [ ] 交接五件套齐全（角色卡/场景卡/提示词/连续性表/镜头表）
- [ ] 高风险镜已标出
- [ ] 文件命名与版本号规范
- [ ] 新人拿到文件能直接开工

## 16.7 抽样放映法

清单之外，做一次"脑内放映"：

1. 只读镜头表的"画面描述"列，按顺序默读。
2. 遇到以下情况即记录：
   - 想不出画面 → 描述不合格
   - 画面跳了但不知道为什么 → 衔接缺失
   - 连续三镜画面差不多 → 景别/构图单调
   - 不知道人物在哪 → 空间丢失
   - 觉得无聊 → 节奏问题
3. 放映完，若能在脑内完整看完一场且不卡，这场基本合格。

## 16.8 常见"看起来完成但其实没完成"

| 表象 | 实际缺什么 |
| --- | --- |
| 镜头表填满了 | `continuity` 全是"无"或空话 |
| 描述很长 | 全是形容词，无可画信息 |
| 有视觉方案 | 方案与镜头表对不上 |
| 有提示词 | 人物锚点每镜不同 |
| 有连续性表 | 只填了人物，道具没填 |
| 镜头数很多 | 功能重复，实际信息量少 |
| 每场都好看 | 场与场之间没有节奏差 |

## 16.9 交付声明模板

```markdown
## 交付说明

本次交付：EP01 全 6 场，共 87 镜，总时长 4 分 12 秒。
采用模式：C（完整分镜）
画幅：9:16（用户指定）

已完成：
- 导演分析（6 场）
- 视觉方案（含母题 4 项、禁色 1 项）
- 镜头表 18 字段全填
- 连续性检查：P0 冲突 0 项，P1 冲突 3 项（见附表）
- [建议] 项 12 处，均已列入待确认

未完成 / 需确认：
- SC06 门内人物身份剧本未明，镜头按"不露脸"处理，待确认
- 3 处 P1 冲突需用户取舍（已附替代方案）

限制说明：
- 未包含拍摄计划、预算、通告
- 未包含最终成片剪辑
```

## 16.10 验收失败的处理

| 情况 | 处理 |
| --- | --- |
| 技术门未过 | 修完再交，不解释 |
| 叙事门未过 | 回到拆镜阶段，不在描述层修补 |
| 事实门未过 | 立即停手，回到剧本核对，可能需重做 |
| 美学门未过 | 回到视觉方案统一，逐场对齐 |
| 用户催交 | 明确说清哪道门未过、代价是什么，让用户决定 |

**验收不合格时如实报告，不隐瞒、不用"基本完成"模糊表述。**

## 16.11 最终确认

交付前最后三问：

1. 如果我是剪辑师，拿到这份分镜能不能直接剪？
2. 如果我是生成方，拿到提示词能不能直接出图？
3. 如果我是导演，看这份分镜会不会觉得"这不是我想拍的"？

三问皆过，方可交付。
