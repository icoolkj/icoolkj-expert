# 05 对白标准化

对白标准化只处理"怎么标注、怎么排版"，不处理"说什么"。

## 5.1 基本格式

```
苏瑾（压低声音）：
你确定他们已经进来了？
```

规则：

- 人物名 + 可选表演提示 + 全角冒号，**冒号后可换行**；换行写法优于同行写法（便于配音分轨与机器解析）。
- 表演提示用全角圆括号，紧贴人物名，中间不留空格。
- 一个说话人一段，不把两人台词写在同一段。
- 台词内容不加引号。
- 台词开头不加空格，不加 `-`、`>` 等提示符。

同一项目内冒号后的换行方式必须一致，不得一半换行一半紧跟。

## 5.2 对白类型与标注

| 类型 | 署名写法 | 用途 |
| --- | --- | --- |
| 正常对白 | `苏瑾：` | 现场同期声 |
| 画外音（OS） | `苏瑾（OS）：` | 人物在场外/画面外说话，如隔壁房间、背对镜头 |
| 内心独白 | `苏瑾（内心）：` 或 `苏瑾（OS）：` | 项目内二选一 |
| 旁白/解说（VO） | `旁白（VO）：` | 非剧中人物视角的叙述者 |
| 电话声音 | `陈默（电话）：` | 需同时说明对方是否可见 |
| 广播/媒体 | `【广播：…】` | 无具体说话人 |
| 群体 | `众人：` | 多人同时 |
| 非人物声音 | `【音效：…】` | 不作对白处理 |

**OS / VO 必须在项目内定义一次并写进规范卡。** 中文剧本里二者常被混用，统一比"正确"更重要。

推荐定义（可被用户规范覆盖）：

- OS = Off Screen，画面外的人声，声音源是剧中人物。
- VO = Voice Over，叙述性人声，声音源不是当前场景中的角色。

## 5.3 表演提示（括号内容）

允许写：语气（`压低声音`、`冷笑`）、对象（`对陈默`）、动作伴随（`起身`）、语言状态（`普通话`、`方言`、`哽咽`）。

不允许写：

- 心理活动：`（心里很难过）` → 应转为可表演的外在表现，或保留原文列入建议。
- 镜头指令：`（特写）`、`（推近）`。
- 导演评价：`（这里要演出层次感）`。
- 剧情解释：`（其实她是装的）` —— 这会提前泄露信息。

提示长度建议不超过 12 字；过长说明写成了描述，应移到动作行。

## 5.4 打断、叠话、停顿

| 意图 | 写法 |
| --- | --- |
| 被打断 | 台词末尾加 `——`，下一人台词直接接上 |
| 拖长音 | `你——` 或 `你……`，项目内统一 |
| 停顿 | `……`，或在括号内写 `（停顿）` |
| 两人同时 | 第一人台词后加 `【叠：陈默】`，再写陈默台词，或人物行注明"叠话" |
| 沉默 | 写动作行，不写 `苏瑾：（沉默）` 空台词 |

空台词（有署名无内容）一律视为需要处理的问题：或补 `（沉默）`，或改为动作行。

## 5.5 台词长度

- 单条台词超过 120 字：标注为 P3 建议，提示可能需按语义切分为两条（短剧镜头节奏通常 3–8 秒一句）。
- 切分不得改变语义和语气，不得新增内容。
- 长独白、旁白段落不适用此阈值，按原稿保留。

## 5.6 语言风格保护

标准化**不得**做以下"润色"：

- 修掉人物口头禅、语病、重复词。
- 把方言改成普通话。
- 把粗俗表达改成书面语。
- 统一不同人物的说话长度和用词。
- 给台词加书面连接词（"因此""然而"）。

只允许修：错别字（明显笔误）、标点、署名、格式。错别字修改须记入修改记录；不确定是否为笔误的（如方言用字、谐音梗）不得改。

## 5.7 电话与跨空间对白

- 电话戏：每句都标 `（电话）`，或在本场首次出现时用动作行说明"苏瑾接起电话，陈默的声音从听筒传出"，后续仅在切换说话人时标注。
- 跨空间交叉剪辑：用 `【切至：…】` 明确空间，不在一场内混写两地。
- 视频通话：`（视频）`，并说明画面可见性（是否需要对方画面）。

## 5.8 字幕与台词的关系

- 字幕内容属于标注层：`【字幕：三年后】`。
- 台词的外语原文/译文如需同屏，写 `【字幕：…】`，不在台词后加括号译文。
- 不得把需要配音的台词写成字幕，也不得把字幕写成台词。

## 5.9 对白检查清单

- [ ] 每条对白都有署名，署名均为标准名
- [ ] 冒号全角，冒号后换行方式全稿一致
- [ ] 表演提示全角括号、长度合理、不含心理与镜头指令
- [ ] OS/VO/电话/广播等特殊声音均已标注且标记统一
- [ ] 无空台词、无孤立署名
- [ ] 无两人台词挤在同一段
- [ ] 语言风格未被统一化"润色"
- [ ] 超长台词已列为建议项（未擅自拆分）
