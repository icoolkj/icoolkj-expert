# 逐镜分镜描述卡

> 用法：每个镜头一张。用于评审、画稿、AI 生成。
> 六段式必须齐全，缺段即不合格。

---

## 模板

### EP__-SC__-SH__ ｜ 景别 ｜ 机位 ｜ 时长 ｜ 功能

| 参数 | 值 |
| --- | --- |
| 集数 / 场次 | |
| 景别 | |
| 机位角度 | |
| 构图 | |
| 运镜 | |
| 时长 | |
| 镜头功能 | |
| 与上镜关系 | 动作接 / 视线接 / 硬切 / 其他 |

**起始**（画面第一眼：景别 + 主体位置 + 环境）

> 

**主体**（画面中最重要的元素及其状态）

> 

**动作**（本镜发生的变化：人物动作 / 光线变化 / 物体移动）

> 

**摄影**（固定或运动；运动写方向、幅度、起止）

> 

**结束**（落幅构图，最后一帧是什么样）

> 

**声音**（对白 / OS / 环境 / 音效 / 音乐 / 静默）

> 

**光影**（光源位置、方向、色温、受光面、明暗比）

> 

**连续性**（本镜必须维持：手持物、服装、湿痕、伤势、朝向、时间）

> 

**视觉提示词**

> 画幅 + 风格 ｜ 景别, 机位 ｜ 角色锚点 ｜ 动作 ｜ 场景锚点 ｜ 光 ｜ 构图 ｜ 质感

## 示例（可直接对照）

### EP01-SC03-SH07 ｜ 近景 ｜ 过肩 ｜ 3.5s ｜ 揭示

| 参数 | 值 |
| --- | --- |
| 集数 / 场次 | EP01 / SC03 老宅二楼走廊·夜·雨 |
| 景别 | 中近 → 近景（推近） |
| 机位角度 | 过肩，略低 |
| 构图 | 前景遮挡（左 1/4 虚焦肩部）+ 三分偏右 |
| 运镜 | 缓推，2 秒内推至近景 |
| 时长 | 3.5s |
| 镜头功能 | 揭示（观众首次看清锁是新的） |
| 与上镜关系 | 视线接（承接 SH06 她看向门） |

**起始**：过肩中近景，前景陈默右肩虚焦占左侧 1/4。苏瑾位于右三分线，侧身面向门，左肩贴画面边缘。

**主体**：她右手抬起，指尖触到黄铜锁芯。锁面反出走廊暖光的一点高光。

**动作**：拇指摩挲锁芯，动作由快到停；视线从锁移到门缝下方。

**摄影**：固定起幅，第 2 秒开始极缓推近，2 秒内景别从中近变近景。

**结束**：近景，锁孔占画面右下，她的眼睛在画面上方偏左，视线向下。

**声音**：雨声持续（窗外，中等）；钥匙串轻响；无对白；SH06 的音乐尾音在此收干。

**光影**：走廊暖光（3000K）从右后侧射入，她的面部左侧落入阴影，明暗比约 1:6；锁面一处镜面高光。

**连续性**：右手持伞已收拢靠墙（SH05 建立）；大衣左肩湿痕；头发半湿贴额；陈默站位不变（其右肩在前景）。

**视觉提示词**：2.39:1 电影感写实摄影，胶片颗粒，低饱和 ｜ 中近景，过肩略低机位 ｜ 25 岁东亚女性，鹅蛋脸，黑色齐肩直发中分，右眉尾一颗小痣，米色羊毛大衣及膝左肩雨渍，黑色高领内搭 ｜ 右手抬起指尖触碰黄铜门锁，拇指摩挲，视线下移 ｜ 老宅二楼走廊，深色木地板，右侧深色木门，墙面米黄剥落 ｜ 暖光 3000K 右后侧入射，面部左半入暗，明暗比 1:6 ｜ 前景虚焦男性肩部占左 1/4，主体右三分线，浅景深

**备注**：`[待确认]` 门牌文字内容（生成时避免文字入画，后期加字）。`[建议]` 锁面高光可强化"新"的质感。

## 自检

- [ ] 六段（起始/主体/动作/摄影/结束/声音）齐全
- [ ] 无抽象心理词
- [ ] 有起始与落幅，剪辑师知道何时切
- [ ] 光影有方向、色温、明暗比
- [ ] 连续性写清手持物与状态
- [ ] 提示词含角色锚点串，措辞与锚点卡一致
- [ ] `[建议]` 未混入既定事实
