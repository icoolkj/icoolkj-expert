# 05 景别与机位：决定观众看多少、从哪看

景别控制**信息量**，机位控制**立场**。两者合起来决定观众与人物之间的心理距离。

## 5.1 景别体系

| 景别 | 画面范围 | 信息功能 | 心理效果 | 常见误用 |
| --- | --- | --- | --- | --- |
| 大远景 ELS | 人物极小，环境为主 | 地理、时代、孤立 | 渺小、宿命 | 用在需要看清表情的段落 |
| 远景 LS | 全身 + 大量环境 | 空间关系、行动 | 客观、旁观 | 台词多时用，观众看不清 |
| 全景 FS | 全身，脚到头顶 | 完整动作、姿态 | 完整、可信 | 竖屏下人物占满高度，无环境 |
| 中全 MFS | 膝以上 | 动作 + 部分环境 | 平衡 | 最常被滥用成"万能镜" |
| 中景 MS | 腰以上 | 手势、姿态、互动 | 社交距离 | 情绪高点仍用中景，力量不足 |
| 中近 MCU | 胸以上 | 表情、反应 | 亲近 | — |
| 近景 CU | 肩以上 | 情绪、决定 | 侵入 | 连续多个近景造成拥挤 |
| 特写 ECU | 局部（眼、手、物） | 细节、象征 | 强调、压迫 | 用来"说明"而非"呈现" |
| 大特写 BCU | 极局部（瞳孔、指尖） | 极端强调 | 几乎生理性 | 滥用即失效 |

### 景别选择判据（按优先级）

1. **观众此刻必须获得什么信息？** 关系→中全以上；决定→近景以上；变化→特写。
2. **人物在此刻是否愿意被看？** 越不愿被看，越用近景，制造不适。
3. **这一场的信息密度** 高密度用中景承载，低密度才允许长特写。
4. **上一镜是什么景别？** 同景别不连排超过 3 个（除非刻意）。

### 景别节奏

| 段落 | 景别走向 |
| --- | --- |
| 进入新空间 | 远 → 中（先给地理，再给人） |
| 冲突升温 | 中 → 中近 → 近（逐步收紧） |
| 情绪爆点 | 在近景停留，或突然切到特写 |
| 收尾 | 近 → 中 → 远（逐步放开） |
| 制造压迫 | 长时间不跳景别，突然跳 |

## 5.2 机位高度

| 高度 | 效果 | 适用 |
| --- | --- | --- |
| 地面/极低 | 压迫、威胁、动物视角 | 打斗、恐惧、儿童视角 |
| 低机位仰拍 | 强大、威压、崇高 | 权力方、英雄时刻 |
| 平视（眼高） | 平等、客观、可信 | 对话主体 |
| 略高俯拍 | 弱势、被审视 | 被质问者 |
| 高机位俯拍 | 无力、被命运俯视 | 崩溃、失败、孤立 |
| 顶视 90° | 图形化、宿命、去人格 | 转场、死亡、仪式 |

**规则**：全片要有统一的"基准高度"。基准之外的机位都是表达，需要理由。

## 5.3 机位角度（水平）

| 角度 | 画面特征 | 叙事用法 | 注意 |
| --- | --- | --- | --- |
| 正面 0° | 直面观众，最强情绪 | 关键台词、对峙 | 过多显得呆板 |
| 四分之三侧 45° | 最自然、有立体感 | 常规对话 | 安全但平淡 |
| 侧 90° | 侧面轮廓，关系感强 | 两人对峙、并行 | 表情信息减少 |
| 背面 | 隐藏表情，看其所看 | 悬念、隐瞒、跟随 | 观众会不安 |
| 过肩 OTS | A 肩部前景带 B 的脸 | 对话标准配置 | 注意肩部不挡关键信息 |
| 主观 POV | 角色所见 | 代入、窥视、恐惧 | 必须交代"这是谁在看" |
| 荷兰角 | 倾斜地平线 | 失衡、疯狂、危险 | 一场不超过一次 |

### 正反打三件套

对话戏的基本配置：

1. **主镜（Master）**：双人中全，交代空间与相对位置。
2. **过肩 A/B**：两次，分别从各自肩后拍对方。
3. **单人近景**：情绪高点切入，可只给一方（表示力量失衡）。

三件套不是必须全用。**只给一方近景，就是明确表态"这场戏属于他"。**

## 5.4 主观镜头规则

| 条件 | 要求 |
| --- | --- |
| 必须有归属 | 前一个镜或后一个镜要交代"谁在看" |
| 视高要匹配 | 角色身高、姿势（坐/躺/蹲）决定机位高度 |
| 视野要匹配 | 受伤/醉酒/恐惧可加变形，正常状态不加 |
| 不能连续滥用 | 两个以上连续 POV 会让观众失去方位 |
| 与客观镜区分 | 必要时用一个"角色入画"的镜头拉回客观 |

## 5.5 景别—机位组合速查

| 目的 | 组合 |
| --- | --- |
| 交代空间 | 远景 + 平视 或 高机位俯拍 |
| 建立人物权力 | 中全 + 低机位仰拍 |
| 表现被压制 | 中近 + 略高俯拍 + 人物贴画面下缘 |
| 制造亲密 | 近景 + 平视 + 浅景深 |
| 制造威胁 | 近景 + 略低机位 + 人物逼近镜头 |
| 表现孤立 | 大远景 + 人物居中偏小 或 全景 + 人物贴边 |
| 窥视感 | 过肩/前景遮挡 + 长焦压缩 |
| 失衡 | 荷兰角 + 手持 + 近景 |

## 5.6 竖屏（9:16）特殊处理

| 问题 | 对策 |
| --- | --- |
| 横向空间不足 | 用前后景纵深代替左右并列 |
| 人物易满屏 | 多用中近，但建立空间靠俯拍全景（纵向容纳） |
| 双人同框困难 | 上下构图（一人站一人坐）、一实一虚、一人画内一人画外 |
| 特写压迫感过强 | 特写比例下调，用中近替代 |
| 字幕区占用下方 | 构图重心上移，避免信息落在下三分之一 |

## 5.7 常见错误

1. **万能中全**：全片 MFS，无远近变化 → 观众疲劳，重点不突出。
2. **特写通胀**：情绪没到就用特写 → 真正需要时已无力量。
3. **机位无理由**：仰拍反派却无权力关系依据 → 观众读不懂。
4. **越轴不自知**：正反打机位跨过轴线 → 观众瞬间失去方位（见 09 号文件）。
5. **POV 无主**：突然主观镜头，观众不知谁在看。
6. **忽视身高差**：儿童/坐者场景仍用成人平视 → 空间失真。

## 5.8 自检

- [ ] 每场有景别跳变，且跳变落在转折点
- [ ] 同景别未连排超过 3 个（或已说明理由）
- [ ] 关键台词有对应的机位表态
- [ ] POV 有归属交代
- [ ] 全片机位高度有统一基准，越界有理由
- [ ] 竖屏项目已按 5.6 调整
