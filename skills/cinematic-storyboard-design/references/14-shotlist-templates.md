# 14 镜头表与分镜模板规范

镜头表是分镜的"数据库"，分镜描述是"正文"。两者互为索引。

## 14.1 编号规则

```
EP{集}-SC{场}-SH{镜}
EP01-SC03-SH07
```

| 规则 | 说明 |
| --- | --- |
| 集号 | 两位数，与剧本一致 |
| 场号 | 两位数，沿用标准化剧本；无则自编并在备注标"自编场号" |
| 镜号 | 两位数，场内连续，不跨场连编 |
| 插入镜 | 用 `SH07A`，不重排后续编号 |
| 删除镜 | 保留编号写"已删"，不回收编号 |

**不重排编号**：一旦交付，编号即引用锚点。改动只增不改。

## 14.2 十八个字段的填写细则

| 字段 | 必填 | 填写细则 | 常见错误 |
| --- | --- | --- | --- |
| shot_id | 是 | 按 14.1 格式 | 编号重复、跨场连编 |
| episode | 是 | EP01 | 与 scene_id 不一致 |
| scene_id | 是 | SC03 | 用了剧本没有的场号未标注 |
| duration | 是 | `3.5s`；未知写"待估" | 写"约 3 秒左右"无法统计 |
| shot_function | 是 | 单值：建立/推进/揭示/反应/强调/过渡/停留 | 写"表现情绪"（不是功能） |
| shot_size | 是 | 见 05 号文件九级 | 写"中景偏近"（不在枚举内） |
| camera_angle | 是 | 平视/俯/仰/侧/背/主观/过肩/荷兰角 | 与 shot_size 混淆 |
| composition | 是 | 三分/中心/对称/框架/遮挡/引导线/留白 | 只写"好看" |
| camera_movement | 是 | 固定/推/拉/摇/移/跟/升降/手持/组合 | 写"缓慢移动"（方向不明） |
| visual_description | 是 | 六段式，见 12 号文件 | 含抽象词 |
| character_blocking | 是（有人物时） | 初始→过程→终态 | 只写"站在窗边" |
| performance | 是（有人物时） | 外部可执行表现 | 写"悲伤" |
| lighting | 是 | 方向+质量+明暗比 | 写"氛围光" |
| dialogue_audio | 是 | 六层分列，无内容写"无" | 混写"音效：紧张音乐" |
| transition | 是 | 切/叠化/淡/划/匹配/硬切对撞 | 留空 |
| continuity | 是 | 本镜需维持的状态 | 留空（最常见） |
| visual_prompt | C/E 模式必填 | 见 12 号文件结构 | 含未确认的 `[建议]` 内容 |
| notes | 否 | 待确认、风险、替代方案 | 把重要信息只写在这里 |

## 14.3 镜头表格式

### Markdown 表格（默认交付）

适合阅读与评审，18 列过宽时拆为两张表：

- 表 A：编号 / 集 / 场 / 时长 / 功能 / 景别 / 机位 / 构图 / 运镜
- 表 B：编号 / 画面描述 / 调度 / 表演 / 光影 / 声音 / 转场 / 连续性 / 提示词 / 备注

### CSV（供脚本与表格软件）

表头用字段键名或中文字段名均可，`shotlist_lint.py` 都识别。

```csv
shot_id,episode,scene_id,duration,shot_function,shot_size,camera_angle,composition,camera_movement,visual_description,character_blocking,performance,lighting,dialogue_audio,transition,continuity,visual_prompt,notes
```

## 14.4 分镜描述卡（逐镜）

每个镜头一张卡，用于评审、画稿、生成：

```markdown
### EP01-SC03-SH07 ｜ 近景 ｜ 过肩 ｜ 3.5s ｜ 功能：揭示

**起始**：过肩，前景陈默右肩虚焦占左侧 1/4。苏瑾位于右三分线，面向门。
**主体**：她右手抬起，指尖触到黄铜锁芯。
**动作**：拇指摩挲锁芯，动作由快到停；视线由锁移到门缝。
**摄影**：固定，第 2 秒起极缓推近。
**结束**：近景，锁孔在右下，她的眼在上方，向下看。
**声音**：雨声；钥匙串轻响；无对白。
**光影**：走廊暖光从右后侧来，面部左侧入暗，1:6。
**连续性**：右手持伞（收拢，靠墙）；左肩湿。
**备注**：[待确认] 门牌文字内容。
```

## 14.5 三档详细度

用户未指定时按"标准"输出，可按需升降。

| 档 | 内容 | 适用 |
| --- | --- | --- |
| 简版 | 只有镜头表 A（编号/景别/机位/运镜/一句话画面） | 快速过稿、预算沟通 |
| 标准 | 镜头表 A+B + 逐镜描述卡 | 常规交付、评审 |
| 完整 | 标准 + 视觉方案 + 连续性表 + 提示词 + 交接单 | AI 制作、实拍执行 |

## 14.6 场次统计块

每场末尾必须给实际统计（不是目标）：

```
SC03 统计：镜头 14 个｜总时长 52s｜平均 3.7s｜
景别分布：全景 1 / 中全 2 / 中景 4 / 中近 3 / 近景 3 / 特写 1｜
动镜 3 个（21%）｜最长镜 SH12（6s）｜最短镜 SH06（1.2s）
```

统计能立刻暴露问题：动镜比例过高、景别集中、平均时长过短。

## 14.7 版本管理

| 项 | 规则 |
| --- | --- |
| 版本号 | v1.0 初稿；v1.1 局部修订；v2.0 结构性调整 |
| 文件名 | `项目名_分镜_v1.1_EP01-EP03.md` |
| 变更记录 | 每次改动列：镜号、改了什么、为什么 |
| 废弃内容 | 不删，移到"已废止"节并注明原因 |
