# 13 质量检查清单

交付正文前逐项过一遍。**每项须给依据，不得用"整体不错"代替。**

## A. 硬性红线（任一不通过，不得交付）

- [ ] 有信息越界：人物说出了他此刻不可能知道的事。
- [ ] 有人物失真：核心人物做出违背其动机的选择，且无解释。
- [ ] 有连续性错误：与前文事实直接冲突（伤、位置、时间、物品、生死）。
- [ ] 有临时放宽：为解决问题放宽了已定的能力或规则边界。
- [ ] 有巧合解决：核心矛盾靠偶然解除。
- [ ] 有元叙述：正文出现"本章""且说""读者""接下来"。
- [ ] 有创作说明混入正文：括号注释、写作笔记、待办标记。

## B. 结构（本章能否立住）

- [ ] 本章目标是否明确、具体到可失败？
- [ ] 是否发生了不可逆的变化？写出这一句变化。
- [ ] 变化是否由人物选择造成，而非外部事件砸下来？
- [ ] 本章是否服务于本卷目标？
- [ ] 转折是否有前置铺垫（≥1 处）？
- [ ] 结尾是否形成承接，而非总结抒情？
- [ ] 本章是否有可整段删除而不影响任何东西的部分？占比多少？

## C. 场景

- [ ] 每场有明确时间、地点、在场人物？
- [ ] 每场有"谁想从谁那里拿到什么"？
- [ ] 进场是否直接（没有起床、走路、抵达描写）？
- [ ] 环境描写是否在"干活"（影响行动/情绪/信息）？
- [ ] 场景数量是否合理（2–4 场）？有无该合并的？

## D. 人物

- [ ] 每个出场人物是否有当下目标？
- [ ] 选择是否符合其欲望与恐惧？
- [ ] 是否体现身体状态（伤、累、饿）？
- [ ] 是否有配角只为推剧情存在？
- [ ] 反派本章是否有自己的行动逻辑？

## E. 对话

- [ ] 遮住人名能否分辨谁在说话？
- [ ] 是否有超过 8 句不插入动作的对话块？
- [ ] 是否有"为了告诉读者"而说的话？
- [ ] 是否有人物在解释双方都知道的事？
- [ ] 潜台词是否足够（有没有太直白的地方）？

## F. 语言

- [ ] 抽象词是否都能"看见"（他很悲伤 → 具体动作）？
- [ ] 陈词滥调是否清掉（心中一紧、五味杂陈、空气凝固）？
- [ ] 是否有连续三句同一句式？
- [ ] 形容词密度是否过高？
- [ ] 是否有"作者在说话"的句子？
- [ ] 朗读是否顺畅？

## G. 节奏

- [ ] 前 300 字是否已经抓住（有具体困境或异常）？
- [ ] 中段是否有新信息持续供给？
- [ ] 是否连续两章用同类型章末钩子？
- [ ] 高潮段落是否短句、短段？
- [ ] 本章强度与前后章相比是否合理（不是连续三章满强度）？

## H. 长篇适配

- [ ] 本章是否有 1–2 处对前文的呼应（不是重复，是回响）？
- [ ] 是否给了新读者必要的锚点（不靠解释，靠情境）？
- [ ] 是否埋下或推进了至少一条伏笔？
- [ ] 是否避免了"与上一章同构"的事件序列？
- [ ] 是否需要更新台账的六个字段？

## I. 分级结论

| 结论 | 条件 |
|---|---|
| 可直接交付 | A 全过，B–H 不超过 3 项轻微未过 |
| 小修后交付 | A 全过，B 或 C 有 1 项未过 |
| 需修改再交 | A 有 1 项未过，或 B/C 有 2 项以上未过 |
| 建议重写 | A 有 2 项以上未过，或核心目标未实现 |

## J. 自检话术（反面清单）

交付时**不得**使用：

- "文笔流畅，情节紧凑，人物鲜明。"
- "整体质量较高，个别地方可以再打磨。"
- "本章情感饱满，张力十足。"
- "建议加强细节描写。"（不指明哪一段、怎么加强）

**必须**使用：

- 指明位置（第几段／哪场戏）。
- 指明问题类型（逻辑／节奏／人物／语言）。
- 给出可执行修法（删／换／并／补）。

## K. 交付前最后五问

1. 这一章读完，读者会想知道下一章吗？为什么？
2. 如果我是读者，哪一段会让我想跳过？
3. 这一章能否用一句话讲给朋友听，且他会想听下去？
4. 有没有一句话是我自己特别满意、但其实只是漂亮而无用的？
5. 如果把主角换成另一个人，这一章还成立吗？成立，说明主角没起作用。
