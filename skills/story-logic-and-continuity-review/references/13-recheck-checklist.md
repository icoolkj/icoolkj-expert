# 13 复审检查表

复审不是"再看一遍"，而是**逐条验证 + 回归扫描**。按以下顺序执行，逐项打勾。

---

## 阶段一：前置确认

- [ ] 已拿到修改稿的**版本号与日期**（未确认版本不得开始复审）
- [ ] 已拿到原审校报告（含全部问题编号）
- [ ] 已拿到修改说明；若无，已自行定位改动处（可用版本对比）
- [ ] 已确认作者对"保留原设计"项的表态（这些项不再提）

---

## 阶段二：逐条核对（对每个问题）

对每个问题编号，依次判断：

- [ ] **是否已修改**（文本层面确有变化，而非作者认为改了）
- [ ] **冲突是否消除**（新旧两段陈述现在能否同时为真）
- [ ] **修改是否触及源头**（只改结果不改源头，常致复发）
- [ ] **是否残留同类表述**（全文检索后，同一错误的其他出现处是否也改了）
- [ ] 结果归类：已解决 / 部分解决 / 未解决 / 转化为新问题

**"部分解决"的判定**：主冲突消失，但存在残留的不一致表述。此类必须列出残留位置。

**"转化为新问题"的判定**：修改后不再与旧基准冲突，但产生了新的矛盾。必须用新编号记录，并在说明中标明来源。

---

## 阶段三：回归检查（改动点的八个方向）

对每一个改动点，检查：

- [ ] **事实连锁**：其他地方引用该事实的表述是否还成立
- [ ] **动机连锁**：人物行为的理由是否仍成立
- [ ] **情感连锁**：人物关系的基础是否被削弱（最易漏）
- [ ] **时间线**：改动是否影响任何时间节点、历时、行程
- [ ] **人物状态**：伤势、装备、位置、认知是否出现新的突变
- [ ] **伏笔**：改动是否使某条伏笔的铺设/回收失效
- [ ] **空间道具**：改动是否使场景布局或道具归属出现新矛盾
- [ ] **跨媒介**：是否需要同步更新剧本、分镜、设定文档、资产

---

## 阶段四：新增问题扫描

- [ ] 对改动点前后各一章做一次模式 A 快速通读
- [ ] 检查改动是否引入"解释过度"（把悬念说破）
- [ ] 检查改动是否引入"补丁感"（生硬加句、与前文语气不符）
- [ ] 检查改动是否削弱了原有的人物质感或节奏

---

## 阶段五：台账与文档同步

- [ ] 问题台账中每条状态已更新（含时间戳）
- [ ] 已关闭的问题保留记录，不删除
- [ ] 新增问题已分配新编号（不占用旧号）
- [ ] 事实基准表已按修改更新（旧值标记 DEPRECATED，不直接覆盖）
- [ ] 若为跨媒介项目，统一事实表已更新并标注版本

---

## 阶段六：结论输出

按以下四档给出结论：

| 结论 | 判定条件 |
|---|---|
| **通过** | 全部 P0/P1 已解决；无新增 P0/P1；无新增 P2 影响主线 |
| **有条件通过** | P0/P1 已解决；存在新增 P2 或残留 P3，可在下一版处理（须列出清单） |
| **需再修** | 仍有未解决的 P0/P1，或"部分解决"项涉及主线 |
| **不通过** | 修改引入新的 P0/P1，或修改方向偏离了原问题 |

结论必须附理由，理由中至少包含：已解决数 / 未解决数 / 新增数。

---

## 附：复审中最常见的五个错误

1. **看作者说"改了"就认为改了** —— 必须验证文本。
2. **只看改的那一段** —— 必须做全文检索。
3. **只查事实连锁，不查情感连锁** —— 改了事件，人物关系的基础可能塌了。
4. **新增问题不另编号** —— 导致后续无法追踪。
5. **复审结论含糊** —— "基本可以"不是结论，必须四档之一。
