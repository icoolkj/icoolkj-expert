# 05 品牌定位与差异化

品牌不是视觉稿，是**用户能复述的一句话 + 一套稳定的取舍**。

## 1. 一句话定位

句式三选一，必须能被用户转述：

| 句式 | 模板 | 适用 |
|---|---|---|
| 给谁·解决什么 | 为【人群】提供【价值】的【品类】 | 用户清晰的项目 |
| 不同于谁 | 不像【竞品 A】的【做法】，我们【做法】，所以【体验】 | 有明确竞品时 |
| 世界观式 | 一个关于【母题】的【题材】故事，主角在【处境】中【选择】 | 强内容 IP |

检验标准：说给一个没看过的人，他能否复述出 70%。不能，重写。

## 2. 品牌主张

三层结构，缺一层就不成立：

| 层 | 内容 | 例子方向 |
|---|---|---|
| 功能价值 | 我提供什么内容体验 | 强反转、严世界观、高频陪伴 |
| 情绪价值 | 我让用户感觉什么 | 被理解、被激励、被抚慰 |
| 态度价值 | 我站在哪一边 | 反内卷、女性自主、个体尊严 |

态度价值是品牌能否长期成立的关键，也是最容易空泛的一层——必须能落到具体情节与角色选择上。

## 3. 品牌关键词

- 3–5 个，每个都要能在内容里找到证据（具体人物行为、场景、台词）。
- 同时列**禁区词**：这个 IP 绝不能变成什么（例如"不能变成职场爽文""不做低幼化"）。

| 关键词 | 内容证据 | 商业化含义 | 禁区 |
|---|---|---|---|
| | | | |

## 4. 差异化优势

必须写成可比较的一句：

> 相比【同类】的【做法】，我们【不同做法】，因此【用户获得什么】；代价是【放弃什么】。

三个常见伪差异化：

1. **更用心/更精良**——所有项目都这么说，不构成差异。
2. **设定更新**——除非设定带来不同的情绪体验，否则只是换皮。
3. **元素叠加**（悬疑+甜宠+职场）——叠加不是差异，除非产生新的矛盾结构。

## 5. 视觉识别方向

不产出设计稿，只给**约束条件**，交给 S08 或设计方执行：

| 项 | 要确定的内容 |
|---|---|
| 主色与辅色 | 2–3 色，说明情绪与场景适配 |
| 造型记忆点 | 一个可被画成贴纸的符号（发型/道具/纹样/面具） |
| 风格基调 | 写实/半写实/风格化；冷暖；颗粒感 |
| 一致性规则 | 角色比例、线条、上色规范 |
| 禁用方向 | 与定位冲突的风格（如黑暗题材禁用糖果色） |

## 6. 传播语言

| 项 | 要求 | 反例 |
|---|---|---|
| 语气 | 2 个形容词（克制、锋利、温柔） | "年轻化、有网感" |
| 句式 | 长句/短句、是否用问句 | 无规定 |
| 人称 | 第一人称叙事 / 旁观者 | 混用 |
| 梗的使用 | 允许 / 有限 / 禁止 | 无边界 |
| 对外称呼用户 | 统一称谓（如"读者""同行者"） | 各处不一致 |

## 7. 对外介绍三版

| 版本 | 字数 | 用途 | 结构 |
|---|---|---|---|
| 短版 | 30–50 字 | 平台简介、名片、合作首句 | 谁 + 什么故事 + 什么不同 |
| 中版 | 150–200 字 | 招商页、媒体介绍 | 故事 + 定位 + 数据 + 差异 |
| 长版 | 400–600 字 | 提案首页、投资材料 | 背景 + 故事 + 用户 + 商业 + 团队 |

三版必须自洽，不得中版讲悬疑、长版讲甜宠。

## 8. 传播口号建议

给 3–5 条候选，标注适用场景（海报/短视频/周边/活动）。口号要满足：6–12 字、可独立成立、不依赖上下文、不与定位冲突。

## 9. 品牌长期发展方向

| 方向 | 说明 | 前置条件 |
|---|---|---|
| 内容品牌 | 以作品系列为核心 | 稳定产能 |
| 角色品牌 | 角色独立流通（表情包、代言、联名） | 视觉资产 + 识别度 |
| 创作者品牌 | 作者人格成为资产 | 持续曝光 + 人设稳定 |
| 圈层品牌 | 特定群体的身份符号 | 社群密度 |
| 生活方式品牌 | 从内容延伸至品类 | 强视觉 + 供应链 |

选择 1 个主方向 + 1 个备选，不要全都写。

## 10. 定位自检

- 竞品能否原样使用这句话？能 → 定位无效。
- 这句话是否限定了内容创作方向？不能 → 定位无效。
- 用户能否用它向朋友介绍？不能 → 定位过虚。
- 是否给出了"不做什么"？没有 → 定位没有边界。

## 11. 禁止项

- 改文案不等于建立品牌，必须配套内容取舍。
- 不写无法验证的形容词（顶级、顶级团队、现象级）。
- 不使用绝对化用语（第一、最、唯一）作为宣传。
