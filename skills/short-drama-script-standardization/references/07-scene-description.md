# 07 场景描述标准化

场景描述解决三个问题：在哪、什么时候、空间关系是否说得清。

## 7.1 场景描述的三层信息

| 层 | 位置 | 内容 | 是否必填 |
| --- | --- | --- | --- |
| 标题层 | 场次标题 | 场号、时间、内外景、地点名 | 必填 |
| 补充层 | 首条动作行 | 环境细节、光线、声音、气味、空间布局 | 按需 |
| 变化层 | 场中动作行 | 空间变化（开门、灯灭、下雨） | 按需 |

不要把所有环境信息堆在补充层一次写完；短剧场景通常只用 1–3 个细节定调。

## 7.2 地点命名一致性

- 全稿唯一名称：`陈默的修车行` vs `修车行` 必须选一个作为标准名，另一写法仅在台词内容中出现。
- 标准名结构：`修饰 + 空间类型`，避免"神秘的地方""那个房间"这类指代。
- 同一空间分区域：`苏家别墅·客厅`、`苏家别墅·二楼走廊`。
- 地名层级从大到小：`城西·旧仓库`，避免两种顺序混用。
- 原稿只有"房间""办公室"等泛称时：不允许自拟具体名称；写 `【待确认：地点】`，或保留泛称并在结构清单中注明可复用场景。

## 7.3 内外景与时间的自洽

常见矛盾（P1）：

- 场景写"外"但动作里有"天花板上的灯"。
- 场景写"日"但动作里"路灯昏黄""满街霓虹"。
- 场景写"内"但写"她抬头看天"。
- 时间写"凌晨"但出现"下班高峰"。

判定方法：把标题四要素与场内所有环境细节对撞，逐条核。

## 7.4 空间关系描述

- 一场内首次出现的人物，需交代其位置：`苏瑾坐在沙发左侧，陈默站在门口`。
- 距离关系用可拍的量词描述：`两步外`、`隔着茶几`、`背对背`。
- 门窗、楼梯、通道等"运动路径"要素若在后续被使用，首次需交代。
- 不写"远处"到"近处"的连续运镜，改为场景拆分或标准转场。

## 7.5 场景复用与场景清单

同一地点被多集重复使用时：

- 场景名完全一致，不因集数变化改写。
- 在场景清单中记录出现场次，便于集中拍摄排期。
- 复用时环境细节可省略，但如果与首次描述矛盾（如首次客厅有落地窗、后来变成无窗），属 P1 连续性问题。

场景清单字段：

| 字段 | 说明 |
| --- | --- |
| 场景名 | 标准名 |
| 内外 | 内/外/内外 |
| 出现场次 | 1-1、2-3、5-6 |
| 出现次数 | 数字 |
| 主要人物 | 该场景常驻人物 |
| 特殊需求 | 雨、火、车、动物、群众、特效 |
| 备注 | 与其它场景的连带关系（如同一实景改造） |

## 7.6 场景转换

| 转换类型 | 写法 | 触发条件 |
| --- | --- | --- |
| 同时间异地 | `【切至：地点】` | 平行叙事 |
| 时间跳跃 | `【转场：三小时后】` | 需交代时长 |
| 场景直接切 | 新场次标题 | 默认，无需额外标注 |
| 淡出/淡入 | `【淡出】`、`【淡入】` | 段落收束 |
| 闪回进出 | `【闪回】…【闪回结束】` | 必须成对 |
| 梦/幻想 | `【梦境】…【现实】` | 必须成对 |

不得用叙述句代替转场（"画面一转，已是第二天"），应转为标准标注。

## 7.7 场景描述的可拍性检查

| 检查项 | 不合格示例 |
| --- | --- |
| 是否是真实可搭/可找的空间 | "无边无际的白色空间" |
| 是否依赖无法实现的天气 | "晴天里暴雨倾盆" |
| 是否需要难以获得的道具 | "整面墙的古董钟表" |
| 是否隐含高成本特效 | "整栋楼瞬间倒塌" |
| 是否涉及真实地点/品牌 | "王府井星巴克门口" |

以上只做提示（P2/P3），不作成本结论，也不擅自改写。

## 7.8 环境声与氛围

- 环境声用标注：`【音效：雨声，持续】`。
- 氛围不用形容词堆叠（"压抑而诡异的氛围弥漫"），改用 1 个可拍细节（"灯管闪了两下"）。
- 音乐不写进场景描述，写 `【音乐：…】` 或列入建议。

## 7.9 场景标准化检查清单

- [ ] 每场标题四要素齐全或已标注待确认
- [ ] 地点名全稿唯一
- [ ] 内外景与场内环境细节自洽
- [ ] 时间与光线、活动描述自洽
- [ ] 首次出现的人物有位置交代
- [ ] 转场使用标准标注，无叙述化转场
- [ ] 场景清单已建立，重复场景已归并
- [ ] 特殊拍摄需求已在清单备注
