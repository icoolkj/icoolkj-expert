# 07 专家交接模板

## 使用说明

- 仅在用户确认项目方向后生成交接资料。
- **生成交接文档不代表其他专家已自动执行任务**，必须在交接单首行注明。
- 只交接"已验证/已确认"的内容；`[待确认]`项单独列出，不作为下游的执行依据。
- 按项目需要选择交接对象，不必全部生成。

## 二、分专家交接块

### 2.1 致 世界观架构师

| 交接内容 | 说明 |
|---|---|
| 需建立的设定范围 | 核心规则 / 代价机制 / 空间结构 / 势力 / 历史 |
| 已确定的世界观要素 | |
| 明确不做扩展的部分 | 避免设定膨胀 |
| 设定必须服务的剧情节点 | 哪些设定是为了支撑哪一段情节 |
| 可复用视觉符号 | 跨媒介资产前置 |
| 验收标准 | 设定能否解释主角为何必须这样选择 |

**常见越界提醒**：不要为"完整"而写与主角选择无关的区域志、年表、物种谱。

### 2.2 致 小说主笔

| 交接内容 | 说明 |
|---|---|
| 目标体量与节奏 | 字数、卷数、每章钩子密度 |
| 分卷目标 | 每卷主角目标 + 阻力 + 转折 |
| 主角四要素 | 外部目标 / 内在需求 / 伤口 / 缺陷 |
| 主副线配比 | 主线推进与慢线兑现的章节分布 |
| 禁区 | 不可改变的核心设定与关系走向 |
| 前3章要求 | 必须完成的处境、钩子、记忆点 |

**常见越界提醒**：不要替主笔定死每一章的写法；给结构、给约束、给节点，不给逐句指令。

### 2.3 致 短剧编剧

| 交接内容 | 说明 |
|---|---|
| 集数与单集时长 | |
| 前3集必须完成的信息 | 身份、处境、核心矛盾 |
| 反转密度要求 | 每集≥1次，每8–12集一次大反转 |
| 卡点设计 | 哪几集设置强钩 |
| 必须保留的记忆点 | 哪 2–3 个场景不能删 |
| 可删减内容 | 哪些文戏可压缩为动作/对白 |

**常见越界提醒**：小说到短剧是**重写**，不是浓缩。需明确哪些内容必须"事件化"。

### 2.4 致 影视导演

| 交接内容 | 说明 |
|---|---|
| 主题陈述 | 一句话主题 + 导演可发挥空间 |
| 影像基调 | 色彩、镜头语言、声音方向 |
| 关键场面 | 3–5 个必须成立的视觉段落 |
| 叙事结构 | 是否非线性、视角限制 |
| 制作约束 | 场景集中度、群戏规模 |

### 2.5 致 AI 视觉设计师

| 交接内容 | 说明 |
|---|---|
| 角色清单 | 主要角色 + 关键配角 |
| 角色视觉关键词 | 年龄、体型、服饰体系、标志物、禁用元素 |
| 场景清单 | 需优先产出的 3–6 个场景 |
| 一致性要求 | 哪些元素必须固定（发型、伤疤、配色） |
| 风格参考方向 | 写实/半写实/风格化，避免指定具体在世艺术家风格 |
| 输出规格 | 三视图/表情包/场景概念图/分镜 |

### 2.6 致 故事审校官

| 交接内容 | 说明 |
|---|---|
| 审校重点 | 逻辑一致性、设定冲突、人物动机 |
| 已知薄弱点 | 策划阶段已识别的风险 |
| 判定标准 | 以本交接单的"已确认设定"为准 |
| 输出形式 | 问题清单 + 严重级别 + 修改建议 |

### 2.7 致 IP 运营官

| 交接内容 | 说明 |
|---|---|
| 品牌定位 | 一句话对外介绍 |
| 核心符号 | 可视觉化的标志性元素 |
| 受众画像 | 主画像 + 次画像 |
| 传播卖点 | 2–3 条 |
| 内容节奏 | 更新频率与节点 |
| 不可消费的点 | 哪些设定不能为营销让步 |

## 四、交接质量自检

- [ ] 接手方看完能说清"主角要什么、谁在阻止、为什么现在"。
- [ ] 已确认与待确认严格分离。
- [ ] 硬约束写明，避免下游误改。
- [ ] 每个专家块都有"越界提醒"。
- [ ] 明确标注"未自动执行"。
