# 10｜场景多视角、材质与光影

## 1. 多视角清单

| 视角 | 说明 | 用途 |
|------|------|------|
| V1 主视觉全景 | 建立镜头的第一印象 | 场景卡封面、宣传 |
| V2 反向视角 | 从主视觉对侧回看 | 正反打对话 |
| V3 侧向视角 | 90° 侧看，展现纵深 | 走廊、纵深调度 |
| V4 俯视空间图 | 顶视，展示布局 | 调度参考、接分镜 |
| V5 关键区域特写 | 桌面、窗边、门口 | 细节镜头、插入镜 |
| V6 入口 / 出口视角 | 从门内外看 | 进出场镜头 |

P0 场景全做；P1 做 V1 + V2；P2 只做 V1。

## 2. 多视角一致性规则

1. **同一平面**：所有视角必须能反推到同一张平面。生成前先用文字核对门窗位置。
2. **同一材质表**：墙、地、家具的颜色与质感在所有视角中一致。
3. **同一构件尺寸**：桌子、门、窗的宽度比例不变。
4. **同一光位**：除非明确是不同时间的状态变体，否则主光方向不变。

## 3. 材质表

```
ENV-003 材质表
地面：哑光环氧自流平，浅灰 #B8BBBD，有细微划痕
墙面：白色瓷砖 20×20cm，勾缝略泛黄；上沿 2.4m 以上为乳胶漆
台面：316 不锈钢，拉丝，可见细密横向纹路
柜体：不锈钢，哑光，把手为竖向长条
门：双层不锈钢，带小观察窗，边角有防撞胶条（已磨损发黑）
```

材质写作要点：**颜色 + 表面处理 + 老化痕迹**。只写"白色墙面"会让不同视角出现三种白。

## 4. 光影设计

### 4.1 光源动机
- 自然光：窗、天窗、门洞。必须与平面中的开口位置一致。
- 实用光源：顶灯、台灯、屏幕、火、车灯。需在画面中可见或可推断。
- 戏剧光：为情绪服务的非写实光，需在视觉圣经中授权，不可随意使用。

### 4.2 光影参数
| 项 | 说明 |
|----|------|
| 主光方向 | 相对空间的方位（如"东窗侧光，与地面成 25°"） |
| 色温 | 数值或描述（3200K 暖钨丝 / 5600K 日光 / 冷白 6500K） |
| 光比 | 主辅比（1:2 柔和 / 1:8 硬朗） |
| 阴影硬度 | 硬阴影（直射）/ 软阴影（漫射） |
| 体积光 | 有无光柱、尘埃、水汽 |
| 反射与高光 | 金属与湿地面是主要反射面 |

### 4.3 时间与天气状态
每个 P0 场景建立状态变体：`ENV-003-S01` 日间晴、`-S02` 夜间（顶灯全开）、`-S03` 停电应急灯、`-S04` 雨夜。

状态变体只改变光与氛围，不改变空间结构。**结构一旦改变就不是状态变体，而是新场景。**

## 5. 场景 Prompt 结构

```
[空间类型与功能] + [结构与构件] + [材质与颜色] + [家具与陈设] + [光位与色温] + [氛围/时间/天气] + [镜头与画幅] + [风格锁定]
```

示例：
```
Forensic autopsy room interior, 8m by 6m rectangular space, 3.6m ceiling,
white 20cm square tiles on north wall with slightly yellowed grout, brushed
stainless steel dissection table at center, four stainless refrigerated cabinets
along west wall, two tall windows on east wall 1.5m from floor.
Lighting: strong side light from east windows, morning, 5600K, soft shadows,
cool white LED strips overhead turned off. Clean, cold, faintly damp atmosphere.
Wide angle 24mm, eye level, symmetrical composition, photorealistic, muted palette.
```

## 6. 验收标准

- 六个视角可反推同一平面，门窗与家具位置无冲突。
- 材质颜色在各视角一致（可用取色比对）。
- 光位方向一致，阴影方向合理。
- 空间尺度可被角色身高验证（人在场景中的比例正确）。
- 关键区域特写与全景中的同一物件外观一致。
