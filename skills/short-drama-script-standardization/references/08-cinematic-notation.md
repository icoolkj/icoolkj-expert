# 08 影视标注符号库

标注是剧本与制作之间的接口。符号不在多，在于**全稿同一含义只用同一种写法**。

## 8.1 默认符号表

| 类型 | 默认写法 | 示例 | 说明 |
| --- | --- | --- | --- |
| 动作 | `△ ` | `△ 苏瑾关上门。` | 行首标记，非标注括号 |
| 音效 | `【音效：…】` | `【音效：远处警笛声，渐近】` | 现场可录或后期拟音 |
| 音乐 | `【音乐：…】` | `【音乐：钢琴，低沉，渐弱】` | 若项目规范允许 |
| 字幕 | `【字幕：…】` | `【字幕：三天前】` | 屏幕文字、时间地点卡 |
| 画面文字 | `【画面文字：…】` | `【画面文字：手机屏幕"未接来电 3"】` | 手机、电脑、文件内容 |
| 画外音 | `（OS）` | `苏瑾（OS）：` | 画面外的剧中人声 |
| 旁白 | `（VO）` | `旁白（VO）：` | 叙述性人声 |
| 电话 | `（电话）` | `陈默（电话）：` | 听筒内声音 |
| 闪回 | `【闪回】` … `【闪回结束】` | | 必须成对 |
| 蒙太奇 | `【蒙太奇】` … `【蒙太奇结束】` | | 必须成对，中途可分条 |
| 切至 | `【切至：地点】` | `【切至：公寓楼道】` | 同时间异地 |
| 转场 | `【转场：…】` | `【转场：三小时后】` | 时间跳跃 |
| 淡入淡出 | `【淡出】` / `【淡入】` | | 段落级使用 |
| 待确认 | `【待确认：…】` | `【待确认：地点】` | 本 Skill 专用，交付前需清理或保留说明 |
| 建议 | `【建议：…】` | 慎用 | 优先写进审查报告，不在正文留痕 |

## 8.2 标注语法规则

1. 标注独立成行，不与动作、台词写在同一行。
2. 全角方头括号 `【】`，类型与内容之间用全角冒号 `：`。
3. 一行一标注，不嵌套 `【音效：【脚步】】`。
4. 需要多条音效时分行写，或写为 `【音效：门响，脚步渐近】`（同层级并列）。
5. 内容用短语，不用完整句；不加句号。
6. 成对标注必须有开有闭，不允许只开不闭。

## 8.3 成对标注的校验

`【闪回】`、`【蒙太奇】`、`【梦境】` 三类必须成对。校验方法：

- 计数法：出现次数开=闭。
- 嵌套法：不得交叉（不允许 `【闪回】【蒙太奇】…【闪回结束】【蒙太奇结束】`）。
- 覆盖法：成对标注不应跨集；跨集使用须在集首集尾各标一次，并在报告中注明。

脚本 `scripts/script_lint.py` 会报告不配对的标记。

## 8.4 自定义标注登记

项目允许自定义标注时（如 `【特效：…】`、`【航拍】`、`【手持】`），必须在规范卡登记：

| 自定义标记 | 含义 | 使用范围 | 谁可以写 |
| --- | --- | --- | --- |
| 【特效：…】 | 后期视觉特效需求 | 全稿 | 编剧/导演 |

未登记的标注视为 P2，需统一或登记。

## 8.5 禁止进入标准剧本的内容

| 内容 | 原因 | 去处 |
| --- | --- | --- |
| 景别/机位/运镜 | 属分镜层 | 分镜表 |
| 剪辑节奏指令 | 属后期层 | 剪辑脚本 |
| AI 视频生成 Prompt | 属生成层 | Prompt 文档 |
| 演员选角建议 | 属casting | 选角表 |
| 成本与预算 | 属制片层 | 预算表 |
| 平台审核判断 | 属合规层 | 合规意见 |
| 批注与修改意见 | 属流程层 | 审查报告/修改记录 |

发现上述内容混入时：从正文剥离，原文位置在修改记录中留档。

## 8.6 标注密度

- 每场标注建议 0–4 条；超过 6 条通常说明该用分镜而非标注。
- 标注不得替代动作：`【音效：他推门进来】` 错误，应为 `△ 门被推开，陈默走进来。`
- 标注不得替代台词：`【字幕：我爱你】` 在剧情需要人物说出时是错误的替代。
- 连续标注（3 条以上相邻）应合并或检查是否重复。

## 8.7 标注与平台/终端的兼容

- 交付给非专业排版环境（如微信、在线文档）时，`【】` 与 `△` 可能显示异常，交付前在目标环境确认一次。
- 若目标环境不支持符号，提供纯文字版：`（音效）远处警笛声`，但需用户确认后再转换，不擅自改符号体系。
- 转 Word 时保留字符，不用自动编号替代手写场号。

## 8.8 标注检查清单

- [ ] 只使用已登记的标注类型
- [ ] 括号全角、冒号全角、内容无句号
- [ ] 成对标注开闭数量一致
- [ ] 标注独立成行
- [ ] 无分镜、Prompt、批注混入
- [ ] 无标注替代动作或台词的情况
- [ ] 每场标注密度合理
- [ ] `【待确认：…】` 已在交付说明中汇总
