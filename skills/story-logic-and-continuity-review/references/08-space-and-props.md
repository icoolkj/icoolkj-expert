# 08 空间与道具连续性（M08）

## 1. 空间审校：先建一张平面图

文字场景的空间问题往往源于作者心中只有"感觉"没有"布局"。审校时把场景画成简图（文字版即可），能立刻暴露矛盾。

### 1.1 场景平面图要素

```
场景名 / 属性（室内外、层数、出入口数量、光源）
├─ 关键位置：门、窗、楼梯、通道、遮蔽物、高台
├─ 人物初始位置（进场方向）
├─ 关键物件位置
└─ 视线关系：谁能看见谁、谁能听见谁
```

### 1.2 六类空间问题

1. **出入口不一致**：第 3 段从后门进，第 9 段从前门出，无解释。
2. **层数/距离漂移**：二楼的距离感与一楼相同；相隔百步却"低声说话也被听到"。
3. **遮蔽物失效**：躲在屏风后却能看到厅中所有人的表情。
4. **视线越界**：背对众人却"看到"他们交换眼神。
5. **听觉越界**：隔着一堵墙听到耳语；嘈杂环境中的低声对话清晰可辨。
6. **空间容量错误**：小房间容纳过多行动（打斗、追逐需要空间）。

**判据统一为**：写出"物理路径 + 感官通道"，若路径不成立或通道不通，即为问题。

### 1.3 追逐与打斗的专项检查

- 路径是否只有一个？若只有一个，追逐必然成立（最易写）；若多条，需交代选择理由。
- 距离变化是否可追踪？用"领先几步/几丈"做标尺，检查前后是否漂移。
- 障碍物是否被使用后又消失？
- 环境破坏是否有累积（打碎的东西不会复原）。

## 2. 道具审校：归属链

道具问题的本质是**所有权/持有权变更缺少记录**。

### 2.1 道具档案字段

| 字段 | 说明 |
|---|---|
| 道具 ID | P-001 |
| 名称 | 半枚铜符 |
| 外观 | 半圆形，边缘有齿 |
| 初始归属 | 母亲 → 主角（第2章） |
| 当前持有者 | （随时间更新） |
| 状态 | 完好 / 缺角 / 已断 / 已失 |
| 特殊属性 | 身份信物（后续扩展需记录） |
| 出现记录 | 第2、6、9、34章 |

### 2.2 归属链记录格式

```
P-001 铜符
  第2章  母亲遗物 → 主角持有
  第9章  主角 → 仍持有（贴身）
  第29章 被搜身 → 未搜出（藏于靴中）
  第31章 主角 → 交予林昭（作为信物）
  第34章 林昭 → 用于开启机关（在凹槽中）
  第35章 主角 → 取回
```

**每一行都必须有文本依据**。缺行即为归属断裂。

### 2.3 七类道具问题

1. **凭空出现**：需要使用某物时它就在身上，此前从未提及。
2. **凭空消失**：重要物件在后续场景不再出现，也无丢失描写。
3. **无声易主**：A 的东西到了 B 手上，无交接。
4. **损坏不记**：道具被打碎/耗尽，后文完好如初。
5. **修复无过程**：断裂的道具忽然完好。
6. **功能扩张**：物件功能超出建立范围（转 M07 无因回收）。
7. **数量错误**：三钱银子花了两钱还剩三钱；"最后一颗药"用了两次。

### 2.4 高价值道具清单

以下类型最容易出问题，建议优先建档案：

- 一次性资源：药、毒、符、子弹、火折子、银两。
- 唯一性信物：玉佩、家传兵器、婚书、密钥。
- 载信息的物件：信、地图、账册、照片、录音。
- 会造成伤害的物件：刀、枪、绳索、锁。
- 会被搜走的物件：任何在被俘/被捕场景中的持有物。

**被俘/被捕/入狱/重伤昏迷是道具连续性最高发的断点**——人物状态被重置，但道具清单常被遗忘。

## 3. 场景与人物位置的双向校验

每次场景切换，检查三件事：

1. **进场方式**：他从哪个方向来？门在哪？
2. **在场名单**：这一刻场内有谁？谁不该在？（最常出错：某人明明已离场）
3. **退场方式**：他何时、如何离开？有没有人注意到？

**在场名单法是最高效的工具**：为每个场景列一个名单表，逐段更新。人物一离场就打勾，避免"幽灵在场"。

## 5. 输出模板示例

```
### 问题编号：SPACE-002
- 问题标题：第 15 章打斗中窗（唯一出口）被提及后消失
- 问题等级：P3
- 问题状态：待确认
- 所属审校模块：M08 空间与道具连续性
- 发生位置：第 15 章「破窗」第 2–7 段
- 问题描述：第2段交代"屋内只有一扇朝北的窗，糊着厚纸"，第4段主角被逼至墙角，
  第7段却"从窗口翻了出去"，中间无破窗动作、无纸被撕开的描写；
  且第2段已说明窗在"北墙"，第4段主角被逼至"南墙角"，距离不成立。
- 原文证据：第15章：「屋里只有一扇朝北的窗，糊着厚纸。」（TEXTUAL）
  第15章：「他被逼到了南墙角的桌案后。」（TEXTUAL）
  第15章：「他翻身从窗口跃了出去。」（TEXTUAL）
- 冲突基准：F-SPACE-015 场景布局：单窗朝北，南墙为死角（TEXTUAL，第15章第2段；
  同类布局亦见第12章同一屋）
- 问题原因：疑为空间跳跃——翻窗过程被省略，且人物位置与窗的方位冲突；
  也可能是作者中途改变了布局但未回头修改前文。
- 影响范围：第15章脱身方式；第16章"跳窗摔伤"的伤势逻辑（若从此处跳下，
  落地高度需核对）；第12章对同一屋子的描写。
- 最小修复方案：改第2段为"屋里两扇窗，南墙那扇对着巷子"，为翻窗留出路径，
  改动一句；第16章伤势无需调整。
- 替代方案：保留单窗设定，改第4段人物被逼至"北窗下"，使翻窗路径成立，
  但会削弱"死角"的压迫感。
- 修复后复审要求：核对第12章同屋描写；确认第16章落地高度与伤势一致；
  确认第15章打斗路径重新走一遍不出现新的位置矛盾。
```
