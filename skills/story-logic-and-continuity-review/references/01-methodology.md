# 01 审校总纲：事实基准、结构还原与对账方法

本文件是所有专项审校的公共底座。任何模块开始前，先完成这里的三件事：**建基准 → 还原结构 → 逐项对账**。

---

## 1. 三段式审校法

### 1.1 第一段：建立事实基准（Baseline）

审校不是凭感觉找错，而是把"故事承诺过什么"变成可比对的结构化记录。

**事实基准表字段：**

| 字段 | 说明 | 示例 |
|---|---|---|
| 事实 ID | 唯一标识，随项目固定 | F-CHAR-012 |
| 主体 | 人物 / 地点 / 物件 / 规则 | 沈砚 |
| 属性 | 年龄、伤势、持有物、能力上限… | 左手受伤 |
| 取值 | 具体事实内容 | 第三集被刀划伤左手，未愈合 |
| 时间点 | 故事内时间或章节位置 | 第3集 第12场 起 |
| 来源 | 文件 + 位置 | 剧本 v2.1 / p.18 |
| 证据等级 | CONFIRMED / TEXTUAL / INFERRED / PENDING / DEPRECATED | TEXTUAL |
| 冲突标记 | 是否已存在矛盾 | 待查 |

**硬性规则：**

1. 同一属性有多个来源时，优先级为：作者口头确认（CONFIRMED）> 最新版正文（TEXTUAL）> 旧版正文 > 设定文档 > 推断（INFERRED）。
2. 设定文档与正文冲突时，不要默认设定文档正确。先判断哪一份是作者当前使用的主基准；无法判断时记为 PENDING，列入待确认事项。
3. 标记为 DEPRECATED 的旧设定不得再作为冲突基准使用。若正文仍在引用已废弃设定，这是独立的问题（RULE 或 MEDIA 类）。
4. 推断出来的事实必须写清推断依据，否则不得进入基准表。

### 1.2 第二段：还原故事结构（Reconstruction）

把散落在正文里的事件整理成可追踪的链条。产物包含七张表：

1. **事件列表**：序号、事件、参与者、地点、故事内时间、章节位置、触发来源、直接后果。
2. **因果链**：`事件 A → 人物行动 → 结果 → 新事件 B`，标注每段衔接是否有文本支撑。
3. **人物目标与行动**：每个主要人物在每一阶段的目标、采取的行动、行动结果、目标是否变化及变化触发点。
4. **冲突清单**：冲突双方、诉求差异、升级节点、解决方式。
5. **关系变化**：关系状态 + 变化原因 + 变化发生位置。
6. **关键时间节点**：故事内日历、时长、跨度。
7. **伏笔—回收对照表**：见 `07-setup-and-payoff.md`。

结构还原不必输出全部七张表给用户，但审校者必须自己过一遍。长篇可只对本次审校范围及前后各一章做还原。

### 1.3 第三段：逐项对账（Reconciliation）

对账即"用结构去校验文本"。三种对账方向：

- **前向对账**：后文的主张是否被前文支持（最常见：能力、信息、道具凭空出现）。
- **后向对账**：前文的承诺是否在后文兑现（伏笔、威胁、伤势）。
- **横向对账**：同一时间点上不同人物/不同文件之间是否自相矛盾（跨媒介审校的主战场）。

对账发现疑点后，进入取证流程（第 3 节），不得直接下结论。

## 2. 审校执行顺序

按以下顺序推进，可显著降低漏检率和重复劳动：

1. **范围确认** → 明确审的是什么、不审什么。
2. **基准建立** → 主线人物、核心规则、关键道具、关键时间。
3. **结构还原** → 至少覆盖审校范围的因果链与时间轴。
4. **高价值模块优先** → 先 M04 时间线、M05 状态、M06 认知，这三类最易产生硬冲突；再 M01 因果、M02 动机；最后 M07 伏笔、M08 空间、M09 跨媒介。
5. **分组取证** → 同一处文本可能同时触发多个模块，合并取证，避免对同一段原文反复引用。
6. **定级 → 修复建议 → 影响分析**。
7. **报告输出 → 台账登记**。

**为什么不按 M01→M10 顺序做**：因果与动机的判断依赖时间线和状态，先做 M04/M05/M06 可以为后续模块提供可靠前提。

## 3. 取证流程

每个疑点走完五步才可定级：

1. **定位**：给出章节/场景/页码/行号/时间码，尽量精确到可检索的片段。
2. **摘录**：引用原文，不改写、不省略关键限定词。
3. **找基准**：指出与哪条事实冲突，写出该事实的证据等级与来源。
4. **排除合理设计**：对照 `10-severity-and-false-positive.md` 的十类豁免逐条排查。
5. **定级**：按实际影响而非"读起来别扭"定级。

任一步不成立，就降级为"潜在风险"或"待确认"，不得写成确定错误。

## 4. 长篇与短剧的抽样策略

### 4.1 长篇小说（>20 万字）
- 必查：开篇三章、结局、所有转折章、所有"第一次"（第一次出场、第一次使用能力、第一次提到过去）。
- 抽样：每 5–10 章抽一章完整对账，重点看状态与时间。
- 关键词扫描：数字、日期、方向、亲属称谓、称谓变化、物品名、伤口、天气、季节。

### 4.2 短剧（单集 1–2 分钟，60–100 集）
- 必查：每集结尾钩子与下集开场是否接得上；每 10 集的爽点节点是否有铺垫。
- 高频问题集中在：人物位置跳变、时间省略无提示、道具在集与集之间易主、配角突然知道主角秘密。
- 建议逐集建"开场状态 / 结尾状态"两栏，相邻集比对。

## 5. 常见失败模式（审校者自查）

| 失败模式 | 表现 | 纠正 |
|---|---|---|
| 无基准定罪 | 凭印象说"这里不对" | 必须写出冲突基准及其来源 |
| 把推断当事实 | "他显然不知道" | 标 INFERRED 并写明推断依据，或降为待确认 |
| 越界改写 | 直接给出重写后的段落并声称已修复 | 只提供方案，等作者确认 |
| 范围虚报 | 声称"全书已审"但只看了三章 | 明确列出实际覆盖范围 |
| 过度判错 | 把悬念、留白、非线性叙事判成漏洞 | 先做意图假设，再判断 |
| 等级通胀 | 大量 P0/P1 | P0 应极少；超过 3 条需重新核验 |
| 修复副作用 | 只改一处，不管后续 | 必做影响范围分析 |
| 引用失真 | 概括代替原文 | 引用原文，保留限定词 |

## 6. 与其他 Skill 的交接约定

- 需要世界观补全时移交 S02，不在审校中自创规则。
- 需要重写段落时移交 S03/S05/S06，S09 只给方案与验收标准。
- 需要重建章节记忆时移交 S04，S09 可消费其状态表作为基准来源之一（需标注来源）。
- 需要核对镜头叙事时与 S07 对照，S09 判断"是否与剧情事实冲突"，不评判镜头美学。
- 需要核对视觉资产时与 S08 对照，S09 判断"是否违反已确认的角色/场景/道具事实"。
