# 06｜角色服装设计

## 1. 服装的三个功能

1. **识别**：在群像中快速区分角色（色彩、剪影、结构）。
2. **叙事**：阶层、职业、时代、心理状态。
3. **一致性锚点**：同一套服装必须能在任意镜头复现。

## 2. 服装层级

| 层级 | 定义 | 数量建议（P0） |
|------|------|----------------|
| 基础装 | 出现时长最长的主力服装 | 1 |
| 日常装 | 生活场景 | 1–2 |
| 特殊场合装 | 仪式、职场、宴会、庭审 | 1 |
| 战斗 / 作业装 | 动作与专业场景 | 1 |
| 剧情阶段装 | 按剧情推进换装（含前后对比） | 按需要 |

每套服装独立编号：`CHAR-001-C01` 起顺延，并在档案中写明对应剧情段落。

## 3. 服装设定表

```
服装编号：CHAR-001-C01
名称：冷灰长风衣通勤装
剧情区间：第 1–6 集
季节 / 天气：深秋，多雨
构成：内搭高领细针织 / 长款风衣 / 直筒长裤 / 短靴 / 单肩包
版型：oversized 风衣，肩线落于肩下 2cm，下摆过膝 10cm
材质：风衣为哑光混纺（微防水），针织为细罗纹，皮靴为哑光牛皮
颜色：主体 #6B6F73 冷灰，内搭 #2E3033 深炭，靴 #1A1A1C
磨损与污渍：袖口内侧有轻微起球，左襟第二颗纽扣略松
配饰：无耳饰；左手腕一条深褐皮绳
禁止项：不许出现亮面材质、不许出现品牌 logo、不许出现格纹
```

## 4. 设计方法

### 4.1 剪影优先
先画纯黑剪影，判断：这个角色在 10 米外能否被认出。剪影不成立就重做轮廓（领型、肩线、下摆长度、体积对比）。

### 4.2 色彩管理
- 每个 P0 角色绑定一个专属色，服装中至少 30% 面积出现该色或其邻近色。
- 群像场景避免所有人同明度，用明度差做层次。
- 回忆 / 闪回段落整体降饱和，但保留角色专属色作为线索。

### 4.3 材质对比
同一角色身上应有材质层次（哑光 + 微光 + 柔软），纯单一材质会显得"纸片"。

### 4.4 时代与地域校验
逐项检查：拉链/纽扣形制、鞋型、包型、面料工艺、印花风格。混用是 AI 生成最常见的穿帮点。

## 5. 服装 Prompt 写法

按「版型 → 材质 → 颜色 → 细节 → 穿着状态」顺序写，避免只写风格词。

```
long oversized wool-blend trench coat in cold gray (#6B6F73), matte finish,
shoulder seam dropped 2cm, hem 10cm below knee, back vent, no belt.
Underneath: dark charcoal fine-ribbed turtleneck. Straight-leg trousers, matte
leather ankle boots. Single shoulder bag, worn on right side. No logos, no
patterns, no glossy fabric.
```

负面词必备：`logo, text, pattern, glossy, shiny, futuristic, fantasy armor, modern print`（按项目时代调整）。

## 6. 服装状态变体

同一套服装要预留状态：
- 干燥 / 潮湿 / 淋透
- 整洁 / 褶皱 / 破损
- 穿好 / 半脱 / 披挂
- 干净 / 沾血 / 沾泥

状态变体不再是新服装编号，而是 `CHAR-001-C01-S1`（状态后缀），并在档案中记录变化触发点。

## 7. 验收标准

- 剪影可辨。
- 颜色数值可被另一制作者复现。
- 材质与时代无冲突。
- 同一套服装在多视角下结构一致（侧缝、袖窿、下摆厚度都有交代）。
- 换装后角色身份仍成立（说明服装没有承担全部识别任务）。
