# 02 世界结构框架：背景、空间、地理、生态

## 1. 时代定位四要素

| 要素 | 需要确定 | 对故事的影响 |
|---|---|---|
| 技术水平 | 能源、交通、通讯、医疗、武器各到哪一步 | 决定信息传递速度与救援可能性 |
| 社会形态 | 部落 / 城邦 / 帝国 / 公司制 / 无政府 | 决定权力来源 |
| 认知水平 | 世界被理解到什么程度（是否有未解之谜） | 决定悬念的合法性 |
| 断裂程度 | 旧文明是否存续（末世、灾变、星际殖民） | 决定"遗物"与"知识断层"能否使用 |

**纪律**：技术进步必须成套。有飞行器就必须有对应的能源、维护、导航体系；单独存在的黑科技会立刻暴露设定偷懒。

## 2. 空间结构：四层模型

| 层 | 内容 | 建到什么程度 |
|---|---|---|
| 世界层 | 星球/大陆/位面的整体形状、边界、天象 | 一句话可描述，有边界感 |
| 区域层 | 气候带、地理分区、文明分布 | 3–7 个大区，各有特征 |
| 聚落层 | 城市、基地、门派驻地、村落 | 主要 3–5 个详写，其余列名 |
| 场景层 | 具体可发生戏的地点 | 按需，与剧情绑定 |

**常见错误**：世界层写了一万字，场景层一个能演戏的地方都没有。

## 3. 地理生成逻辑

地理不是随便画的，它必须能解释文明。

```
地形 → 气候 → 物产 → 人口密度 → 交通线 → 城镇分布 → 势力边界
```

### 检查链

| 检查 | 问题 |
|---|---|
| 水源 | 聚落是否都在水源可及范围 |
| 通行 | 两地之间的人怎么走、走多久、路上有什么 |
| 屏障 | 山脉/河流/荒漠是否与势力边界吻合 |
| 资源 | 关键矿产/灵脉/能源是否解释了某势力的富有 |

**距离必须量化**：写清"从 A 到 B 步行 7 天 / 骑马 3 天 / 飞行 4 小时"。没有距离感的世界，紧张感无法建立（追兵永远追不上，也永远追得上）。

## 4. 环境与生态

### 4.1 生态链最小配置

任何有野外场景的世界，至少写清四层：

| 层 | 内容 | 写作作用 |
|---|---|---|
| 生产者 | 基础植被/灵植/菌毯 | 决定能否生存 |
| 中层 | 常见可猎/可驯生物 | 提供日常风险与食物 |
| 顶层 | 高威胁生物 | 制造禁区，限制地图 |
| 分解者 | 腐化机制/污染 | 解释尸体、废墟、疫病 |

末世与异世界题材尤其需要：**没有生态就等于没有野外**，主角只能一直在城里。

### 4.2 气候作为叙事工具

| 气候设定 | 叙事功能 |
|---|---|
| 周期性极端天气 | 天然倒计时（必须在风暴前赶回） |
| 长夜/长昼 | 制造活动窗口与禁行时段 |
| 毒雾/辐射带 | 划出不可进入区，控制地图边界 |
| 季节窗口 | 限定远征时机，制造"错过就要等一年"的压力 |

## 5. 文明分布与主舞台

### 5.1 主舞台选择标准

故事主舞台应同时满足：

1. 位于多种势力的交界或争夺带（冲突密度最高）。
2. 拥有至少一种稀缺资源（利益可争夺）。
3. 存在一条"进得来出不去"的限制（不能随时逃离）。
4. 与主角的伤口或目标有关联。

四条缺两条以上，故事会缺乏推进动力。

### 5.2 边缘地带的价值

为长篇预留至少 2 个"已命名但未展开"的区域。它们的作用是：主角升级后可以迁移，读者有期待，作者有余地。未展开区只需一句话描述 + 一个传闻，不必建设。

## 6. 重要地点档案模板

| 字段 | 说明 |
|---|---|
| 地点编号 | LOC-000 |
| 名称 | |
| 类型 | 城市/要塞/遗迹/秘境/据点 |
| 位置 | 相对坐标与到达方式 |
| 归属 | 所属势力及实际控制情况 |
| 规模 | 人口/面积量级 |
| 外观特征 | 3 个可视觉化的标志物 |
| 功能 | 交易/军事/宗教/生产/避难 |
| 资源 | 此地能提供什么 |
| 规则例外 | 此地是否有不同于世界规则的局部规则 |
| 危险 | 常驻威胁 |
| 关键人物 | |
| 剧情作用 | 主角为什么会来这里 |
| 状态 | 已确认/待确认 |

**要求**：每个地点至少承担一个剧情功能。纯粹为了"世界观丰富"而存在的城市，删掉。

## 7. 空间与规则的耦合

特殊空间（秘境、副本、结界、异空间）必须有明确条款：

| 条款 | 必须回答 |
|---|---|
| 入口条件 | 谁能进、何时能进、进几次 |
| 内部规则 | 与外界规则有哪些不同（时间流速、能力压制、物理法则） |
| 资源产出 | 里面能得到什么，外界为何得不到 |
| 退出条件 | 怎么出来，出不来会怎样 |
| 稳定性 | 是否会崩塌、扩张、移动 |

**纪律**：特殊空间是资源产地，必须纳入经济体系；否则会变成无限刷宝机，破坏整个世界的力量平衡。
