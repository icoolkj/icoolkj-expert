# 09 质量审校清单

按组执行，逐项给出结论：`通过 / 问题 / 不适用`。不允许"整体看起来没问题"这种结论。

## 9.1 结构完整性

- [ ] 集标记齐全，无中途断集
- [ ] 每集场次数 ≥ 1，场号连续
- [ ] 无空场（有标题无内容）
- [ ] 无孤立元素（只有署名没有台词、只有标注没有场上内容）
- [ ] 集与集之间的衔接有交代（上一集结尾钩子与下一集开头对应）
- [ ] 全稿起止完整（有开场、有收束，非突然中断）

## 9.2 场次编号

- [ ] 场号唯一
- [ ] 场号顺序与阅读顺序一致
- [ ] 集号与场号前缀一致（不会出现 `第02集` 内写 `3-1`）
- [ ] 无跳号，或跳号已说明
- [ ] 标题行格式统一

## 9.3 人物一致性

- [ ] 每个署名都能在人物表找到
- [ ] 标准名唯一，别名有映射
- [ ] 同一场同一人不使用两个署名
- [ ] 人物行与场中实际出场一致
- [ ] 首次出场有身份线索或已标待确认
- [ ] 人物关系前后不矛盾
- [ ] 未出现"出场一次即消失"的可疑角色（或已说明）
- [ ] 群体角色与主要角色不混编

## 9.4 场景一致性

- [ ] 地点名全稿唯一
- [ ] 内外景与场内细节自洽
- [ ] 时间与光线、活动自洽
- [ ] 空间关系可拍（人物位置有交代）
- [ ] 重复场景的环境描述不矛盾
- [ ] 场景清单已完成并核对

## 9.5 时间逻辑

- [ ] 场次之间的时间推进合理（不出现"次日"后又回到当夜）
- [ ] 相对时间词（连续、稍后、同日、次日）使用一致
- [ ] 闪回/梦境的时间层清晰，进出成对
- [ ] 台词内的时间信息与场景时间不冲突（"我明天早上飞"但场景是深夜且下一场已到机场）
- [ ] 跨集时间线连续（见 `14-continuity-check.md`）

## 9.6 对白归属

- [ ] 每条台词有明确说话人
- [ ] 台词内容与说话人身份、语言风格相符
- [ ] 电话/画外/旁白标记正确
- [ ] 无两人台词合并成一段
- [ ] 无台词被误标为动作或字幕

## 9.7 动作合理性

- [ ] 每条动作有执行主体
- [ ] 动作与场景空间不矛盾
- [ ] 动作可表演、可拍摄
- [ ] 无纯心理/抽象描述（或已列建议）
- [ ] 无景别、运镜、剪辑指令混入
- [ ] 动作未泄露后文信息

## 9.8 场景转换

- [ ] 场间有空间或时间跳转依据
- [ ] 转场使用标准标注
- [ ] 无叙述化转场（"画面一转"）
- [ ] 成对标注完整
- [ ] 平行叙事有明确标识

## 9.9 内容完整性

- [ ] 原稿每一场都能在标准稿中定位
- [ ] 无整段丢失
- [ ] 无对白被删（除用户确认）
- [ ] 无擅自新增内容
- [ ] 批注、评审意见已剥离并归档
- [ ] 占位符（TODO、待补、xxx）已全部处理或列入待确认

## 9.10 可拍摄性风险（提示级）

- [ ] 高成本场景已列入场景清单备注
- [ ] 特殊拍摄需求（雨、火、车、动物、儿童、群众）已标注
- [ ] 危险动作已提示
- [ ] 真实品牌/机构/地址已提示
- [ ] 专业操作细节（医疗、法律、金融）已提示
- [ ] 敏感内容已提示（仅提示，不作合规结论）

## 9.11 格式与排版

- [ ] 全角/半角统一
- [ ] 省略号、破折号规范
- [ ] 空行规则一致
- [ ] 无 Tab、无人工缩进
- [ ] 标注符号统一
- [ ] 文件名符合规范

## 9.12 审校记录写法

```
检查项：9.3 人物一致性
结论：问题
覆盖范围：第01–12集，共 86 场
发现问题：C-07、C-11、C-12
未覆盖：第13集未提供，无法核对
```

必须写"覆盖范围"和"未覆盖"，避免把部分检查说成全部检查。

## 9.13 不得声称完成的检查

以下检查本 Skill **不负责**，报告中不得出现"已通过"：

- 导演审查、拍摄可行性终审
- 商业评估、平台审核、备案合规
- 演员适配、预算可行性
- 法律意见（版权、名誉权、隐私）

如需这些结论，明确说明"本报告不含上述评估"。
