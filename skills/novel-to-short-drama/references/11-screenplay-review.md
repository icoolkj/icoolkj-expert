# 11 剧本审校清单

## 使用方法

交付剧本、分集大纲前逐项检查。每项给出 **通过 / 部分通过 / 不通过**，并写一句依据。不通过的项必须先修改，或在交付说明中明确标注为已知问题。

审校不是打分游戏：**任何一项"不通过"都必须有对应的修改动作。**

## 一、十项检查

### 1 故事清晰度

- 看完一集，能否用一句话说清发生了什么？
- 新观众从本集开始看，能否理解人物关系？
- 是否依赖观众看过前集才能理解核心冲突？若是，是否用一句台词或一个画面补足？

不通过信号：需要旁白解释、需要"前情提要"才能看懂。

### 2 人物目标明确度

- 本集主角想要什么？能否用一个动作说明？
- 对手的目标是否同样具体？
- 目标是否有明确的成功/失败判定标准？

不通过信号：主角本集只是"被动应对"，没有主动追求。

### 3 冲突有效性

- 每场是否有正面碰撞（不是各说各话）？
- 冲突是否升级（至少加码一次）？
- 是否有第三方在场形成压力或见证？

不通过信号：冲突靠误会维持、对手太弱、主角轻易获胜。

### 4 因果完整性

- 每个结果能否在前文找到成立条件？
- 反转是否至少埋过一次前置信息？
- 是否出现"剧情需要"的新人物/新能力/新规则？

不通过信号：观众会问"他为什么突然能这样"。

### 5 场景变化

- 每场结束时，谁的处境改变了？
- 是否有"两人对话后各自离开，什么都没变"的场景？
- 场景结果是否与场景目标不同向？

不通过信号：场景只是信息交换，没有利害。

### 6 对白自然度

- 遮住人名能否分辨说话者？
- 是否有解释背景的台词？
- 单句是否过长（竖屏 >20 字，横屏 >60 字）？
- 情绪最强处是否用了潜台词？

### 7 信息重复

- 同一信息是否被说了两遍以上？
- 是否在前集已揭露的信息在本集又被完整复述？
- 是否有两个角色说了同一件事？

处理：保留最有效的一次，其余删除或改为"提及不解释"。

### 8 节奏

- 单场时长是否在区间内？
- 高强度后是否有呼吸点？
- 是否存在连续三场同类型场景？
- 集末钩子是否在最后 10 秒内出现？

### 9 结尾追看力

- 钩子是否与本集已建立的信息强相关？
- 钩子是否可在不解释的情况下理解？
- 下一集开篇是否立即回应（不跳线）？
- 钩子类型是否与上两集重复？

### 10 制作可执行性

- 单集地点数 ≤5，主要演员 ≤6？
- 是否有超预算场面（爆破、车祸、群演、特效、特殊季节）？
- 夜戏/外景比例是否过高？
- 儿童、动物、特技戏是否必要？

## 二、红旗清单（命中即必须改）

| 红旗 | 说明 |
|---|---|
| 靠旁白解释剧情 | 改编失败的典型标志 |
| 主角连续三集不主动 | 观众流失 |
| 反派降智 | 冲突失效 |
| 反转无铺垫 | 观众觉得被骗 |
| 一整集没有处境变化 | 水集 |
| 关键信息只用台词说，没有画面 | 短剧大忌 |
| 场景数超过 8 个/集（竖屏） | 成本与节奏双重失控 |
| 台词中出现"正如你所知" | 说明书式对白 |
| 结局靠天降外力 | 因果崩塌 |
| 原著标志性场面被无声删掉且未告知 | 用户会强烈反弹 |

## 三、修改优先级

发现问题后按此顺序处理：

1. **结构级**（影响多集）：目标缺失、因果断裂、中段塌陷 → 先改结构，不要逐句润色。
2. **集级**：钩子失效、水集、节奏平 → 改集末与集内事件顺序。
3. **场级**：场景无变化、冲突不升级 → 改场景结果。
4. **句级**：对白冗长、说明书台词 → 最后处理。

顺序错了会白做：在结构没定之前润色对白，等于给要拆的房子刷漆。

## 四、审校报告格式

```markdown
## 审校报告：第 1-5 集

| 项 | 结论 | 依据 | 处理 |
|---|---|---|---|
| 1 故事清晰度 | 通过 | 每集可一句话概括 | — |
| 3 冲突有效性 | 不通过 | 第 3 集反派全程被动 | 已改为反派先出手 |

### 主要问题
1. 第 3 集为水集：删掉不影响第 4-5 集。已并入第 2 集结尾。
2. 第 5 集钩子为"主角晕倒"，无信息量。已改为"她在病历上看到自己的名字"。

### 已修改
### 需用户确认
### 遗留风险
```

## 五、交叉检查

审校时至少做两次"换位阅读"：

1. **以观众身份**只看第 3 集：能否看懂、会不会想继续。
2. **以制片身份**看全 5 集：需要几个演员、几个景、几天。

两次阅读都会暴露不同问题，缺一不可。

## 六、完成标准

- 十项全部通过，或有明确标注的遗留问题与解决计划。
- 红旗清单零命中。
- 修改已在文件中落实，不只是写在报告里。
- 审校报告随交付物一起提供。
