# 07 情节、冲突与伏笔

## 1. 冲突的三个层级

好的长篇三层同时存在：

| 层级 | 内容 | 变化周期 |
|---|---|---|
| 外部冲突 | 具体的人／事／危险 | 每章 |
| 关系冲突 | 与重要他人的立场分歧 | 每卷 |
| 内部冲突 | 他不想成为的那种人 | 全书 |

只有外部冲突 = 打怪流水账。只有内部冲突 = 矫情。三层咬合，故事才有重量。

## 2. 障碍升级阶梯

同一个问题被解决四次，读者会腻。每次障碍必须**换维度**：

```
第 1 次：武力不够      → 他练
第 2 次：信息不够      → 他查
第 3 次：立场不对      → 他选边
第 4 次：代价太大      → 他付
第 5 次：赢了也没有意义 → 他改目标
```

规则：**每次升级，改变的不是难度，是问题本身**。

## 3. 悬念与惊奇

| 类型 | 机制 | 效果 |
|---|---|---|
| 悬念（Suspense） | 读者知道有危险，人物不知道 | 持续紧张 |
| 惊奇（Surprise） | 读者和人物同时被震到 | 瞬间冲击 |

比例建议：悬念为主，惊奇为辅（7:3）。纯靠惊奇，读者会疲；纯靠悬念，缺爆点。

**悬念的写法**：先给读者看到威胁（桌子底下有东西），再让人物做别的事（她还在找钥匙）。

## 4. 反转的三种合法方式

反转必须让读者产生"我早该看出来"的感觉，而不是"作者想怎样就怎样"。

| 类型 | 做法 | 前提 |
|---|---|---|
| 信息差反转 | 读者看到的是 A，真相是 B | 前文必须给过至少 2 处可回溯的线索 |
| 动机反转 | 行为不变，动机被重新解释 | 该行为在前文必须有两种解释空间 |
| 规则反转 | 世界的规则被重新理解 | 规则在前文必须明确写过，且被违反过一次 |

**不合法反转**：突然出现的新人物、新能力、新规则、梦境、失忆、"其实他一直在演戏"（无铺垫）。

**自检**：把反转写完之后，回头在 3 处前文加线索。加不进去，说明这个反转没有根基。

## 5. 伏笔系统

### 5.1 三类伏笔

| 类型 | 做法 | 例 |
|---|---|---|
| 道具伏笔 | 一个物品反复出现，后来有用途 | 一枚总在手里的旧钥匙 |
| 台词伏笔 | 一句看似随意的话 | "你父亲从不去北边。" |
| 行为伏笔 | 一个不合常理的小动作 | 他每次进门都先看屋顶 |

### 5.2 伏笔的三段生命周期

```
埋设 → 提醒（1–2 次）→ 回收
```

- **埋设**：自然出现，不加重音（不要写"她忽然觉得这枚钥匙很重要"）。
- **提醒**：以不同场景复现，让读者有印象但不破解。
- **回收**：给出因果解释，并改变局势。

### 5.3 台账字段

| 字段 | 说明 |
|---|---|
| 编号 | FORE-011 |
| 内容 | 黑匣子的来源 |
| 埋设章 | CH-0012 |
| 提醒章 | CH-0019, CH-0031 |
| 计划回收 | CH-0048（约第一卷末） |
| 状态 | 已埋／已提醒／已收／已废 |
| 关联 | CHAR-003 船夫，ITEM-004 |

### 5.4 回收时机

| 距离 | 效果 |
|---|---|
| 3–10 章内 | 读者还记得，容易有"啊"的快感 |
| 10–30 章 | 需要中途提醒，效果更强 |
| 30 章以上 | 必须多次提醒，且回收要足够重 |

超过 40 章未回收也未提醒的伏笔，要么回收，要么标 `[已废弃]`。悬而不决是长篇最常见的失信。

## 6. 巧合的使用规则

**巧合可以救人，不能解决问题。**

- 允许：主角快死时，救援恰好赶到（增加紧张，不解决核心矛盾）。
- 禁止：主角靠偶然捡到的宝物打败反派（解决问题，抹掉成长）。

若必须用巧合推进，让巧合**带来更大的麻烦**，而不是解除麻烦。

## 7. 支线设计

支线必须与主线有**因果连接**，不能只是"顺便做点别的"。

三种合法连接：

1. 支线的结果提供主线所需资源／信息。
2. 支线的人物在主线关键时刻出现。
3. 支线暴露主角的性格侧面，影响主线选择。

支线纪律：一条支线不超过 8 章跨度，超过则必须在中途与主线交汇一次。

## 8. 情节的逻辑链检查

对每个重要事件问四个"为什么现在"：

| 问 | 想不清意味着 |
|---|---|
| 为什么他现在要做这件事？ | 动机不足 |
| 为什么他不能等到明天？ | 缺时间压力 |
| 为什么别人不阻止他？ | 世界不合理 |
| 如果他失败了会怎样？ |  stakes 不足 |

四问答不上两个，这个事件就不能写。

## 9. 中段防塌方（30%–70% 位置）

中段塌陷是长篇第一大死因。三个解法：

| 解法 | 做法 |
|---|---|
| 换目标 | 主角发现真正要解决的问题不是原来那个 |
| 换阵营 | 他被迫与敌人合作，或朋友变成阻碍 |
| 换尺度 | 从个人恩怨升级为群体命运，或反之 |

**中段必须有一次"关系破裂"或"信念动摇"**。否则读者会觉得"他怎么一直在赢"。

## 10. 情节体检表

- [ ] 每一卷的核心冲突，能否用一句话说清"谁要什么、谁不让"？
- [ ] 主角的每次胜利，是否都付出了具体代价？
- [ ] 反派是否至少有两次不依赖主角的主动行动？
- [ ] 是否所有重要转折都有前置铺垫（≥2 处）？
- [ ] 是否有连续 5 章没有实质进展？
- [ ] 是否有伏笔超过 40 章未提醒？
- [ ] 是否有靠巧合解决的核心问题？
- [ ] 支线是否都交汇过或已收束？
- [ ] 读者在第 1/4、1/2、3/4 处，是否都有明确的"想知道接下来会怎样"？
