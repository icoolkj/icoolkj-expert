# 08 人物调度：让人在空间里产生意义

调度＝人物在空间中的位置、移动与相互关系。**好的调度让台词少说一半。**

## 8.1 调度的四个变量

| 变量 | 选项 | 表达 |
| --- | --- | --- |
| 位置 | 近/远、高/低、里/外、中/边 | 关系与权力 |
| 朝向 | 面朝/背朝/侧对/斜对 | 开放或封闭、诚实或隐瞒 |
| 移动 | 靠近/远离/绕行/停顿 | 关系变化的过程 |
| 高低 | 站/坐/蹲/躺/倚 | 权力与状态 |

每个镜头都要能回答：他原来在哪，现在在哪，为什么动。

## 8.2 走位的叙事功能

| 走位 | 读作 |
| --- | --- |
| 靠近对方 | 施压、亲密、威胁 |
| 后退 | 退让、恐惧、拒绝 |
| 绕到对方身后 | 掌控、危险 |
| 停在门口不进去 | 犹豫、界限 |
| 走到窗边 | 逃避、思考、看外部世界 |
| 坐下 | 决定留下、放下防备 |
| 突然起身 | 情绪失控、谈判破裂 |
| 背对镜头 | 隐瞒、拒绝沟通 |
| 挡住对方去路 | 阻拦、控制 |

**没有动机的走位是噪音。** 剧本没写走位时，可以设计，但标 `[建议]`。

## 8.3 距离变化＝关系变化

| 阶段 | 距离 | 镜头处理 |
| --- | --- | --- |
| 开场疏离 | 3m 以上，不同景深 | 双人中全，各自独立 |
| 试探 | 1.5m，侧对 | 中景，两人分置画面两侧 |
| 冲突 | 1m 内，正对 | 过肩 + 近景，画面开始拥挤 |
| 破裂 | 突然拉开到房间两端 | 从近景切到全景，空间突然变大 |
| 和解 | 缩短距离但不对视 | 中近，肩并肩，视线同向 |

**用距离演关系，比用台词演关系高级。**

## 8.4 权力调度

| 手法 | 强方 | 弱方 |
| --- | --- | --- |
| 高度 | 站 | 坐/蹲 |
| 画面占比 | 大 | 小/贴边 |
| 遮挡 | 前景无遮挡 | 被物/人遮挡 |
| 光线 | 有光 | 半暗/背光 |
| 朝向 | 正脸 | 侧脸/背身 |
| 移动自由 | 可自由走动 | 被限制在固定位置 |
| 视线 | 看对方 | 看别处/低头 |

反转权力时，**只改其中一项**（如让弱方站起来），其余保持不变，观众立即读懂。

## 8.5 三人及以上场面

| 结构 | 做法 | 适用 |
| --- | --- | --- |
| 三角站位 | 三人不共线，总有一人被隔开 | 组内矛盾 |
| 二对一 | 两人同侧同高，一人孤立 | 施压/排挤 |
| 环形 | 众人围住中心 | 审判/围观 |
| 纵深排列 | 前中后三层，各占一个景深 | 等级/距离 |
| 背景人墙 | 主体在前，人群在后虚化 | 孤立于人群 |

三人以上必须明确"这场戏属于谁"，否则观众注意力分散。用焦点、光、运动三者之一锁定。

## 8.6 群体场面

| 要点 | 做法 |
| --- | --- |
| 定视线焦点 | 全场的目光方向要统一，否则画面散 |
| 定运动主线 | 群演要有统一方向，制造流动 |
| 留出空间层级 | 前景群演虚化，中景主体，后景环境 |
| 避免抢戏 | 群演不得有独立表演动作特写 |
| 数字要合理 | 描述人数时给范围，如"十余人" |

## 8.7 动作段落调度

| 阶段 | 调度要点 |
| --- | --- |
| 起手 | 明确双方初始位置与距离，一个建立镜交代地形 |
| 交锋 | 保持银幕方向一致；每次击打给一个"力点"镜头 |
| 转折 | 位置关系改变（一人倒地、被逼到墙角） |
| 收束 | 定格在最终位置关系上，观众要能读懂谁赢了 |

动作戏的连续性最易出错：**每一击之后要重新确认双方位置**，否则观众失去空间。

## 8.8 调度的连续性要求

写 `character_blocking` 字段时必须使用"初始→过程→终态"三段式：

```
初始：苏瑾在窗边，面向窗；陈默在门口，面向她背面。
过程：苏瑾转身，向他走三步，停在茶几前。
终态：两人隔茶几相对，距离约 1.5m；苏瑾右手扶桌沿。
```

下一镜的初始状态必须等于上一镜的终态。不等就是穿帮，写进连续性冲突清单。

## 8.9 竖屏调度

| 问题 | 对策 |
| --- | --- |
| 左右并排放不下 | 改用前后站位（一人背对镜头在前，一人在后） |
| 双人同框拥挤 | 一人在画内一人在画外，靠声音与反应镜建立关系 |
| 走位横向不可见 | 改为纵向走位（向镜头走来/走远） |
| 全景难建立 | 用俯拍或高机位一次交代 |

## 8.10 自检

- [ ] 每个走位有动机，不是"为了画面好看"
- [ ] 距离变化对应关系变化
- [ ] 权力关系在构图中有明确落点
- [ ] 三人以上场面已锁定焦点人物
- [ ] 每个镜头的 blocking 有初始与终态
- [ ] 上一镜终态 = 下一镜初始态
- [ ] 竖屏项目已改为纵向调度
