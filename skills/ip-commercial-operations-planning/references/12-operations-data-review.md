# 12 运营数据复盘

## 0. 原则

- 只用真实数据。用户未提供时，列出"需要哪些数据、从哪取"，不得估算后当实测。
- 先核口径，再算指标，最后归因。口径不一致的对比比不比更糟。
- 单一指标不能判断 IP 成败。

## 1. 指标体系（四层）

### 内容传播

| 指标 | 计算 | 用途 | 常见口径坑 |
|---|---|---|---|
| 曝光量 | 平台推送给的展示次数 | 判断分发量 | 是否含重复曝光 |
| 点击率 | 点击 / 曝光 | 判断封面标题 | 曝光定义各平台不同 |
| 播放量 | 播放次数 | 体量参考 | 是否含 3 秒跳出 |
| 完播率 | 完整播放 / 播放 | 内容质量 | "完整"定义不同 |
| 阅读量 | 打开章节次数 | 体量参考 | 与"在读人数"不同 |
| 完读率 | 读完 / 打开 | 内容质量 | 是否按章统计 |

### 用户增长

| 指标 | 计算 | 用途 |
|---|---|---|
| 新增关注 | 期末 − 期初 − 取关 | 拉新效率 |
| 增长率 | (期末 − 期初) / 期初 | 趋势 |
| 7/30 日留存 | 第 N 天仍活跃 / 首日新增 | 习惯形成 |
| 活跃用户 | 周期内有内容消费行为 | 真实规模 |
| 社群参与率 | 发言人数 / 群人数 | 社群质量 |

### 商业转化

| 指标 | 计算 | 用途 |
|---|---|---|
| 付费转化率 | 付费人数 / 触达人数 | 变现效率 |
| 商品转化率 | 下单人数 / 曝光人数 | 商品页效率 |
| 客单价 | 收入 / 订单数 | 价格策略 |
| 复购率 | 二次购买人数 / 首购人数 | 产品力 |
| LTV | 客单 × 复购次数 × 毛利率 | 可承受 CAC |

### 运营效率

| 指标 | 计算 | 用途 |
|---|---|---|
| 单位内容成本 | 总内容成本 / 内容量 | 产能效率 |
| CAC | 营销投入 / 新增付费 | 投放效率 |
| 运营 ROI | 收入 / (内容 + 营销 + 人力) | 整体效率 |

## 2. 口径核对表

复盘第一步，逐项确认：

| 检查项 | 问题 |
|---|---|
| 时间范围 | 各指标统计周期是否一致 |
| 去重规则 | 同一用户多次行为是否去重 |
| 平台差异 | 同一指标在不同平台定义是否相同 |
| 归因方式 | 新用户归到自然流量还是投放 |
| 退款与退货 | 是否从收入中扣除 |
| 分成结算 | 用的是流水还是结算后金额 |
| 时区与结算日 | 是否存在跨日差异 |

口径不一致时，先统一再分析；无法统一时，只做同平台纵向对比。

## 3. 复盘九步

1. **目标回看**：原定目标是什么（量化）。
2. **数据核对**：口径、完整性、异常值。
3. **结果对照**：达成 / 未达成 / 超额，差多少。
4. **漏斗分析**：在哪一环流失。
5. **分层对比**：新老用户、渠道、内容类型分组。
6. **归因**：内部因素（内容/节奏/价格）vs 外部因素（算法/季节/竞品）。
7. **问题排序**：影响 × 可控性。
8. **优化措施**：具体动作 + 负责人 + 判据。
9. **下周期目标**：可验证的 1–3 个目标 + 验证方式。

## 4. 归因方法

| 方法 | 用法 | 注意 |
|---|---|---|
| 漏斗对比 | 找最大流失环节 | 需保证各环节口径一致 |
| 同期群（Cohort） | 按获客周分组看留存 | 样本太小无意义 |
| 内容维度 | 按题材/角色/长度分组看表现 | 注意样本量 |
| 渠道维度 | 按来源看转化质量 | 归因窗口要统一 |
| 时间序列 | 找拐点对应的事件 | 排除季节性与平台活动 |
| 对照测试 | AB 测试封面/标题/付费点 | 一次只测一个变量 |

## 5. 常见伪信号

| 伪信号 | 真相 | 正确做法 |
|---|---|---|
| 粉丝涨但互动降 | 内容与人群错配或买量 | 看互动率与评论质量 |
| 单条爆款 | 可能是算法偶发 | 看连续 10 条的分布 |
| 播放高但付费低 | 用户结构不对（非目标人群） | 看付费人群画像 |
| 首日数据好次日崩 | 钩子强但内容供给不足 | 看 7 日留存 |
| 销量高但退款高 | 预期管理失败 | 看净收入与差评内容 |
| 社群人数多但没人说话 | 拉新而非运营 | 看发言人数占比 |

## 6. 优化措施优先级

按 **影响 × 可控性 / 成本** 排序，一次只推 3 条以内：

| 措施 | 影响 | 可控 | 成本 | 优先级 |
|---|---|---|---|---|
| | 高/中/低 | 高/中/低 | 低/中/高 | P1/P2/P3 |

措施必须写：动作、负责人、开始时间、判据（多久后看什么指标变成什么）。

## 7. 复盘报告模板

```
一、结论（3 条，直接说问题与机会）
二、目标达成情况（目标 / 实际 / 差异 / 原因）
三、数据总览（四层指标表，标口径）
四、关键发现（3–5 条，每条附数据）
五、问题归因（内部/外部，含证据）
六、优化措施（≤3 条，P1 优先）
七、下周期目标（可验证）
八、需要补充的数据与工具
```

## 8. 禁止项

- 不用单点数据下结论（"这条爆了说明方向对了"）。
- 不把相关性当因果。
- 不在口径不同的情况下横向比较。
- 不为了好看隐藏负向数据。
- 不把"数据不好"归因于"用户不懂"。
