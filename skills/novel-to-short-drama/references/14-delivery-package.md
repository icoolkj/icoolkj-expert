# 14 交付包与导演交接

## 目标

把改编成果整理成一套制片、导演、演员都能直接使用的资料，并明确下一阶段的工作接口。

## 一、交付包目录

```
《剧名》_短剧改编交付包_v1.0/
├── 00_交付说明.md
├── 01_改编基准表.md
├── 02_原著解析报告.md
├── 03_人物档案.md
├── 04_分集大纲.md
├── 05_剧本/
│   ├── 第01集.md
│   └── ...
├── 06_场景与道具清单.md
├── 07_改编差异台账.md
├── 08_审校报告.md
└── 09_待确认事项.md
```

按任务范围裁剪，不必每次全出。只交付分集大纲时，也要带 01_改编基准表 与 07_差异台账。

## 二、导演交接重点

导演接手时最需要的不是剧情简介，而是**可拍的判断依据**。交接时明确提供：

| 项目 | 内容 |
|---|---|
| 一句话故事 | 用于向演员/团队解释 |
| 主情绪 | 全剧的情绪基调（爽/虐/悬/甜/燃/暖） |
| 视觉方向 | 色调、质感、参考类型（不给具体影片名，除非用户提供） |
| 关键场面 | 必须拍好的 3-5 场，及为什么重要 |
| 表演重点 | 主角在每个阶段的表演基调 |
| 节奏说明 | 哪些集快、哪些集慢、呼吸点在哪 |
| 成本敏感点 | 高成本场景、可替代方案 |
| 审查敏感点 | 需要处理的表述与画面 |

**交接不代表导演工作已完成。** 明确说明：本文件是改编方的设计意图，导演版分镜需由导演环节完成。

## 三、制片交接重点

| 项目 | 内容 |
|---|---|
| 角色清单 | 角色名、年龄段、戏份集数、演员要求（外形/气质，不指定演员） |
| 场景清单 | 地点、内外景、出现集数、总场次、是否需特殊条件 |
| 道具清单 | 关键道具、首现集、回收集、是否需定制 |
| 时间跨度 | 故事内时间跨度、季节要求 |
| 特殊需求 | 车辆、动物、儿童、群演、特技、特效 |
| 拍摄顺序建议 | 按场景集中度给建议（不按集顺序拍） |

场景集中度建议的价值：同一地点跨多集时，集中拍摄可显著降低成本。

## 四、演员可用资料

每个主要角色提供一张"角色卡"（一页以内）：

- 身份与处境
- 这一季想要什么
- 最大的恐惧
- 与谁关系最紧张
- 三个关键动作（体现性格的行为）
- 一句台词

不要给演员完整的心理分析长文——演员需要的是可演的动作。

## 五、版本与验收

### 命名

```
《剧名》_v1.0_剧本_第01-05集.md
```

### 验收标准

| 项 | 标准 |
|---|---|
| 完整性 | 约定范围内的集数、场次无缺漏 |
| 可拍性 | 场景/人物/道具信息齐全，可直接排期 |
| 一致性 | 已通过第 12 号参考文件的一致性检查 |
| 追踪性 | 每处重大改编有 DIFF 编号 |
| 状态清晰 | 所有待确认事项已列出，无"假装已定"的内容 |

### 交付说明必含

1. 本批范围与版本号。
2. 相对上版的变更摘要。
3. 需用户确认的事项（编号 + 一句话问题）。
4. 已知问题与遗留风险。
5. 下一批范围与预计内容。

## 六、待确认事项清单

集中列出，每条格式：

```
Q-01 [DIFF-004] 是否同意把"母亲知情"从第 30 集提前到第 7 集？
     影响：第 7-12 集的母女对手戏全部改写，中期反转强度下降，前期悬念增强。
     选项：A 同意（推荐） / B 保持原著节奏 / C 折中（提前到第 15 集）
```

给出选项和影响，而不是只问"可以吗"。

## 七、下一阶段接口

| 下一环节 | 需要的输入 | 本 Skill 提供 |
|---|---|---|
| 导演分镜 | 剧本、视觉方向、关键场面说明 | 剧本 + 导演交接说明 |
| 美术/置景 | 场景清单、时代与地域、质感要求 | 场景与道具清单 |
| 选角 | 角色卡、戏份统计 | 人物档案 + 角色卡 |
| AI 视觉制作 | 角色形象、场景描述、画面风格 | 角色卡 + 场景清单（另出制作版时提供画面描述） |
| 后续集数创作 | 差异台账、知识状态表、上集钩子 | 全部三份 |

## 八、常见交付问题

| 问题 | 后果 | 修正 |
|---|---|---|
| 只交剧本，不交基准表 | 后续批次失控 | 基准表必交 |
| 差异只在对话中口头说明 | 无法追溯 | 必须落台账 |
| 场景清单不统计数量 | 制片无法报价 | 必须给地点/场次/演员统计 |
| 把待确认内容写成定稿 | 用户返工 | 状态标记必填 |
| 交付即宣称"完成" | 忽略审校与一致性 | 交付说明中列明检查结果 |

## 九、完成标准

- 目录结构清晰，文件名可辨识。
- 所有文件版本号一致。
- 待确认事项集中在 09 文件，且每条有选项。
- 制片可直接据此排场景、定演员数量。
- 导演可据此判断风格与重点场面。
- 后续批次接手者只需读台账 + 知识状态表即可续写。
