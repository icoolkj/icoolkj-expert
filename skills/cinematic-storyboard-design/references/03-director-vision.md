# 03 导演视觉方案：先有主张，再有机位

分镜不是把剧本翻译成画面，而是用画面提出一个主张。本文件处理"整部片/整集"层面的视觉决策。

## 3.1 视觉方案的四层结构

| 层 | 回答的问题 | 载体 |
| --- | --- | --- |
| 立意层 | 这个戏到底在讲什么 | 一句话主题 + 一句视觉主张 |
| 母题层 | 反复出现的视觉元素 | 3–5 个视觉母题 |
| 语法层 | 用什么镜头语言说话 | 景别/机位/运镜/构图偏好 + 禁忌 |
| 执行层 | 具体怎么拍 | 光色方案、镜头清单、场景设定 |

只有执行层而没前三层，成片会"看起来专业但不像一个导演拍的"。

## 3.2 视觉主张的写法

一个合格的视觉主张要包含"看法 + 手段"：

- ✗ "压抑、冷峻、高级感"
- ✓ "用门框和走廊把人物反复关进画面边缘，让观众始终像站在门外偷看"

- ✗ "温暖治愈"
- ✓ "让阳光永远从人物背后进来，人物始终是半暗的剪影，直到最后一场才第一次被打亮正脸"

判断标准：这句话能不能直接推出机位和光线？能，就是合格的。

## 3.3 视觉母题清单

选 3–5 个，全片复用，每次出现要有变化。

| 母题类型 | 例子 | 用法 |
| --- | --- | --- |
| 空间母题 | 门、走廊、窗、楼梯 | 每次出现代表一次越界或被拒 |
| 物件母题 | 锁、伞、药瓶、镜子 | 承载人物状态，不解释 |
| 动作母题 | 擦手、点烟、整理袖口 | 情绪的外部温度计 |
| 构图母题 | 人物贴边、被切掉一半、隔玻璃 | 关系状态的图形化 |
| 色彩母题 | 某个颜色只在特定人物出现时进入画面 | 无声的身份标记 |

母题滥用会失效。同一个母题在单集出现超过三次，第四次必须变形。

## 3.4 景别策略（集/片级）

不是规定每个镜头，而是定"这部戏的默认视角距离"。

| 策略 | 适用 | 特征 | 风险 |
| --- | --- | --- | --- |
| 远观型 | 命运感、群像、冷峻题材 | 全景与远景为主，人物常小 | 观众难共情，需要关键处插入近景 |
| 贴身型 | 情感戏、独角戏 | 中近与近景为主 | 空间感丢失，需靠声音补环境 |
| 跳变型 | 悬疑、惊悚 | 极远与极近交替，中间层少 | 易疲劳，需节奏控制 |
| 均质型 | 生活流、纪实 | 中景为主，机位克制 | 容易平淡，靠调度和光补 |

**每场至少一次景别跳变**（跨两级以上），否则观众会失去空间感。

## 3.5 机位策略

机位是立场。定三条规则写进方案：

1. **高度基准**：全片以谁的眼睛高度为准？（成人平视 / 儿童视角 / 地面 / 天花板）
2. **权力语法**：强势方偏低机位仰拍、弱势方偏高机位俯拍——或者反过来用（更高级：让弱势方占据画面高度但被压缩在边缘）。
3. **越界条件**：什么情况下才允许荷兰角、主观镜头、极端俯仰？写清触发条件，避免随意使用。

## 3.6 运镜策略

先定"这部戏动不动"：

| 类型 | 主张 | 适用 |
| --- | --- | --- |
| 静观 | 摄影机不动，让人物在画内动 | 压抑、克制、宿命 |
| 跟随 | 摄影机跟着人物走 | 沉浸、焦虑、纪录片感 |
| 揭示 | 摄影机移动到露出新信息 | 悬疑、反转 |
| 侵入 | 缓慢推近 | 心理压强逐步升高 |
| 失衡 | 手持、晃动 | 危机、暴力、失控 |

写进方案时给出比例上限，例如"每场动镜不超过 30%，手持仅限 EP06 之后"。

## 3.7 光色方案

用一句话定调，再落成参数表。

| 项 | 设定 |
| --- | --- |
| 主光方向 | 侧逆为主（制造半暗人脸） |
| 色温 | 日戏 5600K 偏青；夜戏 3200K 偏琥珀 |
| 明暗比 | 关键情绪场 1:8；日常场 1:4 |
| 实景光源 | 只用画内可见光源（窗、台灯、手机屏） |
| 高光策略 | 保留一处过曝，作为"出口" |
| 色彩禁则 | 不用饱和红，除暴力时刻 |

## 3.8 画幅与构图比例

| 画幅 | 视觉性格 | 注意 |
| --- | --- | --- |
| 2.39:1 | 孤独、空间、电影感 | 竖构图人物易被切头，需留天 |
| 1.85:1 | 通用、平衡 | 最安全 |
| 16:9 | 通用、平台友好 | 构图略松 |
| 4:3 | 怀旧、封闭、压迫 | 适合回忆与幽闭场 |
| 9:16 | 竖屏短剧 | 横向信息量小，强调纵向层次与前后景 |

竖屏特别注意：**纵向堆叠代替横向并列**。两人对峙时用前后景纵深，不要并排站。

## 3.9 与制作者的对齐

视觉方案末尾附一页"对齐页"，用最少的字说清执行要求：

```
画幅：2.39:1
整体：侧逆光，人物常处半暗；机位偏低；动镜≤30%
禁则：不用环绕镜头、不用无源柔光、不用饱和红
关键三场：SC03 门（框架构图）、SC07 雨（手持）、SC12 打亮正脸
参考：无（避免直接抄参考片的镜头）
```

## 3.10 方案自检

- [ ] 视觉主张能直接推出机位与光线
- [ ] 母题 3–5 个，每个有"首次出现"和"变形出现"的位置
- [ ] 景别策略与题材匹配，且规定了跳变频率
- [ ] 机位三条规则已写
- [ ] 运镜有比例上限和触发条件
- [ ] 光色有具体参数，不是形容词
- [ ] 画幅已确认，竖屏项目已调整构图逻辑
- [ ] 有禁则（说清"不做什么"比"做什么"更重要）
