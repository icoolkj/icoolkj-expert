# 06 构图：让画面自己说话

构图不是"好看"，是**在画面里安排权力、距离和信息**。观众先读构图，后读台词。

## 6.1 构图三问

1. **主体在哪**？观众第一眼落在谁/什么上？
2. **画面在说什么关系**？近/远、高/低、里/外、完整/被切。
3. **留白给了谁**？空白朝向谁，谁就拥有"未来"。

若三问答不出来，这个镜头只是"拍到了"，不是"设计了"。

## 6.2 基础法则与适用条件

| 法则 | 做法 | 什么时候用 | 什么时候别用 |
| --- | --- | --- | --- |
| 三分法 | 主体置于三分线交点 | 通用、快速建立重心 | 需要绝对对称或压迫时 |
| 中心构图 | 主体正中 | 权威、正面、仪式、对峙 | 想表现失衡时 |
| 对称 | 左右镜像 | 秩序、禁锢、双人对立 | 想表现自然随意时 |
| 框架构图 | 门/窗/镜/缝隙框住人 | 被困、窥视、隔离 | 空间已经很挤时 |
| 前景遮挡 | 虚焦前景压住画面一角 | 偷窥感、层次、不安 | 会挡住关键信息时 |
| 引导线 | 走廊/栏杆/道路指向主体 | 纵深、方向、命运牵引 | 线条指向与叙事相反时 |
| 对角线 | 主体沿对角线分布 | 动感、不稳定 | 表现静止安详时 |
| 负空间 | 大面积留空 | 孤独、渺小、等待 | 信息密集段落 |
| 黄金分割 | 比三分更精细的重心 | 需要精确平衡 | 快速作业时不必强求 |

法则可以破，但要能说出破的理由。

## 6.3 关系构图（最核心）

观众从"人物在画面中的相对位置"读取关系，比台词更快。

| 关系 | 构图做法 |
| --- | --- |
| 亲密 | 同框、距离近、身体有重叠、共享同一光源 |
| 疏离 | 同框但被空间/物隔开，一人亮一人暗 |
| 对立 | 画面左右分置，中间有分隔物（桌、门框、柱子） |
| 权力差 | 一人高一人低；一人满画面一人占边角；一人正脸一人背身 |
| 同盟 | 同侧、同高、同朝向、动作同步 |
| 隔阂 | 玻璃、雨帘、栅栏、门缝作为中间层 |
| 监视 | 前景有人（虚焦背影），后景是被看者 |
| 孤立 | 一人居画面，其余全空；或人群中的静止个体 |

### 距离的视觉刻度

| 画面距离 | 读作 |
| --- | --- |
| 身体接触/重叠 | 亲密或强制 |
| 一臂之内 | 私密 |
| 一桌之隔 | 谈判/对峙 |
| 房间两端 | 决裂 |
| 隔着门/窗 | 不可沟通 |
| 不同景深（一实一虚） | 心理不同频 |

## 6.4 画面重心与视觉重量

视觉重量排序（从重到轻）：人脸 > 运动物 > 高对比区 > 饱和色 > 文字 > 大块暗部 > 空景。

用途：

- 想让观众看 A，就让 A 拥有更重的视觉重量，或让其他元素"让路"。
- **两人同框时，视觉重量更重的一方在观众心里更强**——即使剧情里他是弱者。可用此制造反讽。
- 若关键信息在轻的一侧，用光、色彩或运动把它加重。

## 6.5 视线与留白

| 人物朝向 | 留白位置 | 读作 |
| --- | --- | --- |
| 向右看 | 右侧留白 | 有期待、有去处 |
| 向右看 | 右侧无留白（贴边） | 受阻、被困、无路 |
| 背对镜头 | 前方大片留白 | 面向未知 |
| 低头 | 上方留白 | 被压、无出路 |
| 仰头 | 上方无留白 | 压抑、天花板压迫 |

**留白方向＝心理方向。** 这是最便宜也最有效的构图手段。

## 6.6 高度与画面的上下关系

| 位置 | 读作 |
| --- | --- |
| 画面上三分之一 | 支配、理想、希望 |
| 中心 | 稳定、平等 |
| 下三分之一 | 沉重、被压、现实 |
| 贴画面边缘 | 被排斥、即将离场 |
| 被画框切掉头顶 | 压抑、去人格化 |
| 被画框切掉下半身 | 悬置、不稳定 |

## 6.7 景深与层次

| 层次 | 作用 | 常见做法 |
| --- | --- | --- |
| 前景 | 提供窥视感、框定、增加层次 | 虚焦人物背影、门框、植物 |
| 中景 | 主体，叙事承担者 | 清晰对焦 |
| 后景 | 环境信息、隐喻 | 略虚，但信息可辨 |

**三层俱全的画面最有电影感。** 只有一层的画面（主体贴墙）适合表现压迫或孤立。

## 6.8 竖屏构图补充

| 原则 | 做法 |
| --- | --- |
| 纵向分层 | 上（天/顶）中（人）下（地/桌），用高度差表达权力 |
| 上下叠人 | 前后景纵深成为主要关系手段 |
| 重心上移 | 关键信息不放画面下 1/4（字幕区） |
| 单人满屏 | 近景/中近占比提高，靠机位角度制造变化 |
| 横向元素 | 横移、横排道具改用纵向排列 |

## 6.9 构图与 AI 生成

给生成模型的构图描述要具体到可执行：

- ✗ "电影感构图"
- ✓ "过肩构图，前景左侧为男子虚焦肩部占画面 1/4，中景女子面部位于右三分线，背景门框垂直分割画面"

必须写清：主体位置（三分线左/右/中）、前景有无及占比、背景元素、画面分割线、留白方向。
