# 11 世界观交接包模板

## 1. 交接原则

1. 交接的是**资料与约束**，不是"我已替你完成任务"。
2. 接收方需要的不是全部设定，而是**他不能违反的那部分**。
3. 每个接收方都要收到"禁止事项"清单——这比"可以做什么"更能防止崩设定。
4. 生成交接文档不代表其他专家已自动执行。

## 2. 交接包总览

```
交接包
├── 0. 通用包（所有接收方共享）
│     ├── 世界一句话
│     ├── 核心规则速查表
│     ├── 编号索引
│     └── 全局禁止事项
├── 1. 小说主笔包
├── 2. 短剧编剧包
├── 3. 影视导演包
├── 4. AI视觉设计师包
├── 5. 故事审校官包
├── 6. IP运营官包
└── 7. 总编策划官包
```

### 3.4 全局禁止事项

> 任何后续创作都不得违反的硬约束。逐条写明，例如：

- 不得让任何人在不付出代价的情况下使用 RULE-001。

## 4. 小说主笔包

| 交付项 | 内容 |
|---|---|
| 世界背景 | 时代、主舞台、日常景象描述 |
| 规则约束 | 主角能做什么、不能做什么、代价是什么 |
| 人物档案 | 全部主要人物完整卡 |
| 关系与信息差 | 谁知道什么、误会什么 |
| 时间线 | 绝对时间轴 + 截至故事开始的伏笔 |
| 语言基调 | 称谓、地名用法、常用词汇表 |
| 章节可用素材 | 可引爆的社会矛盾清单 |
| 禁止事项 | 见通用包 + 人物禁止写法 |

**特别提醒**：主笔最容易崩的是"规则代价"和"信息越界"。交接时把这两条列为红线。

---

## 5. 短剧编剧包

| 交付项 | 内容 |
|---|---|
| 核心冲突 | 最短路径上的主要矛盾 |
| 势力对立 | 谁和谁争，争什么，观众能否 30 秒听懂 |
| 人物精简表 | 只保留能撑 60 集的人物（≤8 人） |
| 世界观"一句话交代" | 第 1 集必须讲清的世界规则（越少越好） |
| 规则可视化 | 哪些规则可以用画面直接表现 |
| 爽点与限制 | 主角的优势是什么，凭什么有（必须有代价） |
| 禁止事项 | 不得引入未交代的设定、不得依赖旁白解释规则 |

**关键约束**：短剧没有篇幅做世界观铺陈。交接时必须明确"哪 3 条规则是必须保留的，其余可以砍"。

## 6. 影视导演包

| 交付项 | 内容 |
|---|---|
| 时代与地域参照 | 可对应的现实时期/地区，供美术参考 |
| 空间清单 | 主要场景、规模、相互关系、距离 |
| 环境与气候 | 光线条件、天气、季节性视觉差异 |
| 视觉母题 | 3 个可反复出现的视觉符号 |
| 规则的可拍摄化 | 哪些规则能用镜头表现，哪些只能靠台词 |
| 调度限制 | 空间限制造成的调度特点（狭窄/开阔/垂直） |
| 群演与规模 | 各场景需要的人数级别 |
| 禁止事项 | 不得出现与技术等级不符的道具/建筑 |

---

## 7. AI视觉设计师包

| 交付项 | 内容 |
|---|---|
| 人物视觉卡 | 每人 3 个标志特征 + 服饰 + 装备（来自 CHAR 档案的"外观"栏） |
| 阶层视觉差 | 不同阶层的服饰、材质、色彩逻辑 |
| 场景视觉清单 | 地点 3 个标志物 + 光照 + 材质 |
| 规则视觉化 | 能力/技术的视觉表现规范（颜色、形态、粒子、光的处理） |
| 色彩脚本 | 世界主色调、势力配色、禁用色 |
| 器物设定 | ITEM 的外观、材质、尺寸参照 |
| 禁止事项 | 不得出现与时代/技术等级不符的元素；不得使用未定义的符号系统 |

**纪律**：视觉设定必须能反过来验证文字设定。画不出来的东西，通常是想不清楚的东西。

## 8. 故事审校官包

| 交付项 | 内容 |
|---|---|
| 规则清单 | 全部 RULE，含代价与限制（供逐条核对） |
| 时间线 | 绝对时间轴 + 年龄校验表 |
| 关系表 | 全部关系及其状态 |
| 认知矩阵 | 谁在第几阶段知道什么 |
| 已知风险点 | 本次建设中已识别的 P2/P3 问题 |
| 待观察项 | `[待验证]` 状态的设定 |
| 检查重点 | 列出最容易出错的 5 个位置 |

---

## 9. IP运营官包

| 交付项 | 内容 |
|---|---|
| 世界特色 | 3 个可传播的世界记忆点 |
| 人物记忆点 | 每个主要人物一句话 + 一个符号 |
| 可开发资产 | 世界观中可独立成产品的元素（组织、器物、地点、规则） |
| 视觉资产清单 | 已定义、可直接出图的部分 |
| 延展空间 | 预留扩展区（可做前传/外传/衍生） |
| 传播禁区 | 不宜对外披露的设定（剧透性真相） |

## 10. 总编策划官包

| 交付项 | 内容 |
|---|---|
| 完成度 | 各模块完成情况（表格） |
| 设定规模 | 条目数量、关系数量 |
| 风险 | P0/P1 项、逻辑薄弱环节 |
| 待确认 | 需决策事项清单 |
| 跨媒介适配 | 各形态所需改造工作量（定性） |
| 后续建议 | 下一步该做什么，不该做什么 |
