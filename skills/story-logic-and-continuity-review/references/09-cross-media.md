# 09 跨媒介一致性审校（M09）

## 1. 版本基准：先定权威源

跨媒介审校的核心不是"比差异"，而是**先确定哪一份是权威基准**。否则会把正确的改编判成错误。

### 1.1 权威源优先级

| 层级 | 来源 | 说明 |
|---|---|---|
| L1 | 作者明确指定 + 最新确认 | 最高 |
| L2 | 已定稿正文（小说终稿 / 剧本拍摄稿） | |
| L3 | 已批准的大纲 / 分集 / 场景表 | |
| L4 | 设定文档、人物档案、资产档案 | |
| L5 | 早期草稿、废弃版本 | 不得作为冲突基准（除非标 DEPRECATED 用于说明演变） |

**规则**：L5 与 L2 冲突不是问题；L2 与 L4 冲突需要判断——通常正文优先，但若正文是笔误则由作者裁定。

### 1.2 改编不是错误

改编作品对原作的有意修改，只要符合已批准的改编方案，**不构成不一致**。审校要做的是：

1. 确认该差异是否在改编方案中被明确批准。
2. 若未批准 → 记为"未授权偏离"，请作者确认是接受还是修正。
3. 若已批准 → 检查该差异是否在下游（剧本、分镜、资产）被一致执行。**批准了却只改了一半，才是真问题。**

---

## 2. 六组对照关系

| 对照 | 检查重点 | 高发冲突 |
|---|---|---|
| 设定 ↔ 小说 | 规则、地理、人物档案 | 正文违反自己写的设定；设定未及时更新 |
| 小说 ↔ 短剧改编 | 事件因果、人物动机、结局 | 压缩导致动机缺失；合并角色造成信息错配 |
| 大纲 ↔ 剧本 | 集数节奏、钩子位置、关键转折 | 集数与内容错位；钩子写在大纲没写的位置 |
| 剧本 ↔ 分镜 | 场次、台词、动作、镜头可见性 | 分镜拍了剧本没有的动作；台词与画面矛盾 |
| 分镜 ↔ 角色资产 | 年龄、体型、发型、服装、伤痕、标志物 | 分镜要求"左脸刀疤"，资产在右脸；服装季节错 |
| 分镜 ↔ 场景资产 | 空间结构、出入口、陈设、光线时段 | 分镜从"不存在的门"进出；资产是白天、分镜是夜戏 |
| 剧情 ↔ 道具资产 | 道具外观、归属、状态 | 道具在第 5 集已断，资产仍为完好版 |

## 3. 统一事实表（Single Source of Truth）

跨媒介审校必须落一张**中立事实表**，各版本对同一事实的表述并排放置：

| 事实 ID | 属性 | 小说 | 剧本 | 分镜 | 角色/场景资产 | 一致性 |
|---|---|---|---|---|---|---|
| F-CHAR-012 | 沈砚年龄 | 27（第3章） | 25（第1集台词） | — | 25（设定卡） | 冲突（剧本+资产 vs 小说） |
| F-CHAR-020 | 林昭伤处 | 左手（第9章） | 右手（第6集） | 左手（S12） | 右臂有疤 | 冲突 |
| F-SPACE-004 | 药铺门朝向 | 朝南（第2章） | — | 朝东（S08） | 朝东 | 冲突 |

**这张表就是交付物**。报告正文只需引用表内 ID，不必重复罗列。

### 3.1 必须建档的高冲突事实

年龄、身高、体型、发型、面部特征（疤/痣/眼镜）、惯用手、服饰（季节/颜色/制式）、
称谓与称呼变化、亲属关系、地名与方位、时间与季节、能力上限、关键道具外观与状态、
空间布局与出入口、人数（军队/门派/家族规模）。

### 3.2 一致性判定四态

- **一致**：表述兼容。
- **兼容差异**：表述不同但不矛盾（小说写"二十七"，剧本未提）。
- **冲突**：两者不能同时为真。
- **待确认**：信息缺失或来源不可靠。

只有"冲突"才进入问题记录；"兼容差异"只在必要时提示。

## 4. 改编专项检查

### 4.1 压缩导致的动机缺失
小说用一章铺垫的动机，剧本压缩成一句台词时，常丢失"为什么"。

- 判据：剧本中该行动前，是否有任何一句提供理由？无 → P2。
- 修复优先：加一句台词或一个动作，而非加场。

### 4.2 角色合并导致的信息错配
两个小说角色合并为一个时，原属 A 的秘密可能落到 B 头上，破坏认知边界。

- 检查：合并后的角色知道的信息，是否都能通过他的经历获得？（转 M06）

### 4.3 集数/时长导致的因果跳跃
为控制时长删掉过程，导致结果无因。

- 检查：每集结尾钩子与下集开场的因果是否成立。
- 短剧特有问题：**"爽点前置"**会让前因后置，需确认后置的因在揭示时能解释前面的果。

### 4.4 视觉化导致的可行性问题
小说可以写"他心中一惊"，分镜必须给出可见的表达。

- 检查：分镜中的动作是否在剧本中有依据？分镜"加戏"是否改变了人物关系或信息传递？
- 典型问题：分镜为了让画面好看，让角色在不该出现的场景出现（转 M08）。

### 4.5 资产与剧情的时序错配
角色资产通常是"标准版"，但剧情中人物状态在变（受伤、换装、变老）。

- 检查：每个关键节点是否有对应的状态版资产？缺失则记为制作风险（P2 级，标注为资产缺口而非剧情错误）。

---

## 5. 跨媒介审校流程

1. 确认各文件版本号与定稿状态，排出权威源顺序。
2. 建立统一事实表（先做 3.1 的高冲突项）。
3. 逐组对照（第 2 节的六组），只记录"冲突"。
4. 对每个冲突判断：是笔误、是未授权偏离、还是获批改编。
5. 定级：影响剧情理解的 P1/P2；仅影响视觉细节的 P3。
6. 输出：统一事实表 + 冲突清单 + 修订建议（指明改哪一份文件）。

## 6. 输出模板示例

```
### 问题编号：MEDIA-004
- 问题标题：林昭受伤部位在小说、剧本、角色资产之间不一致
- 问题等级：P1
- 问题状态：待确认
- 所属审校模块：M09 跨媒介一致性
- 发生位置：小说第9章 / 剧本第6集第12场 / 角色资产设定卡 v1.2
- 问题描述：小说写左手被划伤，剧本第6集写"右手一道血口"，
  角色资产设定卡标注"右臂旧疤"。三份文件指向两个不同部位，
  且该伤在第12集有"左手不能持刀"的关键情节。
- 原文证据：小说第9章：「刀锋擦过左手手背。」（TEXTUAL）
  剧本 6-12：「他捂住右手，血从指缝里渗出来。」（TEXTUAL）
  角色资产卡：「右臂内侧有旧疤，长约三寸。」（TEXTUAL）
- 冲突基准：F-CHAR-020 林昭伤处（小说 L2 为权威源：左手）
- 问题原因：改编过程中未同步资产与剧本；资产可能沿用了早期设定。
- 影响范围：剧本第12集"左手不能持刀"（与剧本自身第6集冲突）；
  分镜 S14、S21 的持刀手；角色资产全部含手臂的画面。
- 最小修复方案：以小说为准，将剧本 6-12 改为左手，资产卡改为"左臂内侧旧疤"，
  第12集情节无需改动（改动 2 处文本 + 1 处资产标注）。
- 替代方案：以剧本为准改为右手受伤，则第12集"左手不能持刀"需重写，
  并影响后续 3 集的动作设计，代价明显更大。
- 修复后复审要求：核对该角色全部出场镜头的手部状态；确认第12–15集动作描述
  与最终伤处一致；确认资产已出新版并标注替换旧版。
```
