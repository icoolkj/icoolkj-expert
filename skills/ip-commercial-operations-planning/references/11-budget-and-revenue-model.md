# 11 预算与收益模型

## 0. 纪律

- 不在缺少数据时给出精确数字。所有预测标 E4，并附假设表。
- 每个数字必须写清：**单位、周期、口径（含税/不含税、分成前/后、含不含人力）**。
- 必须三情景并列（乐观 / 基准 / 保守），不给单点预测。
- 敏感变量单列，说明"若假设不成立，结论怎样变化"。

## 1. 成本科目

| 类别 | 明细 | 一次性 / 经常性 | 备注 |
|---|---|---|---|
| 内容创作 | 写作、编剧、分镜、绘制 | 经常性 | 按千字/集/页计价 |
| 制作 | 拍摄、剪辑、配音、动画、后期 | 一次性（单项目） | 按集/分钟计价 |
| 视觉资产 | 角色设计、场景、立绘、表情包 | 一次性 | 可复用资产优先 |
| 发行 | 平台上线、适配改造、保证金 | 一次性 | 易被低估 |
| 营销推广 | 内容制作、达人、投流、活动 | 经常性 | 波动最大 |
| 人力 | 全职、兼职、外包管理 | 经常性 | 按人月 |
| 平台成本 | 分成、技术服务费、支付通道 | 变动 | 按收入比例 |
| 供应链 | 打样、模具、生产、包装、仓储 | 一次性 + 变动 | 含最小起订量 |
| 商务 | 差旅、样品、法务、中介 | 经常性 | |
| 管理 | 财务、行政、工具订阅 | 经常性 | 按比例分摊 |

成本表必须区分三类：**沉没成本（已发生）**、**刚性成本（必须付）**、**弹性成本（可停）**。停损方案依赖这个区分。

## 2. 收入科目与计算式

| 收入线 | 计算式 | 关键参数 |
|---|---|---|
| 付费阅读 | 付费章节数 × 单章价 × 付费用户数 × 购买率 | 单章价、付费率 |
| 会员订阅 | 会员数 × 月费 × 留存月数 | 续费率 |
| 平台分账 | 有效播放/阅读量 × 单价 × 分成比例 | 单价（平台规则，需核实） |
| 短剧付费 | 投流曝光 × 点击率 × 付费转化 × 客单 − 投流成本 | CPM、转化率 |
| 广告/激励 | 播放量 × 千次单价 | 单价波动 |
| 品牌合作 | 合作数 × 单笔金额 | 成交率 |
| 授权 | 保底 + 销售额 × 分成率 | 分成基数 |
| 商品 | 销量 × 单价 − 退货 − 成本 − 履约 | 退货率、履约成本 |
| 线下活动 | 票数 × 票价 + 赞助 − 场租成本 | 到场率 |

## 4. 单位经济模型

| 指标 | 计算式 | 健康判断 |
|---|---|---|
| 毛利率 | (收入 − 变动成本) / 收入 | 内容 ≥50%，商品 ≥40%（E4 参考） |
| 用户获取成本 CAC | 营销总投入 / 新增付费用户 | 需 < 首单毛利 |
| 用户生命周期价值 LTV | 客单价 × 复购次数 × 毛利率 | LTV / CAC > 3 才有扩张空间 |
| 回本周期 | 累计净现金流转正所需月数 | 内容 ≤12 月，商品 ≤6 月（E4） |
| 盈亏平衡点 | 固定成本 / 单位贡献毛益 | 需低于保守情景销量 |
| 投入产出比 | 总收入 / 总投入 | <1 即亏损 |

单位经济不成立时，扩大规模只会放大亏损——这是最重要的判断。

## 7. 表达规范

- 单位统一：元 / 万元，全文一致。
- 金额注明含税与否。
- 分成收入注明是"分成前"还是"分成后"。
- 人力成本注明是否计入。
- 所有外部参数（平台单价、分成比例）标来源与时间，否则标 E4。
- 预测不写小数点后两位——精度与依据不匹配即是误导。

## 8. 输出格式

```
1. 预算总表（一次性 / 经常性 / 变动，含口径说明）
2. 收入测算表（每条收入线一个计算式 + 参数）
3. 三情景表（保守/基准/乐观）
4. 单位经济（毛利率、CAC、LTV、回本、盈亏平衡）
5. 月度现金流（含最大资金缺口月）
6. 敏感性分析（Top3 变量）
7. 关键假设表（每条假设 + 若不成立的影响）
8. 止损线与调整预案
```
