# 04｜人物状态与关系档案

## 人物档案条目模板

```
【人物编号】C-001
【姓名】
【身份】
【外貌】（固定特征，含明显标记如伤疤）
【性格】（核心性格 + 行为倾向）
【目标】（长期目标 / 当前阶段目标）
【动机】
【能力与资源】
【重要经历】（带章节来源）
【当前状态】
  - 位置：
  - 时间点：（该状态对应的故事时间）
  - 身体状况：（伤势、疲劳、中毒等）
  - 情绪状态：
  - 装备/持有物：
  - 金钱/资源：
【掌握的信息】（知道哪些秘密、见过什么、记得什么）
【不知道的信息】（认知盲区，防止续写越界）
【语言特点】（口头禅、说话风格、称呼习惯）
【人物弧线进度】（成长/黑化/转变进行到哪一步）
【来源章节】首次登场：第X章；最近出场：第X章
```

## 人物状态追踪规则

1. **状态随事件更新**：每次续写完成后，更新所有出场人物的「当前状态」字段，注明对应章节。
2. **区分即时状态与长期状态**：伤势、情绪会随时间恢复；性格、能力、关系性质属于长期状态，不能无故回退。
3. **状态连续性检查**：续写时核对人物上一状态——
   - 上一章受重伤，本章不能毫发无损（除非有治疗情节）。
   - 上一章在 A 地，本章出现在 B 地必须有移动过程或时间跳跃说明。
   - 上一章持有/失去的物品，本章必须一致。
4. **离场人物不冻结**：长期未出场人物在再次登场前，检查其离场时状态和离场期间合理的变化（时间推进带来的恢复、情绪沉淀等）。

## 人物关系档案模板

```
【关系编号】R-C001-C002
【双方】A ↔ B
【当前性质】（盟友/敌对/师徒/恋人/陌生人/表面X实际Y）
【信任程度】（高/中/低 + 简述）
【信息差】（A 知道但 B 不知道的事；反之亦然）
【变化历史】
  - 第X章：建立关系，原因是……
  - 第Y章：因……事件恶化/升温
【当前张力】（未解决的误会、亏欠、矛盾）
```

## 关键检查点

- 关系变化必须有事件支撑，不能无因突变。
- 信任和敌意是渐进的，单章内避免「一夜反目/一夜交心」，除非有足够强的触发事件。
- 信息差是剧情张力的来源，续写利用信息差前先核对本档案。
- 配角群像：保持次要人物的名字、外貌、称呼一致性（这是长篇最常见的穿帮来源），建立配角速查表。
