# 10 人物 / 势力 / 地点 / 物品档案模板

所有档案共用一条纪律：**每个字段都写，写不出就填"未定"，不要留空**。空格会被后续读者（包括作者自己）误认为"不存在"。

---

## 1. 人物档案卡

```
CHAR-000  姓名
═══════════════════════════════
【基本信息】
别名/绰号      自称、他称、敌人怎么叫
年龄           具体年龄 + 关键事件时的年龄
性别
身份           社会身份 / 真实身份
所属势力       FACTION-000（实际立场：效忠/敷衍/潜伏/被挟持）
活动区域       LOC-000

【外观】
标志特征 1      （可直接交给视觉设计）
标志特征 2
标志特征 3
服饰/装备     与社会阶层、职业、规则相关
体态变化      受伤/变异/衰老等随时间的变化

【性格】
行为模式       具体行为，不用形容词
口头习惯       一句话体现阶层或地域
应激反应       被逼急时做什么
矛盾点         他自己没意识到的自相矛盾之处

【动机】
表层欲望       他嘴上说要什么
真实目标       他实际在追什么
内在需求       他缺什么才完整（他未必自知）
核心恐惧       宁可毁掉一切也不愿面对的事

【背景】
出生地         LOC-000
关键经历      按时间排列 3–5 条，每条挂 EVENT 编号
伤口           造成当下性格的那一件事（只写一件）
转折           他曾经做过的、无法回头的一个选择

【能力】
能力来源       RULE-000
能力等级       体系中的位置
核心手段       他最常用的一招
明确短板       打不过谁、怕什么、缺什么
成长空间       下一步能到什么程度，需要什么

【秘密】
秘密内容
知情者         CHAR-000 / 无人
部分知情者     谁只知道一半，误以为什么
暴露后果       谁会因此杀他/救他
揭示计划       第几阶段、由谁揭穿

【关系】
CHAR-000      关系类型 / 依据 / 强度 1–5 / 当前状态 / 变化条件
CHAR-000      ...

【成长弧线】
起点状态 →
第一次动摇（触发事件）→
中点转变（认知级）→
最低点 →
终点状态
代价           他失去了什么

【当前状态】
故事开始时，他在哪、在做什么、最想要什么、最怕什么

【写作提示】
一句话人设      读者应该用哪句话记住他
禁止写法      最容易写崩的地方（如"不要让他突然变善良"）

设定状态 / 版本
═══════════════════════════════
```

## 2. 势力档案卡

```
FACTION-000  势力名称
═══════════════════════════════
【标识】
自称            他们怎么称呼自己
他称            外界怎么叫他们（通常带贬义）
标志/口号
据点            LOC-000

【起源】
建立时间       绝对年
建立者         CHAR-000（可能已死）
建立原因       因哪个 EVENT，为解决什么问题

【目标】
核心目标        一句话，可执行
次级目标        当前正在推进的 1–3 件事
不做什么        明确的禁区（让势力有底线，才可信）
三年后愿景      若无人阻止，会变成什么样

【结构】
组织形式        层级/扁平/网络/家族
决策方式        独裁/议会/投票/血脉/实力
层级表          层级 - 人数 - 职责 - 准入条件
情报流向        谁知道什么（决定内鬼能否存在）
成员规模        数量级

【人员】
领导者          CHAR-000 / 掌权依据 / 执政风格 / 软肋
核心成员        CHAR-000 ×3–5，各标注立场（拥护/观望/不满）
关键小人物      一个能代表基层的普通成员

【资源】
控制区域
关键资源        ITEM-000
收入来源
维持成本        每天/每月需要消耗什么（写不清就没有真实感）

【优劣】
核心优势        别人做不到的事（1–3 条）
结构性弱点      组织层面的缺陷，不是"首领性格不好"
致命依赖        失去什么就会崩

【关系】
FACTION-000     关系类型 / 交换标的 / 当前状态 / 变化条件

【内部矛盾】
派系            派系名 / 主张 / 代表人物 / 与主线派的分歧
代际矛盾        老人 vs 新人
路线矛盾        激进 vs 保守

【设定状态 / 版本】
═══════════════════════════════
```

## 3. 地点档案卡

```
LOC-000  地点名称
═══════════════════════════════
类型            城市/要塞/遗迹/秘境/据点/野外
位置            相对坐标；从最近聚落如何到达，耗时多少
归属            FACTION-000；实际控制情况（名义归属 ≠ 实际控制）
规模            人口 / 面积量级
外观            3 个可视觉化标志物
功能            交易 / 军事 / 宗教 / 生产 / 避难 / 通道
资源            此地产出什么
规则例外        此地是否有局部规则（时间、能力、物理）
危险            常驻威胁 + 概率
关键人物        CHAR-000
日常景象        一天是怎么过的（写 3 句，用于场景描写）
历史            EVENT-000
剧情作用        主角为什么会来这里 / 谁会在这里死
设定状态 / 版本
═══════════════════════════════
```

**纪律**：没有剧情作用的地点，只保留名字进"地点清单"，不建卡。

## 5. 事件档案卡

```
═══════════════════════════════
正式名 / 民间叫法

起因            上一事件

```

## 7. 档案填写检查

| 检查 | 问题 |
|---|---|
| 空字段 | 是否有"未定"以外的空白 |
| 编号引用 | 引用的是编号还是名称（应统一编号） |
| 量化 | 年龄、距离、时间、数量是否给具体值 |
| 因果 | 每个"结果"是否都有"原因" |
| 功能 | 人物/地点/势力是否有不可替代的作用 |
| 独立性 | 势力目标是否依赖主角 |
| 状态 | 是否只有一个状态标签 |

## 8. 档案与正文的边界

档案是**给作者用的工具**，不是正文内容。

交付时明确：

- 档案中的"禁止写法""写作提示"不进入正文。
- 档案中的"秘密/真相"不能直接写入人物对白。
- 设定集可交给人看，档案卡主要给创作者看。
