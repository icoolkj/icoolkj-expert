# 02 故事解构与要素提取

## 目标

把原著从"文本"变成"可重排的零件"：事件卡、因果链、关系网、节奏曲线。重构的每一步都基于此层，而不是凭印象。

## 一、事件卡

每个值得独立成场的事件写一张卡：

```
【E-编号】事件名
- 原文位置：第 X 章
- 谁做了什么：
- 为什么做（动机）：
- 谁受损/受益：
- 结果（可观察的后果）：
- 是否改变人物处境：是/否 → 若无改变，标"装饰性事件"
- 是否不可替代：是（因为结果是后续 X 的前提）/ 否
- 情绪类型：爽/虐/悬/甜/燃/暖
- 视觉强度：高（可拍成冲突场面）/ 中 / 低（偏心理或叙述）
```

只有"改变人物处境"的事件才具备分集价值。连续出现三张以上"装饰性事件"，说明该段落需要压缩成一个过场。

## 二、因果链

把事件卡串成链条：

```
E01 主角被退婚 → 主角进城打工 → 遇到旧识 A → A 透露秘密 → 主角决定反击 → 对手反扑 → ...
```

检查三条：

1. **每条箭头是否有动机支撑**。没有动机的箭头是"剧情需要"，改编时必须补动机或改事件。
2. **是否存在断链**。原著靠巧合推动的地方，短剧中必须换成人物主动选择。
3. **是否可删除某环而不影响结果**。可删的环就是不承载因果的冗余。

> 判断法：删掉 E07，后面的 E10 结局是否仍能成立？能 → 冗余；不能 → 因果节点，进"不可删清单"。

## 三、不可删节点清单

改编最常犯的错，是删掉了"看起来像铺垫"的因果节点，结果让高潮失去说服力。

必须进入清单的内容类型：

- 主角获得关键能力 / 身份 / 证据的那一场。
- 反派形成敌意的那一场。
- 秘密第一次露出破绽的那一场。
- 关系从 A 变 B 的那个动作。
- 造成最终代价的那个选择。

清单格式：

| 节点 | 原著位置 | 删掉的后果 |
|---|---|---|
| 主角捡到账本 | 第 6 章 | 后文所有"证据反杀"不成立 |

## 四、人物关系网

用文字矩阵表达，避免画图：

```
主角 —(血缘/敌对/利益/情感)— 对手：敌对，动机 = 争夺继承权，温度 = 冷
主角 — 挚友：绑定理由 = 少年救命之恩，可被利用的弱点 = 家人
对手 — 主角母亲：利益同盟，随时可能反水
```

每个关系标注三项：**绑定理由、当前温度、可被打破的条件**。第三项是短剧最重要的可用资源——关系破裂的那一刻就是高潮。

## 五、主线与支线判定

- **主线**：删掉它，故事不存在。
- **副线**：删掉它，主线仍成立，但人物变薄。
- **支线**：删掉它，不影响任何东西。

短剧的处理原则：

| 类型 | 处理 |
|---|---|
| 主线 | 保留，但压缩过程、提高事件密度 |
| 副线 | 保留 1-2 条，且必须与主线在同一集内交汇 |
| 支线 | 合并进主线人物，或整体删除 |

支线判断经验：一条支线如果连续 5 集不与主线发生交集，观众会快进。

## 六、节拍提取（Beat Sheet）

把原著映射到节拍表，用于发现结构缺口：

| 节拍 | 原著对应 | 强度（1-5） | 缺口判断 |
|---|---|---|---|
| 开场画面（主角当前平衡） | | | |
| 激励事件 | | | |
| 第一次拒绝/犹豫 | | | |
| 跨过门槛（主动进入冲突） | | | |
| 中点（翻面/真相/立场改变） | | | |
| 坏人逼近（压力最大） | | | |
| 至暗时刻（失去最重要的东西） | | | |
| 顿悟（想通什么） | | | |
| 高潮（正面对决） | | | |
| 结局画面（新的平衡） | | | |

常见缺口与对策：

- **缺中点**：故事"平"，前二十集都在铺垫。对策：把原著第 1/3 处的真相或背叛提前到中点位置。
- **缺至暗时刻**：主角一路赢，没有代价感。对策：让主角在中后段失去一个具体的人或物。
- **缺激励事件**：前几集只在介绍人物。对策：把原著第 5 章才发生的冲突挪到第 1 集前 3 分钟。

## 七、情绪曲线

按集（或按章节）标注主情绪与强度：

```
第1集 悬(3) → 第2集 虐(4) → 第3集 爽(5) → 第4集 悬(4) ...
```

检查：

- 是否有连续 3 集以上同一情绪且强度不升。
- 是否在阶段高潮前有情绪低点（没有低点，爽点不成立）。
- 结局情绪是否与主情绪一致（主爽的故事不能以压抑结尾，除非明确做开放式）。

## 八、提取结果的用法

| 产物 | 去向 |
|---|---|
| 事件卡 | 03 评估（判断密度与可拍性）、04 重构（重排顺序） |
| 不可删节点清单 | 04 重构的硬约束、12 一致性校验的基准 |
| 关系网 | 05 人物改编（合并/删除依据） |
| 节拍表 | 06 整体结构（阶段划分） |
| 情绪曲线 | 07 分集规划（钩子与爽点分布） |

## 九、完成标准

- 事件卡数量与原著篇幅匹配（一般每 3000-5000 字一张，长篇可合并）。
- 因果链无断点，或断点已标注并给出补救方案。
- 不可删节点清单能回答"删了会怎样"。
- 每条关系都有"可被打破的条件"。
- 节拍表缺口已识别，并给出具体对策。
