# 05 跨媒介开发

## 0. 前提

**不得默认所有项目都要跨媒介开发。** 大多数项目适合单一形态做深做透。跨媒介的前提是：

1. 核心设定具备**可迁移性**（换媒介后仍然成立）。
2. 已有单一形态的**验证基础**（内容完成度或用户反馈）。
3. 有明确的**开发顺序**与**资产复用**逻辑。

三者缺一，跨媒介规划就只是愿望清单。

## 1. 媒介适配矩阵

| 维度 | 小说 | 竖屏短剧 | 横屏剧集 | 动态漫 | AI影视 | 有声剧 |
|---|---|---|---|---|---|---|
| 核心驱动力 | 叙事与心理 | 冲突与反转 | 人物与主题 | 画面与设定 | 概念与视听 | 对白与声音 |
| 节奏单位 | 章 | 60–120 秒 | 40–45 分钟 | 3–5 分钟 | 镜头/段落 | 20–30 分钟 |
| 信息密度 | 高 | 极低（单点多） | 中 | 中 | 中低 | 中 |
| 世界观承载 | 极强 | 弱 | 强 | 中 | 中 | 中 |
| 内心戏 | 强 | 弱 | 中 | 弱 | 弱 | 强（旁白） |
| 制作成本 | 低 | 中 | 高 | 中 | 中 | 低 |
| 周期 | 长（创作） | 短 | 长 | 中 | 中 | 短 |
| 主要风险 | 无人知晓 | 同质化 | 招商与审查 | 作画与更新 | 一致性与技术 | 声音辨识度 |

## 2. 五问适配判断

对每个候选媒介，逐一回答：

1. **核心体验是否能保留？** 若某媒介会摧毁核心体验，直接排除。
2. **节奏硬指标是否满足？** 竖屏短剧要求 15 秒入戏，慢热型创意不适用。
3. **需要新增多少内容？** 从小说到短剧需大量"事件化"改写，需评估工作量。
4. **资产能否复用？** 人物设定、场景设定、视觉符号能否跨媒介共享。
5. **成本与周期是否可控？** 尤其是 AI 影视的生成一致性成本。

## 3. 常见跨媒介路径

| 路径 | 逻辑 | 适用 | 注意 |
|---|---|---|---|
| 小说 → 短剧 | 用小说验证故事与人设，再事件化改编 | 关系张力强、冲突密集 | 需重写而非浓缩 |
| 短剧 → 小说 | 用短剧验证钩子，反向扩充文本 | 已有爆款结构 | 需补人物弧光，否则空心 |
| 小说 → 动态漫 | 视觉符号强、设定可视化程度高 | 奇幻、异能、悬疑 | 单格信息量重新设计 |
| 小说 → AI影视 | 场景集中、概念清晰 | 科幻、悬疑、单元剧 | 一致性是首要工程问题 |
| 小说 → 有声剧 | 对白密集、角色声音差异大 | 群像、悬疑、言情 | 需重写旁白与音效提示 |
| 任何 → 系列IP | 世界观可扩展、角色可衍生 | 有稳定世界规则 | 需先建立设定圣经 |

## 4. 各媒介所需内容资产

### 通用基础资产（任何媒介都需要）

- 一句话故事与核心卖点（对外沟通用）。
- 主角小传（外部目标、内在需求、伤口、缺陷）。
- 核心关系图（含张力与变化方向）。
- 主线三阶段 / 前3个循环单元。
- 记忆点清单（画面、台词、关系、规则）。

### 分媒介增量资产

| 媒介 | 增量资产 | 交付给谁 |
|---|---|---|
| 小说 | 分卷大纲、章节钩子表、设定集 | 小说主笔 |
| 竖屏短剧 | 分集大纲、前3集逐场、卡点表 | 短剧编剧 |
| 横屏剧集 | 分集梗概、人物小传、主题陈述 | 编剧 + 导演 |
| 动态漫 | 角色三视图、场景设定、分镜脚本 | 美术 + 分镜 |
| AI影视 | 视觉设定（人物一致性参考）、镜头表、提示词规范 | AI视觉设计师 + 导演 |
| 有声剧 | 角色声音设定、旁白改写稿、音效提示 | 音频制作 |

## 5. 开发优先级排序

排序依据三个变量：**验证价值 × 成本可控性 × 资产复用率**。

| 优先级 | 判断 | 典型选择 |
|---|---|---|
| P0 | 成本最低、最能验证核心假设 | 文本（小说/大纲/样章） |
| P1 | 复用 P0 资产、能扩大受众 | 有声、动态漫样片 |
| P2 | 需重写结构、投入较大 | 短剧、剧集 |
| P3 | 高成本、高门槛 | 长片、游戏、实景 |

**纪律**：不要把 P2/P3 写进"下一阶段任务"，除非 P0/P1 已完成。

## 6. 制作难点与风险

| 风险 | 说明 | 缓解方式 |
|---|---|---|
| 一致性风险 | AI 影视/动态漫中角色形象漂移 | 建立角色参考包与提示词规范 |
| 结构移植风险 | 小说内心戏无法影视化 | 改为行为与对白外化，重写场景 |
| 成本失控 | 大场面、群戏、复杂动作 | 策划阶段就做"场景预算意识"设计 |
| 更新风险 | 连载类产能不足 | 预留存稿期，单元化设计 |
| 同质化风险 | 与同期项目撞设定 | 强化关系与人物差异 |
| 审查风险 | 题材、尺度、价值导向 | 提前识别红线，准备替代方案 |

## 7. 版权与权利分层

策划阶段需明确权利边界（具体法律问题应咨询专业人士，此处仅作结构提示）：

| 权利层 | 内容 | 注意 |
|---|---|---|
| 原创著作权 | 文本、设定、人物 | 确认完全原创，避免无意识雷同 |
| 改编权 | 跨媒介改编的授权范围 | 明确媒介、期限、地域、独家性 |
| 衍生开发权 | 周边、游戏、线下 | 通常单独约定 |
| 素材授权 | 参考图、音乐、字体、配音 | AI 生成物的商用条款需单独确认 |
| 合作方权利 | 平台、制作方、演员 | 明确署名与收益分配 |

**输出要求**：在策划案中列出"待确认的权利事项"，而非给出法律结论。

## 8. 输出格式

| 媒介 | 适配度 | 理由 | 需新增资产 | 主要难点 | 优先级 |
|---|---|---|---|---|---|
| 小说 | 高/中/低 | | | | P0 |

并在表下补充：

- **建议路径**：一句话说明先做什么、再做什么。
- **不建议路径**：说明哪些媒介当前不做，以及为什么。
