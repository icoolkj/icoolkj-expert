# 01 世界观构建方法论

## 1. 世界观的本质

世界观不是背景资料集，而是**一套能自动生成情节的规则系统**。

判断一个世界的成熟度，不看设定字数，而看三个能力：

| 能力 | 检验方式 |
|---|---|
| 生成能力 | 给定一个人物放进这个世界，能否自然产生冲突 |
| 约束能力 | 主角遇到困难时，能否从规则中找到"他不能这样做"的理由 |
| 推断能力 | 未写过的场景，读者能否自行推断出大致样貌 |

三个能力都具备，世界才算"能跑"。

## 2. 分层模型：冰山结构

世界观分三层，创作只露出第一层，但必须建好下面两层。

| 层级 | 内容 | 读者可见度 | 建设要求 |
|---|---|---|---|
| 表层 | 地名、人物、组织、名词、外观 | 100% | 必须精彩、有记忆点 |
| 结构层 | 规则机制、利益关系、制度逻辑、因果链 | 30–50% | 必须自洽，能撑住表层 |
| 底层 | 世界的核心命题（这个世界在追问什么） | 5–10% | 必须存在，决定世界的气质 |

**常见失败**：只建表层，越写越空；或只建底层，读者看不到，变成作者自嗨。

**纪律**：底层命题用一句话写清。例如"末世世界的底层命题是：秩序崩塌后，人还愿不愿意做一个人"。所有设定都应能与这句话对话。

## 3. 构建顺序与依赖关系

必须按依赖顺序建，跳步会导致返工。

```
① 核心规则（世界为什么不一样）
      ↓
② 资源与代价（规则带来的稀缺与分配）
      ↓
③ 社会结构（谁掌握资源，形成什么制度）
      ↓
④ 势力组织（谁在争夺，为什么争）
      ↓
⑤ 人物（谁被这套结构挤压，做出什么选择）
      ↓
⑥ 历史与时间线（这套结构如何演化到今天）
      ↓
⑦ 关系图谱（实体之间如何连接）
```

**关键依赖**：人物永远最后建。先有人物再补世界，会导致世界围着主角转，失去独立运行能力。

## 4. 深度分级：三档建设标准

### A 档：轻量（短篇、单本、单季短剧）

| 项目 | 标准 |
|---|---|
| 核心规则 | 1–3 条，且必须有代价 |
| 地点 | 3–5 个，只需功能区分 |
| 势力 | 2–3 个，动机清晰即可 |
| 人物 | 主角 + 3–5 个功能人物 |
| 历史 | 一条关键前史事件 |
| 工期感受 | 一次交付 |

### B 档：标准（中长篇、系列短剧、动态漫）

在 A 档基础上增加：完整势力关系表、双线时间线、资源经济雏形、8–15 个人物档案、地图级空间结构。

### C 档：重型（长篇连载、长期 IP、游戏世界观）

在 B 档基础上增加：历史分层（神话/远史/近史/当代）、多文明体系、制度细节（税、兵、教、法）、生态链、语言与称谓体系、可扩展预留区、设定版本库。

**禁止**：短篇项目按 C 档建，会造成 90% 设定永不使用，且拖慢创作节奏。

## 5. 四种常用构建路径

### 5.1 规则驱动型（科幻、异能、系统流）

从一个核心规则出发，推演到底。

```
核心规则 → 谁能用 → 用了付什么代价 → 谁因此获利 → 谁因此被淘汰 → 社会如何重组
```
优势：逻辑最硬。风险：容易写成设定说明书，缺人味。补救：在第 5 步强制落到具体人物的具体损失上。

### 5.2 灾难驱动型（末世、灾变、封闭空间）

从一个断裂事件出发。

```
灾变 → 旧秩序失效 → 幸存者聚集 → 资源规则重建 → 新权力诞生 → 人性冲突
```
关键：必须写清"灾变第 1 天、第 30 天、第 1 年"三个时间点的差异。跳过演化过程直接给结果，世界会假。

### 5.3 文明冲突型（玄幻、史诗、国战）

从两种不可调和的生存方式出发。

```
环境差异 → 生存策略差异 → 价值体系差异 → 利益必然冲突 → 战争或共存
```
关键：冲突双方都必须"有道理"。若一方纯粹邪恶，冲突降级为打怪。

### 5.4 谜题驱动型（悬疑、怪谈、无限流）

从一条被隐藏的真相出发。

```
表象规则 → 异常现象 → 认知偏差 → 真相分层揭示 → 规则被重新解释
```
关键：必须建"信息可见性表"（谁在第几阶段知道什么），否则推理会崩。见 `07-world-graph-and-knowledge-model.md`。

## 6. 五个高频失败模式

| 失败模式 | 表现 | 修复 |
|---|---|---|
| 名词通货膨胀 | 一堆听起来很酷但无作用的名称 | 每个名词问六问，答不上就删或标记待验证 |
| 规则漏勺 | 主角总能绕过限制 | 每条规则补"反制方式"，并为反派配置该反制 |
| 世界围着主角转 | 所有势力都在关注主角 | 给每个势力写一个与主角无关的年度计划 |
| 时间失锚 | 事件先后矛盾、年龄对不上 | 建立绝对时间轴（见 `06-history-and-timeline.md`） |
| 层级错配 | 短篇建了个史诗世界 | 按第 4 节定档，超出的设定进"预留区"不展开 |

## 7. 构建对话的提问纪律

一次最多问 3 个问题，且只问**会改变整体结构**的问题。

优先级排序（从高到低）：

1. 这个世界"不一样"的那一点是什么？（核心规则）
2. 主角在这个世界里最缺什么？（资源与代价）
3. 谁不希望主角得到它？（势力与冲突）

**不要问**：地名想叫什么、主角长什么样、有没有龙。这些是填充项，可以先用占位名后补。

## 8. 交付节奏

| 阶段 | 交付物 | 用户确认点 |
|---|---|---|
| 一次交付 | 设定盘点 + 核心规则草案（3 条以内） | 核心规则是否成立 |
| 二次交付 | 空间结构 + 社会结构 + 势力框架 | 世界逻辑是否可信 |
| 三次交付 | 人物 + 关系 + 时间线 | 人物是否可写 |
| 四次交付 | 完整设定集 + 一致性报告 + 交接包 | 定稿 |

每阶段结束必须停下等确认。一次性输出全部内容，用户无法逐层纠偏，返工成本极高。
