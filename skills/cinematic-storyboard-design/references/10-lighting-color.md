# 10 光影与色彩：不写在剧本里的第二台词

光决定观众"看见什么"，色决定观众"感觉什么"。两者都不该是无源的气氛。

## 10.1 光的三件事

| 要素 | 决定 | 写法 |
| --- | --- | --- |
| 方向 | 立体感与情绪 | 顺/侧/逆/侧逆/顶/底 |
| 质量 | 硬或软 | 硬光（清晰影子）/ 柔光（过渡柔和） |
| 强度比 | 明暗关系 | 主辅比 1:2 / 1:4 / 1:8 |

任何镜头的光影描述都要包含这三项，只写"昏暗"不合格。

## 10.2 光位速查

| 光位 | 效果 | 情绪 | 适用 |
| --- | --- | --- | --- |
| 顺光（正面） | 平、少阴影、信息全 | 中性、坦白、平淡 | 交代、日常 |
| 侧光 45° | 立体，一半亮一半暗 | 复杂、有隐情 | 对话、心理戏 |
| 侧光 90° | 强对比，脸被切成两半 | 分裂、矛盾 | 关键抉择 |
| 侧逆光 | 轮廓亮，面部半暗 | 神秘、危险、尊严 | 反派、权威 |
| 逆光 | 剪影 | 身份不明、宿命 | 登场、离别 |
| 顶光 | 眼窝阴影，骷髅感 | 压迫、非人 | 审讯、恐怖 |
| 底光 | 阴影反向 | 恐怖、诡异、失控 | 惊悚 |
| 无方向柔光 | 无影 | 失真、梦境、医院 | 特殊段落 |

**规则**：短剧/网剧以侧光与侧逆为主，最耐看且有电影感；纯顺光显得像电视剧。

## 10.3 实景光源优先

优先使用"画内可见光源"，观众才会信。

| 场景 | 可用实景光 |
| --- | --- |
| 夜·室内 | 台灯、走廊灯、电视屏、手机屏、冰箱 |
| 夜·室外 | 路灯、车灯、招牌、窗内漏光 |
| 日·室内 | 窗（方向明确）、门口 |
| 雨夜 | 路灯在水面与伞面的反光 |

描述时写清"光从哪来"：`主光来自画面右侧窗外街灯，冷青；辅光为走廊暖光从背后渗入`。

## 10.4 明暗比与情绪

| 比例 | 观感 | 用途 |
| --- | --- | --- |
| 1:1 | 平、无秘密 | 日常、纪录片 |
| 1:2 | 舒适、有层次 | 常规叙事 |
| 1:4 | 有戏剧性 | 冲突场 |
| 1:8 | 强烈、压迫 | 情绪高点、悬疑 |
| 1:16 以上 | 大面积黑，只剩轮廓 | 极端恐惧、隐藏 |

**短剧实用值**：日戏 1:2~1:3，夜戏 1:4~1:6，关键情绪场 1:8。

## 10.5 色温与时间感

| 场景 | 色温倾向 | 说明 |
| --- | --- | --- |
| 清晨 | 冷蓝 + 微暖高光 | 清冷、开始 |
| 正午 | 中性偏冷 | 客观、暴露 |
| 黄昏 | 暖橙 | 怀旧、结束、温柔 |
| 夜·城市 | 青蓝 + 钠灯橙 | 冷暖对撞 |
| 夜·室内 | 琥珀暖 + 窗外冷 | 安全与危险的边界 |
| 荧光灯 | 绿偏 | 疏离、机构、病态 |

**冷暖对撞**是最经济的情绪手段：同一画面里暖光区＝安全/人性，冷光区＝危险/制度。

## 10.6 色彩策略

| 策略 | 做法 | 效果 |
| --- | --- | --- |
| 单色调 | 全片一个色相家族 | 统一、风格化 |
| 互补对撞 | 青橙、红绿 | 张力、商业感 |
| 三色限定 | 只允许三种颜色出现 | 高级、可控 |
| 点色 | 全片灰调，仅一个颜色出现 | 极强视觉锚点 |
| 递变色 | 随剧情推进整体色相偏移 | 情绪弧线外化 |

写进方案时要给"禁色"：如"除暴力时刻外不使用饱和红"。

## 10.7 色彩与人物绑定

给主要人物分配色彩身份：

| 人物 | 主色 | 用法 |
| --- | --- | --- |
| 苏瑾 | 冷白/灰 | 她的场景整体降饱和 |
| 陈默 | 暗褐/墨绿 | 出现时画面加暖浊 |
| 父亲 | 琥珀（仅光源，非服装） | 只以光的形式存在 |

两人同框时，色彩分区即立场分区。**观众不会说出来，但会感觉到。**

## 10.8 光线变化作为叙事事件

光可以演"发生了什么"：

| 变化 | 读作 |
| --- | --- |
| 灯突然亮/灭 | 有人来了/有人走了、真相暴露 |
| 云过遮日 | 情绪转阴、命运转折 |
| 车灯扫过 | 时间流逝、有人接近 |
| 手机屏点亮脸 | 信息到来、孤立中的连接 |
| 蜡烛/手电移动 | 探索、不安 |

把光线变化写成镜头事件（`shot_function` = 揭示/过渡），而不是背景描述。

## 10.9 竖屏与低光环境

| 问题 | 对策 |
| --- | --- |
| 竖屏手机观看亮度低 | 整体提亮半档，避免大面积死黑 |
| 夜景噪点 | 提高环境基础照度，靠色温而非亮度做夜感 |
| 小屏细节丢失 | 关键信息不要只放在暗部 |
| 高对比在小屏偏硬 | 明暗比下调一档 |

## 10.10 AI 生成的光影描述

模型对"电影感光线"理解模糊，需要具体参数：

| ✗ 模糊 | ✓ 可执行 |
| --- | --- |
| 昏暗的氛围光 | 单一台灯从画面右下方照射，暖 3000K，人物右侧脸受光，左侧落入阴影，明暗比约 1:6 |
| 唯美的逆光 | 夕阳从人物背后偏左 30° 射入，发丝与肩线形成金色轮廓光，面部处于阴影，仅补微弱反光 |
| 冷色调 | 整体青蓝色调，色温约 7000K，高光略带品红 |

必须写：**光源位置 + 方向 + 色温 + 受光面 + 明暗比**。

## 10.11 自检

- [ ] 每个镜头的 lighting 有三要素（方向/质量/比值）
- [ ] 光源在画内有依据
- [ ] 同一场光位一致，变化有叙事理由
- [ ] 有人物色彩绑定，且同框时有分区
- [ ] 有禁色规则
- [ ] 竖屏/小屏已调亮
- [ ] 生成提示词中的光有具体参数
