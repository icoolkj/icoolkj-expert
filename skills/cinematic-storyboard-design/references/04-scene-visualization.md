# 04 场次视觉化：从戏剧单位到视觉单位

单场戏是分镜的最小完整单位。本文件处理"这一场怎么变成一组镜头"。

## 4.1 场次视觉化的三步

1. **定功能**：这一场在整集里干什么？（建立/推进/揭示/转折/情绪/收束）说不出功能，这场就该考虑删或并。
2. **定形状**：这场戏的"力"怎么走？起—承—转—合，还是单向压迫，还是来回拉锯？
3. **定镜头组**：把形状落成"建立—展开—转折—落点"四段式镜头组。

## 4.2 四段式镜头组

| 段 | 任务 | 常用手段 | 常见错误 |
| --- | --- | --- | --- |
| 建立 | 交代空间与人物位置 | 全景/建立镜，或含环境的半身 | 直接上特写，观众不知道在哪 |
| 展开 | 推进冲突，给信息 | 正反打、过肩、中景交替 | 景别不变导致平 |
| 转折 | 力量易位或新信息公开 | 景别跳变、机位越界、运镜介入 | 转折点没有镜头强调，被剪平 |
| 落点 | 停在情绪或悬念上 | 近景/特写停留、拉远、空镜 | 台词说完就切走，没给反应时间 |

不是每场都要四段齐全。短场（15 秒内）可以只有"建立+落点"。

## 4.3 场次功能与镜头配置对照

| 场次功能 | 镜头数倾向 | 景别重心 | 节奏 | 落点 |
| --- | --- | --- | --- | --- |
| 建立世界观 | 少（3–6） | 远→中 | 慢 | 一个待解释的细节 |
| 信息推进 | 中（8–15） | 中景为主 | 匀 | 信息落地的那一刻 |
| 冲突交锋 | 多（15–30） | 中近/近景交替 | 递进加速 | 一方失去平衡 |
| 情绪停留 | 少（3–8） | 近景/特写 | 慢 | 一个未完成动作 |
| 转折/反转 | 中（8–15） | 跳变 | 由慢骤快 | 新信息占满画面 |
| 收束/过渡 | 少（2–5） | 远 | 慢 | 空镜或背影 |

## 4.4 空间建立的方法

观众必须在前 10 秒知道三件事：**这是哪、谁在哪、门在哪**（出入口＝逃生与入侵的可能）。

| 方法 | 做法 | 适用 |
| --- | --- | --- |
| 建立镜 | 一个全景交代全空间 | 新场景首次出现 |
| 跟随入 | 跟着人物进门，边走边交代 | 场景复杂、需要动线 |
| 局部拼贴 | 2–3 个细节镜拼出空间 | 风格化、悬疑 |
| 声音建立 | 先出声，后出画 | 画外空间重要时 |
| 角色视线 | 用角色的看带出空间 | 主观性强 |

同一场景第二次出现，**不必重建**，但要用一个"变化"提示观众（光线变了、东西移了、人少了）。

## 4.5 场面调度的视觉化

把剧本的"位置关系"落成可执行的画面：

| 剧本表述 | 视觉化 |
| --- | --- |
| "两人对峙" | 明确距离（1.5m/隔一张桌/隔一道门）、朝向（正对/侧对/一人背对）、高度差（一人坐一人站） |
| "她躲在门后" | 门框成为前景遮挡，画面被切成两半 |
| "他跟在后面" | 前后景纵深，后者虚焦，或过肩带出 |
| "一群人围着他" | 环形构图，主体被压缩在中心 |
| "隔着车窗说话" | 玻璃反光叠印，两层信息同框 |

**距离即关系**：越近越亲密或越危险；隔物即隔阂。

## 4.6 情绪曲线的镜头化

情绪不是靠演员脸，是靠"镜头如何对待人物"。

| 情绪走向 | 镜头处理 |
| --- | --- |
| 逐步升温 | 景别逐步收紧（全→中→近→特），机位逐步降低，节奏逐步加快 |
| 骤然爆发 | 长时间静止后突然切近景/手持/声音爆点 |
| 压抑不发的怒 | 保持中景不推近（观众想看清却不给），让对方占画面更多 |
| 崩溃 | 先给全景（孤立），再给局部（手、膝盖），避免正面大特写 |
| 释然 | 景别放松（拉远），光线变亮，声音变静 |

## 4.7 场末落点设计

场末镜头决定观众是否想看下一场。

| 落点类型 | 做法 | 效果 |
| --- | --- | --- |
| 信息悬置 | 停在一个未被解释的物或表情 | 悬念 |
| 动作未完 | 手伸向门把，切 | 期待 |
| 视线引导 | 人物看向画外，切到他所看 | 转移 |
| 反打空镜 | 人走后留下空空间 | 余味/失落 |
| 声音先行 | 下一场的声音提前进入 | 无缝，压缩时间 |
| 硬切对撞 | 从极静切到极吵 | 冲击 |

## 4.8 场间衔接

| 衔接方式 | 说明 | 适用 |
| --- | --- | --- |
| 动作接 | 上一场动作在下一场继续 | 同人物跨空间 |
| 视线接 | 上一场看向某处，下一场是那处 | 建立关联 |
| 声音接 | 声音跨场延续 | 时间压缩 |
| 图形接 | 形状/构图相似 | 隐喻、时间跳跃 |
| 因果接 | 上一场结果即下一场原因 | 常规叙事 |
| 对比接 | 内容强反差 | 讽刺、主题对照 |

衔接方式必须在 `transition` 字段写明，不要留给后期猜。

## 4.9 场次视觉化自检

- [ ] 这场戏的功能能一句话说清
- [ ] 前 10 秒交代了"哪、谁、门在哪"
- [ ] 有建立—转折—落点，不是平铺
- [ ] 景别有至少一次跨两级跳变
- [ ] 转折点有专门的镜头（不是靠台词带过）
- [ ] 场末落点有明确设计
- [ ] 与上一场/下一场的衔接方式已确定并写入字段
- [ ] 本场镜头数与时长已统计，与内容复杂度相称
