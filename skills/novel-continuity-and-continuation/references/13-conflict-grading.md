# 13｜冲突分级与审查报告格式

## 冲突四级分级

| 等级 | 定义 | 处理要求 |
|---|---|---|
| 严重冲突 | 直接违反已确认事实，导致剧情不成立 | 必须修复后才能继续；给出修复方案 |
| 潜在冲突 | 当前不一定矛盾，但可能影响后续剧情 | 提示用户；建议观察或预防性处理 |
| 连续性风险 | 缺少过渡、解释或必要信息，易造成读者理解困难 | 建议补充过渡或解释 |
| 通过 | 未发现明显问题 | 明确输出通过结论 |

## 定性纪律

1. 报告中必须说明冲突依据，尽量标明涉及章节和原文位置。
2. 不得将合理的人物成长、关系变化或经过确认的剧情调整误判为错误。
3. 拿不准的问题标「待核实」，并说明核实所需的信息。
4. 大纲与正文冲突时区分计划与事实：已写正文的事实优先，大纲相应节点标记为需更新，由用户决定。

## 审查报告模板

```
# 连续性审查报告

【检查范围】第X章至第Y章 / 指定情节
【审查基准】记忆档案版本 / 正文范围
【总体结论】通过 / 发现N个问题（严重a 潜在b 风险c）

## 问题清单

### 问题 1｜[严重冲突] 标题
- 位置：第X章第Y段
- 冲突类型：人物 / 认知 / 时间 / 空间 / 事件 / 物品 / 世界规则 / 伏笔
- 问题描述：
- 原文依据：当前写法："……"  ←→  既有事实：第Z章 "……"
- 影响分析：若不修复，将导致……
- 修改建议：方案A…… / 方案B……
- 备注：待用户选择方案

### 问题 2｜[潜在冲突] ……

## 通过项摘要
（列出已检查且无问题的维度，简要说明）

## 待核实项
（无法确证、需要用户补充信息的问题）
```

## 各模式交付格式汇总

- **续写模式**：当前剧情状态（必要时简要）→ 章节衔接说明（必要时）→ 续写正文 → 连续性检查结果 → 本章记忆更新。
- **前文解析模式**：章节覆盖范围 → 重要事件 → 人物状态 → 时间线 → 伏笔清单 → 未解决问题 → 信息缺口。
- **连续性审查模式**：检查范围 → 问题位置 → 冲突类型 → 严重程度 → 原文依据 → 影响分析 → 修改建议。
- **记忆恢复模式**：当前创作进度 → 当前人物状态 → 当前时间与地点 → 已发生事件 → 未解决问题 → 伏笔状态 → 下一章承接信息。

## 修复后的闭环

问题修复（用户采纳方案并改稿/续写）后：

1. 用修正后的正文更新相关记忆条目（references/10）。
2. 在变更记录中登记「事实修正」及原因。
3. 复查受影响的其他条目（人物状态、伏笔、时间线），防止修复引入新矛盾。
