# 04 文明与社会结构 / 势力组织设计

## 1. 文明设计的因果起点

文明不是风格选择，而是**对环境的适应方案**。

```
环境压力 → 生存策略 → 组织形式 → 价值观念 → 制度与习俗
```

写文明先写压力：缺什么、怕什么、争什么。压力不同，文明必然不同。

| 环境压力 | 衍生的文明特征 |
|---|---|
| 资源稀缺 | 分配制度严格、排外、重纪律 |
| 外敌持续 | 军事化、等级森严、崇尚牺牲 |
| 土地肥沃但孤立 | 重商、重契约、城邦林立 |
| 灾变频发 | 宗教化、重仪式、有避难传统 |
| 知识断层 | 尊古、重传承、禁忌多 |

**反面案例**：一个缺水的文明却以沐浴为最高礼仪，且没有任何解释。要么改设定，要么写清这是宗教性奢侈（只限贵族，用回收水）。

## 2. 政治与管理体系

| 类型 | 权力来源 | 优势 | 内在缺陷（必须写） |
|---|---|---|---|
| 集权帝制 | 血统/天命 | 动员力强 | 继承危机、信息失真 |
| 贵族分封 | 土地/军功 | 稳定、地方自治 | 中央虚弱、内战 |
| 城邦共和 | 财富/选举 | 活力强 | 内斗、短视 |
| 军政府 | 武力 | 执行力强、末世常见 | 合法性缺失、腐化 |
| 教权 | 信仰 | 凝聚力强 | 教义僵化、排斥异端 |
| 公司制 | 资本/契约 | 效率高、赛博常见 | 无公民、只有雇员 |
| 无政府/部落 | 血缘/强者 | 灵活 | 无法支撑大规模协作 |

**纪律**：每种制度必须写出它解决什么问题、制造什么问题。只写优点的制度是纸片。

## 3. 经济与资源分配

### 3.1 经济三问

1. 这个世界的"钱"是什么（货币/以物易物/贡献点/灵石/信用）？
2. 普通人一天能挣多少，能买什么？
3. 什么东西是钱买不到的（名额、身份、豁免）？

第三问最重要——它决定了权力运作的真实方式。

### 3.2 分配制度

| 制度 | 谁得到资源 | 冲突来源 |
|---|---|---|
| 按需分配 | 老弱优先 | 生产者不满 |
| 按贡献分配 | 强者多得 | 弱者被淘汰 |
| 按身份分配 | 阶层决定 | 阶层对抗 |
| 按武力分配 | 强者通吃 | 秩序不稳 |
| 配给制 | 统一发放 | 黑市、腐败 |

**必写**：黑市或灰色渠道。任何配给制度都会产生黑市，没有黑市的世界不真实。

## 4. 社会阶层

用"金字塔 + 流动性"描述，不用"贵族/平民/奴隶"三个词打发。

| 层 | 身份 | 占比 | 权力 | 上升通道 | 典型困境 |
|---|---|---|---|---|---|
| 上 | | | | | |
| 中 | | | | | |
| 下 | | | | | |
| 外 | 无身份者（流民、变异者、外来者） | | | | |

**关键**：无身份者群体是故事金矿。他们既是主角最可能的出身，也是所有社会矛盾的承受端。

## 5. 文化、信仰、习俗

### 5.1 文化最小集

| 项 | 内容 | 剧情作用 |
|---|---|---|
| 禁忌 | 不能做什么 | 制造压力与冲突 |
| 仪式 | 婚丧、成人、祭祀 | 提供场景与情绪节点 |
| 称谓 | 怎么称呼不同人 | 一句话体现阶层与关系 |
| 时间观 | 纪年方式、节日 | 建立历史感 |
| 死亡观 | 如何处理死者 | 塑造价值底色 |
| 审美 | 什么被认为是美/强 | 塑造人物形象 |

**纪律**：每项文化设定至少要能变成一场戏。变不成戏的，只是装饰。

### 5.2 信仰体系

| 类型 | 结构 | 冲突点 |
|---|---|---|
| 一神教 | 唯一真理 | 排他、圣战 |
| 多神教 | 各司其职 | 教派竞争 |
| 祖先崇拜 | 血脉延续 | 家族压迫 |
| 理性崇拜（科学教） | 知识即权力 | 技术垄断 |
| 灾变崇拜 | 恐惧具象化 | 献祭、极端化 |

信仰必须回答：它给信徒什么安慰，向信徒索取什么。只索取不安慰的是邪教，只安慰不索取的是空壳。

## 6. 教育与知识传承

| 模式 | 谁能学 | 后果 |
|---|---|---|
| 师徒制 | 少数人 | 知识垄断、门派化 |
| 家族传承 | 血亲 | 阶层固化 |
| 学院制 | 考试选拔 | 形成知识阶层 |
| 公开教育 | 全民 | 旧权威崩塌 |
| 无教育 | 口传 | 知识快速退化（末世典型） |

**末世必写**：识字率。识字率决定信息能否传递，直接影响阴谋能否成立。

## 7. 势力设计

### 7.1 势力必填字段

| 字段 | 要求 |
|---|---|
| 编号 | FACTION-000 |
| 名称 | 含自称与他称（敌人怎么叫他们） |
| 起源 | 谁在什么时候为什么建立 |
| 核心目标 | 一句话，且必须是可执行的 |
| 次级目标 | 当前正在推进的具体事务 |
| 组织结构 | 层级、决策方式、情报流向 |
| 领导者 | 掌权依据、执政风格、软肋 |
| 核心成员 | 3–5 人，各有独立立场 |
| 控制区域 | 地盘与影响力范围 |
| 关键资源 | 靠什么维持 |
| 主要优势 | 别人做不到的事 |
| 主要弱点 | 结构性缺陷（不是"首领太骄傲"这种性格缺点） |
| 合作关系 | 与谁合作，交换什么 |
| 敌对关系 | 与谁敌对，争什么 |
| 内部矛盾 | 派系、代际、路线之争 |
| 未来走向 | 若不被打断，三年后会变成什么样 |
| 设定状态 | |

### 7.2 独立目标原则

每个势力必须有**不依赖主角而存在**的年度计划。

检验方法：假设主角从不存在，这个势力今年会做什么？答不上来，说明该势力只是主角的陪衬。

### 7.3 势力利益矩阵

不要用"正派/反派"，用利益坐标。

| 势力 | 想要什么 | 怕失去什么 | 愿意付出什么 | 绝不让步什么 | 与主角的利益交集 |
|---|---|---|---|---|---|
| | | | | | 一致/部分一致/冲突/无关 |

**"与主角无关"是合法且必要的选项**。世界必须有不在乎主角的部分，否则世界失真。

### 7.4 组织真实感三件套

| 要素 | 作用 |
|---|---|
| 内部派系 | 让组织不是铁板一块，可被分化 |
| 科层制缺陷 | 层级导致信息延迟与失真，制造失误 |
| 资源限制 | 组织不能无限投入，必须有取舍 |

## 8. 势力关系动态

静态关系表不够，必须给关系加"变化驱动力"。

| 关系 | 触发变化的条件 | 变化后结果 |
|---|---|---|
| A 与 B 结盟 | A 的资源耗尽 | A 变成 B 的附庸 |
| C 与 D 敌对 | 出现共同威胁 E | 暂时停战，埋下背叛 |
| E 内部稳定 | 领袖死亡 | 分裂为两派 |

**纪律**：至少写清 3 组关系的演变条件，它们是长线剧情的天然引擎。

## 9. 文明与势力的交付清单

1. 文明档案（环境压力 → 制度 → 价值观）。
2. 政治、经济、阶层、文化四张结构表。
3. 势力档案（每个势力一张完整卡）。
4. 势力利益矩阵。
5. 势力关系演变条件表。
6. 社会矛盾清单（至少 3 条可随时引爆的矛盾）。
