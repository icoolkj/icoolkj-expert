# 02 创作圣经（Novel Bible）

## 1. 用途

创作圣经唯一的作用：**防止越写越不像同一本书**。

写到 20 万字时，人会不自觉改变口味——语感飘了、人物软了、尺度松了。圣经是锚，每次开工对照一遍。

圣经不是给读者看的文档，因此**允许粗糙、允许私密、允许写"这里暂时空着"**。它只需要准确。

## 2. 必填字段

| 字段 | 要求 | 不填的后果 |
|---|---|---|
| 书名 | 暂定名也可，但须唯一 | 无 |
| 题材与子类型 | 例如"东方玄幻／宗门成长"，不只写"玄幻" | 写偏读者预期 |
| 核心主题 | 一句话，且是一个**问题**而非结论 | 全书失焦 |
| 目标读者 | 年龄段 + 阅读场景（通勤／睡前一章／追更） | 节奏与尺度错配 |
| 故事定位 | 一句话卖点（"一个 X 在 Y 处境下必须 Z"） | 无法回答"这书讲什么" |
| 叙事人称 | 第一人称／第三人称 | 中途改人称＝重写 |
| 叙事视角 | 全知／限知／多视角（需列视角人物） | 信息泄露，悬念失效 |
| 语言风格 | 三条**可执行**特征，不用形容词 | 文风漂移 |
| 情绪基调 | 冷／热／压抑／荒诞／明亮 | 读者情绪预期错位 |
| 总篇幅目标 | 万字级（如 120 万） | 结构比例失控 |
| 分卷数 | 卷数 + 每卷字数区间 | 中段无处安放 |
| 单章字数区间 | 如 3000–3500 | 交付不稳定 |
| 更新节奏 | 日更／周更／整卷交付 | 章末钩子强度错配 |
| 主要人物 | 3–7 人，每人一行"欲望 + 障碍" | 人物功能重叠 |
| 核心冲突 | 谁要什么、谁不让、为什么现在 | 剧情推不动 |
| 创作限制 | 不写什么（尺度、雷点、忌讳） | 用户不满意 |

## 3. 关键字段的写法

### 3.1 核心主题：写成一个问题

| 不合格 | 合格 |
|---|---|
| 本书讲述成长与坚持 | 一个人为了活下去，可以把自己改成什么样？ |
| 探讨人性的复杂 | 当规则由坏人制定，守规则还算不算善？ |
| 爱与救赎 | 原谅一个不悔改的人，是宽容还是共谋？ |

主题不进入正文，但它决定每一次取舍：遇到"要不要让主角做脏事"这类问题，主题会给出答案。

### 3.2 语言风格：写三条可执行特征

不合格："文笔细腻，画面感强"。

合格示例（悬疑）：

1. 句子短，平均 15 字以内，长句只用于环境。
2. 心理描写不超过两句，靠动作承接。
3. 每章至少一个"具体的怪"（不合常理的细节）。

合格示例（古风玄幻）：

1. 对白半文半白，叙述用现代白话，不用生僻字。
2. 战斗写招式与结果，不写能量数值。
3. 每场戏收在一个物件上。

这三条可以直接拿来检查稿件。

### 3.3 视角选择决策

| 视角 | 适合 | 代价 |
|---|---|---|
| 第一人称 | 强代入、悬疑、心理 | 无法写主角不在场的戏；主角必须会叙述 |
| 第三人称限知（默认） | 绝大多数长篇 | 需要严格的信息纪律 |
| 第三人称全知 | 群像、史诗、讽刺 | 悬念削弱，易变说书 |
| 多视角轮换 | 双线、群像、权谋 | 需明确每章归属，读者易迷失 |

多视角必须写清：**哪几条线、每条线谁、多久轮一次、在哪些章交汇**。

### 3.4 篇幅换算

| 总字数 | 卷数 | 每卷章数 | 单章字数 |
|---|---|---|---|
| 30 万 | 1–2 | 30–40 | 3000 |
| 60 万 | 2–3 | 40–60 | 3000 |
| 100 万 | 4–6 | 50–70 | 3000 |
| 200 万+ | 8–12 | 60–80 | 3000 |

网文连载常见单章 2000–3000 字（追更友好）；出版向单章 4000–6000 字（阅读沉浸）。用户未指定时按题材惯例给建议。

## 4. 文风锚点（强烈建议）

在圣经里存三段**自己写的**样本，各 100–200 字：

1. **动作段**——一段打斗或追逐。
2. **对话段**——两个人争执。
3. **情绪段**——一个人独处时的低落。

作用：写到语感飘的时候，读一遍这三段，立刻回到原位。样本必须是本书的原文，不能抄别人的。

## 5. 圣经的更新规则

| 情况 | 处理 |
|---|---|
| 用户改题材/读者/尺度 | 立即更新，并检查已写章节是否需调整 |
| 写作中自然形成的风格 | 可补入圣经，标 `[已确认]`，说明"实际写法已如此" |
| 想改视角/人称 | 停下，评估已写章节改造成本，报给用户决定 |
| 人物新增 | 补入，不超过 7 人；超出说明这是群像，需重设结构 |

圣经不记录剧情细节。剧情记在台账（`10-continuity-and-story-state.md`）。

## 6. 冷启动检查（每次开工前）

30 秒内回答：

- 这本书一句话讲什么？
- 主角现在最想要什么？最怕什么？
- 这一章要改变什么？
- 我的句子多长？多用哪种描写？

答不出，说明圣经没建好或已经漂移，先修圣经再写。
