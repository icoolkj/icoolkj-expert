# 12 章节记忆卡与承接单

## 1. 为什么需要记忆卡

下一章不是从"故事"接着写，是从**上一章结束那一秒的状态**接着写。

记忆卡的作用：让写下一章的人（可能是三个月后的自己）在 30 秒内知道"现在是什么局面"。

## 2. 摘要的三段式

不要写"本章讲述了……"。按三句写：

```
1. 发生了什么（事实）
2. 改变了什么（不可逆）
3. 留下了什么（悬念/待办）
```

示例：

```
CH-0012 夜渡
1. 苏瑾买通船夫夜渡，河心遇巡夜队的灯。
2. 船夫认出匣子后被杀，苏瑾右臂重伤，行踪暴露给第三方。
3. 谁指使巡夜队未明；陆沉仍失联；匣子已过河。
```

三句话，全部是"已发生"，不含计划。

**禁止**在摘要里写：心理分析、主题阐释、"这章表现了……"、评价性语言。

## 3. 摘要长度标准

| 类型 | 长度 |
|---|---|
| 单章摘要 | 3 句 / 60–100 字 |
| 每 10 章汇总 | 5 行 |
| 每卷摘要 | 10–15 行 |

超过这个长度，等于没摘要——下次根本不会读。

## 4. 承接单结构

用户问"下一章写什么"、或每章交付后，输出承接单：

```
## 下一章承接单｜CH-0013

### 此刻局面
苏瑾在河心，船已无人掌，右臂伤重，天亮约两小时。

### 人物状态
- 苏瑾：伤重、失血、知道被第三方盯上，不知道对方是谁
- 船夫：死，尸体在船上
- 陆沉：失联，最后出现在 CH-0009

### 未解决冲突
1. 她要过河，但河上没有第二个人会撑船
2. 巡夜队会追，且知道她的方向
3. 船夫之死会被算在谁头上

### 下一章可推进的目标（3 选 1）
A. 自救过河（推进主线，强度 3）
B. 被追上，被迫交代匣子（转折，强度 4）
C. 有人从对岸来（引入新变量，强度 3）

### 必须承接
- 右臂伤（不能一秒痊愈）
- 匣子在身（不能丢，也不能随手放）
- 她不知道指使者是谁（不能猜对）

### 不得提前揭露
- 巡夜队背后的势力（计划 CH-0048）
- 陆沉的真实身份（计划 CH-0031）
- 匣子里是什么（全书核心，计划 CH-0060）

### 与主线关联
本章应把"她被迫向北"这个方向确定下来，为第二卷做入口。
```

## 5. 承接单的三个常见错误

| 错误 | 表现 | 后果 |
|---|---|---|
| 承接单写成大纲 | 写了未来 5 章的计划 | 下一章被计划绑死 |
| 只写剧情不写状态 | 只写"她过了河" | 忘了伤、忘了情绪、忘了时间 |
| 不写"不得揭露" | 未标明禁区 | 提前泄底，后文失效 |

## 6. 批量交付时的章末说明

用户要求连写多章时，每章后只附 3–5 行：

```
【承接】苏瑾已过河，伤重，匣子在身。巡夜队已知方向。
      下一章建议：CS-01 自救 / 遇人。
      新增伏笔：FORE-012 河心的灯。
```

不与正文混排，不写创作心得。

## 7. 冷启动摘要（回归写作时）

隔很久回来，不要读全书。读三样：

1. 上一章原文最后 800 字。
2. 上一章记忆卡。
3. 当前卷承接单。

三样读完（约 5 分钟），即可动笔。

## 8. 交班给下游时

向短剧、视觉、审校等环节交付时，额外给：

| 内容 | 用途 |
|---|---|
| 已成片段的桥段清单 | 短剧可直接成集 |
| 标志性场景 3 个 | 视觉参考 |
| 人物外形与行为要点 | 形象设计 |
| 已知薄弱章节 | 审校重点 |
| 核心事实不可推翻清单 | 所有环节的红线 |
