## 十、验收标准

| 项 | 判定方法 |
| --- | --- |
| 角色一致性 | 与锚点卡对比：面部特征、发型、服装三项全符 |
| 空间一致性 | 门/窗/家具位置与场景卡一致，无凭空出现 |
| 光线一致性 | 主光方向与镜头表 `lighting` 一致 |
| 构图符合 | 主体位置与 `composition` 一致 |
| 技术缺陷 | 无穿模、无多指、无文字错乱、无肢体扭曲 |
| 运动符合 | 视频镜头的运动方向与幅度符合描述 |
