# 07 运镜：摄影机为什么动

摄影机运动是**最强的注意力武器**，也是最容易被滥用的。判据只有一条：**不动能不能达到目的？能，就不动。**

## 7.1 五种运动动机（只有这些）

| 动机 | 说明 | 典型场景 |
| --- | --- | --- |
| 跟随 | 跟着主体走，保持观看关系 | 人物穿过走廊/人群 |
| 揭示 | 移动以露出原本看不到的信息 | 从人脸横移到手上的刀 |
| 转移 | 把注意力从 A 交给 B | 从门口移到床上的人 |
| 压强 | 靠近或远离，改变心理距离 | 缓慢推近逼问 |
| 视点代入 | 模拟角色视线移动 | 扫视房间、寻找 |

 motivations 之外的运镜（"这样好看""增加动感"）一律删。

## 7.2 基本运动类型

| 类型 | 定义 | 效果 | 慎用场景 |
| --- | --- | --- | --- |
| 固定 | 摄影机不动 | 稳定、观察、克制 | 长段静止需靠调度支撑 |
| 推 Push in | 向前接近主体 | 压强、聚焦、进入内心 | 对话每句都推会疲 |
| 拉 Pull out | 向后远离 | 抽离、揭示环境、孤独 | 情绪高点拉远会削弱 |
| 摇 Pan | 水平转动 | 转移注意、扫视 | 速度过快产生眩晕 |
| 俯仰摇 Tilt | 垂直转动 | 揭示高度、打量 | 用来"扫全身"显得廉价 |
| 移 Track | 平行移动 | 陪伴、旁观、展示纵深 | 无前景时移动感弱 |
| 跟 Follow | 跟随主体移动 | 沉浸、紧张 | 手持跟易晃 |
| 升降 Crane | 垂直升降 | 宏大、俯瞰、命运 | 小场景显得过火 |
| 手持 | 人为晃动 | 纪实、危机、失控 | 全片手持会降低质感 |
| 变焦 Zoom | 焦距变化 | 突兀强调、复古 | 与推镜混用显得廉价 |
| 环绕 Orbit | 绕主体旋转 | 仪式感、时间凝固 | 短剧滥用率最高，慎用 |
| 甩镜 Whip | 快速甩动 | 冲击、场景切换 | 一场不超一次 |

## 7.3 组合运动

组合可以，但**一次只承担一个动机**。

| 组合 | 效果 | 示例 |
| --- | --- | --- |
| 推 + 升 | 从局部到全貌 | 从手上升到手的主人再上升露出房间 |
| 跟 + 摇 | 跟随中转向 | 跟着人走，到门口转向他看的方向 |
| 移 + 变焦 | 保持主体大小改变透视 | 压缩/拉伸空间感 |
| 拉 + 俯 | 抽离并俯视 | 人物失败后拉远俯拍 |

两个以上同时变化（推+摇+升）会让观众失去方位，除非刻意制造失衡。

## 7.4 速度与情绪

| 速度 | 读作 |
| --- | --- |
| 极慢（几乎察觉不到） | 潜意识压强，最有效也最难被察觉 |
| 慢 | 沉浸、压迫、仪式 |
| 中 | 自然跟随 |
| 快 | 紧张、冲击、失控 |
| 极快（甩） | 断裂、暴力 |

**最有效的推镜是观众没意识到它在推。** 一秒移动画面高度 1–2% 即够。

## 7.5 起幅与落幅

任何运动镜头都要写清三件事：

1. **起幅**：运动开始时的构图（观众看到什么）
2. **过程**：路径与速度
3. **落幅**：运动结束时的构图（停在哪）

不写落幅的运镜在剪辑台上无法使用，因为不知道什么时候切。

| 字段写法示例 |
| --- |
| 起幅：中景，男子位于画面右侧，左侧为关闭的门。过程：摄影机向左缓慢横移 2 秒。落幅：门占画面中心，男子被推出画面左缘。 |

## 7.6 运镜与剪辑的配合

| 情况 | 处理 |
| --- | --- |
| 运动未结束就切 | 会"断"，除非刻意制造突兀 |
| 运动结束停稳再切 | 安全，但拖节奏 |
| 运动中切到同方向运动 | 可形成流动感（动接动） |
| 运动中切到反方向 | 制造撞击感 |
| 固定切运动 | 常用节奏变化点 |

在 `transition` 字段标注"运动中切"或"停稳后切"。

## 7.7 稳定与设备暗示

镜头表不必指定设备，但描述要能让执行者判断：

| 描述 | 暗示 |
| --- | --- |
| 平稳匀速 | 三脚架/稳定器 |
| 轻微呼吸感 | 肩扛 |
| 明显晃动 | 手持 |
| 完全静止但有微动 | 长焦 + 三脚架 |

## 7.8 AI 生成视频的特殊约束

生成模型对运动的理解有限，写 `visual_prompt` 时：

| 做法 | 原因 |
| --- | --- |
| 一个镜头只写一种运动 | 多运动会生成混乱 |
| 写明方向与幅度（缓慢向左横移，约画面宽 1/4） | 模型需要相对量 |
| 避免"环绕""复杂运镜" | 极易崩坏人物一致性 |
| 运动镜头时长控制在 3–5s | 越长越容易漂移 |
| 需要复杂运动时拆成两个镜头 | 分别生成再剪 |

## 7.9 常见错误

1. **全片都在动**：观众疲劳，且失去"动＝重要"的信号。
2. **环绕滥用**：短剧里最常见，除了"人物登场"几乎无叙事功能。
3. **无落幅**：剪不动。
4. **推镜替代表演**：情绪靠推近而不是演员，成片空洞。
5. **运动方向与人物方向冲突**：人物向左走，镜头向右移，观众困惑。
6. **变焦当推镜**：透视不变，显得廉价（除非刻意复古）。
