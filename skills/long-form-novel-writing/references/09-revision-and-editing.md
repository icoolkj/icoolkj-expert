# 09 修改、润色与审校

## 1. 三遍法

不要一遍改所有问题。按尺度从大到小：

| 遍次 | 只看 | 允许的改动 |
|---|---|---|
| 第一遍：结构 | 目标、因果、转折、节奏 | 删段、并章、调序、重写结尾 |
| 第二遍：场景 | 进场出场、冲突、对话 | 换场景、拆合场、改对话 |
| 第三遍：句子 | 语言、重复、语感 | 改句、删词、调节奏 |

**顺序不能反**。先抠字，后面结构一改全白费。

## 2. 问题分级

| 级别 | 判定 | 处理 |
|---|---|---|
| A 必须改 | 逻辑断裂、人物失真、信息矛盾、目标未达成 | 立即修，不修不能交付 |
| B 建议改 | 节奏拖、场景弱、对话平、描写赘余 | 提出方案，用户可保留 |
| C 可接受 | 风格选择、个人偏好、类型惯例 | 只说明，不改 |

**不得**把 C 级问题当 A 级改。把作者的风格改成"标准好文笔"，是最常见的越界。

## 3. 八种高频问题与修法

### 3.1 开场太慢

症状：前 500 字在写景、写心情、写背景。
修法：找到第一个"有人想做什么"的句子，把它提到第一段。前面全删。

### 3.2 信息倾倒

症状：一段超过 5 行在解释设定／历史／人物关系。
修法：拆成三份，一份变成人物的代价，一份变成对话里的争执，一份删掉（读者不需要）。

### 3.3 场景无冲突

症状：人物在场景里聊天、走路、吃饭，什么都没争。
修法：给这场戏加一个"谁想从谁那里拿到什么"。加不进，就把这场压成一句叙述。

### 3.4 情绪假

症状：人物哭、喊、心痛，但读者无感。
修法：删掉情绪词，改成一个具体的错位动作（见 `05` 第 7 节）。**先写他忍，再写他崩**。

### 3.5 节奏拖

症状：连续几段没有新信息。
修法：逐段问"这段给了读者什么新东西"。没有就删。通常能删掉 20%。

### 3.6 对话平

症状：两人你一句我一句，礼貌、完整、有逻辑。
修法：让一方答非所问；让一方打断；删掉所有"他说""她说"能省则省；把最长的那段发言砍一半。

### 3.7 逻辑跳

症状：人物忽然知道了他不该知道的事；忽然出现在他到不了的地方。
修法：补一句过渡（他怎么知道的、怎么来的），或改结果。**补过渡优于改结果。**

### 3.8 结尾泄气

症状：高潮之后还有两三段总结、抒情、展望。
修法：砍在高潮的最后一句动作上。下一章再处理余波。

## 4. 局部改还是重写

| 情况 | 判断 |
|---|---|
| 本章目标没实现 | 重写中段，保留开头结尾 |
| 视角人物选错 | 重写全章 |
| 只有对话平 | 局部改对话 |
| 因果链断了 | 先补前文铺垫，本章小改 |
| 场景地点无趣 | 换地点重写，情节不变 |
| 情绪不到位 | 加一场戏在前面铺垫，本章微调 |

**原则**：问题越靠前（因果、动机），改动越大。仅语言问题，永远局部改。

## 5. 润色的边界

润色是"让原有的更好"，不是"换成我喜欢的"。

允许：

- 删冗词、拆长句、去陈词。
- 把抽象改具体。
- 调整段落节奏。
- 统一称谓与术语。

不允许：

- 改变人物说话方式（那是人物设定）。
- 增删情节。
- 改变叙事视角。
- 把口语改成书面语（或反之），除非用户要求。

## 6. 审校报告格式

```
## 审校报告｜CH-0012 夜渡

### 结论
可用（3 处 A 级问题需修，5 处 B 级建议）

### A 级（必须改）
1. 位置：第 3 段
   类型：逻辑
   说明：船夫此时不应知道匣子在箱中，前文未给信息来源。
   方案：a) 改为他猜的；b) 前移至 CH-0011 让他看见。
   需重写：否

### B 级（建议改）
1. 位置：第 7–9 段
   类型：节奏
   说明：三段落均在写雨，信息重复，建议合并为一段。
   方案：保留第 7 段的屋檐滴水，删 8、9 段。

### C 级（说明，不改）
1. 第 12 段短句密集，属本章紧张段落的风格选择，保留。

### 连续性
- 苏瑾右臂伤：第 4 段用左手撑船，一致。
- 时间：子时到天亮约 4 小时，与行程相符。
```

**要求**：每条问题必须给出位置、类型、为什么是问题。禁止"整体不错，个别地方可以再打磨"这类无信息量评语。

## 7. 朗读检查

最后一关，出声读：

- 读不顺 → 句子结构有问题。
- 读着想跳 → 那段是废话。
- 读着喘不上气 → 句子太长。
- 读着平淡 → 缺具体细节。

默读发现不了的问题，朗读全能发现。
