# 01 总体方法：从剧本到分镜交付

本文件是 S07 的方法总纲。接手任何分镜任务前先读本文件，确定"这次到底做到哪一步、哪些是剧本事实、哪些是我加的"。

## 1.1 三条边界

| 边界 | 含义 | 越界示例 |
| --- | --- | --- |
| 不改剧本 | 不改台词、不改人物关系、不改事件顺序、不删场加场 | 觉得第三场多余，直接合并到第二场 |
| 不冒充原作 | 新增的视觉设计必须标 `[建议]` | 原剧本没写雨，为气氛加雨且不标注 |
| 不越到后段工序 | 不写完整拍摄计划、不排通告、不估预算、不做最终成片剪辑 | 输出"本场需 2 天拍摄，建议用 A 机 B 机" |

发现剧本层面的问题（逻辑断裂、伏笔无回收、人物动机缺失），写进"待确认事项"，不在分镜里替编剧悄悄补上。

## 1.2 八阶段与产出对照

| 阶段 | 动作 | 产出 | 卡点（不过不进下一步） |
| --- | --- | --- | --- |
| 一 认料 | 判断输入形态与范围 | 任务卡（模式+范围+默认参数） | 不知道要处理哪几场 |
| 二 析本 | 抽信息 | 场次信息卡 | 场次边界不清、人物不明 |
| 三 立意 | 导演分析 | 每场叙事目标+视觉策略 | 说不出这场戏"为什么存在" |
| 四 定调 | 视觉规划 | 视觉方案（画幅/风格/景别/机位/光色） | 前后场风格互相打架 |
| 五 拆镜 | 切节拍 | 镜头序列骨架（只有功能，无细节） | 镜头功能重复或缺失 |
| 六 写镜 | 填 18 字段 | 镜头表 + 分镜描述 | 字段空、描述不可画 |
| 七 校验 | 连续性与机器检查 | 冲突清单 + lint 报告 | 有未处理 P0 冲突 |
| 八 交付 | 出件 | 九段式交付包 | 待确认事项未分档 |

前四阶段只写文字，不排镜头号。**先想清楚再编号**，否则改一处要重排全表。

## 1.3 认料：输入形态判断表

| 形态 | 识别特征 | 处理策略 | 风险 |
| --- | --- | --- | --- |
| 标准化剧本（S06 产出） | 有集/场编号、人物标注、△动作行 | 直接进第二阶段，引用原场号 | 低 |
| 非标准剧本 | 无场号、对白与动作混排 | 先做临时场次切分，切分结果单独列出待确认 | 中：场界可能切错 |
| 分集大纲 | 每集一段概要，无对白无场次 | 只做"场次建议+视觉策略"，**不硬拆镜头** | 高：信息不足以拆镜 |
| 单场戏 | 一场完整，前后文缺失 | 只做本场，前后衔接标待确认 | 中 |
| 故事片段/小说段落 | 叙述性文字，视角混杂 | 先转"可拍事件序列"再拆镜，转换结果需确认 | 高 |
| 已有分镜 | 有镜头表或画稿 | 转 D 审校模式，先审后改 | 低 |
| 视觉参考（图/片） | 只有风格意向 | 提取风格参数写入视觉方案，不当作剧情依据 | 低 |

## 1.4 参数默认值

用户未指定时采用下表默认，并在交付首段声明"以下为默认值，可覆盖"。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 画幅 | 16:9 | 短剧竖屏项目改 9:16 |
| 单集时长 | 按剧本实际 | 不预设 |
| 镜头数量 | 不预设 | 由内容决定 |
| 视觉风格 | 写实电影感 | 避免广告感、滤镜感 |
| 景别偏好 | 中景为主，特写克制 | 除非剧本要求强情绪 |
| 运镜偏好 | 固定为主，动机驱动 | 手持仅在紧张/纪实段落 |
| 光影 | 有明确光源方向 | 拒绝"无源柔光" |
| 输出粒度 | 镜头表 + 逐镜描述 | 用户要"简版"时只出镜头表 |

## 1.5 不确定性处理

| 情况 | 做法 |
| --- | --- |
| 剧本没写时间/地点 | 从上下文推断并标 `[待确认]`，不静默假设 |
| 剧本没写道具 | 需要道具承载信息时标 `[建议]`，并说明为什么需要 |
| 人物外观未描述 | 在视觉方案里给一版设定并标 `[建议]`，后续集数沿用 |
| 台词有歧义 | 按最直白字面拆镜，另一解写进待确认 |
| 场次之间跳跃 | 标"场间缺口"，问是否补过渡镜，不自行补戏 |

## 1.6 节奏与镜头密度的经验参照

以下是参照区间，不是配额。超出区间要能说出理由。

| 段落类型 | 单镜时长倾向 | 说明 |
| --- | --- | --- |
| 对话交锋 | 2–5s | 越到冲突高点越短，可用反应镜切碎 |
| 情绪停留 | 5–10s | 长镜给表演空间，别切碎 |
| 动作段落 | 0.8–3s | 短切建立力度，关键动作可延长 |
| 空间建立 | 4–8s | 一个镜头交代完地理关系 |
| 悬念铺垫 | 6–12s | 缓慢推近或静止等待 |

## 1.7 常见失败模式

1. **台词图解**：一句一台词一镜头，剪出来像配音幻灯片。→ 按节拍合并，用反应镜代替说话镜。
2. **景别单调**：全片中景。→ 每场至少一次景别跳变（远→近或近→远）。
3. **机位无立场**：所有镜头都在视线高度正打。→ 给关键台词一个越常规机位。
4. **运镜装饰**：每个镜头都在动。→ 一场里动镜不超过三成。
5. **空间消失**：观众不知道谁在哪。→ 每场开头一个建立镜或含环境的半身镜。
6. **连续性漏账**：道具/伤势/服装跨场漂移。→ 强制填 `continuity` 字段并建账。
