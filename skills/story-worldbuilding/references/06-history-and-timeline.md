# 06 历史与时间线

## 1. 历史分层

按"距故事现在的距离"分四层，越远越粗，越近越细。

| 层 | 时间跨度 | 建设详细度 | 作用 |
|---|---|---|---|
| 神话/创世层 | 不可考 | 只需 1–2 个版本（且可以互相矛盾） | 提供信仰、正统性争议、终极谜题 |
| 远史层 | 数百至数千年 | 只需阶段名 + 3–5 个大事件 | 提供文明底色与宿怨 |
| 近史层 | 10–100 年 | 事件表，含参与者与结果 | 提供当下格局的成因 |
| 当代层 | 故事开始前 1–10 年 | 精确到月，含主角相关事件 | 直接支撑剧情 |

**纪律**：神话层可以矛盾（不同势力有不同版本，这本身就是冲突源），近史层与当代层**绝不能**矛盾。

## 2. 历史事件档案

| 字段 | 说明 |
|---|---|
| 编号 | EVENT-000 |
| 名称 | 正式名 + 民间叫法（体现立场差异） |
| 时间 | 绝对纪年 + 距今年数 |
| 地点 | LOC 编号 |
| 起因 | 上一事件的直接结果 |
| 过程 | 关键转折 2–3 个 |
| 结果 | 格局变化 |
| 参与者 | 人物/势力编号，标注其当时立场 |
| 伤亡/代价 | 量化，用于建立历史重量 |
| 各方叙事 | 不同势力如何讲述这件事（至少 2 个版本） |
| 遗留问题 | 至今未解决的隐患 |
| 伏笔价值 | 可被后续揭示的部分 |

**"各方叙事"是最有价值的一栏**：同一场战争，胜者称解放，败者称屠杀。这决定了人物立场的历史根据。

## 3. 因果链检查

每个重大事件必须能回答"它由什么引起"和"它引起了什么"。

```
EVENT-001 资源枯竭
   → EVENT-002 北境大迁徙
      → EVENT-003 边境战争
         → EVENT-004 停战协定与隔离墙
            → 当下格局：墙内/墙外两个社会
```

**检测方法**：把事件表按时间排列，画箭头。出现孤立事件（无前因或无后果）说明设定有断点，要么补因果，要么删。

## 4. 绝对时间轴

必须建立一条绝对时间轴，所有相对描述（"三年前""二十年前"）都换算成绝对年份。

| 绝对年 | 事件 | 涉及人物 | 人物当时年龄 |
|---|---|---|---|
| 元年前 800 | | | |
| 元年 | 灾变爆发 | | |
| 元年 + 12 | | | |
| 元年 + 30 | 故事开始 | CHAR-001 | 28 |

**规则**：时间轴只用一种纪年制。若世界内有多种纪年（各国年号、教会历），必须给出换算表，否则时间线必然出错。

## 5. 年龄倒推校验

每个重要人物的年龄必须能从事件表倒推出来。

| 人物 | 出生年 | 关键事件 A（年/年龄） | 关键事件 B（年/年龄） | 当前年龄 | 是否自洽 |
|---|---|---|---|---|---|
| | | | | | |

**高频错误**：

- 人物在灾变时已经 20 岁，故事开始时灾变才过 5 年，人物却写 30 岁。
- 师徒关系要求师父在收徒时已成名，但师父的成名事件晚于收徒时间。
- 角色"从小看着他长大"，但两人年龄只差 5 岁。

## 6. 双线时间线

世界观需要两条线并行：

| 线 | 内容 | 用途 |
|---|---|---|
| 世界线 | 世界大事（战争、灾变、政权更替） | 提供背景压力 |
| 人物线 | 主角与核心人物的私人经历 | 提供情感动力 |

**要求**：两条线必须有至少 2 个交点，且交点上人物的私人遭遇由世界大事直接造成。两线永不相交，世界与人物就是两张皮。

## 7. 伏笔与揭示管理

| 伏笔编号 | 埋设位置 | 内容 | 真相 | 计划揭示点 | 关联实体 | 状态 |
|---|---|---|---|---|---|---|
| F-001 | | | | 第 X 阶段 | | 未回收/已回收 |

**纪律**：

1. 每个伏笔必须写明"读者当时会误以为什么"，否则不构成伏笔，只是信息延迟。
2. 伏笔数量与作品体量匹配：短篇 2–3 个，中长篇 5–10 个，长篇可更多但必须有台账。
3. 已埋未收的伏笔，必须在设定集中单独列出，避免遗忘。

## 8. 历史与当下的接口

历史不是背景板，必须能给当下提供四样东西：

| 接口 | 具体化 |
|---|---|
| 制度遗产 | 哪个现行制度是某历史事件的产物 |
| 领土争议 | 哪块地的归属源于哪场战争 |
| 人物宿怨 | 哪两个人物的仇恨源自哪个事件 |
| 禁忌与创伤 | 哪个话题全社会不敢提，为什么 |

四项各写 1–2 条，历史就"活"了。写不出，说明历史与故事脱节。

## 9. 时间线交付清单

1. 分层历史概览（四层各一段）。
2. 重大事件表（含各方叙事）。
3. 因果链图（可用 Mermaid 或缩进列表）。
4. 绝对时间轴（覆盖故事开始前 100 年至故事开始）。
5. 人物年龄校验表。
6. 双线交点说明。
7. 伏笔台账。
8. 历史遗留问题清单（可直接转为剧情素材）。
