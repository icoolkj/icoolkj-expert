# 01｜总体方法论与视觉圣经

## 1. 视觉资产体系的五层结构

```
L1 风格层  STYLE-001  美术基调、色彩、光比、材质、镜头语言
L2 身份层  CHAR/ENV/PROP 基础资产（不含状态变化）
L3 状态层  -C / -S     服装、年龄、伤势、昼夜、天气
L4 视角层  多视角 / 局部 / 特写
L5 镜头层  SHOT 引用   具体镜头的资产组合与角度
```

上层锁定后下层才能派生。跳过 L1 直接做 L5，必然返工。

## 2. 视觉圣经（STYLE-001）必填项

建立项目视觉圣经时逐项填满，缺项标注【待确认】并给默认假设。

### 2.1 基础信息
- 项目名、题材、时代、地域、世界观类型。
- 目标媒介：真人短剧 / 动画 / 漫剧 / CG / AI 生成视频。
- 画幅比例与安全框：16:9、9:16、2.39:1、4:3。
- 交付分辨率与单帧用途（参考图 / 首帧 / 关键帧 / 成片）。

### 2.2 美术风格
- 风格坐标：写实 ←→ 风格化，一条轴说明落点。
- 参考锚点：3–5 部作品的「哪一点」参考（光线 / 材质 / 色彩，而非笼统"像某片"）。
- 造型夸张度：头身比、五官比例、手部处理。
- 线条与边缘：硬边 / 柔边、有无描边、渲染精度。

### 2.3 色彩体系
- 主色（3 个色相 + HEX / 色温描述）。
- 辅助色与点缀色。
- 角色色彩标签：每个 P0 角色一个专属色，用于服装、道具、光效呼应。
- 场景色彩分区：安全区 / 危险区 / 回忆区的色偏规则。
- 禁用色：与项目调性冲突、易与其他角色混淆的颜色。

### 2.4 光影原则
- 主光方向偏好（顶光 / 侧光 / 逆光 / 混合）。
- 光比范围（如 1:3 柔和、1:8 硬朗）。
- 光源动机：自然光 / 实用光源（灯、火、屏）/ 戏剧光。
- 允许的"破格"情形（如高潮段落允许高饱和逆光）。

### 2.5 材质与质感
- 皮肤：油润 / 哑光 / 颗粒感。
- 织物：棉麻、丝、皮革、金属的处理规则。
- 环境：石材、木材、金属、尘土、水汽的表现标准。

### 2.6 视觉禁用项
逐条列出：不得出现的服装风格、不得出现的镜头、不得使用的滤镜、不得混用的时代元素。这是最容易被忽略却最能救一致性的一节。

## 3. 资料缺口处理

收到资料后先做「缺口清单」：

| 缺口 | 影响 | 默认假设 | 需用户确认 |
|------|------|----------|-----------|
| 角色年龄未定 | 影响面部与体态设计 | 按台词推断 28 岁 | 是 |
| 场景平面未给 | 影响多视角一致性 | 按剧本动线推单进深布局 | 是 |

原则：**先给可用默认值并推进，同时标注待确认**，不要停下来等。

## 4. 优先级判定

| 等级 | 判定标准 | 制作深度 |
|------|----------|----------|
| P0 | 主角、贯穿全剧、特写多 | 全套：基础 + 三视图 + 表情 9 种 + 服装 3 套 + 状态 |
| P1 | 重要配角、多场出现 | 基础 + 三视图 + 表情 5 种 + 服装 1–2 套 |
| P2 | 功能性角色、群像 | 基础 + 正面半身 + 关键特征 |
| P3 | 背景群演 | 类型化描述 + 统一 Prompt 模板 |

场景同理：P0 主场（多视角 + 平面 + 光影状态）、P1 次场（主视角 + 反打）、P2 过场（单视角）。

## 5. 输出顺序建议

1. 视觉圣经（1 页速览 + 详细规范）。
2. 资产清单与优先级表。
3. P0 角色基础形象 → 确认 → 三视图 → 表情/服装/状态。
4. P0 场景平面 → 确认 → 主视觉 → 多视角 → 光影状态。
5. P1/P2 批量派生。
6. 道具（先于其高频出现的镜头）。
7. Prompt 库与一致性报告。
