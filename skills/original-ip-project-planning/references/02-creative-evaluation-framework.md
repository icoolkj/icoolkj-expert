# 02 创意评估框架

## 1. 一句话故事（Logline）

### 结构公式

> **在【特定处境】下，【主角：身份+缺陷】为了【具体目标】，必须【面对的具体阻力】，否则【失败代价】。**

要点：

- 必须有**具体的人**，不能是"人类""少女们"。
- 必须有**可验证的目标**，不能是"追求自由""寻找自我"。
- 必须有**具体阻力**，不能是"命运""社会"。
- 必须有**代价**，没有代价就没有张力。

### 优劣对照

| 不合格 | 问题 | 修正 |
|---|---|---|
| 一个少年在末世中成长为英雄 | 无阻力、无代价、无具体性 | 末世第七年，靠捡废墟维生的17岁少年，为换回被"回收站"扣押的妹妹，必须冒充登记员潜入这座每天吞掉一批人的城市 |
| 她穿越后收获了爱情与事业 | 双线模糊，无敌手 | 穿越成即将被休的商户女，她必须用三个月把亏空的铺子做出账面盈余，否则全族被抄——而唯一能帮她的人，正是要休她的人 |

### 检验口径

给一个没听过这个项目的人读一遍，然后问："接下来会发生什么？你想看吗？"  
- 能预测出大致走向 → 结构清晰，但也可能套路。
- 完全猜不到 → 可能缺信息，也可能有新鲜感。
- 想追问"然后呢" → 合格。

## 2. 核心卖点四象限

卖点不是"很好看"，而是**用户能一句话转述给别人的东西**。

| 象限 | 卖点类型 | 判断标准 | 示例方向 |
|---|---|---|---|
| A 设定卖点 | 世界观/规则足够新 | 能否用一句话说清且让人觉得"没见过" | 独特规则、独特职业、独特生态 |
| B 关系卖点 | 人物关系的张力 | 两人同框时是否天然有戏 | 宿敌、共犯、错位亲密、互相利用 |
| C 情绪卖点 | 提供什么情绪体验 | 读者代入后主要获得什么感受 | 爽、虐、燃、治愈、窒息、荒诞 |
| D 形式卖点 | 讲述方式本身有辨识度 | 结构/视角/节奏是否独特 | 倒叙、多视角拼图、伪纪录片、单元式 |

**组合纪律**：一个项目最多主打 2 个卖点，其余作为辅助。四类全占通常等于没有卖点。

## 3. 差异化三层检验

### 第一层：同类识别

写出 2–4 部最接近的同类作品，找出它们的**共同公式**。看不见公式，就无法差异化。

### 第二层：变量替换

在公式中找出可替换的变量，逐个尝试：

| 变量 | 常规设定 | 替换方向 |
|---|---|---|
| 主角身份 | 常见主角职业 | 换到产业链的冷门环节 |
| 核心规则 | 通行设定 | 加一条反直觉的代价规则 |
| 冲突来源 | 常见反派 | 把冲突内化为关系内部 |
| 解决方式 | 力量压制 | 改为信息、交易、妥协、牺牲 |
| 叙事视角 | 主角视角 | 改为旁观者/对手/制度视角 |

### 第三层：不可替代性

回答：**如果把这个项目交给别人写，最容易丢掉的是什么？**

- 若答案是"设定" → 设定需要更严密，且易被模仿。
- 若答案是"人物关系的具体化学反应" → 这是最强的护城河。

## 4. 故事记忆点

读者合上作品后能复述的，通常只有 1–3 个画面或句子。策划阶段就要**指定**这些记忆点。

| 类型 | 说明 | 策划要求 |
|---|---|---|
| 画面记忆点 | 一个极具视觉冲击的场景 | 明确描述该场景的核心元素 |
| 台词记忆点 | 一句会被引用的话 | 给出方向，不需成稿 |
| 关系记忆点 | 一个关系的转折瞬间 | 标明发生在哪个阶段 |
| 规则记忆点 | 一条残酷或精妙的设定 | 说明它如何反复制造困境 |

**纪律**：记忆点必须是**能被第三方转述**的，不能是"氛围很好""文笔很棒"。

## 5. 创意强度评分表

每项 1–5 分，**必须写依据**；无依据不得给分，资料不足标"暂定"。

| 维度 | 1分 | 3分 | 5分 | 依据要求 |
|---|---|---|---|---|
| 概念新鲜度 | 完全套路 | 有局部新意 | 可一句话说清且少见 | 对比哪部同类、新在哪 |
| 冲突必然性 | 冲突靠巧合 | 有动机支撑 | 冲突由设定与人物共同逼出 | 指出冲突的结构性来源 |
| 主角能动性 | 全程被动 | 关键节点主动 | 每个阶段都主导选择 | 举出至少两个主动选择 |
| 情绪浓度 | 情绪平淡 | 有明确情绪曲线 | 强情绪且有反差 | 标明主情绪与反差情绪 |
| 展开空间 | 只够一个短篇 | 够中篇 | 可持续多阶段 | 说明第2、3阶段靠什么撑 |
| 差异化清晰度 | 说不出差异 | 差异需解释 | 差异即卖点 | 用一句话说出差异 |
| 受众指向性 | 谁都能看 | 有主要人群 | 明确人群+场景+动机 | 写出观看/阅读场景 |
| 形态适配性 | 与目标形态冲突 | 需较大改造 | 天然适合目标形态 | 指出形态层面的匹配点 |
| 资料完整度 | 仅一句话 | 有人物与片段 | 有设定与样章 | 列出已有资料清单 |

**总分参考（仅辅助，不构成市场结论）：**

- 36–45：可推进，直接进入开发规划。
- 28–35：有条件推进，补齐短板项再定。
- 20–27：建议调整核心方向后重评。
- ＜20：暂不建议立项，或降级为短篇试水。

## 6. 红黄绿灯裁决

评分之外，用三条硬指标做最终裁定（任一红灯即暂停）：

| 灯 | 指标 | 判定 |
|---|---|---|
| 红灯 | 主角没有明确、可验证的目标 | 结构必然松散 |
| 红灯 | 冲突完全依赖巧合或反派单方面作恶 | 无法持续 |
| 红灯 | 目标形态与该创意天然冲突（如强氛围文艺向创意要做竖屏强反转短剧） | 改形态或改创意 |
| 黄灯 | 卖点依赖大量解释才能成立 | 需要更强的直给设计 |
| 黄灯 | 差异化只在设定层，人物层无差异 | 需补关系设计 |
| 绿灯 | 一句话故事能引发追问，且主角有主动选择 | 可进入下一阶段 |

## 7. 使用建议

- 评分表用于**自我校准**，不用于向用户"证明"项目好坏。
- 向用户呈现时，优先给"三个最强点 + 两个最大风险"，再附评分明细。
- 若用户对评分不认同，回到依据层面讨论，而不是调分数。
