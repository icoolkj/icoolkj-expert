# 12 镜头描述与视觉提示词

镜头描述是给"人"看的，视觉提示词是给"模型"看的。两者都要具体，但写法不同。

## 12.1 好描述的五条标准

| 标准 | 检查问句 |
| --- | --- |
| 可见 | 这句话能被画出来吗？ |
| 具体 | 有没有"氛围""感觉""情绪"这类词？有就删 |
| 有序 | 读者能按顺序想象出画面变化吗？ |
| 有主体 | 观众第一眼看谁？写清了吗？ |
| 可执行 | 摄影师/美术/模型能照做吗？ |

## 12.2 六段式描述结构

按此顺序写，读者能在脑中"放一遍"：

```
【起始】画面一开始是什么（景别+主体位置+环境）
【主体】画面中最重要的元素（谁/什么，状态如何）
【动作】发生了什么变化（人物动作 / 光线变化 / 物体移动）
【摄影】摄影机如何（固定/运动，方向与幅度）
【结束】画面最后停在哪（落幅构图）
【声音】本镜的声音要点
```

示例：

```
【起始】中近景，苏瑾位于画面右侧三分线，左肩贴画面边缘，背景是关闭的主卧门。
【主体】她面部半暗，右侧受走廊暖光，左侧落入阴影。
【动作】她抬手，指尖触到门锁，停住；拇指摩挲锁芯，动作变慢。
【摄影】固定。第 2 秒开始极缓推近，2 秒内景别从中近变为近景。
【结束】落幅为近景，锁孔占据画面右下，她的眼睛在画面上方，视线向下。
【声音】雨声持续；钥匙串轻响；无对白。
```

## 12.3 禁止的写法

| 类型 | 反例 | 问题 | 改法 |
| --- | --- | --- | --- |
| 抽象心理 | 她内心充满恐惧 | 不可拍 | 呼吸变浅，手指停在半空 |
| 抽象氛围 | 气氛压抑 | 不可拍 | 空间狭窄，天花板压住画面上缘，无窗 |
| 文学比喻 | 像被抽走了灵魂 | 不可拍 | 肩膀塌下，视线失焦 |
| 因果说明 | 因为她知道真相所以… | 非画面 | 删，或改为可见细节 |
| 无主体 | 画面很乱 | 无法构图 | 写清前景/中景/背景各有什么 |
| 演员指令 | 演出绝望感 | 不可执行 | 下颌收紧，眼睛不眨 |

## 12.4 从描述到提示词

提示词不是描述的缩写，而是**重新组织成模型能理解的参数序列**。

### 结构（建议顺序）

```
画幅 + 风格 + 景别 + 机位 + 主体(外观/服装/状态) + 动作 + 环境 + 光 + 色调 + 构图 + 画质
```

### 对照示例

| 镜头描述 | 提示词 |
| --- | --- |
| 中近景，苏瑾在画面右侧，手指触门锁停住，极缓推近 | 2.39:1 电影感写实摄影，中近景，平视略低机位，25 岁亚洲女性，黑色短发，米色大衣左肩湿，右手抬起指尖触碰黄铜门锁，表情克制下颌收紧，老宅走廊，背景关闭的深色木门，走廊暖光从画面右侧照射，面部左侧落入阴影，明暗比 1:6，三分构图主体偏右，浅景深，胶片颗粒 |

### 关键差异

| 项 | 描述 | 提示词 |
| --- | --- | --- |
| 运动 | 可以写"极缓推近" | 静态图不写运动；视频写"缓慢推近，约画面高 5%" |
| 抽象词 | 少量允许 | 一律删除 |
| 情绪 | 可用"克制"辅助 | 必须转为可见特征（下颌收紧） |
| 一致性 | 不必重复 | 每次都要重复外观与服装锚点 |

## 12.5 人物一致性锚点

同一角色跨镜头必须重复同一组锚点，否则模型会换脸。

建立角色锚点卡：

```
苏瑾：25 岁东亚女性，鹅蛋脸，黑色齐肩直发，眉形平直，右眉尾有一颗小痣，
      米色羊毛大衣（及膝，左肩有雨渍），内搭黑色高领，无饰品。
```

每次写提示词时原样复用，**不改语序、不改用词**。模型对措辞变化敏感。

## 12.6 场景一致性锚点

```
老宅二楼走廊：深色木地板，右侧三扇关闭的门，尽头一扇窗，窗外雨夜街灯，
              墙面米黄剥落，天花板有吊灯但未开，左侧墙上挂一幅山水画。
```

跨镜复用时只改机位与光，不改描述。

## 12.7 视频提示词的额外要求

| 要求 | 说明 |
| --- | --- |
| 一个镜头一种运动 | 多运动会崩 |
| 时长 3–5s | 越长越易漂移 |
| 首帧描述要完整 | 模型靠首帧定调 |
| 避免手部复杂动作 | 手指是弱项，必要时用特写+景别规避 |
| 避免多人快速交互 | 换脸/穿模高发 |
| 动作幅度写相对量 | "头部向左转约 30°" |
| 不写剪辑指令 | 模型不做剪辑 |

## 12.8 提示词的负面清单

常见的失败原因，写提示词时主动规避：

| 失败 | 原因 | 规避 |
| --- | --- | --- |
| 脸部漂移 | 缺锚点或锚点措辞变动 | 固定锚点卡 |
| 手部畸形 | 手占画面过大或动作复杂 | 缩小手部占比或用手部特写单独生成 |
| 服装变化 | 未重复描述 | 每次重复服装 |
| 光线混乱 | 光源描述矛盾 | 只写一个主光源 |
| 构图不对 | 只写"电影感" | 写清位置与占比 |
| 风格漂移 | 风格词每次不同 | 固定风格串 |

## 12.9 提示词模板

```
[画幅] [风格串] | [景别]，[机位角度]，[镜头焦段倾向]
主体：[角色锚点]，[当前状态/服装细节]
动作：[单一明确动作]
环境：[场景锚点]，[与主体的空间关系]
光：[主光位置+方向+色温]，[明暗比]，[高光处理]
色：[整体色调]，[禁色]
构图：[主体位置]，[前景/中景/背景]，[留白方向]
质感：[胶片/数字]，[颗粒]，[对比度]
```

## 12.10 自检

- [ ] 每条描述能被画出来（无抽象词）
- [ ] 六段式结构完整（至少含起始/主体/结束）
- [ ] 人物锚点跨镜一致，措辞不变
- [ ] 场景锚点跨镜一致
- [ ] 提示词含画幅、景别、机位、光、构图
- [ ] 视频提示词只有一个运动，3–5s
- [ ] 未把 `[建议]` 内容写成既定事实
- [ ] 无负面清单中的高风险写法
