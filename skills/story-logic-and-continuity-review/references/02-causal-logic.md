# 02 故事因果逻辑审校（M01）

## 1. 核心公式

一切因果关系审校都回到这条链：

```
既有条件（谁、在哪、有什么、知道什么、想要什么）
  → 触发事件（发生了什么）
  → 人物行动（他做了什么、为什么这样做）
  → 直接结果（行动产生了什么）
  → 新条件（局面因此变成什么样）
  → 下一个触发事件
```

**审校动作**：逐环检查"是否成立"，并检查"是否缺环"。断裂或缺失的环节，就是问题位置。

---

## 2. 六类因果缺陷

### 2.1 缺因（结果有，原因没有）
事件发生了，但没有交代起因。

- 判据：把结果句单独抽出来，问"为什么会这样"，若在文本中找不到任何回答，即为缺因。
- 常见场景：配角突然出现在关键地点、势力突然敌对、机密突然泄露。
- 定级：影响主线走向 → P1；仅影响细节合理性 → P2。

### 2.2 弱因（有原因，但不足以支撑结果）
原因存在，但强度、份量、可信度不够。

- 判据：换一个同等强度的事件，是否也能推出同样的结果？若能，说明原因是通用借口而非真正原因。
- 典型："因为他是主角的朋友，所以他愿意为他挡刀"——若文本从未建立这份关系的重量，则为弱因。
- 定级：P2；若该结果不可替代地支撑主线，升 P1。

### 2.3 假因果（先后关系被当作因果关系）
A 发生了，接着 B 发生了，文本暗示 A 导致 B，但实际并无因果机制。

- 判据：能否写出 A 影响 B 的具体路径（物理、信息、心理、制度）？写不出即假因果。
- 常见：巧合叠加、预言自我实现但无闭环、反派"正好"犯下关键错误。

### 2.4 断链（中间环节缺失）
从行动到结果之间缺少必要过程，读者无法理解结果如何产生。

- 判据：行动与结果之间是否能插入"然后呢？"且文本无答案。
- 典型：潜入计划一句话带过，下一段人已在内库；谈判尚无交锋，对方已同意。
- 定级：P2（重要过程缺失）；若关键转折依赖该过程 → P1。

### 2.5 过度顺利（冲突解决成本过低）
冲突建立得很大，解决得过于轻易。

- 判据：解决所用资源是否在冲突建立前就已具备？若是，冲突本身失效。
- 检查：解决的代价是否与冲突的量级匹配（时间、人物损失、道德成本）。
- 定级：P2；若是全剧核心冲突 → P0/P1。

### 2.6 结果越界（结果超出条件允许）
结果包含前置条件中不存在的东西。

- 判据：结果中的每一项要素，是否都能在前置条件里找到来源？
- 典型：人物获得了他不可能知道的信息（转 M06 认知边界）；道具出现在他未到过的地方（转 M08）。

## 3. 巧合的合法边界

巧合本身不是错误，**未经铺垫的巧合才是**。判定三问：

1. 这个巧合是否在事前有过提示（哪怕一句闲笔）？
2. 巧合是否给人物制造了新麻烦，而不只是解决麻烦？
3. 巧合是否可被替换为人物主动选择？若能，优先建议替换。

- 巧合制造困境 → 通常合法（甚至加分）。
- 巧合解决困境 → 需前置铺垫，否则记 P2。
- 巧合同时解决多个困境 → 高度可疑，记 P1。

---

## 4. 非线性叙事的特殊处理

倒叙、插叙、多线并行、时间循环会制造大量"表面矛盾"。审校时必须先画**真实时序轴**，再与**叙述顺序**分开比较。

- 若真实时序自洽，仅叙述顺序跳跃 → 不是问题。
- 若真实时序不自洽 → 是问题，且应归入 M04 时间线。
- 若叙述顺序造成读者误解且无回收 → 可能是 P3（体验问题），而非逻辑错误。
- 不可靠叙述者：叙述者的错误陈述不是文本错误，但需要检查文本是否给了"这是叙述者在说谎"的可识别信号。

## 6. 输出模板示例

```
### 问题编号：LOGIC-003
- 问题标题：主角在无任何线索的情况下直奔废弃仓库
- 问题等级：P2
- 问题状态：待确认
- 所属审校模块：M01 故事因果逻辑
- 发生位置：第 9 章「夜行」第 3 段
- 问题描述：主角在上一章明确表示"不知道对方藏在哪里"，且未获得任何新信息，
  本章开场即"径直走向城西废弃仓库"，行动缺少信息来源。
- 原文证据：第9章：「他一路没停，径直走向城西那座废弃仓库。」（TEXTUAL）
  对照 第8章：「他连对方藏在哪儿都不知道。」（TEXTUAL）
- 冲突基准：F-CHAR-031 主角在第8章结束时无地点信息（TEXTUAL，第8章末）
- 问题原因：疑为断链——从"无线索"到"知道地点"之间缺少发现过程；
  也可能是有意隐藏，若为后者则缺少必要的叙述提示。
- 影响范围：第9章全章行动线；若此处需要重写，第10章的对峙地点亦受影响。
- 最小修复方案：在第9章开头补 2–3 句发现线索的过程（如收到纸条、跟踪眼线），
  不改变后续任何情节。
- 替代方案：将第8章那句"不知道藏在哪儿"改为"知道大概方位但不敢确定"，
  使第9章的判断成立，改动量最小但会削弱第8章的无助感。
- 修复后复审要求：确认第9章有明确信息来源；确认第8章表述与新信息不冲突；
  检索全书其他"他不知情"的表述是否连带失效。
```
