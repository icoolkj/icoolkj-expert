# 04 市场与受众分析

## 0. 纪律先行

本文件提供**分析框架与方法**，不提供实时市场数据。

- 涉及平台规则、榜单现状、用户规模、分账政策、竞品最新动态时，**必须联网检索并标注来源与时间**。
- 无法检索或无法验证时，只给出定性判断与验证建议，并明确标注 `[待验证]`。
- **严禁**编造数据、收入区间、用户数量、成功率、爆款案例收益。

## 1. 受众画像

不要写"面向18–35岁年轻人"。要写清三件事：**谁 + 什么场景 + 为什么追下去**。

| 维度 | 要写的内容 | 反例 |
|---|---|---|
| 身份 | 具体职业/生活状态 | "年轻女性" |
| 场景 | 在什么时间地点以什么设备消费 | "有空的时候" |
| 需求 | 想获得什么情绪或心理补偿 | "喜欢好故事" |
| 替代品 | 不看这个会去看什么 | "没什么替代" |
| 决策触发 | 什么让他点开第一集/第一章 | "看到推荐" |

### 需求地图（按情绪分类）

| 情绪需求 | 内容供给特征 | 适配题材 |
|---|---|---|
| 补偿型爽感 | 快速兑现、压制—反转 | 都市、逆袭、系统流 |
| 悬念型紧张 | 信息差、逐步揭开 | 悬疑、犯罪、密室 |
| 情感型沉浸 | 关系细腻、情绪留白 | 言情、家庭、年代 |
| 世界观型探索 | 规则严密、可推演 | 科幻、奇幻、末世 |
| 陪伴型轻松 | 单元结构、低门槛 | 日常、轻喜剧、治愈 |
| 身份型认同 | 群体共鸣、价值观表达 | 行业剧、女性向、 youth |

**用法**：一个项目主打 1 个主需求 + 1 个辅需求。主需求决定节奏，辅需求决定气质。

## 2. 竞品拆解表

选 3–5 部最接近的作品（含成功与失败案例），逐项拆解。

| 项目 | 形态/体量 | 核心公式 | 主角设定 | 主要卖点 | 节奏特征 | 明显短板 | 与本项目的关系 |
|---|---|---|---|---|---|---|---|
| | | | | | | | 参照/规避/超越 |

### 拆解要点

1. **找公式而非抄情节**：公式是"什么人 + 什么困境 + 什么解法"。
2. **看失败案例**：同类作品的差评集中在哪（拖沓、降智、烂尾、人设崩），这些就是本项目的红线。
3. **确认差异点是否真的差异**：若差异只在"设定更新"，通常不足以支撑竞争。

## 3. 差异化优势陈述

用一句话格式：

> 相比【同类作品A】的【做法】，本项目把【变量】换成【新做法】，因此能提供【不同的体验】。

写不出这句，说明差异化尚未成立。

## 4. 平台与形态适配

平台规则变化快，**具体政策必须检索确认**。以下是适配逻辑层面的判断框架。

| 形态 | 内容要求 | 节奏要求 | 适配创意特征 | 不适配特征 |
|---|---|---|---|---|
| 长篇网文 | 可持续展开、追读钩子 | 每章有钩，每卷有升级 | 目标可迭代、对手可升级 | 强氛围、弱事件、依赖视听 |
| 短篇/短篇小说 | 单点爆发、结尾翻转 | 前 3 段必须抓住 | 概念精巧、反转强 | 需要长篇铺垫的世界观 |
| 竖屏短剧 | 强冲突、高频反转 | 15 秒入戏，每集一反转 | 关系张力强、处境极端 | 慢热、内心戏、复杂设定 |
| 横屏剧集 | 人物弧光、结构完整 | 每集有推进，季末有大转折 | 群像、社会性议题 | 单线爽感、无人物成长 |
| 动态漫 | 单格信息量、视觉记忆点 | 每话 1 个高潮 | 强画面、强设定可视化 | 大量抽象思辨 |
| AI影视 | 场景/人物一致性可控 | 镜头语言清晰 | 有限场景、强概念 | 大群戏、复杂动作、精细表演 |
| 有声剧 | 声音可辨识、对白驱动 | 每集留钩 | 对话密集、角色声音差异大 | 依赖视觉的叙事 |

**适配判断三问**：

1. 这个创意的**最强体验**，目标形态能不能承载？
2. 目标形态的**硬性节奏要求**，这个创意能不能满足？
3. 目标形态的**制作约束**（成本、周期、技术），会不会破坏创意的核心？

三问有一个"不能"，就应调整形态或调整创意。

## 5. 传播卖点识别

可传播的内容，通常具备以下之一：

| 类型 | 说明 | 设计方法 |
|---|---|---|
| 可截图 | 单张画面/单句台词就能传达吸引力 | 设计 1–2 个"截图级"场景 |
| 可争论 | 存在合理的两种立场 | 设计道德困境而非简单对错 |
| 可代入 | 观众能说"这就是我" | 主角处境具备普遍性痛点 |
| 可二创 | 留有角色组合与想象空间 | 关系线不要全部写死 |
| 可复述 | 一句话能讲清且有趣 | 打磨一句话故事 |

## 6. 低成本验证方法

在投入大成本前，可用以下方式验证假设（均为定性验证，不能替代真实市场结果）：

| 方法 | 验证什么 | 判断标准 |
|---|---|---|
| 一句话测试 | 概念吸引力 | 10 个目标受众中，多数会追问"然后呢" |
| 前三章/前三集样片 | 开场留存 | 反馈集中在"想知道后续"而非"文笔不错" |
| 竞品评论区调研 | 用户痛点 | 提炼出 3 条以上高频抱怨，并逐条在设计上规避 |
| 卖点复述测试 | 卖点清晰度 | 对方能用自己的话复述出核心卖点 |
| 结局测试 | 结构完整性 | 提前告知结局，看目标受众是否仍愿意看过程 |

## 7. 输出格式

市场部分在策划案中控制在 1–2 页，包含：

1. 目标受众（画像表，1 个主画像 + 1 个次画像）。
2. 同类参照（3–5 部，含短板）。
3. 差异化陈述（一句话）。
4. 平台适配建议（首选 + 备选 + 理由）。
5. 传播卖点（2–3 条）。
6. `[待验证]` 事项清单（明确验证方式与所需资料）。

**若本次未联网检索**，必须在段首注明："本节为定性分析，未引用实时市场数据。"
