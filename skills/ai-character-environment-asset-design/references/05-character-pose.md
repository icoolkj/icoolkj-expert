# 05｜角色姿态与动作设计

## 1. 姿态是角色的第二张脸

同一个角色，站姿、重心、手的默认位置决定观众是否能在一秒内认出他。姿态资产的价值在于：让镜头里的角色不只是"长得对"，而是"动得对"。

## 2. 标准姿态清单

| 编号 | 姿态 | 用途 | 设计要点 |
|------|------|------|----------|
| -P01 | 标准站姿 | 三视图基准 | 双脚肩宽、双臂微离身体、重心居中 |
| -P02 | 标准坐姿 | 对话场景 | 脊柱弧度、手放位置、腿的开合 |
| -P03 | 行走 | 移动镜头 | 步幅、摆臂、头部稳定性 |
| -P04 | 奔跑 | 动作场景 | 前倾角、着地方式、手臂轨迹 |
| -P05 | 战斗 / 对抗 | 冲突场景 | 重心高低、护住的身体部位、武器持握 |
| -P06 | 倚靠 | 生活场景 | 靠的部位、支撑手、腿部交叠方式 |
| -P07 | 蹲 / 跪 / 倒地 | 弱势或危机 | 脊柱折叠方式、手撑地位置 |
| -P08 | 剧情标志动作 | 角色签名 | 一个只属于他的动作 |
| -P09 | 手部特写姿态 | 特写镜头 | 手指张力、指甲、习惯小动作 |

P0 角色做 P01–P08；P1 做 P01/P02/P03/P08。

## 3. 设计方法

### 3.1 从性格推姿态
- 戒备型：重心后置，肩略前扣，手常在身前（护住躯干）。
- 掌控型：重心稳，站距宽，手在身后或插袋，下巴平。
- 虚浮型：重心偏一侧，常用单腿支撑，手部动作多。

### 3.2 从职业推动作
法医的手永远稳、动作幅度小；武人的手常处于预备位；服务行业者习惯性微微前倾。

### 3.3 从身体条件推限制
旧伤、身高、体重会限制动作。写清"他做不到什么"，比写"他能做什么"更能塑形。

## 4. 姿态 Prompt 要点

- 用骨骼语言而非情绪语言："weight on left leg, right foot slightly forward, right hand at hip, left hand holding strap" 优于 "confident pose"。
- 明确手部：手指数量与姿态是 AI 高发错误区，需在负面词中加 "extra fingers, deformed hands"。
- 明确服装与动作的交互：衣摆、袖口、发丝在运动中的状态。
- 动作连贯性：动作类资产建议给「起始 / 中段 / 结束」三帧，避免单帧无法推演。

## 5. 动作与镜头语言的匹配

| 镜头类型 | 姿态选择 |
|----------|----------|
| 全景 | 完整剪影可读的姿态，避免手挡身体 |
| 中景 | 上半身姿态为主，手部入画 |
| 近景 / 特写 | 面部 + 肩线，姿态仅通过肩颈传递 |
| 俯拍 | 强调头顶与肩背，姿态需有明确方向性 |
| 仰拍 | 强调下颌与胸廓，站姿需挺拔 |

## 6. 动态资产（AI 视频项目专用）

AI 视频需要的不只是一张姿态图，而是可驱动的动作参考：

1. **关键姿态帧**：动作起、中、止三帧，构图一致、光位一致。
2. **运动方向标注**：入画方向、出画方向、屏幕内位移轨迹。
3. **可循环动作**：走路、呼吸、等待需给出可循环的起止同帧描述。
4. **物理提示**：重心变化、衣物惯性、头发延迟。

## 7. 验收标准

- 剪影可辨：纯黑剪影下仍能认出角色。
- 姿态与性格一致，不出现"通用模特姿势"。
- 手部结构正确，无穿模。
- 同一动作在不同视角下身体朝向一致。
