# 02｜角色基础身份设计

基础身份 = 不随服装、年龄、伤势、情绪改变的部分。这一层必须先锁定，后续所有资产都在它之上派生。

## 1. 档案必填字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 资产编号 | CHAR-XXX | CHAR-001 |
| 姓名 / 代号 | 剧中称呼 | 林晚 |
| 身份定位 | 主角 / 配角 / 群像 | 主角 |
| 年龄感 | 视觉年龄，非设定年龄 | 视觉 28，设定 32 |
| 性别呈现 | 含中性 / 跨性别表达 | 女 |
| 身高体型 | 数值 + 体型语言 | 168cm，瘦削偏骨感 |
| 头颅比例 | 头身比 | 7.5 头身 |
| 职业 / 阶层 | 决定服装与体态 | 法医 |
| 核心性格 | 3 个词 | 克制、敏锐、执拗 |
| 视觉母题 | 一个可复用的视觉符号 | 冷白与雨 |

## 2. 面部结构设计

按「骨 → 肉 → 皮 → 特征」四层描述，避免直接写"很好看"。

1. **骨相**：脸型（鹅蛋/方/长/圆/菱形）、下颌角明显度、颧骨高低、额头宽度、下巴形状。
2. **五官比例**：三庭五眼偏移量。例如"中庭偏长，眼距略宽"。
3. **眼睛**：形状（杏/丹凤/圆/下垂）、内眦、眼皮单双、瞳孔色、眼神特质（钝/锐/散）。
4. **鼻**：鼻梁高低、鼻头肉感、鼻翼宽窄。
5. **嘴**：唇厚、唇峰、嘴角走向（上扬/下垂/平）、牙列。
6. **耳**：形状、是否露耳（影响侧脸识别）。
7. **皮肤**：色号倾向、质感（哑光/油润）、瑕疵（疤、痣、雀斑）及位置。
8. **识别特征（3 个锁定项）**：全项目生成时必须复现的最小特征集。

### 识别特征写法示例
```
锁定项 A：左眉尾一道 1.5cm 断眉疤痕
锁定项 B：眼尾微下垂，双眼皮窄且不完全对称（右眼更窄）
锁定项 C：下颌线极清晰，嘴角自然下垂
```

三条足够。超过五条模型无法稳定复现，反而稀释重点。

## 3. 发型设计

- 长度与层次：发长落点（锁骨 / 肩下 / 腰际）、有无刘海、层次高低。
- 发质：直/卷、粗硬/细软、毛躁度。
- 发色：主色 + 高光色 + 发根差异；避免纯黑（模型常渲染为死黑块）。
- 日常固定方式：马尾、盘发、半扎、披散，以及"乱的程度"。
- 剧情可变项：哪些可以随状态改变（如淋湿、散开），哪些不能（如长度、刘海形状）。

## 4. 身材与体态

- 体型描述用可画语言：肩宽、锁骨明显度、腰臀比、四肢粗细、手指长度。
- **体态即性格**：含胸/挺背、重心偏前/偏后、站姿开合、习惯性小动作。
- 站姿基准：脚位（并拢/八字/一前一后）、手的默认位置。
- 走路节奏：步幅、步频、摆臂幅度。

## 5. 气质与视觉母题

用一个「光线 + 动作」的组合描述气质，比形容词有效：
- "常处在侧逆光里，习惯性低头看人" → 疏离、审视。
- "永远站在门口不进房间" → 边界感。

## 6. 基础形象 Prompt 骨架

见 `12-prompt-engineering.md`。基础形象 Prompt 只写身份层，不写情绪与剧情动作。

## 7. 验收标准

- 三个锁定特征在任意角度都成立。
- 背面 / 侧脸仍能认出是谁。
- 换掉服装后仍是同一人。
- 与项目内其他角色在剪影层面可区分。
