# 06 项目策划案模板

## 使用说明

- 按项目规模合并不必要章节，**不为填满模板而编造内容**。
- 所有关键结论标注状态：`[已确认]` `[用户原始设想]` `[专家建议]` `[待确认]` `[待验证]`。
- 无法确定的项写"暂缺 + 影响 + 补齐方式"，不要留空，也不要猜。
- 本节模板可直接复制为输出文档骨架。
