# 02 文档与集层级格式规范

规定剧本文件从文件名到标点的层级格式，是"看起来统一"的基础层。

## 2.1 文档层级结构

```
[项目名]（可选，首页或页眉）
  └─ 第NN集 集标题（可选）
       └─ N-N 时间 内外景 地点
            ├─ 人物：…
            ├─ △ 动作
            ├─ 人物（提示）：台词
            └─ 【标注：…】
```

层级只允许四层：项目 → 集 → 场 → 场内元素。不得出现"集下直接写对白""场下再设小标题"这类越层结构。

## 2.2 集标记

| 写法 | 判定 |
| --- | --- |
| `第01集` | 默认标准（两位补零） |
| `第1集` | 可接受但须全稿统一 |
| `EP01` / `EP1` | 仅在用户项目规范要求时使用 |
| `第一集` | 中文数字，除非用户规范要求，否则改为阿拉伯数字补零 |
| `1` / `01` 单独一行 | 不达交付标准，须补"第…集" |

集标题规则：

- 有标题：`第01集 她回来了`
- 无标题：只写 `第01集`，**不得自拟标题**
- 集标题与分集大纲标题不一致时，以剧本正文为准，差异记入待确认

## 2.3 场次标题

格式：`N-N 时间 内外景 地点`

- 场号与时间之间用**一个半角空格**；后续要素同样用单空格分隔。
- 场号不使用 `第`、`场`、`S`、`#` 等前缀（除非用户规范要求）。
- 标题行不出现句号、冒号、括号。
- 地点含空格或特殊符号时整体不加引号，直接写出。

详见 `03-scene-structure.md`。

## 2.4 场内元素顺序

推荐固定顺序，便于阅读和机器解析：

```
场次标题
人物行
△ 首次动作/环境补充（可选）
对白 / 动作交替
【标注】穿插在触发位置
【切至：…】或转场标记收尾
```

不强制每场都有全部元素，但同一项目内顺序一致。

## 2.5 空行与缩进

- 集标题上方空一行，场次标题上方空一行。
- 人物行与场次标题之间空一行。
- 对白与对白之间空一行（便于阅读和配音分段）。
- 动作行与相邻元素之间空一行。
- 不使用 Tab 缩进；不使用首行缩进两个全角空格（Markdown 与排版软件都会错乱）。
- 连续两个以上空行压缩为一个。

## 2.6 标点规范

| 场景 | 规范 | 说明 |
| --- | --- | --- |
| 句末 | 。 | 动作描述完整句用句号 |
| 台词内停顿 | ， | 不用空格代替 |
| 省略 | …… | 六个点，不用 `...` 或 `。。。` |
| 打断/拖长 | —— | 破折号两个连写，不用 `-` 或 `--` |
| 表演提示 | （） | 全角圆括号，紧跟人物名 |
| 标注 | 【】 | 全角方头括号 |
| 引号 | "" '' | 台词内引用他人话语时使用；台词本身不加引号 |
| 书名/片名 | 《》 | |
| 并列 | 、 | 人物行分隔用顿号 |
| 数字 | 阿拉伯数字 | 场号、集号、年龄、时间点；序数词可用中文 |

全稿禁止混用 `()` 与 `（）`、`:` 与 `：`。检测脚本会把混用列为 P2。

## 2.7 数字与时间写法

- 场次编号：`1-1`、`1-10`（场号不补零，集号补零）。
- 时钟时间：`23:47` 或 `深夜十一点四十七分` 台词内表述，二者不混。
- 日期：`3月12日`。
- 年龄、金额、楼层、门牌：阿拉伯数字。
- 台词内数字按口语习惯写（"三千块"而非"3000块"），保持口语感。

## 2.8 段落长度

- 单个动作段建议不超过 3 行；超过则按动作节拍拆分。
- 单句台词超过 120 字时提示可能需切分（见 `05-dialogue-standardization.md`），但不得擅自拆分。
- 不以"……"或空段替代缺失内容。

## 2.9 文件名规范

```
项目名_第NN集_vX.Y_状态_YYYYMMDD.md
示例：暗涌_第01集_v1.0_standardized_20261101.md
```

状态词见 `11-version-management.md`。交付时如有多个文件，统一命名前缀，便于排序。

## 2.10 格式检查清单

- [ ] 全稿集标记写法一致、补零一致
- [ ] 场次标题四要素齐全或已标注缺失
- [ ] 标题行无多余标点
- [ ] 全角/半角括号不混用
- [ ] 省略号、破折号写法统一
- [ ] 空行规则一致，无三重空行
- [ ] 无 Tab 缩进、无人工首行缩进
- [ ] 文件名符合命名规则
