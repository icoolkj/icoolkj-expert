# 09 空间连续性与轴线：不穿帮的底线

观众可以接受一切非现实，唯独不能接受**空间错乱**。空间一乱，观众立刻退出故事。

## 9.1 连续性十项清单

每场结束前逐项核，逐项打勾或写"冲突"。

| # | 项目 | 具体内容 |
| --- | --- | --- |
| 1 | 人物位置 | 谁说这句时在哪；有没有凭空移动 |
| 2 | 视线方向 | 看左还是看右；与对方位置是否一致 |
| 3 | 动作状态 | 上一镜抬手，这一镜不能已放下 |
| 4 | 道具 | 在谁手里、放哪了、用没用过 |
| 5 | 服装发型伤势 | 湿/脏/破/血迹位置是否连贯 |
| 6 | 光线方向 | 光源在东不能西边亮；室内外亮度差 |
| 7 | 时间天气 | 夜不能突然日；雨不能中途停 |
| 8 | 空间关系 | 门/窗/桌/楼梯的相对位置 |
| 9 | 镜头轴线 | 是否越轴（见 9.3） |
| 10 | 场间衔接 | 上一场结束时状态＝下一场开始时状态 |

## 9.2 建立空间地图

动镜之前先画"文字平面图"，写在交付件里：

```
SC03 老宅二楼走廊（内，夜）
  北 ── 楼梯口（C 位）
  南 ── 主卧门（锁被换），门内为父亲房间
  东 ── 走廊窗，雨，街灯
  西 ── 挂画与侧门（关闭）
  苏瑾：楼梯口偏西，面向南（主卧门）
  陈默：主卧门前，面向北（苏瑾）
```

有了这张图，所有景别/机位/视线都能对得上。

## 9.3 轴线（180° 规则）

**定义**：两个对话主体之间连一条假想线，摄影机只能在线的同一侧。

### 为什么

观众靠"人物在画面左右的位置"判断谁在看谁。越轴后左右互换，观众会以为两人换了位置。

### 建立轴线

| 场景 | 轴线 |
| --- | --- |
| 两人对话 | 两人连线 |
| 一人走向目标 | 人物与目标的连线 |
| 一人移动 | 运动方向线（观众默认人往右走就是往右走） |
| 三人围坐 | 任取一条主轴线，其余人按此排布 |

### 越轴的合法方式

| 方式 | 做法 |
| --- | --- |
| 插入中性镜 | 先切一个轴线上的正面/背面/空镜，再切到另一侧 |
| 摄影机运动过轴 | 在一个连续镜头里移过轴线，观众看到过程 |
| 人物移动过轴 | 让人物自己走到对面，轴线随之重建 |
| 插入全景区 | 先给一个能看清双方位置的全景，重建空间认知 |
| 主观镜过渡 | 切到某人 POV，再切回即已在新侧 |

**禁止**：两个正反打镜头直接对切却分处轴线两侧。这是最典型的穿帮。

## 9.4 银幕方向

| 规则 | 说明 |
| --- | --- |
| 运动方向一致 | 人物从左往右走，切镜后仍应向右（除非表现折返） |
| 追逃方向 | 追者与被追者必须同向；反向即"擦肩而过" |
| 出入口一致 | 从画面右边出门，下一场应从左边进（延续方向感）或明确交代时间跳跃 |
| 视线匹配 | A 看向画面右，切到 B 时应从画面左回看 |

反用银幕方向表示"相遇"：两人相向而行，各自画面中向对方方向移动。

## 9.5 视线匹配

三个要素必须同时正确：

1. **高度**：站着看站着 → 平视；站着看坐着 → 俯视。
2. **方向**：A 在画面右看左，B 应在画面左看右。
3. **距离**：近景对视距离感要与实际距离一致（远距离用长焦压缩要说明）。

视线不匹配是最常见的"廉价感"来源。

## 9.6 动作接（Match on Action）

同一动作跨两个镜头，剪辑点藏在动作中段。

| 做法 | 要点 |
| --- | --- |
| 切在动作最快处 | 观众注意不到剪辑 |
| 两个镜头的动作幅度要重叠 | 前一镜做到 60%，后一镜从 40% 接 |
| 手部/身体朝向必须一致 | 否则出现"两只右手" |

写镜头表时，在 `continuity` 字段注明"动作接：抬手至肩，接下一镜"。

## 9.7 道具连续性

建道具表，跨场维护：

| 道具 | 首次出现 | 当前持有人 | 状态 | 位置 |
| --- | --- | --- | --- | --- |
| 新门锁钥匙 | SC03-SH05 | 陈默 | 已使用 | 陈默右裤袋 |
| 雨伞 | SC02-SH01 | 苏瑾 | 湿，半开 | 右手 |
| 药瓶 | SC07 | 父亲 | 已倒空 | 床头柜 |

规则：

- 道具消失必须有交代（放下、收起、被拿走）。
- 道具易手必须在画面内发生，或明确交代。
- 关键道具每次出现给一个清晰镜头，观众要认得出。

## 9.8 服装、伤势、湿度

| 项 | 记录内容 |
| --- | --- |
| 服装 | 每场穿着（含外套脱穿状态） |
| 湿度 | 淋雨后头发/肩部的湿痕位置 |
| 伤势 | 位置、程度、是否渗血、是否包扎 |
| 妆造 | 妆容是否已花、口红是否掉 |

跨场连续的状态必须写进 `continuity` 字段，否则实拍/生成时必错。

## 9.9 光线连续性

| 检查点 | 要求 |
| --- | --- |
| 光源方向 | 同一场内主光方向不变（除非画内有理由） |
| 色温 | 日/夜/室内外不混 |
| 亮度比 | 相邻镜头曝光差异不超过 1 档（除非刻意） |
| 实景光 | 窗外亮度与室内灯是否矛盾（夜戏窗外全白＝穿帮） |
| 影子 | 影子方向必须一致 |

## 9.10 时间与天气

| 检查点 | 要求 |
| --- | --- |
| 时间推进 | 明确每场在故事时间中的位置 |
| 天气 | 雨/雪/风的状态跨场一致，变化要有过程 |
| 季节 | 植被、衣着、光线角度相符 |
| 时钟/手机屏 | 若入画，时间必须符合剧情 |

## 9.11 冲突记录格式

发现冲突时按此格式记录，不隐瞒、不含糊：

| 冲突编号 | 涉及镜头 | 冲突内容 | 影响 | 建议处理 |
| --- | --- | --- | --- | --- |
| C-01 | SC03-SH07 / SH09 | SH07 苏瑾右手持伞，SH09 变为左手 | 穿帮 | 改 SH09 为右手，或 SH07 加换手动作 |
| C-02 | SC03-SH12 / SC04-SH01 | SH12 在走廊东侧，SC04 开场在西侧无交代 | 观众失去方位 | SC04 开场加一个移动镜 |

**P0 冲突（穿帮级）必须解决后才能交付**；P1（可能被察觉）需用户确认；P2（细看才发现）记录即可。
