# 09 IP 授权与衍生开发

## 0. 前置铁律

**不得默认用户拥有全部相关权利。** 在权利未厘清前，任何授权报价、授权方案都只能标为"待权利确认"。

授权是法律行为，本文件只提供商业侧的结构化框架，不构成法律意见；涉及具体条款须由专业法律人士审核。

## 1. 权利盘点

| 权利 | 内容 | 常见问题 |
|---|---|---|
| 著作权（财产权） | 复制、发行、改编、信息网络传播等 | 是否与平台签了专有许可 |
| 改编权 | 短剧、漫画、动画、影视、游戏 | 是否已单独授出、是否独家 |
| 角色形象权 | 美术作品著作权 + 商品化权益 | 画师是否保留权利、是否职务作品 |
| 商标 | IP 名称、标识、角色名 | 是否已注册、类别是否覆盖 |
| 邻接权 | 配音、音乐、表演 | 是否取得表演者与录音制作者许可 |
| 合作共有 | 联合出品、委托创作 | 是否需共有人书面同意 |
| 姓名/肖像 | 真人原型、作者本人 | 是否取得本人授权 |

盘点结论写成一句话：`可用于授权的资产：【x】；受限资产：【y】（原因）；不可授权：【z】`。

## 2. 授权资产清单

| 资产 | 可授权范围 | 建议独家性 | 审核难度 |
|---|---|---|---|
| A 级角色形象 | 商品、联名、广告、代言 | 品类内独家 | 高 |
| 角色名称 | 商品名、店铺名、活动名 | 可非独家 | 中 |
| IP 标识/logo | 物料、包装、联名署名 | 可非独家 | 低 |
| 世界观元素 | 场景、道具、术语 | 可非独家 | 中 |
| 内容片段 | 用于宣传的图文/视频 | 可非独家 | 低 |
| 改编权 | 按媒介分别授权 | 媒介内独家 | 高 |

## 3. 授权九要素

每份授权方案必须写全，缺一项都会在履约时出问题：

| 要素 | 说明 | 常见坑 |
|---|---|---|
| 授权资产 | 具体到文件/角色/图稿版本 | 只写"IP 形象"导致范围争议 |
| 授权范围 | 商品品类 / 使用场景 | 品类描述宽泛被超范围使用 |
| 授权地域 | 国家/地区 | 默认全球 |
| 授权期限 | 起止日期 + 续约条件 | 无终止后库存处理条款 |
| 使用渠道 | 线上/线下/特定平台 | 跨渠道滥用 |
| 独家性 | 独家/排他/非独家 + 品类限定 | "独家"未限定品类 |
| 再授权 | 是否允许转授权 | 层层转授失控 |
| 费用结构 | 保底 + 分成 / 纯分成 / 买断 | 只谈分成无保底，无履约动力 |
| 审核机制 | 图稿审核、样品确认、上市后抽检 | 无审核导致质量事故 |

## 4. 费用结构

| 结构 | 适用 | 优点 | 风险 |
|---|---|---|---|
| 保底 + 分成 | 成熟 IP、成熟品类 | 有下限、共享增长 | 保底定高会劝退 |
| 纯分成 | 早期 IP、试水品类 | 门槛低、易签约 | 无收入保障、难核查销量 |
| 买断 | 一次性、低价值品类 | 简单 | 长期价值损失 |
| 阶梯分成 | 大额合作 | 激励做大 | 核算复杂 |
| 保底 + 里程碑 | 改编授权 | 分阶段收款 | 需明确交付节点 |

分成必须约定：计算基数（出厂价/零售价/净销售额）、结算周期、对账权、审计权。

## 5. 衍生开发优先级

按"低成本 × 高相关性 × 快验证"排序，不要一上来做重资产：

| 序 | 方向 | 成本量级 | 前置条件 | 验证方式 |
|---|---|---|---|---|
| 1 | 数字内容（表情包、壁纸、头像、电子设定集） | 低 | 视觉资产 | 下载/使用量 |
| 2 | 轻周边（贴纸、徽章、亚克力、明信片） | 低 | 视觉资产 + 打样 | 预售转化 |
| 3 | 出版物 / 设定集 | 中 | 内容量 + 编辑 | 预订量 |
| 4 | 联名（茶饮、服饰、文具） | 中 | 品牌调性 + 商务 | 合作方意愿 + 首店数据 |
| 5 | 音频剧 / 广播剧 | 中 | 改编权 + 制作方 | 播放与付费 |
| 6 | 服饰 / 箱包（自有） | 中高 | 供应链 + 库存能力 | 小批量测试 |
| 7 | 主题展览 / 快闪 | 高 | 粉丝密度 | 预售票量 |
| 8 | 动画 / 影视 / 游戏 | 极高 | 投资 + 改编权 + 团队 | 投资到位才启动 |

## 6. 质量与品牌风险控制

| 风险 | 后果 | 控制手段 |
|---|---|---|
| 品质事故 | 品牌信誉受损 | 打样确认、抽检、召回条款 |
| 超范围使用 | 权利被稀释 | 品类清单化、违约条款 |
| 调性不匹配 | 用户反感 | 合作前做调性匹配表 |
| 商标被抢注 | 无法使用自有名称 | 提前注册核心类别 |
| 盗版与仿品 | 收入流失 | 登记存证、平台投诉、防伪 |
| 库存积压 | 现金流压力 | 预售制、小批量、可退换条款 |
| 合作方履约失败 | 项目烂尾 | 里程碑付款、保证金 |

## 7. 输出格式

```
1. 权利盘点结论（可授权/受限/不可授权）
2. 授权资产清单 + 分级
3. 授权方案表（九要素逐项填）
4. 费用结构建议 + 报价区间（标 E4，说明定价依据）
5. 审核与品控流程
6. 衍生开发优先级（含成本量级与验证方式）
7. 风险与前置动作（商标、存证、合同要点）
8. 待律师确认事项
```

## 8. 禁止项

- 不在权利不明时给出具体报价。
- 不承诺授权成交或合作方意向。
- 不设计"全品类全球永久独家"这类明显失衡的条款而不提示风险。
- 不忽略合同终止后的库存与物料处理。
