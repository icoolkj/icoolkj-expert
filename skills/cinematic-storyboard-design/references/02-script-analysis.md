# 02 剧本分析：把文字拆成可拍的单位

分镜的原料不是"剧本"，是"场次信息卡"。本文件说明如何从剧本抽出拆镜所需的全部信息。

## 2.1 场次信息卡（每场一张）

| 项 | 内容 |
| --- | --- |
| 场号 | SC03（沿用原稿；无则自编并标注） |
| 内外景 | 内 / 外 / 内外 |
| 地点 | 老宅二楼走廊 |
| 时间 | 夜 / 雨夜 / 凌晨 |
| 在场人物 | 苏瑾、陈默（画外：管家） |
| 缺席但被提及 | 父亲 |
| 事件一句话 | 苏瑾发现门锁被换 |
| 戏剧冲突 | 苏瑾要进门 vs 陈默阻止 |
| 人物目标 | 苏瑾：确认父亲是否在房内；陈默：不让开门 |
| 阻碍 | 陈默的身体阻挡与话术 |
| 转折点 | 门内传出咳嗽声 |
| 情绪曲线 | 疑惑→警觉→强压怒意→惊惧 |
| 关键信息 | ①门锁是新的 ②陈默有钥匙 ③房内有人 |
| 伏笔 | 陈默左手无名指的伤 |
| 动作节点 | 上楼／摸锁／转身／逼近／听见咳嗽 |
| 关键对白 | "这锁谁换的？""老爷子吩咐的。" |
| 场末钩子 | 门内咳嗽，苏瑾回头 |
| 认知边界 | 苏瑾不知道房内是谁；观众也不知道 |

信息卡填不满，说明剧本信息不足，先问或标待确认，不要靠猜补。

## 2.2 从文字到事件的四步翻译

1. **剥离文学修饰**：把"她的心像被冷水浇透"译为可拍的外部表现——手指停在半空、呼吸变浅。
2. **切事件**：一句话里若有多个动作或状态变化，就是多个事件。例："苏瑾推门进来，看见桌上的信，脸色变了"= 进门／看见信／读信／神色变化（4 个可拍单位）。
3. **定信息顺序**：观众先看到什么、后看到什么，决定悬念。原剧本常把信息给得太快，允许**调整揭示顺序**（不改事件本身），并标 `[建议]`。
4. **识别不可拍内容**：心理活动、作者议论、时间跨度概括。处理方式见 2.5。

## 2.3 节拍切分（拆镜的真正依据）

节拍＝一次注意力的转移或一次力量关系的变化。判据：

- 有新信息进入画面 → 新节拍
- 有一方攻守易位 → 新节拍
- 观众需要看另一人的反应 → 新节拍
- 空间或时间跳变 → 新节拍

| 台词行 | 是否新节拍 | 理由 |
| --- | --- | --- |
| "这锁谁换的？" | 是 | 信息首次出现，需要看清锁 |
| "老爷子吩咐的。" | 是 | 攻守易位，陈默接招，需要他的脸 |
| "他凭什么换我的锁。" | 否 | 同一情绪延续，可与上一句同镜或用一个反应镜带过 |
| （门内咳嗽） | 是 | 画外新信息，必须有镜头承接 |

**一个节拍可以是 0 个镜头（用声音带过），也可以是 3 个镜头（正反打+反应）。** 数量由表演与信息需要决定。

## 2.4 对白处理规则

| 情况 | 处理 |
| --- | --- |
| 核心台词 | 给足镜头，允许近景/特写，不与动作抢注意力 |
| 过场台词 | 可与动作同镜，或转为画外 |
| 长段独白 | 拆为"说—听—环境"三个层次交替，避免长时间单一脸 |
| 打断/抢话 | 用短切和声音重叠，镜头不必等话音落 |
| 电话/画外对话 | 明确谁在画面内，另一侧只用声音，必要时给听者反应 |
| 台词与动作冲突 | 优先保表演，把台词推为画外 |

## 2.5 不可拍内容的转译表

| 原剧本写法 | 不可拍原因 | 转译方向 |
| --- | --- | --- |
| "她想起了三年前" | 心理 | 闪回镜头／焦点变化／她视线落向某物 |
| "他其实早就知道" | 内心状态 | 提前给一个"早知"的外部细节（如他不惊讶）`[建议]` |
| "三年后" | 时间跨度 | 字幕卡／季节与服装变化／同一空间的状态差 |
| "气氛凝固了" | 抽象 | 静止、无声、众人不动、只余环境音 |
| "她崩溃了" | 抽象情绪 | 具体行为（滑坐、抓桌沿、笑出声）`[建议]` |
| 作者议论 | 非叙事 | 不入分镜；如需保留改用旁白 VO 并确认 |

## 2.6 伏笔与回收的登记

建一张伏笔表，跨场维护。分镜的责任是**给伏笔一个清晰可见的画面**，不是解释它。

| 伏笔 | 埋设场/镜 | 视觉处理 | 回收场 | 状态 |
| --- | --- | --- | --- | --- |
| 陈默左手伤 | SC03-SH09 | 手部特写，不动声色 | SC11 | 已埋 |
| 新门锁 | SC03-SH04 | 锁孔特写，反光 | EP05 | 已埋 |

未被视觉化的伏笔等于没埋。若剧本写了但没给镜头，标 `[建议]` 补一个。

## 2.7 角色认知边界表

每个角色"此刻知道什么"必须单列，否则容易出现角色说出他不该知道的话、或镜头提前泄露信息。

| 角色 | 已知 | 未知 | 误解 |
| --- | --- | --- | --- |
| 苏瑾 | 锁被换、陈默有钥匙 | 房内是谁 | 以为是父亲躲她 |
| 陈默 | 房内是谁 | 苏瑾已起疑 | 以为她不会追问 |
| 观众 | 与苏瑾同步 | 房内是谁 | — |

**视点镜头只能给角色看得见的东西。** 若剧情需要观众先知道，必须用客观镜（角色不在场的镜头）并明确这是导演选择。

## 2.8 分析产出清单

第二阶段结束时应具备：

- 场次信息卡（每场一张）
- 节拍表（每场一行一节拍，标注对应的剧本行）
- 伏笔表
- 角色认知边界表
- 不可拍内容转译记录（哪些转了什么、标了什么）
- 待确认问题（不超过 3 条，按影响排序）
