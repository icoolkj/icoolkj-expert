# 03 故事结构框架

## 1. 主角的四要素

任何主角必须同时具备四项，缺一项就会导致推进乏力。

| 要素 | 含义 | 策划要求 | 检验问题 |
|---|---|---|---|
| 外部目标（Want） | 他想要什么 | 具体、可验证、有期限 | 能否用一句话说清"他这一卷要拿到什么" |
| 内在需求（Need） | 他真正缺什么 | 与外部目标形成张力 | 得到想要的东西，会不会反而更糟 |
| 伤口（Wound） | 什么让他变成现在这样 | 只需一幕关键往事 | 这个伤口如何持续影响判断 |
| 缺陷（Flaw） | 他错误的行为模式 | 必须造成实际损失 | 哪一次失败是他的缺陷直接导致的 |

**常见错误**：把"善良""坚强""不服输"当作缺陷。缺陷必须是**会害到他自己的东西**。

## 2. 冲突分层

故事需要三层冲突同时运转，只做一层会很薄。

| 层级 | 内容 | 表现形式 |
|---|---|---|
| 外部冲突 | 主角与对手/环境/规则 | 明确的对立面与倒计时 |
| 关系冲突 | 主角与重要他者的立场分歧 | 同一目标下的不同手段 |
| 内部冲突 | 主角与自己的缺陷 | 每次选择都在重复旧模式 |

**设计纪律**：高潮应当是三层冲突同时引爆——主角必须用"克服缺陷"的方式，在与对手的正面交锋中，赢下也失去某段关系。

## 3. 人物关系网设计

不要写"人物列表"，要写"关系张力表"。

| 人物 | 与主角的关系 | 立场 | 他能给主角什么 | 他会夺走什么 | 关系变化方向 |
|---|---|---|---|---|---|
| | | 同盟/对手/摇摆/镜像 | 资源、信息、情感、能力 | 安全感、退路、身份、信任 | 靠近/背离/反转 |

### 关系设计要点

- **镜像人物**：与主角处境相似但选择相反的人，用于把主题说透而不说教。
- **功能人物**：每个配角至少承担一个推进功能（提供信息、制造障碍、代读者提问），纯装饰人物应删。
- **关系必须有变化**：策划阶段就标出"哪一阶段这段关系发生不可逆改变"。

## 4. 故事阶段模型

不同媒介用不同骨架，选一种主骨架，不要混用。

### 4.1 三幕式（适合电影化叙事、中长篇、AI影视）

| 幕 | 占比 | 功能 | 关键节点 |
|---|---|---|---|
| 第一幕 | 20–25% | 建立常态与缺口 | 日常 → 打破常态的事件 → 主角被迫做出选择 |
| 第二幕 | 50% | 升级与反噬 | 初次胜利 → 规则变严 → 中点反转 → 全面失败 |
| 第三幕 | 25–30% | 决战与代价 | 最低点 → 认知转变 → 高潮对决 → 新常态 |

### 4.2 起承转合（适合短篇、单元剧、动态漫）

- 起：给出一个异常。
- 承：异常扩大，规则显形。
- 转：规则被颠覆或反转。
- 合：代价落定，留下余味。

### 4.3 网文循环单元（适合长篇连载）

每个循环单元 15–40 章，结构固定：

```
新地图/新层级 → 遭遇压制 → 获得关键资源 → 反打 → 阶段胜利 → 暴露更大威胁 → 进入下一单元
```

**策划要求**：至少写出前 3 个循环单元的目标与对手。写不出第 3 个，说明可持续性不足。

### 4.4 短剧节拍（适合竖屏短剧，单集 60–120 秒）

| 位置 | 要求 |
|---|---|
| 第 1 集前 15 秒 | 必须出现强冲突或强反差 |
| 第 1–3 集 | 完成身份/处境/核心矛盾全部交代 |
| 每集 | 至少 1 次反转或信息揭露 |
| 每 8–12 集 | 一次大反转或关系重组 |
| 卡点集 | 停在最不可接受的位置（付费/追更动机） |

## 5. 转折与高潮设计

### 有效转折的三个条件

1. **意外但合理**：回看时能发现伏笔。
2. **改变处境**：转折后主角的选项集必须变化。
3. **付出代价**：转折不能纯赚。

### 中点反转

第二幕中点应发生"认知级"变化，而非"事件级"变化：

- 事件级（弱）：主角打赢了一场仗。
- 认知级（强）：主角发现自己一直在帮对手做事。

### 高潮的判断标准

高潮不是"最大场面"，而是**主角必须做出他最不愿做的选择**。若高潮中主角只是"变强了然后赢了"，则张力不足。

## 6. 结局方向

策划阶段只需确定结局**类型**与**代价**，不需写具体情节。

| 结局类型 | 特征 | 适合 |
|---|---|---|
| 代价型胜利 | 目标达成，失去重要之物 | 严肃向、现实向 |
| 认知型和解 | 目标改变，接受新的活法 | 治愈向、成长向 |
| 反转型揭示 | 世界规则被重新定义 | 悬疑、科幻 |
| 循环型延续 | 问题未解决，但主角位置变了 | 系列化、单元剧 |
| 悲剧型必然 | 主角的缺陷导致必然失败 | 文学向、短片 |

**纪律**：结局必须回应第一章提出的问题。若开篇问"他能不能救回妹妹"，结局不能只回答"他成为了英雄"。

## 7. 持续创作能力评估

长篇与系列化项目必须评估：

| 指标 | 评估问题 | 不足时的补救 |
|---|---|---|
| 世界可扩展性 | 除了主角的活动范围，还有几个可开发的区域/层级 | 预留 2 个未展开的设定区 |
| 对手梯度 | 是否有 3 个以上强度递进的对手 | 增设制度性对手（非个人） |
| 目标迭代 | 主角目标能否自然升级 | 把"拿到X"升级为"改变X的规则" |
| 单元可复制性 | 能否容纳独立成篇的小故事 | 设计可复用的事件模板 |
| 情感账户 | 是否有尚未兑现的关系承诺 | 提前埋 2 条慢线 |
