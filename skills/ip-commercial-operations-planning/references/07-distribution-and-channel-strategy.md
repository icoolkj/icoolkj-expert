# 07 发行与渠道策略

## 0. 纪律先行

平台规则、分成政策、审核尺度、流量机制变化快。**具体政策必须检索确认并标注时间**，本文件只给判断框架。

## 1. 渠道清单与定位

| 渠道类型 | 作用 | 适合形态 | 主要局限 |
|---|---|---|---|
| 网络文学平台 | 长篇连载、付费阅读、分账 | 小说 | 新人曝光难、分成低 |
| 短剧平台/小程序 | 投流+付费解锁 | 短剧 | 投流成本高、回收周期敏感 |
| 视频平台 | 分账、会员、IP 孵化 | 短剧/动画/影视 | 审核严、排期不确定 |
| 内容社区 | 圈层发酵、二创 | 图文/短内容/设定 | 变现弱、需持续运营 |
| 社交平台（短视频/图文） | 获客与切片分发 | 切片、图文、角色内容 | 算法波动、易被搬运 |
| 漫画平台 | 连载+付费+出版 | 漫画/动态漫 | 更新成本高 |
| 音频平台 | 有声、广播剧 | 小说/音频剧 | 制作门槛、版权 |
| 自有站点/应用 | 私域沉淀、会员 | 全形态 | 需自建流量 |
| 线下渠道 | 书店、展会、快闪 | 出版物/周边 | 成本高、覆盖窄 |
| 商业合作渠道 | 品牌方、渠道商 | 联名/分销 | 议价权弱 |

## 2. 渠道评估九维

对每个候选渠道打 1–5 分：

| 维度 | 判断问题 |
|---|---|
| 用户匹配 | 该渠道的用户是否就是我们的核心/次级用户 |
| 形态适配 | 内容是否需要大幅改造才能适配 |
| 平台规则 | 分成、流量分配、推荐机制是否透明 |
| 审核要求 | 是否有题材/尺度/资质门槛 |
| 发行成本 | 上线成本、制作改造成本、保证金 |
| 获客能力 | 能否带来自然流量，还是完全依赖自投 |
| 变现能力 | 该渠道的付费习惯与结算周期 |
| 版权要求 | 是否要求独家、是否取得改编权 |
| 数据可得性 | 能否拿到后台数据用于复盘 |

单渠道出现"独家 + 数据不透明 + 分成偏低"三项叠加，视为高危。

## 3. 主辅渠道结构

**1 主 + 2 辅**，不超过三个，否则运营资源被摊薄。

| 角色 | 定义 | 判断标准 |
|---|---|---|
| 主渠道 | 主要收入或主要用户来源 | 用户匹配度最高 + 变现路径最短 |
| 辅渠道 A | 获客与传播 | 内容分发效率高、二创活跃 |
| 辅渠道 B | 长尾或沉淀 | 私域、音频、出版等长期资产 |

主渠道选择的常见错误：把"流量最大的平台"当主渠道，而忽略该平台用户是否付费、内容是否适配。

## 4. 内容适配改造

一稿多投通常失败。每个渠道需要**形态改造**，不是简单搬运：

| 渠道 | 改造要点 |
|---|---|
| 网文平台 | 章节切分、章末钩子、更新节奏、简介关键词 |
| 短剧 | 前 3 秒钩子、每 30 秒一个转折、竖屏构图 |
| 短视频切片 | 单点情绪、可独立成立、字幕与封面信息 |
| 漫画 | 分镜重排、信息密度下调、视觉节奏 |
| 音频 | 去掉视觉依赖、增加叙述性对白、音效补充 |
| 出版 | 结构重编、去网络化表达、校对与注释 |

改造工作量必须计入成本（通常占发行成本的 15–40%，标 E4）。

## 5. 发布节奏

| 阶段 | 目标 | 动作 | 判据 |
|---|---|---|---|
| 预热（D-14 ~ D-1） | 建立期待 | 角色卡、设定碎片、作者自述、预约 | 预约/关注增量 |
| 冷启（D1–D7） | 冲首轮推荐 | 集中更新、达人分发、评论区运营 | 首周完读/完播 |
| 爬坡（D8–D30） | 稳住数据曲线 | 稳定更新、话题运营、二创激励 | 追更率、回访率 |
| 稳定（M2–M6） | 形成习惯 | 固定节奏、社群、活动 | 周活跃、付费率 |
| 转化（节点） | 变现 | 付费点、周边预售、会员 | 转化率、客单 |
| 长线（M6+） | 品牌经营 | 跨形态、授权、线下 | 品牌搜索、合作数 |

节奏规划必须与产能对齐：承诺日更但产能不足，是最常见的自毁行为。

## 6. 发行风险清单

| 风险 | 表现 | 应对 |
|---|---|---|
| 独家条款 | 单一平台锁死，其他渠道无法动 | 谈期限与解约条件，保留改编权 |
| 分成不透明 | 后台数据与实际收入对不上 | 要求可核查数据、保留对账权 |
| 审核下架 | 题材/尺度触发 | 预备删改方案与备用渠道 |
| 盗版与搬运 | 内容被洗稿、切片被盗 | 登记存证、平台投诉机制、加水印 |
| 数据黑箱 | 无法复盘 | 自建数据记录（时间/曝光/转化） |
| 排期不确定 | 上线延后错过窗口 | 备用渠道与内容储备 |
| 平台政策变动 | 分账规则调整 | 提前分散，不押单一平台 |

## 7. 输出格式

```
1. 渠道清单 + 九维评分表
2. 主辅渠道结构（1 主 2 辅）+ 理由 + 放弃的渠道及原因
3. 内容适配改造方案（每渠道要点与工作量）
4. 发布节奏表（阶段/时间/动作/判据）
5. 发行成本估算（区间 + 口径）
6. 风险与应对（含独家与版权条款关注点）
7. 数据记录方案（自建指标口径）
```
