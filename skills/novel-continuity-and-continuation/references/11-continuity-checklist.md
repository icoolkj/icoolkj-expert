# 11｜连续性八维度审查清单

## 使用方式

连续性审查模式按以下八个维度逐项检查。每个维度先调取对应记忆档案/参考资料，再核对正文，发现问题记录到审查报告（格式见 references/13）。

## 维度一：人物连续性 → references/04

- [ ] 出场人物的外貌、性格、能力与档案一致
- [ ] 人物状态（伤势、情绪、装备、资源）从上一状态合理延续
- [ ] 人物行为符合其动机和性格逻辑
- [ ] 人物称呼、名字、头衔前后一致
- [ ] 配角没有张冠李戴
- [ ] 长期离场人物重新登场时状态合理

## 维度二：人物认知连续性 → references/09

- [ ] 每个角色的知情内容与认知档案一致
- [ ] 信息获取有合理途径，无「无径知晓」
- [ ] 角色反应与其信息量匹配
- [ ] 有限视角叙述未泄露视角外信息
- [ ] 保密与揭露的时机符合悬念规划

## 维度三：时间连续性 → references/05

- [ ] 事件时间单调递增，无时间倒流
- [ ] 时间推进有正文交代
- [ ] 行程耗时与距离/交通设定匹配
- [ ] 恢复周期（伤病、修炼）时间充足
- [ ] 年龄随时间正确变化
- [ ] 多线叙事时间可对齐

## 维度四：空间连续性 → references/04、05、07

- [ ] 人物位置迁移有过程或交代
- [ ] 地点描写与既有设定一致（布局、距离、环境）
- [ ] 季节、天气、昼夜与时间线一致
- [ ] 场景内物品陈设前后一致

## 维度五：事件连续性 → references/02

- [ ] 未与已发生事件矛盾
- [ ] 引用前文事件时细节与原文一致
- [ ] 事件后果得到延续（重大事件的余波未凭空消失）
- [ ] 未重复已完成剧情（同一冲突被原样再解决一遍）
- [ ] 因果链完整：新情节有起因，旧线索有着落

## 维度六：物品连续性 → references/02、04

- [ ] 重要物品归属与最新记录一致
- [ ] 已损毁/消耗/交出的物品未复活
- [ ] 物品功能与设定一致
- [ ] 物品获得途径可追溯

## 维度七：世界规则连续性 → references/07

- [ ] 未无解释地违反已确立的世界规则
- [ ] 能力使用遵守等级与代价设定
- [ ] 势力关系与最新状态一致
- [ ] 新设定不与旧设定冲突
- [ ] 契约、诅咒、承诺的效力持续兑现

## 维度八：伏笔连续性 → references/08

- [ ] 本章未与既有伏笔信息矛盾
- [ ] 未无意中提前揭穿伏笔答案
- [ ] 计划回收的伏笔已按计划回收且与铺设一致
- [ ] 新埋伏笔已登记台账
- [ ] 悬念密度未失衡

## 审查纪律

- 依据优先级：正文原文 > 用户确认的记忆档案 > 大纲 > AI 推断。
- 合理的人物成长、关系变化、经过确认的剧情调整不算错误。
- 拿不准的问题标「待核实」，不武断定性。
- 审查结果无论好坏都如实报告；无问题时明确输出「通过」。
