# 03 场次结构规范

场次是短剧的最小制作单元，也是标准化投入产出比最高的一层。

## 3.1 场次编号规则

| 规则 | 要求 |
| --- | --- |
| 基本形式 | `集号-场号`，如 `3-7` |
| 集号 | 两位补零：`第03集` 内场号为 `3-1` |
| 场号 | 不补零，从 1 起递增：`3-1 … 3-12` |
| 连续性 | 同一集内场号连续，不跳号 |
| 唯一性 | 全稿不得出现重复场号 |
| 新增场 | 插在场间时用 `3-4A`、`3-4B`，不打乱后续编号 |
| 删除场 | 保留空号并在清单注明"已删除"，或整体重排并在修改记录说明 |

原稿使用 `场1`、`#1`、`S01`、`第一场` 等写法时统一转换为默认格式；若用户规范另有要求，以用户为准，但全稿必须一致。

## 3.2 场景标题四要素

```
4-2 夜 外 城郊公路
 │   │  │   └── 地点（必填，原稿无则写"未指定"）
 │   │  └────── 内外景（内 / 外 / 内外）
 │   └───────── 时间（必填）
 └───────────── 场号
```

**不得为了填满四要素而编造。** 原稿缺时间时，写 `未指定` 或按上下文可推定值补全并记录依据；两者都做不到则留 `【待确认：时间】`。

## 3.3 时间词表

推荐使用单一时间粒度，避免混用：

| 类别 | 可用值 |
| --- | --- |
| 日间 | 日、晨、清晨、上午、中午、下午、黄昏、傍晚 |
| 夜间 | 夜、深夜、凌晨 |
| 相对 | 同日、次日、连续、稍后、片刻后 |
| 特殊 | 回忆、闪回、梦境、幻想、未来 |

- 同一项目建议收敛为 `日 / 夜 / 晨 / 黄昏 / 深夜` 五档，写细粒度会让制片排期困难。
- `连续` 表示与上一场时间连续，是重要制作信息，原稿若有必须保留。
- `回忆/闪回` 属于叙事层，应同时配 `【闪回】` 标注（见 `08-cinematic-notation.md`）。

## 3.4 内外景判定

| 值 | 判定 | 边界情形 |
| --- | --- | --- |
| 内 | 有顶、有墙、封闭空间 | 车内算内景（除非明确车外拍摄） |
| 外 | 露天、街道、田野 | 天幕、帐篷内部按内景 |
| 内外 | 同一场跨越内外，如从门口走进屋内 | 能拆成两场时优先拆场 |

内外景直接影响灯光、录音、天气备案，原稿缺失时应提示补充。

## 3.5 地点命名

- 同一地点全稿使用**唯一名称**：`苏瑾的公寓` 不得同时写作 `苏瑾公寓`、`苏家`、`公寓`。
- 名称结构建议：`归属/特征 + 空间类型`，如 `陈默的修车行`、`医院走廊`、`地下车库B2`。
- 地点首次出现可在动作行补充空间描述，后续场次不重复描述。
- 同一物理空间的不同区域视为不同地点：`苏瑾的公寓·客厅` 与 `苏瑾的公寓·卧室`，用 `·` 连接。
- 不得在场景标题里写剧情（如 `苏瑾发现真相的房间`），剧情属于动作行。

## 3.6 人物行

格式：`人物：A、B、C`

规则：

- 用顿号分隔，不用逗号、斜杠、空格。
- 只列**本场有动作或有台词**的人物；纯背景群演写 `群演若干`。
- 使用标准名（见 `04-character-standardization.md`），不用称谓。
- 未具名人物沿用原稿写法：`黑衣人`、`护士甲`。
- 人物行缺失时：能从场中动作/对白推定则补全并记录；否则留 `人物：【待确认】`。

## 3.7 场次内容最小完整性

一场至少要有：场次标题 + （人物行 或 可识别的出场人物）+ 至少一个动作或一句对白。

以下情形视为**空场**，必须报告：

- 只有场次标题，正文空白。
- 只有 `【切至：…】` 而无任何内容。
- 只有一句"（此处待补）"类占位。

空场处理：不删除、不补写，报告中列为 P0/P1，交用户决定。

## 3.8 场间衔接

- 上一场结尾与下一场开头应有明确的空间或时间跳转依据。
- 使用 `【切至：地点】` 表示同时间异地切换；使用 `【转场：…】` 表示时间跳跃。
- 上一场在 A 地结束，下一场在 B 地开始但无任何过渡说明时，属 P1 连续性问题（见 `14-continuity-check.md`）。
- 不得用"与此同时""镜头一转"等叙述性文字充当转场，应转为标准标注。

## 3.9 场次清单字段

| 字段 | 说明 |
| --- | --- |
| 场号 | `4-2` |
| 时间 | 标准化后的值 |
| 内外 | 内/外/内外 |
| 地点 | 标准化地点名 |
| 人物 | 本场人物标准名列表 |
| 对白数 | 台词条数（不含标注） |
| 页码/行号 | 便于定位 |
| 备注 | 空场、待确认、疑似重复等 |

## 3.10 常见场次问题与处理

| 问题 | 等级 | 处理 |
| --- | --- | --- |
| 场号重复 | P0 | 按出现顺序重排或加字母后缀，记录修改 |
| 场号跳号 | P2 | 补号或注明缺号原因 |
| 缺时间/内外景 | P1 | 可推定则补，否则标 `【待确认】` |
| 地点名不统一 | P2 | 统一为一个名称，记入修改记录 |
| 一场内含两个地点 | P1 | 报告并建议拆场，不擅自拆 |
| 人物行与场中人物不符 | P1 | 以场中实际出场为准修正人物行并记录 |
| 空场 | P0 | 报告，不补写 |
| 场次过长（超 3 页） | P3 | 建议按节拍拆分，不擅自拆 |
