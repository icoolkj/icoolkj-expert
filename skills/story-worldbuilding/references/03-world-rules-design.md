# 03 世界规则设计

## 1. 规则卡：唯一标准格式

每条关键规则必须用同一张卡记录，缺字段即为未完成。

```
RULE-000 规则名称
──────────────────────────────
内容      用一句话说清机制（不得使用"神秘""强大"等模糊词）
生效条件  什么情况下这条规则起作用
使用限制  谁不能用、什么时候不能用、用几次
资源消耗  每次使用付出什么（体力/寿命/材料/情感/记忆）
失败风险  失败会发生什么（必须有，且不可逆的部分）
反制方式  如何被打断、抵消、免疫、欺骗
能力范围  上限在哪，明确"做不到什么"
成长路径  变强需要付出什么，台阶有几级
关联实体  影响的人物/势力/地点/事件
设定状态  [已确认] 等
──────────────────────────────
```

**核心判据**：如果一条规则无法被反派利用，它就不是规则，只是主角的外挂。

## 2. 力量体系设计（修炼 / 异能 / 魔法）

### 2.1 五要素

| 要素 | 设计要求 | 反面案例 |
|---|---|---|
| 来源 | 力量从哪来（血脉/灵气/契约/科技/信仰） | 凭空而来 |
| 门槛 | 谁能获得，如何获得 | 人人可学但只有主角学会 |
| 代价 | 每次使用与每次突破的付出 | 只涨不付 |
| 上限 | 世界最强能到什么程度 | 无限升级无天花板 |
| 稀缺性 | 为什么强者少 | 强者遍地却仍被压制 |

### 2.2 层级设计的三条纪律

1. **层级数量 4–9 级为宜**。低于 4 级缺乏成长空间，高于 9 级读者记不住。
2. **每级必须有"质变"而非"量变"**。若第 5 级只是"比第 4 级强三倍"，读者会失去兴趣。质变指：新增一种能力维度、或解除一种旧限制。
3. **跨级战斗必须有明确条件**。写清"低阶胜高阶"的三种合法方式（阵法、道具、偷袭、环境、代价换爆发），否则跨级战胜会直接摧毁体系可信度。

### 2.3 突破机制

| 模式 | 说明 | 叙事效果 |
|---|---|---|
| 资源堆叠 | 靠材料/丹药累积 | 稳定，适合日常流 |
| 顿悟 | 靠认知突破 | 高潮点，但不可频繁 |
| 生死历练 | 靠极限压力 | 制造险境 |
| 剥夺替代 | 夺取他人 | 制造道德冲突与反派动机 |

**纪律**：突破必须有失败样本。世界里必须存在"突破失败者"，否则升级毫无风险。

### 2.4 力量与社会结构绑定

力量体系必须解释社会：

- 强者如何被制度约束（否则没有政治，只有丛林）。
- 力量是否可继承（决定阶层是否固化）。
- 力量是否可交易（决定是否形成市场）。
- 力量是否可被普通人对抗（决定平民的地位）。

四条全不写，力量体系就与文明脱钩，世界会分裂成"修炼文"和"背景板"两套互不相干的系统。

## 3. 科技体系设计（科幻 / 赛博 / 末世遗存）

### 3.1 技术树原则

技术必须成链，不能点状存在。

```
能源 → 动力 → 制造 → 交通 → 通讯 → 医疗 → 武器 → 信息
```

任一环节缺失，下游技术必须给出替代方案或说明为何不存在。

### 3.2 技术的社会成本

每项关键技术必须写清：

| 维度 | 问题 |
|---|---|
| 谁拥有 | 垄断还是普及（决定权力结构） |
| 谁维护 | 有无技术阶层（决定新阶级） |
| 谁被替代 | 哪些人失业（决定社会矛盾） |
| 副作用 | 污染、依赖、伦理争议（决定故事议题） |

**末世题材特殊要求**：旧技术必须"降级可用"。写清哪一级技术还能运转、哪一级彻底失效、失效原因是什么（无电网、无芯片厂、无卫星）。这决定幸存者能用到什么程度，是最容易出戏的地方。

## 4. 灾变与感染机制（末世核心）

### 4.1 灾变档案必填项

| 字段 | 内容 |
|---|---|
| 灾变类型 | 病毒/辐射/天灾/异界入侵/规则改写 |
| 起始时间与地点 | 精确到日，决定所有后续时间线 |
| 传播/扩散方式 | 空气/体液/辐射区/主动猎杀 |
| 感染阶段 | 潜伏 → 发病 → 转化，各阶段时长与表现 |
| 转化后行为 | 是否有组织性、是否保留记忆、是否有目的 |
| 免疫条件 | 谁能免疫，为什么 |
| 可控性 | 能否治愈、抑制、驯化、利用 |
| 变异速度 | 是否进化，进化驱动力是什么 |

### 4.2 感染阶段表（模板）

| 阶段 | 时长 | 外观 | 能力 | 传染性 | 是否保留意识 |
|---|---|---|---|---|---|
| 潜伏 | | 无异常 | 无 | 高 | 是 |
| 初期 | | | | | |
| 中期 | | | | | |
| 转化 | | | | | |
| 变异 | | | | | |

**纪律**：必须有"潜伏期可传染"这类隐藏条款，否则无法产生"最亲近的人变成威胁"的经典冲突。

### 4.3 末世资源与秩序

末世世界的三根支柱：

| 支柱 | 必须写清 |
|---|---|
| 生存资源 | 水、食物、药品、燃料、弹药各能撑多久，补给从哪来 |
| 安全边界 | 城墙、巡逻、警报、隔离制度 |
| 权力来源 | 谁分配资源，凭什么（武力/知识/旧权威/宗教） |

**高频漏洞**：食物无限、药品随取、子弹打不完、燃料永远有。任何一项无限制，紧张感立即消失。

## 5. 资源体系设计

### 5.1 资源三层

| 层 | 例子 | 作用 |
|---|---|---|
| 生存资源 | 水、粮、药、燃料 | 制造日常压力 |
| 战略资源 | 矿、灵脉、能源、数据 | 制造势力争夺 |
| 象征资源 | 圣物、血脉、名分、技术专利 | 制造合法性与认同冲突 |

### 5.2 守恒检查

| 检查项 | 问题 |
|---|---|
| 产出 | 这种资源每年能产多少，谁在生产 |
| 流向 | 谁消耗最多，为什么 |
| 稀缺度 | 稀缺到什么程度（人人可得/贵族可得/传说级） |
| 替代品 | 有没有替代方案，成本差多少 |
| 剧情用途 | 主角需要它做什么，反派为什么要抢 |

**纪律**：主角获得的每一份稀有资源，都要在设定中扣减一次；不能凭空再生。

## 6. 规则间的一致性法则

### 三条硬法则

1. **同等条件同等结果**。同一规则对不同人物必须一致生效，除非有明写的例外条款。
2. **例外必须付费**。任何"只有主角可以"的情况，必须写清原因与代价。
3. **新规则不得否定旧规则**。新增规则只能扩展适用范围，不能使旧规则失效；确需否定，走版本变更（见 `08-consistency-and-version-control.md`）。

### 冲突检测三问

- 把这条规则交给反派，反派能不能用它击败主角？不能 → 规则太弱或太偏。
- 把所有规则交给一个理性人，他会怎么最优利用？想不出 → 规则未写透。
- 两个规则同时生效时，谁优先？未定义 → 迟早出bug。

## 7. 规则输出清单

交付时至少包含：

1. 核心规则卡（3–8 条，按重要性排序）。
2. 力量/科技体系的层级表。
3. 代价与风险一览（必须能列成表）。
4. 反制手段清单（每条规则至少 1 种）。
5. 规则漏洞与待验证事项（主动暴露，不藏）。
6. 规则与社会结构的对应关系说明。
