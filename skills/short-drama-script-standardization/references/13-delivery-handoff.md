# 13 制作交接说明

交接说明面向的不是编剧，而是导演、制片、统筹、后期。目标：让非编剧岗位在 5 分钟内掌握"要拍什么、缺什么、注意什么"。

## 13.1 必含内容

| 模块 | 内容 |
| --- | --- |
| 项目概况 | 项目名、集数、场次总数、覆盖范围、版本号 |
| 场景统计 | 按内外景、按出现次数排序的主场景 |
| 人物统计 | 主要角色、出场场次、群体角色需求 |
| 特殊需求 | 雨/火/车/动物/儿童/群众/特效/道具 |
| 时间跨度 | 故事内时间线（几天/几年、有无跨季） |
| 缺失与待确认 | 影响制作的信息缺口 |
| 风险提示 | 拍摄、安全、合规、版权提示（仅提示） |
| 使用说明 | 标注体系说明（△、【】、OS/VO 定义） |

## 13.5 时间线摘要

```
故事时间跨度：约 3 个月
关键时间节点：第1集 当下 → 第3集 闪回（三年前） → 第6集 次月 → 第12集 三个月后
```

时间线不清时，明确写"时间线待确认，见 Q07"。

## 13.7 风险提示写法

```
R-01 | 4-2 | 夜间公路实拍含车辆行驶 | 建议核实拍摄许可与安全保障
R-02 | 8-3 | 出现真实品牌门店 | 建议核实商标使用
R-03 | 11-2 | 医疗操作细节 | 建议专业顾问复核
```

只提示，不下结论，不替代法务与制片判断。

## 13.8 标注体系说明

必须向制作方交代：

```
动作行：△ 开头
标注：【音效：】【字幕：】【切至：】【转场：】
画外音：人物（OS）：= 剧中人在画面外说话
旁白：旁白（VO）：= 叙述者
电话：人物（电话）：
待确认：本稿保留 9 处【待确认：…】，见清单
```

不同项目标记可能不同，交接时务必写明，避免误读。

## 13.9 交接声明

固定写法：

> 本稿为格式标准化交付稿，已完成结构、场次、人物、对白、动作、标注、格式的规范化处理，并完成对应质量检查。本稿不代表已通过导演审查、拍摄可行性评估、平台审核或商业评估。剧本内容版权与创作责任归原权利人。

## 13.10 交接常见失误

| 失误 | 后果 |
| --- | --- |
| 只给剧本不给清单 | 制片要自己数场次 |
| 特殊需求未列 | 到场才发现缺道具/许可 |
| 待确认项混在正文没汇总 | 拍摄当天才发现 |
| 没说明标注体系 | 演员误读 OS/VO |
| 声称"可直接开机" | 越权承诺 |
