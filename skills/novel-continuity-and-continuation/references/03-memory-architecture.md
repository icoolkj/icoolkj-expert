# 03｜五层记忆档案结构

## 总原则

五层记忆各有职责，不能混为一谈。稳定性从 L1 到 L5 递减，更新频率从 L1 到 L5 递增。档案以文件形式保存在小说项目目录下（建议 `novel-memory/` 目录），便于跨会话恢复。

## L1 作品核心记忆（最稳定，很少修改）

文件建议：`L1-core.md`

记录：

- 小说题材、类型、基调
- 小说主题和核心立意
- 核心世界观（一句话概括 + 指向世界观资料）
- 叙事人称（第一/第三人称）
- 叙事视角（单视角/多视角/全知）
- 文风和语言特点（句式偏好、用词风格、幽默感、留白习惯）
- 核心创作约束（如：无超自然、不写阴暗结局、每章字数区间）

修改条件：仅当用户明确要求调整基准时修改，并记录修改原因和日期。

## L2 人物与关系记忆

文件建议：`L2-characters.md`（每人一节）+ `L2-relationships.md`

每名主要人物记录：

- 身份背景、外貌特征、性格特点
- 目标与核心动机
- 重要经历（带章节来源）
- 能力 / 技能 / 资源
- 当前状态（位置、伤势、情绪、装备——每次续写后更新）
- 掌握的信息 / 不知道的信息（认知边界）
- 人物关系表：对象、当前性质、变化历史

详细追踪规则见 references/04。

## L3 故事事实记忆

文件建议：按卷或按每 10 章分文件，如 `L3-facts-ch01-10.md`

- 采用 references/02 定义的事实条目格式。
- 每条事实必须带章节来源；重要事实带原文短句。
- 只记录已发生事实和待核实事实；计划和构想存入 L4。

## L4 动态剧情记忆

文件建议：`L4-plot.md`

记录：

- 当前主线进度（主线目标、已完成节点、下一节点）
- 当前冲突（表层冲突 + 深层冲突）
- 未解决的问题清单
- 伏笔台账（指向伏笔档案，见 references/08）
- 已确认的后续计划（用户确认过的剧情走向）
- 尚未确认的剧情建议（AI 提出、用户未拍板的想法，禁止当作计划使用）

## L5 章节上下文记忆（最动态，每章更新）

文件建议：`L5-context.md`，只保留最近 2-3 章的详细上下文 + 一份滚动更新的「当前状态快照」。

记录：

- 最近章节摘要（每章 3-5 句）
- 上一章结尾原文（续写衔接的直接依据）
- 当前场景、当前故事时间
- 当前在场人物及其即时状态
- 当前正在进行的冲突
- 下一章承接点（悬念、待回应的话、未完成的动作）

## 记忆文件初始化流程

首次为一个小说项目建档时：

1. 建立目录和五个层级的文件骨架。
2. 从正文提取内容填充 L1-L3。
3. 与用户核对 L1 核心设定和 L2 主要人物档案，确认无误。
4. 生成 L4、L5。
5. 之后每次续写按 references/10 的规则更新。

## 使用纪律

- 续写前必读：L5（上下文）+ L4（剧情进度）+ 相关人物的 L2 条目。
- 续写后必更：L5、L2 状态字段、L3 新增事实、L4 进度与伏笔。
- 记忆与正文冲突时，以正文为准，并修正记忆档案。
