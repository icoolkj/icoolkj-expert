# 10 商务合作与资源整合

## 0. 纪律

不得虚构合作意向、客户资源、已达成关系或过往案例。方案中所有合作方一律标注状态：`[已接触]` / `[目标]` / `[假设]`。

## 1. 合作对象画像

每类对象写清五件事：

| 项 | 内容 |
|---|---|
| 他是谁 | 品类、体量、决策链 |
| 他缺什么 | 内容、流量、话题、年轻用户、场景 |
| 他能给什么 | 预算、渠道、生产、背书 |
| 他为什么选你 | 一句话价值（不是"我们很优秀"） |
| 他为什么不选你 | 反对理由与化解方式 |

## 2. 价值交换表

合作成立的前提是**双向价值**，单向索取必然失败。

| 我方提供 | 对方提供 | 归属与成本 |
|---|---|---|
| 内容与形象使用权 | 预算 / 保底 | |
| 受众与传播 | 渠道与曝光 | |
| 创意与制作 | 生产与供应链 | |
| 数据与案例 | 品牌背书 | |
| 独家权益 | 长期订单 | |

## 3. 合作模式

| 模式 | 说明 | 适合阶段 | 关键条款 |
|---|---|---|---|
| 内容植入 | 品牌进入内容 | P2+ | 植入深度、是否影响剧情、修改权 |
| 联合营销 | 双方共同推广 | P2+ | 费用分摊、素材归属、数据共享 |
| 定制内容 | 为品牌定制短内容 | P3+ | 交付标准、修改次数、署名 |
| 渠道分销 | 商品进入对方渠道 | P3+ | 供货价、账期、退换 |
| 联名商品 | 共同开发产品 | P3+ | 设计审核、分成、库存 |
| 联合开发 | 共同做新内容形态 | P3+ | 投资比例、版权归属、决策机制 |
| 活动/线下 | 展会、快闪、主题店 | P4 | 场地、安全、票务分成 |

## 4. 商务提案结构

八页逻辑，一页一个结论：

1. **一句话**：我们是谁 + 能为对方带来什么。
2. **机会**：对方所在品类的一个真实问题（有依据）。
3. **我们**：IP 定位、用户结构、数据（真实，标注口径）。
4. **为什么是我们**：差异化与匹配度（调性、人群、场景）。
5. **合作方式**：2–3 个方案，从轻到重。
6. **权益清单**：对方得到什么，具体到数量与位置。
7. **执行与排期**：时间表、责任分工、审核节点。
8. **报价与下一步**：价格区间 + 明确的下一步动作。

## 5. 权益清单与报价逻辑

权益要可计量：露出次数、素材数量、渠道位置、时长、独家期限、二次使用范围。

报价逻辑三选一，并说明依据：

- 成本加成（有制作成本时）。
- 对标同类案例（须有公开依据，E2）。
- 价值分成（按对方预期收益分成，须约定核算方式）。

不得凭空给出"行业标准价"。

## 6. 谈判准备

| 项 | 内容 |
|---|---|
| 目标 | 理想结果（量化） |
| 底线 | 不可让的核心项（价格下限、权利范围、品牌审核权） |
| 让步梯度 | 可让的 3 档，每档换回什么 |
| BATNA | 谈不成怎么办（备用合作方/自营方案） |
| 对方痛点 | 3 条，对应话术 |
| 可能反对意见 | 5 条 + 回应 |
| 必须当场确认 | 决策人、预算、时间表 |

## 7. 尽职调查清单

| 项 | 核查内容 |
|---|---|
| 主体资格 | 营业执照、经营范围、存续状态 |
| 履约能力 | 过往案例、产能、供应稳定性 |
| 财务健康 | 账期历史、是否有拖欠记录 |
| 品牌风险 | 舆情、行政处罚、产品质量记录 |
| 权利链条 | 对方是否有权使用其提供的素材 |
| 合同要点 | 违约责任、终止条件、争议解决 |

## 8. 常见问题

| 问题 | 表现 | 处理 |
|---|---|---|
| 只谈曝光不谈钱 | "给你曝光机会" | 折算曝光为可计量权益，或拒绝 |
| 无限修改 | 交付标准不清 | 约定修改轮次 |
| 账期过长 | 90–180 天 | 分期收款或提高报价 |
| 权益超范围 | 一次授权多场景使用 | 场景清单化 |
| 决策链不清 | 对接人无权限 | 先确认决策人再出方案 |
| 口头承诺 | 无书面记录 | 会议纪要 + 邮件确认 |

## 9. 输出格式

```
1. 合作目标（一句话，量化）
2. 合作对象画像（2–3 类，含状态标注）
3. 价值交换表
4. 合作模式建议（从轻到重 2–3 个）
5. 商务提案（八页结构）
6. 权益清单 + 报价区间（含定价依据）
7. 谈判要点（目标/底线/梯度/BATNA/反对意见）
8. 尽调清单
9. 待确认事项
```
