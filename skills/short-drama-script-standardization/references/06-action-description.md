# 06 动作与表演描述标准化

动作行是剧本里最容易被"文学化"污染的部分。本文件给出可执行的判定与改写原则。

## 6.1 动作行格式

```
△ 苏瑾站在窗边，透过窗帘观察楼下。
```

规则：

- 统一以 `△ ` 开头（全角三角 + 半角空格）；不要混用 `▲`、`-`、`*`、`[动作]`。
- 一句一动作节拍，句末用句号。
- 现在时、主动语态、第三人称。
- 不写"他/她"开头时省略主语可接受（连续动作段内），但**首次动作必须出现人名**。
- 段内不换行写多条不相干动作。

## 6.2 可执行性四要素

一条动作合格，需要能回答：

| 要素 | 问题 | 缺失后果 |
| --- | --- | --- |
| 主体 | 谁做的 | 演员无法站位 |
| 动作 | 做什么 | 无法表演 |
| 对象 | 对谁/对什么 | 道具与配合不明 |
| 结果/指向 | 造成什么可见变化 | 剪辑无落点 |

判定示例：

- `△ 她很不安。` → 无可见动作，抽象。
- `△ 苏瑾不安地站着。` → 有主体但无可拍动作。
- `△ 苏瑾反复捏着手机边缘，指节发白。` → 合格。

## 6.3 抽象描述的处理：建议不替换

| 原稿 | 处理 |
| --- | --- |
| `△ 苏瑾内心翻江倒海。` | 保留原文；报告 B 类，建议栏给 2–3 个可视化选项 |
| `△ 气氛凝固了。` | 保留；建议改为可拍的环境或人物反应 |
| `△ 时间仿佛静止。` | 保留；建议用定格、静音、慢镜等标注（若项目允许） |

建议栏写法：

```
B-03 | 2-3 △ 第2行 | 原文："苏瑾内心翻江倒海" | 建议 A：她盯着手机屏幕，拇指悬在拨号键上不动。建议 B：她把杯子放回桌面，水晃出来一圈。 | 未采用，待确认
```

必须明确写"未采用"，避免与已改内容混淆。

## 6.4 可用于镜头的边界

可以写：可见动作、可听声音、可触变化、环境状态、人物位置关系。

不应写：

| 类型 | 示例 | 处理 |
| --- | --- | --- |
| 景别机位 | 特写、近景、全景、过肩 | 剥离，若用户需要则另建分镜文件 |
| 运镜 | 推、拉、摇、移、升降 | 同上 |
| 剪辑指令 | 快切、跳切、蒙太奇节奏 | 只允许用标准标注 `【蒙太奇】`，不写具体剪辑节奏 |
| 表演指导细则 | "眼神要有三层变化" | 移入建议，不进正文 |
| AI 生成 Prompt | "cinematic lighting, 35mm, shallow depth of field" | 一律剥离，不进标准剧本 |
| 音乐情绪 | "悲伤的钢琴曲渐入" | 可转为 `【音乐：钢琴，低沉】`（若项目规范允许），否则列入建议 |

## 6.5 空间与方位

- 方位词统一使用：画面左/右、门口、窗边、桌旁、楼梯口；避免"这边""那边"。
- 人物位置变化必须有动作支撑（不能一场之内人物凭空换位）。
- 同一场内的空间描述首次交代清楚，后续不重复。
- 方位与场景标题地点必须自洽：场景写"客厅"，动作不得出现"她从卧室床上下来的"而未交代进入卧室。

## 6.6 动作与对白的节奏

短剧单场常见结构：

```
环境/动作起手 → 一句关键台词 → 反应动作 → 台词推进 → 动作收束（钩子）
```

标准化时不改节奏，但可以指出：

- 连续 6 条以上对白无任何动作行（P3，建议插入反应镜头位）。
- 连续 5 行以上纯动作无台词（P3，提示是否遗漏台词）。
- 一场结尾无收束动作或钩子（P2，叙事节奏问题，只报告）。

## 6.7 危险与合规提示

动作涉及以下内容时，在报告中提示复核（不作商业或合规判定）：

- 未成年人参与的危险动作
- 驾驶、爆破、明火、高空、水下
- 吸烟、饮酒、赌博、暴力细节
- 真实品牌、真实机构、真实地址
- 医疗、法律、金融等专业操作细节

提示写法：`R-05 | 4-2 | 含明火特写 | 建议核实拍摄安全与平台规范`。

## 6.8 动作行常见问题清单

| 问题 | 等级 |
| --- | --- |
| 无主体（不知谁做） | P1 |
| 纯心理/抽象，无可拍动作 | P2（B 类建议） |
| 混入景别/运镜/剪辑指令 | P1（须剥离） |
| 混入 AI Prompt 或英文技术参数 | P1（须剥离） |
| 动作与场景空间矛盾 | P1 |
| 标记符号不统一（△/▲/- 混用） | P2 |
| 一句里塞多个不相干动作 | P2 |
| 时态混乱（"她已经走了"与当下动作混写） | P2 |
| 动作泄露后文信息 | P1 |

## 6.9 改写示例（仅作建议格式示范）

原文：

```
△ 苏瑾心里一沉，感觉事情不对。
```

建议（B 类，不自动替换）：

```
△ 苏瑾的手指停在半空，慢慢收回，看向门口。
```

原则：把"内在判断"换成"可见停顿 + 视线转移"，不新增剧情信息，不替人物做决定。
