# 04｜角色表情设计

## 1. 标准表情集

| 编号后缀 | 表情 | 强度梯度 | 关键肌肉 |
|----------|------|----------|----------|
| -E01 | 中性 | 基准 | 全面放松，眼睑自然 |
| -E02 | 微笑 | 轻 / 中 / 强 | 口角提肌、眼轮匝肌 |
| -E03 | 愤怒 | 压抑 / 爆发 | 皱眉肌、鼻唇沟加深 |
| -E04 | 悲伤 | 隐忍 / 崩溃 | 眉内侧上提、下唇外翻 |
| -E05 | 恐惧 | 警觉 / 惊恐 | 额肌上提、眼白露出 |
| -E06 | 惊讶 | 微 / 大 | 眉上提、口张开 |
| -E07 | 坚定 | 冷 / 热 | 下颌收紧、目光定焦 |
| -E08 | 疲惫 | 生理 / 心理 | 上睑下垂、口周松弛 |
| -E09 | 警惕 | 侧目 / 直视 | 眉心微收、头部偏转 |
| -E10 | 复杂表情 | 苦笑 / 强忍 / 释然 | 两组反向肌肉同时激活 |

P0 角色做 9–10 个；P1 做 E01/E02/E03/E04/E07 五个；P2 做 E01 + 一个标志性表情。

## 2. 表情设计要点

### 2.1 身份锚定
每个表情 Prompt 必须复用基础档案中的三个识别特征，否则每次生成都是"另一个人在做这个表情"。

### 2.2 强度分级
同一情绪必须给强度值，否则跨镜头表演无法衔接。建议用「轻 / 中 / 强」或 1–5 级，并写明可见变化：
```
愤怒-中：眉心纵纹出现，鼻翼张开，口角下压约 3mm，颈部胸锁乳突肌微起
```

### 2.3 眼睛优先
观众读表情先读眼。写 Prompt 时先描述眼周，再描述嘴。

### 2.4 与角色性格匹配
同一情绪不同角色的表达方式不同：克制型角色愤怒时只有下颌收紧，外放型角色会整脸变形。写「角色专属表情逻辑」，不要用通用表情库。

## 3. 表情资产规格

- 画幅：正脸方图或 3:4，面部占画面 60–70%。
- 光位：与三视图同一柔光，确保可比对。
- 角度：正面 + 45°（关键表情加侧面）。
- 背景：中性。
- 分辨率：面部细节可辨（建议长边 ≥ 1024）。

## 4. 表情 Prompt 结构

```
[基础身份描述（复用）] + [表情：肌肉层面] + [强度] + [视线方向] + [头部角度] + [光位] + [背景]
```

示例：
```
same woman as reference: 28-year-old East Asian female, narrow double eyelids,
left eyebrow tail with 1.5cm scar, sharp jawline, straight black hair to collarbone.
Expression: suppressed anger — inner brows pulled down and together, nasolabial
folds deepened, lips pressed thin with corners slightly down, eyes fixed forward,
chin slightly tucked. Intensity 3/5. Frontal view, eye-level, soft frontal light,
neutral gray background, no makeup change.
```

## 5. 表情与镜头的关系

- 特写镜头优先使用表情资产作为首帧参考。
- 中景以下表情强度需提升一级，否则画面读不到情绪。
- 连续镜头注意表情过渡方向（同一场景内不要从 E06 直接跳 E01）。

## 6. 验收标准

- 换到任意角度仍能读出同一情绪。
- 同一角色的 E01–E10 面部身份一致（可用并排比对）。
- 表情不依赖夸张妆造或光线才能成立。
- 强度描述可被另一名制作者复现。
