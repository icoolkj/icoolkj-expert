> 无集标题时不写标题部分，不得自拟。原稿没有的信息不得补写，改为 `【待确认：…】`。

## 填写检查

- [ ] 集标记为 `第NN集`，两位补零
- [ ] 场号为 `集-场`，集内连续
- [ ] 场景标题四要素齐全（缺失写 `【待确认：…】`）
- [ ] 人物行使用标准名，顿号分隔
- [ ] 动作行以 `△ ` 开头
- [ ] 对白冒号全角、冒号后换行
- [ ] 标注为 `【类型：内容】`，独立成行
- [ ] 成对标注（闪回/蒙太奇）开闭一致
- [ ] 无分镜、运镜、Prompt、批注
