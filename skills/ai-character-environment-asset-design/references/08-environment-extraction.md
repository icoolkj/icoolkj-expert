# 08｜场景资产提取与分类

## 1. 场景提取来源

从剧本、分镜、场次表中提取，按以下线索识别：
- 场次标题（"内景·法医中心·日"）。
- 动作描述中的空间信息（"他推门进去""绕过柜台"）。
- 对话中的空间指代（"楼上""对面楼"）。
- 重复出现的空间（同一地点多场使用 → 高优先级）。

## 2. 场景分类

| 维度 | 分类 |
|------|------|
| 内外 | 室内 / 室外 / 半开放（走廊、天井、车棚） |
| 功能 | 家宅、职场、公共、交通、荒野、幻想空间 |
| 叙事角色 | 主舞台 / 过场 / 对立空间 / 秘密空间 / 转化空间 |
| 结构 | 单间 / 多房间 / 多层 / 开放街区 |
| 是否可复用 | 一次 / 多场 / 贯穿全剧 |

## 3. 场景优先级

| 等级 | 判定 | 制作深度 |
|------|------|----------|
| P0 | 贯穿多集、承载主要动作 | 平面布局 + 主视觉 + 反向 + 侧向 + 俯视 + 关键区域特写 + 昼夜/天气状态 |
| P1 | 出现 2–5 场 | 主视觉 + 反打视角 + 一种光影状态 |
| P2 | 一次性过场 | 单主视觉 + 材质光位说明 |
| P3 | 背景 / 氛围空镜 | 类型描述 + 批量 Prompt 模板 |

## 4. 场景清单表

```
场景编号：ENV-003
场景名：法医中心·解剖室
类型：室内 / 职场 / 主舞台
出现场次：SHOT-006, 009, 012, 018, 024
优先级：P0
关联角色：CHAR-001, CHAR-004
关联道具：PROP-007（解剖刀组）, PROP-011（记录板）
功能：主角职业身份的空间外化；两次关键情绪爆发发生地
```

## 5. 提取时的判断要点

1. **合并同类**：剧本里"某咖啡馆"和"某餐厅"若结构相似、功能相同，可合并为一个基础场景 + 状态变体，降低制作量。
2. **拆分复合空间**：同一地点的"客厅"和"卧室"若都有主要动作，拆为两个独立场景资产（空间连通性在文档中说明）。
3. **识别隐形场景**：剧本未写但分镜需要（如"她走出门"需要一个门外空间）——主动补入清单并标注【设计建议】。
4. **标注空间逻辑**：同一栋楼内的多个场景需共享建筑逻辑（层高、窗位、走廊方向），否则剪辑后空间感崩塌。

## 6. 输出

1. 场景清单（编号、名称、优先级、场次、关联角色与道具）。
2. 场景关系图（同一空间群建筑的相对位置和连通关系，可用文字描述或简单示意）。
3. 场景缺口清单（剧本未提供但制作需要的空间）。
