# 10 严重程度判定与误判防护

## 1. 定级的唯一标准：影响

定级不看"读起来别不别扭"，只看**这个问题破坏了什么**。

| 等级 | 破坏对象 | 判定问句 |
|---|---|---|
| P0 | 故事核心成立条件 | 如果这个问题存在，这个故事还成立吗？（主角为何复仇、世界为何如此、结局为何可能） |
| P1 | 明确的人物/时间/身份/规则/关键事件事实 | 两条陈述能否同时为真？不能 → P1 |
| P2 | 动机、信息来源、转折、关键事件的可信支撑 | 读者会不会问"他凭什么"且文本无答案？会 → P2 |
| P3 | 衔接、铺垫、解释、节奏 | 读者会不会短暂困惑但仍能继续？会 → P3 |
| P4 | 表达与体验 | 会不会略感不解但不影响理解？会 → P4 |

### 1.1 升降级规则

**升级条件（满足任一，升一级）：**
- 该问题位于主线关键转折点。
- 该问题影响三个以上后续章节。
- 该问题是同类问题的第一处（源头问题，后续多为派生）。
- 该问题使核心人物的关键选择失去依据。

**降级条件（满足任一，降一级）：**
- 该问题只影响一个次要场景，且不影响后续。
- 存在文本内可自洽的解释（读者可自行补全，且补全方式唯一合理）。
- 该问题属于风格选择而非事实冲突。

### 1.2 等级分布健康度自查

一次完整审校的正常分布大致为：

- P0：0–2 条（超过 3 条极可能是定级通胀或基准建错）
- P1：3–10 条
- P2：10–25 条
- P3/P4：若干

若 P0 占比超过 10%，必须逐条复核：是不是把"我不喜欢的写法"当成了"故事不成立"。

## 2. 十二类"不是错误"的情形（误判防护）

遇到以下情形，**先假设它是作者有意为之**，再寻找反证。

### 2.1 有意设置的悬念
未解释的信息，若后文有回收 → 合法。检查点：是否有回收计划或已回收迹象。

### 2.2 尚未到回收时机的伏笔
状态为 PLANTED/REINFORCED 但故事未结束 → 不得记为遗漏。

### 2.3 人物有意隐瞒
角色不说真话不构成矛盾。检查点：文本是否给了"他在隐瞒"的信号（停顿、转移话题、内心回避）。

### 2.4 有铺垫的性格转变
改变必有原因。有触发事件 → 合法，哪怕变化很大。

### 2.5 有原因的行为反常
反常是塑造人物的手段。检查点：是否有原因（哪怕是后文才揭示的原因）。

### 2.6 非线性叙事
时序跳跃本身不是错误。检查点：真实时序是否自洽。

### 2.7 不可靠叙述者
叙述者说谎不是文本说谎。检查点：是否有可识别的信号（前后矛盾被文本自身指出、他人视角的差异）。

### 2.8 世界观允许的特殊现象
若设定明确允许（预言、复活、时间循环），则相关"矛盾"可能是有意设计。检查点：该现象是否有规则、有代价。

### 2.9 留白与省略
作者省略过程是常见手法。检查点：省略的部分是否"无信息量"（不承载体力、风险、情绪、因果）。无信息量的省略 → 合法。

### 2.10 类型惯例
某些类型有默认约定（武侠的轻功、悬疑的巧合、言情的一见钟情）。检查点：是否在类型契约范围内。但**类型惯例不能豁免核心逻辑**（悬疑的凶手不能是无铺垫的陌生人）。

### 2.11 视角限制导致的读者困惑
限知视角下读者不知道某些事是设计。检查点：困惑是否在后文被解决。

### 2.12 版本差异
用户提供的可能不是最新版。检查点：先确认版本，再判冲突。**永远先问版本，再定 P1。**

## 3. 判错前的六道闸门

对每个疑似问题，依次过闸，任一闸通过即撤案或降级：

1. **版本闸**：这是最新版吗？旧版问题不算。
2. **范围闸**：我审的范围内确实没有解释吗？还是解释在范围外的章节？
3. **基准闸**：我的冲突基准本身可靠吗？证据等级是什么？
4. **意图闸**：这可能是悬念/留白/不可靠叙述/类型惯例吗？
5. **读者闸**：目标读者真的会困惑吗？还是会自然补全？
6. **影响闸**：这个问题真的破坏了什么？还是只是我不喜欢？

## 4. 常见误判案例

| 误判 | 为什么错 | 正确处理 |
|---|---|---|
| "主角第 5 章和第 20 章对同一件事态度不同，矛盾" | 中间有 15 章的经历，态度改变是成长 | 查中间是否有触发事件；有则合法 |
| "他说不知道凶手的名字，但第 3 章听过，矛盾" | 可能听过但没记住 / 有意隐瞒 | 查第3章是否有"他记住了"的表述 |
| "这段没有任何解释，是逻辑漏洞" | 可能是悬念 | 查后文是否回收；未完结作品不得判遗漏 |
| "反派为什么不直接杀掉主角，不合理" | 反派动机可能不是杀（玩弄、利用、承诺） | 查反派目标设定；有目标即合法，但需文本支撑 |
| "两个角色同名，是错误" | 可能是有意的重名设计（对照、宿命） | 查是否有意使用（并置出现、被角色自己指出） |
| "这里跳过了三个月，衔接断裂" | 无信息量的时间跳跃是合法省略 | 查这三个月是否有事件影响后续；无则合法 |
| "道具颜色前后不一样" | 可能是不同道具 / 有意替换 | 查是否为同一物件 ID |

## 5. 潜在风险的表述方式

对证据不足但值得提醒的疑点，**不得写成确定错误**，使用以下表述：

- "此处存在潜在风险：……（依据不足，建议作者确认是否有意为之）"
- "若后文不回收此处信息，可能形成认知断层。"
- "当前资料未显示该设定，无法判断是否冲突，建议补充。"

并在问题字段中标注：
- 问题状态：待确认
- 证据等级：INFERRED 或 PENDING
- 等级：通常 P3/P4，或写"待定（依赖作者确认）"

## 6. 定级自检清单

提交报告前，逐条自问：

- [ ] 这条的冲突基准写出来了吗？来源和证据等级是什么？
- [ ] 我是否已经排除第 2 节的十二类情形？
- [ ] 如果作者说"这是我故意的"，我有没有准备好转问（那文本是否给了读者信号）？
- [ ] 这个等级，换一个审校者会同意吗？会不会偏高？
- [ ] 修复方案是否真的"最小"？会不会引出更大的问题？
- [ ] 我是否在报告里写清了"未覆盖范围"？
