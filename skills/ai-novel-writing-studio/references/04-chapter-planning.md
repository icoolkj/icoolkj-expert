# 04 章节规划

## 1. 章的功能类型

每章先定功能，再定内容。功能混乱的章，写出来一定平。

| 类型 | 作用 | 强度 | 占比建议 |
|---|---|---|---|
| 推进章 | 目标前进一格 | 3 | 40% |
| 转折章 | 目标失效／更换 | 4–5 | 15% |
| 揭示章 | 信息揭露，认知改变 | 4 | 15% |
| 关系章 | 人物关系变化 | 2–3 | 10% |
| 喘息章 | 消化、铺垫、日常 | 2 | 10% |
| 爆发章 | 冲突总摊牌 | 5 | 10% |

**连续三章同类型 = 节奏事故**。写完三章回头看一眼类型标签。

## 2. Chapter Brief 模板

```
CH-0012｜第 12 章　夜渡
位置：第二卷 · 第 4 章（卷内 12/48）

核心目标：苏瑾必须在天亮前把匣子送过河。
开场状态：她右臂负伤，只有半刻钟；陆沉失联。
出场人物：苏瑾（伤，急）、船夫（贪，怕）、巡夜队（循规）
场景：LOC-014 老渡口 / 子时 / 雨
核心事件：渡口被封锁 → 换船 → 船夫索价 → 交易 → 河心遇灯
主要冲突：她要过去，规矩不许她过去
情绪曲线：急 → 疑 → 险 → 静（假安全）→ 惊
关键信息：巡夜队受人指使，不是例行
本章转折：船夫认得匣子
结尾承接：河心的灯灭了
与后续关系：引出 FORE-011，为第 15 章揭示铺路
本章变化：她的行踪暴露给第三方
```

写不出"本章变化"这一行，说明这章可以删。

## 3. 章内四段结构

| 段 | 字数占比 | 任务 | 失败表现 |
|---|---|---|---|
| 钩子 | 10% | 抛一个待答问题 | 从起床、赶路、风景开始 |
| 发展 | 40% | 目标推进，阻力出现 | 目标模糊，人物在聊天 |
| 转折 | 25% | 原方案失效 | 靠巧合解决 |
| 收束+钩尾 | 25% | 结果落地 + 新的不平整 | 抒情收尾，或用总结句 |

**直接进场**：删掉抵达过程。读者不需要看人物走路、上楼、敲门。

## 4. 场景切分

一章通常 2–4 场。每场写清：

- **谁要什么**（本场目标，必须具体到可失败）
- **谁挡着**（阻力，可以是人、规则、时间、自己）
- **结果**（是／否／是但付代价——最好用第三种）
- **带出什么**（信息、物件、关系变化）

一场戏若没有"争夺"，就不是戏，是交代。交代可压缩成一句叙述。

## 5. 章末钩子类型库

| 类型 | 做法 | 例 |
|---|---|---|
| 新信息 | 抛出一个改变认知的事实 | 信封里不是钱，是一张她的照片 |
| 打断 | 在动作中途切断 | 他抬手，门开了 |
| 威胁临近 | 危险已可见 | 楼下的车停了很久没熄火 |
| 决定 | 主角做出不可撤回的选择 | 他把火折子扔进了油库 |
| 反转 | 之前的理解被推翻 | 死的人不是他 |
| 身份揭露 | 某人不是他自称的人 | 她开口，用的是家乡话 |
| 倒计时 | 期限被明确 | 三天。他心里默数，今天算第一天 |
| 悬念物件 | 出现不该出现的东西 | 桌上多了一只他用过的杯子 |
| 关系裂缝 | 一句话改变关系 | "你早就知道，对吗" |
| 场景切换 | 切到另一条线的最坏时刻 | ——北境，雪停了 |

纪律：**连续两章不用同一类型**。悬念套路化是长篇最明显的疲态。

## 6. 多章节奏编排

以 5 章为一组做编排，避免同质：

```
CH1 推进（低强度，埋信息）
CH2 关系（中，人物互动，读者喜欢人物）
CH3 转折（高，目标失效）
CH4 喘息（低，消化 + 铺垫）
CH5 爆发（最高，卷内小高潮）
```

循环时**换场景、换对手、换失败方式**。同样结构重复三次，读者会预判。

## 7. 章纲的三档精度

| 精度 | 内容 | 用在 |
|---|---|---|
| 粗纲 | 每章一行：谁 + 干什么 + 结果 | 全书或整卷预排 |
| 中纲 | 每章 3–5 行：目标、阻力、转折、钩子 | 未来 5–10 章 |
| 细纲 | 完整 Brief + 场景切分 | 正在写的这一章 |

**只细排未来 3 章**。排太远，人物一动就要全改。

## 8. 章纲自检清单

- [ ] 每章都有一句"本章变化"，且变化不可逆？
- [ ] 连续三章不是同一功能类型？
- [ ] 每章都有具体的时间地点？
- [ ] 章末钩子类型没有连续重复？
- [ ] 本章用到的信息，前文已经给过？
- [ ] 本章揭示的信息，是否过早（抢了后文的戏）？
- [ ] 有没有两章其实是同一件事，可以合并？
- [ ] 有没有章可以整章删掉而不影响主线？有则删。
- [ ] 每 5 章是否至少一次让读者情绪波动的场面？
- [ ] 主角是否每章都在"做事"，而不是"被事情推着走"？
