# 06｜章节衔接规划与正文续写

## 衔接方式选择

根据前文结尾状态和剧情需要，选择合适的衔接方式：

| 衔接方式 | 适用场景 | 要点 |
|---|---|---|
| 无缝衔接 | 上一章结尾有未完成的动作/对话/危机 | 从结尾场景直接推进，保持节奏连续，允许小幅时间推移（几秒到几分钟） |
| 时间推进 | 需要跳过平淡期、恢复期、旅程期 | 开头用时间标记（如「三日后」），必要时一句带过中间发生的事 |
| 视角切换 | 多视角叙事，切到另一条线 | 开头快速锚定新视角的时间和地点，避免读者迷失 |
| 平行叙事 | 两条线同时推进 | 注意两线的时间对齐 |
| 情节承接 | 上一章留下悬念/任务/邀请 | 本章直接回应悬念，不回避已抛出的问题 |

不能机械地从上一章最后一句开始续写——先分析上一章结尾的叙事势能，再选择最自然的进入点。

## 衔接规划步骤

1. **读上一章结尾**：确认结尾场景、在场人物、最后动作、最后对话、留下的悬念。
2. **确认续写要求**：目标篇幅、剧情方向、出场人物、必须/禁止出现的内容；用户未指定的，遵循现有小说基准。
3. **确定本章目标**：本章要推进什么剧情、解决/加深什么冲突、埋下/回收什么伏笔、读者读完应获得什么感受。
4. **确定进入点和节奏**：选择衔接方式，规划本章的场景序列（起→承→转→合）。
5. **核对约束**：人物状态（04）、认知边界（09）、时间线（05）、世界观规则（07）。

## 正文续写十条准则

1. 保持叙事人称和叙事视角，与全书一致。
2. 保持人物语言特点，对话符合各人物的语言档案。
3. 尊重人物当前状态：伤势、情绪、装备、资源从上次状态出发。
4. 尊重人物认知边界：人物只使用其知道的信息做判断和行动。
5. 尊重已发生事件：不与前文事实矛盾，引用前文时与原文一致。
6. 不重复大量前文：衔接处以推进为主，回顾性内容控制在一两句。
7. 不无依据跳跃剧情：情节推进有因果链，跳过的时间有交代。
8. 不擅自揭露秘密：未到时机的伏笔不提前揭开（见 08、09）。
9. 保持自然的文学表达：与 L1 记忆中的文风基准一致，避免机械感。
10. 新设定（新人物、新地名、新能力）出现时随手登记，供记忆档案收录。

## 续写自查清单（写完正文后逐项核对）

- [ ] 衔接自然，与前文结尾无断裂感
- [ ] 叙事人称、视角与全书一致
- [ ] 出场人物状态与档案一致
- [ ] 无人物认知越界
- [ ] 时间推进有交代，行程/恢复合理
- [ ] 地点、物品与前文一致
- [ ] 未与已发生事件矛盾
- [ ] 未提前揭露未到时机的秘密
- [ ] 文风与基准一致
- [ ] 新增设定已登记

## 输出要求

按 SKILL.md 第 12 节续写模式交付格式输出；用户只要求正文时可简化前置说明，但事实校验不可省略。
