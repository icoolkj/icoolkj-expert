# 03 人物行为动机、情绪与成长审校（M02 / M10）

## 1. 动机三元校验

任何一次重要行动，都要能通过三问：

1. **想要什么**（目标）：此刻他最想达成的事是什么？是否明确？
2. **为什么现在**（触发）：为什么是这一刻动手，不是上一刻或下一刻？
3. **为什么用这种方式**（手段）：为什么选择这个手段，而不是更简单/更安全的方式？

三问都答得出 → 动机成立。答不出任一 → 记录问题。

**关键区分**：人物自己不需要说清理由，但文本必须提供读者可推断的依据（可为行动、细节、他人评价、前史）。作者脑中的理由不算依据。

---

## 2. 五类动机缺陷

### 2.1 无动机行动
行动发生，但缺少可辨识的目标或理由。

- 判据：删掉这次行动，故事是否照常推进？若是，说明该行动是作者为了推进情节而设。
- 定级：影响关键转折 → P1；局部行为 → P2。

### 2.2 动机与性格不符
行动与已建立的人格特质矛盾，且无过渡。

- 判据：列出该人物此前三次同类情境的选择。若此次选择与三次全部相反且无铺垫，即冲突。
- 注意：**性格可以改变，但改变需要成本与事件**。给出触发事件即为合法转变，不判错。

### 2.3 动机与能力不符
人物做出超出其能力的事（知识、技能、体能、权限、资源）。

- 判据：该能力是否在文本中被建立过？由谁建立、何时建立？
- 若无建立 → 转 `04-worldbuilding-rules.md`（能力越界）或 `06-knowledge-boundary.md`（信息越界）。

### 2.4 动机与结果不符
人物想要 X，行动却导向 Y，且文本未解释。

- 判据：行动的实际后果是否是他能预见的？若能预见却仍为之，需要给出代价评估（他愿意付出这个代价吗）。
- 常见：为了救人却引发更大伤亡，文本不作任何心理反应 → 疑为动机缺失。

### 2.5 动机雷同（扁平化）
所有人物在同一情境下做出同一种选择。

- 判据：把 A 的台词换给 B，是否需要改写？若几乎不用改，说明人物没有独立动机。
- 定级：通常 P3，影响作品辨识度。

## 3. 情绪变化的合法性（M10）

情绪不是独立变量，它是"事件 → 评价 → 情绪"的结果。审校看的是**评价环节是否成立**。

### 3.1 情绪曲线四问
1. 情绪变化的触发事件是什么？（必须能指出具体段落）
2. 该事件对该人物的意义，是否与他的目标/创伤/关系史一致？
3. 情绪强度是否与事件量级匹配（不夸大、不缩水）？
4. 情绪是否有出口（行动、语言、身体反应），还是只被叙述者宣告？

### 3.2 高发问题

| 问题 | 表现 | 判据 |
|---|---|---|
| 情绪断层 | 上一场悲痛欲绝，下一场谈笑自如 | 两场之间是否有时间跨度或过渡段落 |
| 情绪宣告 | "他心中充满仇恨"但无任何行为体现 | 删掉这句宣告，读者是否还能感知情绪 |
| 情绪通胀 | 小事引发极端反应 | 该人物此前对小事的反应基线是什么 |
| 情绪失语 | 重大打击后毫无反应 | 是否存在合理压抑（并给了压抑的信号） |

### 3.3 合法的"反常情绪"
压抑、麻木、解离、强撑、反向表达（用笑掩饰）都是真实反应，**只要有信号**。信号包括：身体细节、行为偏差、他人视角的观察。有信号即不判错。

## 4. 关系变化审校

关系变化必须有**至少一个可指认的节点**，且该节点必须改变双方的"信息"或"代价"结构。

### 4.1 关系状态机
建议用状态 + 转移的方式记录：

```
陌生 → 戒备 → 试探 → 有限信任 → 信任 → 托付
                ↘ 失望 → 敌意 ↗
```

每次转移记录：转移前状态、触发事件、转移后状态、位置。

### 4.2 三类典型断裂
- **无冲突和解**：双方矛盾未解决即和解 → 需要至少一方让步或外部压力。
- **无过程决裂**：多年关系因一句话决裂 → 除非该句话触及核心创伤，否则需前置张力。
- **关系跳跃**：从戒备直接到托付，缺中间两级 → P2，除非有重大事件作为压缩理由。

### 4.3 检查关系是否"只增不减"
健康的关系线应有损耗。若全程只升温不降温，需检查是否缺少冲突设计（P3 叙事问题，非逻辑错误）。

## 5. 人物成长的支撑条件

成长 ≠ 变强。成长是"面对同类情境时，选择发生改变"。审校四条件：

1. **有旧我**：此前明确展示过旧的行为模式。
2. **有代价**：旧模式曾让他付出代价（失败、失去、羞耻）。
3. **有事件**：发生了一件迫使他重新评估的事。
4. **有验证**：后文出现同类情境，他做出了不同选择。

四条缺一，成长即为"宣称式成长"，记 P2；若成长是主题核心支撑，升 P1。

**反向检查**：主角能力提升但性格不变，属于"升级"而非"成长"，不应按成长线标准判错，但需检查能力提升是否有训练/代价支撑（转 M03）。

## 6. 人物动机审校工作表

对每个主要人物填一次（按阶段）：

| 项 | 阶段一 | 阶段二 | 阶段三 |
|---|---|---|---|
| 目标 | | | |
| 目标来源（为何想要） | | | |
| 阻碍 | | | |
| 可接受代价 | | | |
| 不可跨越底线 | | | |
| 本阶段关键行动 | | | |
| 行动是否服务于目标 | | | |
| 目标变化及触发点 | | | |

**底线栏尤其重要**：人物跨越底线是强情节，但必须在此前的文本中建立"这是他的底线"。未建立即跨越 → P1/P2。

## 7. 输出模板示例

```
### 问题编号：CHAR-004
- 问题标题：林昭在得知母亲死讯后立刻投入谈判，缺少情绪过渡
- 问题等级：P2
- 问题状态：待确认
- 所属审校模块：M10 情绪与人物成长
- 发生位置：第 21 章「旧信」结尾 → 第 22 章「议价」开场
- 问题描述：第21章末林昭读到母亲死讯，情绪崩解（"他把信纸捏成了一团"）；
  第22章开场即"林昭语气平稳地报出价格"，中间无时间跨度标记、无过渡段落。
- 原文证据：第21章末：「他把信纸捏成了一团，指节泛白。」（TEXTUAL）
  第22章首：「林昭语气平稳地报出价格。」（TEXTUAL）
- 冲突基准：F-CHAR-046 林昭的情绪反应模式为"外显型"，此前三次重大打击均有
  可见的行为失控（TEXTUAL，第5、12、17章）
- 问题原因：疑为情绪断层，可能缺少一夜时间跨度的交代；也可能作者有意表现
  "强撑"，但缺少强撑的信号（身体细节、他人观察）。
- 影响范围：第22章全章的人物可信度；第22章谈判结果的说服力。
- 最小修复方案：在第22章开场补一句时间与状态提示（如"一夜未眠，眼下发青"），
  并在报价后加一个身体细节（手指在桌下发抖），不改变任何情节。
- 替代方案：将谈判延后一场，插入一段独处场景，代价是节奏变慢。
- 修复后复审要求：确认第22章有可见的"强撑"信号；确认第21–22章之间有明确
  时间跨度；确认后续章节未再出现"他还没从丧母中恢复"式的反向表述。
```
