# 16｜质量验收与风险控制

## 1. 验收四个维度

| 维度 | 问题 | 判定方式 |
|------|------|----------|
| 完整性 | 该有的资产是否都有 | 对照资产清单逐项勾选 |
| 一致性 | 跨图、跨视角是否同一身份 | 并排比对 + 平面核对 |
| 质量 | 单张是否达到可用标准 | 按 2. 的评分表 |
| 可用性 | 下游能否直接使用 | 让分镜/生成/后期各抽一个镜头试跑 |

## 2. 单张质量评分（每项 0–2 分，满分 20）

| # | 项目 | 0 分 | 1 分 | 2 分 |
|---|------|------|------|------|
| 1 | 身份准确 | 认不出 | 大致像 | 三锁定项全部成立 |
| 2 | 结构正确 | 明显错误 | 轻微错误 | 解剖/透视正确 |
| 3 | 手部与肢体 | 崩坏 | 可修 | 正确 |
| 4 | 服装还原 | 不符 | 部分符合 | 版型材质颜色全对 |
| 5 | 材质质感 | 塑料感 | 一般 | 材质可辨 |
| 6 | 光影合理 | 矛盾 | 基本合理 | 光位明确、阴影正确 |
| 7 | 色彩符合规范 | 偏离 | 接近 | 在色卡范围内 |
| 8 | 分辨率与清晰度 | 不可用 | 勉强 | 满足用途 |
| 9 | 无穿帮 | 有文字/水印/多肢 | 轻微 | 干净 |
| 10 | 可复用性 | 只能看 | 可作参考 | 可作母版 |

判定：18–20 可用作母版；14–17 可用作参考；10–13 需局部重绘；<10 重做。

## 3. 角色验收清单

- [ ] 三个识别锁定项在正面、45°、侧面、背面均成立。
- [ ] 纯黑剪影可辨。
- [ ] 与项目内其他角色在剪影与色彩上可区分。
- [ ] 表情序列面部身份一致。
- [ ] 换装后仍可识别。
- [ ] 不同年龄段共享不可变特征。
- [ ] 伤势位置左右正确、演变合理。
- [ ] 手部结构正确。
- [ ] 服装材质、颜色、版型与设定表一致。
- [ ] 侧脸 / 背面有明确设定（非生成时臆造）。

## 4. 场景验收清单

- [ ] 有平面描述（尺寸、门窗位置、家具定位）。
- [ ] 六个视角可反推同一平面。
- [ ] 材质颜色与材质表一致（可取色比对）。
- [ ] 主光方向在各视角一致。
- [ ] 人物与空间的比例正确。
- [ ] 状态变体只改光与氛围，不改结构。
- [ ] 关键区域特写与全景中的物件一致。
- [ ] 镜头机位在空间内物理可行。
- [ ] 入口/出口清晰，动线合理。

## 5. 道具验收清单

- [ ] 关键识别面清晰（刻字、磨损、标签）。
- [ ] 尺寸与手部比例正确。
- [ ] 材质反光与场景光源匹配。
- [ ] 状态变体差异可辨且符合剧情。
- [ ] 血迹/污损位置与角色伤势一致。
- [ ] 特写与全景外观一致。

## 6. 交付前总检查

- [ ] 资产编号唯一，`asset_registry.py validate` 通过。
- [ ] 所有 Approved 资产有确认记录。
- [ ] 所有 Draft / Review 资产在清单中显式标出。
- [ ] 事实分层标注完整，无把建议写成设定的情况。
- [ ] Prompt 库与资产编号一一对应。
- [ ] 一致性报告已出具，问题项有处理结论。
- [ ] 交接说明已写清硬约束与已知限制。
- [ ] 版本变更记录完整。

## 7. 风险控制

| 风险 | 触发信号 | 预防措施 |
|------|----------|----------|
| 风格漂移 | 不同批次拼在一起像两部片 | 母版锁定 + 批次抽检 |
| 资产爆炸 | 角色 40 个、每个都做全套 | 严格分级，P2 只做最低配置 |
| 编号混乱 | 出现两个 CHAR-003 | 只用脚本分配编号 |
| 需求反复 | 用户不断改基础设定 | 基础形象先签字确认再派生 |
| 技术不可达 | 承诺了模型做不到的一致性 | 提前说明能力边界，给替代方案 |
| 交付不可用 | 下游打不开、命名混乱 | 按交接包结构组织文件 |
| 版权与合规 | 参考图直接商用 | 参考图仅作风格参考，不直接复制；提醒用户确认素材授权 |

## 8. 向用户汇报的固定结构

1. **做了什么**：资产清单与数量。
2. **关键设定**：3–5 条最重要的视觉决策。
3. **待确认**：明确列出需要用户拍板的项。
4. **已知限制**：生成或一致性上的现实约束。
5. **下一步建议**：按优先级给出后续动作。
